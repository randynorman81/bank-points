        HTML & CSS cheat sheet
        

        

          
1. OPENING, CLOSING & VOID TAGS

          
Matched pairs like <h1>...</h1> and <p>...</p> must match names and nest properly. Void elements like <img>, <input>, and <br> never have a closing tag (no </img> or </input>).

        

        

          
2. LINKS, IMAGES & ACCESSIBILITY

          
Links use <a href="..."> (watch out for herf!). Images use <img src="..." alt="..."> (watch for scr or missing alt). Labels pair with inputs via for="id".

        

        

          
3. LISTS, TABLES, SEMANTICS & CSS

          
Only <li> belongs directly inside <ul>/<ol>. Table cells (<th>/<td>) belong inside <tr>. CSS uses property: value; with American spelling (color) and no space before units (16px).
