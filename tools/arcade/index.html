// EARNING POINTS

  • Points are earned per stage or level cleared — not just per boss defeated
  • Points scale upward the deeper into a game you get
  • All current work must be turned in before playing during class time
  • Teacher verifies level completion before points are logged — no self-reporting
  • You can earn points on any given game only once per school year
  • Points count as extra credit added to your formative grade category

// SAVING YOUR PROGRESS

  • If you can save your progress, you can continue across multiple class sessions
  • Completing a full game unlocks Milestone Bonuses (see the Bonuses tab)
  • Without save states, you earn points only for what you clear in a single session
  • Ask your teacher about how save states work in class

// DIFFICULTY TIERS

  • Easy — Good for beginners. Short games, forgiving mechanics
  • Medium — Some challenge. You'll need a few attempts
  • Hard — Punishing. One hit can end your run
  • Brutal — Historically notorious. You have been warned

// INTEGRITY RULES

  • You must be the one playing — no watching someone else play for you
  • Using cheat codes or skipping content means no points awarded
  • Friendly competition is encouraged; trash talk is monitored
  • Teacher's point decisions are final — no appeals to the Konami Code
