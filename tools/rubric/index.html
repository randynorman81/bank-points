✅ Rubric Grader

Step 1: put your rubric in the standard template. Step 2: upload your graded copies. Step 3: get the class data (averages, strengths, weak spots and who needs support). Everything stays in your browser.

1Convert your rubric to the template

Upload your rubric (PDF, photo, Word file or Google Doc) and I rebuild it in one standard PDF template: criteria down the side, each level with its points across the top, a Score column and a Total row. When every rubric uses the same layout, every graded copy is read the same way. Print the template, mark it by hand (circle, highlight or X the box for each row), and upload the marked copies in step 2.

2Upload graded rubrics

One file per student, marked on the template from step 1 (circle, highlight, check or X in the box for each row). Name each file with the student's name. Colored pen and highlighter are read best.
