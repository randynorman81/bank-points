=== a45 | Intro to Digital Information | digital-info-intro
learn: how many patterns n bits make, the biggest number n bits can hold, how many bits a set of things needs, bytes and kilobytes, sampling, and overflow and round-off errors
ap: A bit is a 0 or 1 and a byte is 8 bits. n bits make 2 to the n patterns. A computer stores analog data by sampling it, so a little is always lost. Overflow means a number is too big for its bits, and round-off means a number cannot be stored exactly.

--- Count the patterns
notes: How Many Patterns?
say: Every extra bit doubles the number of patterns. In Python, `2 ** bits` is 2 to the power of `bits`, so it counts the different patterns that many bits can make.
tip: Why does each bit double the patterns?
tipbody:
p One bit can be 0 or 1, so it makes 2 patterns. Add a second bit and each of those 2 can be followed by a 0 or a 1, so you get 4. Every new bit doubles the count.
rows 1 bit | 2 patterns | 0, 1
rows 2 bits | 4 patterns | 00, 01, 10, 11
rows 3 bits | 8 patterns | 000 up to 111
good The shortcut is `2 ** bits`: 2 to the power of the number of bits.
.

--- From analog to digital: sampling
notes: Analog vs Digital
say: The real world is **analog**: it changes smoothly. A computer can only keep numbers, so it **samples**: it measures the value every so often and stores the measurements. Measuring less often means less data, but more is lost between the samples.

tipbody:

--- Overflow and round-off errors
notes: Two Errors to Know
say: A fixed number of bits can only hold so much. In 8 bits the biggest number is 255, so 255 + 1 has no room and **wraps around** to 0. That is an **overflow error**. Some decimals can never be stored exactly, so the computer keeps a very close number. That is a **round-off error**.
tip: Overflow or round-off?
tipbody:
rows Overflow | the number is too big for the bits | 255 + 1 in 8 bits wraps to 0
rows Round-off | the number cannot be written exactly | 0.1 + 0.2 is 0.30000000000000004
good Do not mix them up. Overflow means **too large**. Round-off means **slightly off**.
.

--- Encrypt a whole word

say: A loop can shift every letter of a word. For each letter it takes the number, adds the key, and turns the new number back into a letter. HELLO with a key of 3 becomes KHOOR. Anyone who grabs KHOOR on the way sees only nonsense.

--- The encrypt function
notes: The Caesar Cipher
say: Put it all in a function. It loops over the text and shifts only the **letters**, leaving spaces and punctuation alone. It remembers whether a letter was capital or lowercase by starting from `ord("A")` or `ord("a")`.
tip: What is this function doing?
tipbody:
steps `ch.isalpha()` is True for letters, so spaces and punctuation skip the shift. ;; `ch.isupper()` picks the right starting letter, A or a. ;; `(ord(ch) - base + shift) % 26 + base` shifts and wraps. ;; Everything else is copied unchanged.
good `encrypt("xyz", 3)` is `abc`, because it wraps around.
.
code:
def encrypt(text, shift):
    result = ""
    for ch in text:
        if ch.isalpha():
            if ch.isupper():
                base = ord("A")
            else:
                base = ord("a")
            result = result + chr((ord(ch) - base + shift) % 26 + base)
        else:
            result = result + ch
    return result
print(encrypt("HELLO", 3))
print(encrypt("xyz", 3))

--- Public key encryption
notes: Public Key Encryption
say: **Public key encryption** solves the sharing problem with **two different keys** that belong together. Anyone can use the **public key** to encrypt a message to its owner, but only the owner's **private key** can decrypt it. This program is only a **toy model** of the idea, because with Caesar the private key is easy to work out from the public one.
