Weekly Student Report

Teacher page. Builds a one-page summary of each student's week (what they opened, how far they got, time spent, bank points) that you can print, save as a PDF, or copy into an email to a parent or coach.

Data comes from the HTML editor, Python editor, Arduino editor and the bank. A "week" runs Monday 12:00 am to the next Monday.

Class overview
How the "work ethic" label is decided

It is only a suggestion; change it on any student's report before you send it. It uses the week's activity: days with work saved, minutes active, and assignments submitted. Excellent: 4+ days and (a submission or 60+ minutes). Good: 3+ days, or a submission with 20+ minutes. Inconsistent: 2 days or some work. Needs improvement: 1 day with little work. Not working: no work saved all week. HTML assignments only record their latest save, so a student who worked on HTML on several days may show fewer days than they really worked. Python work is tracked minute by minute, so it is more exact. A student who was absent will look low: add a note.

These reports contain student education records. Send them only to the student's parents/guardians or to coaches and staff with a school need to know.
