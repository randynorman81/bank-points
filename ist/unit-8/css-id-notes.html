CSS by ID

A class is a team jersey, an id is a student ID number: it points at exactly one element.

#id @CHIP@middot; one element
01

Your Student ID Is One of a Kind

Lots of students share a grade, a homeroom, or a team. Those are like classes. But your student ID number belongs to exactly one person. If the office ever handed the same number to two students, lunch accounts and grades would get mixed up. An id in CSS works the same way: it points at one element and nobody else.

Try it. Click a card to hand it the id. The id can only live on one card at a time.

A rule for one id that sets a dark background and padding
One id, one element.Every id name may be used once per page. If you need to style several elements the same way, that is a job for a class.
02

Two Halves: the Attribute and the Rule

Just like classes, an id needs a matching pair: the name on the element in the HTML, and a rule in the CSS that uses the same name. The only difference is the symbol.

In the HTML: the id attribute

<h2 id="banner"> Welcome </h2>

The name goes in quotes, with no symbol in front.

In the CSS: start with a hash

#banner { padding: 12px; }

A # comes before the name. Classes use a dot, ids use a hash.

Quick check. Pick the symbol that goes before each name in a CSS file:

class="menu"
id="logo"

04

Common Mistakes

Wrong: the same id twice

<p id="note">One</p> <p id="note">Two</p>

Browsers may only style the first one, and the page is technically broken.

Right: different ids, or use a class

<p id="noteA">One</p> <p id="noteB">Two</p>

Each element gets its own name. Same look on both? Make it a class.

Wrong: a dot where the hash goes

.banner { ... } /* the HTML uses id="banner" */

A dot looks for a class, so nothing matches and nothing changes.

Right: hash for an id

#banner { ... }

The symbol must match the kind of name.
