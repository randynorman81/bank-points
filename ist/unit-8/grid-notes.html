CSS Grid Basics

Arrange items into rows and columns at the same time, like a muffin tin for your layout.

display: grid
01

A Spreadsheet for Your Layout

Flexbox lines things up in one direction, like books on a shelf. A grid is more like a muffin tin or a spreadsheet: rows and columns at once. You decide how many columns the tin has, and the browser drops each item into the next open cup. Perfect for photo galleries and card layouts.

Container

The tin

The div that gets display: grid. All the layout rules go here.

Items

The muffins

The children. You never set their width, the columns decide it.

Gap

The tin walls

Even space between every row and column at once.

What Does fr Mean?

The fr unit stands for "fraction of the leftover space." Think of splitting a pizza after you set aside a fixed slice for yourself. Every fr gets a share of what remains, so the grid always fills its container no matter how wide the screen is.

Pick a column recipe and see how the space gets divided.

Equal columns: repeat the same number of fr.Three columns of equal width is three fr values, all the same. A fixed size next to an fr makes a sidebar that never grows while the rest flexes.

05

Common Mistakes

Wrong: widths on every item

.gallery img { width: 33%; }

You are fighting the grid. Let the columns decide.

Right: columns on the container

.gallery { display: grid; grid-template-columns: 1fr 1fr 1fr; }

The container sets the column sizes.

Wrong: display grid but no columns

Without grid-template-columns you get one wide column, so everything just stacks like normal.

Right: always add the columns

display: grid turns it on. grid-template-columns makes it a grid you can see.
