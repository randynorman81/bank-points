LESSON5.1

External CSS and Classes

One file in charge of the whole site, and name tags for the elements that need their own look.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson
GOALMove your styles into one file called style.css, plug it into the page with a link tag, and use classes to style some elements but not others.
WORDS TO KNOW
external CSS styles kept in their own file (like style.css) and shared by the whole site
link tag a head tag that plugs the CSS file into the page
rule a selector plus the properties inside curly braces
selector the part of a rule that says which elements it is for
class a name you make up; every element wearing it gets the matching rule
ON THE SITENotes: external-css-notes  ·  Walkthrough: Snack Shack  ·  Assignment: Spotify Playlists  ·  Quiz game: 5.1

LEARNOne remote for every room

Until now every style lived inside a tag, in a style attribute. That works for one paragraph, but imagine a school where every classroom has its own light switch and the principal wants the lights dimmer. Someone has to walk into every room.

External CSS is one master panel in the office. Your styles live in one separate file, and every page plugs into it. A 40-page website with inline styles needs 160 edits to change one color. With an external file it needs one.

Style rules move out of the page into a file called style.css. One rule in that file can style every page that links it.

LEARNThe link tag is the plug

The CSS file does nothing on its own. The page has to be told where to find it, like plugging in a lamp. That plug is the link tag:

<link rel="stylesheet" href="style.css">

PartRule
whereinside the head, never in the body: the browser needs it before it draws the page
closingno closing tag: it stands alone, like img and br
relrel="stylesheet" tells the browser the file is a stylesheet
hrefthe exact file name. If the page says style.css and the file is styles.css, nothing is styled and no error shows

LEARNInside a CSS file: only rules

A CSS file holds only rules. It is not a web page, so no style tags and no quotes around values belong in it. A rule has three parts:

PartExample
selectorp (says which elements the rule is for)
curly braces{ } around the declarations
declarationcolor: navy; (a property, a colon, a value, a semicolon)

A rule for every p tag looks like this: p { color: navy; }. A tag rule is a school-wide announcement: every element of that tag hears it.

LEARNClasses: style some, not all

A tag rule styles everything of that tag. A class is a name tag: only the elements wearing it get the style, and you can give the same name tag to as many elements as you like.

A class needs two matching halves:

WhereHow it is written
in the HTML<p class="deal">: the name goes in the class attribute with no dot
in the CSS.deal { ... }: the rule starts with a dot before the name
Same name in both places. The dot belongs only to the CSS side. If you write class=".deal" in the HTML, nothing matches.

LEARNTag rule or class rule?

Use a tag rule for the basics that every element of a kind shares, like the color of all paragraphs. Use a class rule for a look only some elements should have, like one special deal paragraph. They work together: a paragraph wearing a class still gets the tag rule too, so the deal paragraph below is navy from the p rule and gold from the .deal rule.

EXAMPLEWorked Examples

index.html (the body it styles)
<p>Fresh popcorn.</p>
<p class="deal">Two for one today.</p>
<p>Open until nine.</p>
index.html (the body it styles)
<h1>Snack Shack</h1>
<p>Open until nine.</p>

What it looks likeWhat goes wrongHow to fix it

LESSON5.2

CSS by ID

Point at exactly one element: the student ID number of the web.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson
GOALPoint a rule at exactly one element with an id, and decide when to use a class and when to use an id.
WORDS TO KNOW
id a name for one single element; written with a hash in CSS
id attribute the part of the tag that holds the name, like id="banner"
unique used only once on a page
hash the # symbol that starts an id rule
ON THE SITENotes: css-id-notes  ·  Walkthrough: Pixel Arcade  ·  Assignment: Nintendo Game Cards  ·  Quiz game: 5.2

LEARNYour student ID is one of a kind

Lots of students share a grade, a homeroom or a team. Those are like classes. But your student ID number belongs to exactly one person. If the office gave the same number to two students, lunch accounts and grades would get mixed up.

An id in CSS works the same way: it points at one element and nobody else.

A class can go on many elements. An id goes on one.

LEARNTwo halves, one symbol different

Like a class, an id needs a matching pair: the name on the element in the HTML, and a rule in the CSS that uses the same name. Only the symbol changes.

WhereClassId
in the HTMLclass="menu"id="banner"
in the CSS.menu { } (a dot)#banner { } (a hash)

In the HTML the name goes in quotes with no symbol in front. In the CSS the rule starts with the hash.

LEARNClass or id? Decide in five seconds

ClassId
how many elementsas many as you likeexactly one
symbol in CSSdothash
real lifethe team jerseythe student ID number
use it fora look you will reuseone special element, like the page title

An element can wear both at the same time: <p class="row" id="record"> gets the class rule and the id rule.

LEARNThe rule you must not break

Every id name may be used once per page. Two paragraphs with id="note" make the page technically broken: browsers may style only the first one. If you need the same look on several elements, make it a class. If you need different looks, give each element its own id.

EXAMPLEWorked Examples

index.html (the body it styles)
<h1 id="title">Pixel Arcade</h1>
<p class="row">Play all day.</p>
<p class="row" id="record">Score: 9999</p>
index.html (the body it styles)
<p class="row">Play all day.</p>
<p class="row" id="record">Score: 9999</p>

WATCH OUTWatch Out: Common Mistakes

What it looks likeWhat goes wrongHow to fix it
#banner rule but class="banner" in the HTMLThe hash looks for an id, so nothing matches.Make the symbol match the kind of name: hash for id, dot for class.
.banner { } for id="banner"A dot looks for a class, so nothing changes.Use #banner { }.
id="#banner" in the HTMLThe hash is part of the name now, so the rule does not match.Write id="banner". The hash belongs only in the CSS.
The same id on two elementsThe page is technically broken and only one may be styled.Use different ids, or make it a class.
An id for a look you reuseYou end up writing one rule per element.Use a class for anything shared.

LESSON5.3

Selectors and Specificity

When two rules fight, the more specific one wins, and you choose how precisely to aim.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson
GOALPredict which rule wins when two rules fight, put more than one class on an element, and aim a selector at exactly the elements you mean.
WORDS TO KNOW
specificity the ranking that decides which rule wins when rules disagree
combined selector two selectors joined to aim more precisely, like p.warning
descendant selector two selectors with a space between: the second is inside the first
multiple classes several class names in one class attribute, separated by spaces
ON THE SITENotes: specificity-notes  ·  Walkthrough: Bakery Board  ·  Assignment: Netflix Show Guide  ·  Quiz game: 5.3

LEARNWhen two rules disagree

A teacher says "everyone wear a uniform." Your coach says "wear the team jersey today." You obey the more specific instruction. CSS settles arguments the same way: when two rules style the same thing, the more specific rule wins, no matter which one is written first.

StrengthKind of ruleSpeaks to
weakesttag rule pevery paragraph
strongerclass rule .namea group
stronger stillid rule #nameone element
strongestinline style written on the tagthat one tag
The winner is decided by who is more specific, not who is written last.

LEARNTwo classes on one element

Think of a locker with two stickers: one for your team and one for your grade. An element can wear more than one class too. List them in the same class attribute, separated by a space, and every class rule that matches applies.

WrittenResult
class="big red"right: both rules apply
class="big" class="red"wrong: the second attribute is ignored
class="big, red"wrong: no commas

LEARNCombining selectors

Sometimes one selector is too broad. "Every student" is too many people, but "every student on the soccer team" is exactly who the coach means. Selectors can be combined:

Written asMeans
p.warningonly paragraphs that also wear the class warning (no space)
ul liany li inside a ul (a space means inside)
.warninganything at all that wears the class warning

LEARNWhy inline styles are avoided

An inline style is a trump card: it beats class rules and id rules in your stylesheet. That sounds powerful, but it is a trap. If one element has an inline color, your CSS file can never change it again without hunting it down in the HTML. Real teams keep style rules in the stylesheet so one file stays in charge.

Rule of thumb: tag rules for the basics, classes for looks you reuse, ids for the one-of-a-kind element, and skip inline styles.

EXAMPLEWorked Examples

index.html (the body it styles)
<p>Fresh bread.</p>
<p class="warn">Nuts inside.</p>
<p class="warn" id="star">Star baker</p>
index.html (the body it styles)
<ul>
<li>Rye</li>
<li>Wheat</li>
</ul>
<ol>
<li>Mix</li>
</ol>
<p class="warn">Careful</p>
<p>Plain</p>

WATCH OUTWatch Out: Common Mistakes

What it looks likeWhat goes wrongHow to fix it
p { color: blue; } written last, expecting it to winA class or id rule on the same element still wins.Remember the order: tag, class, id, inline. Position in the file only breaks a tie between equal rules.
class="big" class="red"The second class attribute is ignored.Use one attribute: class="big red".
class="big, red"Commas become part of the names.Separate the names with a space.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson

pseudo-class a style that applies only during a temporary state, written with a colon

LEARNStyles for a moment in time

A traffic light is not red forever: it is red while the cars need to stop. A pseudo-class works like that. It is a style that only applies while something is happening to an element. Nothing changes in your HTML: the browser simply watches what the user is doing.

Pseudo-classApplies whileExample
:hoverthe mouse is on the elementa link changes color
:focusthe element is selected (clicked into or reached with the Tab key)a link gets a yellow background
:activethe element is being pressed downa link flashes tomato

LEARNPseudo-classes cannot go inline

You cannot write :hover inside a style attribute. A pseudo-class needs a rule, so it must live in a stylesheet: one more reason to keep your CSS in its own file.

LEARNSnap or glide? The transition

Without a transition a hover change happens like flipping a light switch: instant. With a transition it is more like a dimmer dial, gliding from one look to the other.

transition: color 0.3s;

PartMeaning
propertywhich property glides, like color or background-color. The word all works too
durationhow long the glide takes, written in seconds like 0.3s

LEARNWhere does the transition go?

This is the part everyone gets wrong. Put the transition on the normal rule, not the hover rule.

WhereWhat happens
on the normal ruleglides in and glides back out
only on the hover ruleglides in, but snaps back the moment the mouse leaves

LESSON5.5

Flexbox Basics

Let the browser do the spacing math: a row of items, in the order and spacing you choose.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson
GOALTurn a container into a flex container, and use justify-content, align-items, flex-direction and gap to arrange its items.
WORDS TO KNOW
flexbox a layout system for arranging items in a row or a column
flex container the parent element that has display: flex
flex item a direct child of a flex container
justify-content spacing along the main direction (left to right in a row)
align-items alignment across the main direction (top to bottom in a row)
gap even space between the items
ON THE SITENotes: flexbox-notes  ·  Walkthrough: Flex Menu  ·  Assignment: Chipotle Order Board  ·  Quiz game: 5.5

LEARNA shelf that arranges itself

Picture a bookshelf with a helpful robot. You tell the robot "line them up with equal gaps" or "push everything to the middle," and it does the measuring. Flexbox is that robot. You put it on a container, and it arranges the container's direct children, the items, in a row or a column.

NameWhat it is
containerthe parent: the div that holds the items. It gets display: flex. This is where you write the layout rules
itemsthe direct children. They never get the flex rules themselves
defaultthe moment a container turns flex, its items jump into one row
The parent decides the layout. Flex rules go on the container, never on the items.

LEARNTwo properties do most of the work

In a row, justify-content spreads the items left to right and align-items moves them top to bottom.

justify-contentWhere the items go
flex-startbunched at the start
centerbunched in the middle
flex-endbunched at the end
space-betweenfirst at the start, last at the end, equal space between
space-aroundequal space on both sides of every item

align-items takes flex-start, center, flex-end or stretch. A container needs a height before align-items has room to move things.

LEARNDirection and gap

flex-direction: column stacks the items top to bottom instead of side by side. When you switch to a column, justify-content and align-items swap jobs: justify-content now works up and down. gap: 20px puts the same space between every pair of neighbors.

LEARNThe classic trick: perfect centering

Centering something both ways used to be famously annoying. With flexbox it takes two properties. Set both to center on a container that has a height, and whatever is inside lands in the middle, every time:

display: flex; justify-content: center; align-items: center; height: 200px;

CSS Grid Basics

Rows and columns at the same time: a muffin tin for your layout.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson
GOALArrange items into rows and columns at the same time with a grid, size the columns with fr, and know when to use flexbox and when to use grid.
WORDS TO KNOW
grid container the parent element with display: grid
grid item a direct child of the grid container
fr unit a fraction of the remaining space
grid-template-columns sets how many columns there are and how wide each is
gap even space between rows and columns
ON THE SITENotes: grid-notes  ·  Walkthrough: Photo Gallery  ·  Assignment: Pinterest Boards  ·  Quiz game: 5.6

LEARNA spreadsheet for your layout

Flexbox lines things up in one direction, like books on a shelf. A grid is more like a muffin tin: rows and columns at once. You decide how many columns the tin has, and the browser drops each item into the next open cup. Perfect for photo galleries and card layouts.

NameWhat it is
containerthe tin: the div with display: grid. All the layout rules go here
itemsthe muffins: the children. You never set their width, the columns decide it
gapthe tin walls: even space between every row and column at once

LEARNWhat does fr mean?

The fr unit means a fraction of the leftover space. Think of splitting a pizza after you set aside a fixed slice for yourself: every fr gets a share of what remains.

WrittenResult
1fr 1fr 1frthree equal columns
1fr 2frtwo columns, the second twice as wide
1fr 100pxa fixed 100px column and one that takes the rest
display: grid turns the grid on. grid-template-columns makes it a grid you can see. With no columns you get one wide column and everything stacks like normal.

LEARNColumns on the container, never widths on the items

If you write width: 33% on every item you are fighting the grid. Let the columns decide: write them once, on the container. The items are placed in order, row by row: six items in three columns make two rows. The gaps use space first, then the fr columns share what is left: in a 600px grid with three equal columns and a gap of 30px, each column is (600 - 2 x 30) / 3 = 180px wide.

you size things withjustify-content spacinggrid-template-columns on the container

Glossary

:active while the element is being pressed down
:focus while the element is selected by a click or the Tab key
:hover while the mouse is on the element
align-items alignment across the main direction (top to bottom in a row)
class a name you make up; every element wearing it gets the matching rule
combined selector two selectors joined to aim more precisely, like p.warning
descendant selector two selectors with a space between: the second is inside the first
external CSS styles kept in their own file (like style.css) and shared by the whole site
flex container the parent element that has display: flex
flex item a direct child of a flex container
flexbox a layout system for arranging items in a row or a column
fr unit a fraction of the remaining space
gap even space between rows and columns
grid container the parent element with display: grid
grid item a direct child of the grid container
grid-template-columns sets how many columns there are and how wide each is
hash the # symbol that starts an id rule
id a name for one single element; written with a hash in CSS
id attribute the part of the tag that holds the name, like id="banner"
justify-content spacing along the main direction (left to right in a row)
link tag a head tag that plugs the CSS file into the page
multiple classes several class names in one class attribute, separated by spaces
pseudo-class a style that applies only during a temporary state, written with a colon
rule a selector plus the properties inside curly braces
selector the part of a rule that says which elements it is for
specificity the ranking that decides which rule wins when rules disagree
transition makes a change glide over time instead of snapping
unique used only once on a page
