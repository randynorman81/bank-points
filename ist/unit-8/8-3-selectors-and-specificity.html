Notes

Specificity is the rulebook the browser uses when more than one CSS rule tries to style the same element. From weakest to strongest: tag selectors (like p or h1) lose to class selectors (like .card), which lose to id selectors (like #hero). The most specific selector wins, no matter which order the rules are written in.

  • Combining selectors lets you target something more precisely than one selector alone. p.warning means "only p tags that also have the class warning" — more specific than .warning by itself.
  • ul li (a space between two selectors) means "any li inside a ul", not "an element that is both at once."
  • An element can have more than one class at a time: class="card featured" lets both .card and .featured style the same element.
  • Inline styles (written right on the tag with style="...") beat everything — even an id selector in a stylesheet. That is one reason developers avoid inline styles on a real site: nothing in the stylesheet can override them.

Look up these terms if anything above is unclear: specificity, combined selector, descendant selector, multiple classes.
