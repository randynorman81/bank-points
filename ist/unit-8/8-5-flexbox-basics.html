Notes

Flexbox is a layout system for arranging a container's direct children in a row or a column, with the browser handling the spacing math for you. Turn any container into a flex container with one line: display: flex;.

Property (on the container)What it does
display: flex;Turns this element into a flex container; its direct children become flex items, side by side by default
flex-directionrow (default, side by side) or column (stacked)
justify-contentSpacing along the main direction: flex-start, center, space-between, space-around
align-itemsAlignment across the other direction: flex-start, center, flex-end, stretch
gapEven spacing between items, without margin math
flex-wrapwrap lets items drop to a new line instead of squeezing or overflowing

Real trick: display: flex; justify-content: center; align-items: center; on a container perfectly centers whatever is inside it, both ways, every time.

Look up these terms if anything above is unclear: flex container, flex item, main axis, cross axis.
