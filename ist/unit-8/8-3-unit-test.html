8.3 — Unit Test

🔔 Bell Ringer — Think About It
  1. If a tag selector, a class, and an id selector all try to style the same element differently, only one wins. Why do you think id was designed to beat class, and class beat tag, instead of the reverse order?
  2. Imagine you inherit a real company website where every element has three or four different selectors fighting to style it. Is that good practice, or a sign the original developer made a mess? Why?
  3. If tag selectors always won over id and class, what would that mean for how usable CSS could even be on a large website?
  4. Knowing the specificity hierarchy, how would you deliberately design your own CSS from the start to avoid ever needing to fight it later?

Test day — specifics on the website-build portion are given the day of the test.
