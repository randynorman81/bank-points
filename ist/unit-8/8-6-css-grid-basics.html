Notes

CSS Grid is a layout system for arranging children into rows and columns at the same time, defined entirely on the container. Turn any container into a grid with display: grid;.

Property (on the container)What it does
display: grid;Turns this element into a grid container
grid-template-columns: 1fr 1fr 1fr;Creates 3 equal-width columns. fr means "a fraction of the remaining space"
grid-template-columns: 200px 1fr;A fixed 200px sidebar, then everything else in one flexible column
gapEven spacing between every row and column, in both directions at once
grid-template-rowsSame idea as columns, but for row heights

You never set a width on the individual grid items — the columns on the container decide their size automatically. That is the biggest difference from the old inline-block/percentage-width method.

Look up these terms if anything above is unclear: grid container, grid item, fr unit, grid-template-columns.
