Notes

A pseudo-class styles an element based on a temporary state, not something written in the HTML. You already met a:link, a:visited, a:hover, and a:active for links — but any element can use :hover, not just links.

  • :hover — applies while the mouse is on top of the element.
  • :focus — applies while the element is selected, by click or by keyboard (Tab).
  • :active — applies for the split second the element is being clicked.
  • Pseudo-classes cannot go inline — they must live in an internal <style> block or an external stylesheet.

The transition property makes a property change happen smoothly over time instead of instantly, written as transition: property duration;:

ExampleWhat it does
transition: background-color 0.3s;Background color fades over 0.3 seconds instead of snapping
transition: all 0.2s;Every property that changes on hover transitions smoothly

The transition goes on the normal rule (not the :hover rule) — it tells the browser how to animate any change to that element.

Look up these terms if anything above is unclear: pseudo-class, hover, focus, transition.
