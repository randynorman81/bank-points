Flexbox Basics

Turn a container into a flex container and let the browser handle the spacing math for you.

display: flex
01

A Shelf That Arranges Itself

Picture a bookshelf with a helpful robot. You tell the robot "line them up with equal gaps" or "push everything to the middle," and it handles the measuring. Flexbox is that robot. You put it on a container, and it arranges the container's direct children, the items, in a row or a column.

Container

The parent

The div that holds the items. It gets display: flex. This is where you write the layout rules.

Items

The direct children

The things inside the container. They never get the flex rules themselves.

The Flex Playground

Two properties do most of the work. justify-content controls spacing along the main direction (left to right in a row). align-items controls the other direction (top to bottom in a row). Build your own layout and watch the code write itself.

03

The Classic Trick: Perfect Centering

For years, centering something both ways was famously annoying. With flexbox it takes two properties. Set both to center and whatever is inside lands in the middle, every time.

04

Common Mistakes

Wrong: flex on the items

.item { display: flex; }

Nothing arranges, because the container never got the rule.

Right: flex on the parent

.row { display: flex; }

The class on the div holding the items gets the flex rules.

Wrong: items nested deeper

Putting each item inside its own extra div inside the container. Only the direct children are flex items.

Right: items directly inside

The three paragraphs or links sit right inside the container div, no extra wrappers.
