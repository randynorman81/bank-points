8.2 — CSS by ID

🔔 Bell Ringer — Think About It
  1. An id is only supposed to be used once per page, but nothing technically stops you from reusing it. What could actually break in a website if two elements share the same id?
  2. Why would a web developer choose to style something by id instead of by class, if a class can technically do almost the same job?
  3. If you were building a huge website with hundreds of elements, would you rather rely mostly on ids or mostly on classes for styling? What's the risk of leaning too hard on either one?
  4. JavaScript often uses an element's id to grab it and change it. Why might that make ids more fragile to rename than classes once a site is live?
