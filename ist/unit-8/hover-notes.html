Hover Effects and Transitions

Make elements react to the mouse, and glide between looks instead of snapping.

:hover @CHIP@middot; transition
01

Styles for a Moment in Time

A traffic light is not red forever. It is red while the cars need to stop. A pseudo-class works like that: a style that only applies while something is happening to an element, such as a mouse resting on it. Nothing changes in your HTML. The browser simply watches what the user is doing.

:hover

The mouse is on it

Applies while the pointer sits on top of the element.

:focus

It is selected

Applies when an element is clicked into or reached with the Tab key.

:active

It is being clicked

Applies for the split second the button is pressed down.

Try all three on the same link-style button. Hover it, press and hold it, then click away and Tab back to it.

Live pseudo-classes
Waiting for you...
Pseudo-classes cannot go inline. They must live in a style block or an external stylesheet, which is one more reason to keep your CSS in its own file.
02

Snap or Glide? The Transition Property

Without a transition, a hover change happens like flipping a light switch: instant. With a transition it is more like a dimmer dial, gliding from one look to the other. It is a tiny detail, but it is what makes a site feel polished.

Slide the duration, then hover the button. At 0 it snaps.

0s0.4s
Hover this button
PROPERTYWhich property should glide, like a background color. The word all works too.
DURATIONHow long the glide takes, written in seconds like 0.3s.
03

Where Does the Transition Go?

This is the part everyone gets wrong. Put the transition on the normal rule, not the hover rule. Then the element glides in and glides back out. Put it only on the hover rule and it glides in, but snaps back the moment your mouse leaves.

Compare the two. Hover each, then move away and watch how it returns.

RIGHT: on the normal rule
WRONG: only on the hover rule

Wrong

a { color: navy; } a:hover { color: red; transition: color 0.3s; }

Glides in, snaps back out.

Right

a { color: navy; transition: color 0.3s; } a:hover { color: red; }

Smooth both ways.

Wrong: space missing before the colon part

a : hover { ... }

A pseudo-class sticks to the selector with no spaces.

Right: one tight selector

a:hover { ... }

Tag name, colon, state, all together.
