External CSS and Classes

Your styles move out of the page into their own file, and a class lets you style some elements but not others.

01

One Remote for Every Room

Imagine a school where every classroom has its own light switch, and the principal wants the lights dimmer. Someone has to walk into every single room. Now imagine one master panel in the office that controls all of them. External CSS is that master panel: your styles live in one separate file, and every page just plugs into it.

The Link Tag Is the Plug

Your CSS file does nothing on its own. The page has to be told where to find it, like plugging in a lamp. That plug is the link tag, and it always lives in the head.

03

Inside a CSS File, the Rules Change

A CSS file holds only rules. It is not a web page, so HTML tags and quotes do not belong in it.

Wrong: HTML habits in the CSS file

<style> p { color: "blue"; } </style>

No style tags, and no quotes around values.

Right: just selector and rules

p { color: blue; }

A selector, curly braces, then property: value; pairs.

04

Classes: Style Some, Not All

A tag rule is a school-wide announcement: every paragraph hears it. A class is a name tag. Only the elements wearing that name tag get the style, and you can hand the same name tag to as many elements as you want.

Click a paragraph to give it the class, click again to take it away.

A class rule that sets a gold background
IN THE HTMLThe element gets the name inside its class attribute. No dot here.
IN THE CSSThe rule starts with a dot before the name.
RESULTOnly elements with that name change.

Wrong: dot in the HTML

<p class=".spotlight">

The dot only belongs in the CSS rule.

Right: dot in the CSS only

.spotlight { ... } /* the HTML says class="spotlight" */

Same name both places, dot only on the CSS side.
