6.13 — Unit Test

Test day — specifics on the website-build portion are given the day of the test.

🔔 Bell Ringer — Think About It
  1. Out of everything you learned this unit — structure, styling, box model, colors, block vs. inline, div, tables — which single concept do you think the rest of the unit actually depended on the most?
  2. Today you're building a website using every tag from this unit at once, instead of one tag at a time like every other day. Why does combining everything feel so different from learning each piece separately?
  3. If you had to cut just one topic from this whole unit and still build a working, decent-looking website, what would you cut, and what would you lose by cutting it?
  4. Think about the very first site you built on 6.1 versus what you can build now. What's the biggest difference between those two versions of you as a web designer?
