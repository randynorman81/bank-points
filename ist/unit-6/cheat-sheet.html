HTML Cheat Sheet

Every tag we use, with a code example and what it looks like in the browser. Keep this open while you build.

The skeleton

<!DOCTYPE html>

The very first line. It tells the browser this is a modern HTML page. No closing tag. Lesson 3.1

<!DOCTYPE html>
<html>

Wraps the whole page. Everything else goes inside it. Lesson 3.1

<html> ...head and body go here... </html>
<head>

Information about the page that does not show on the page itself. Lesson 3.1

<head> <title>My Page</title> </head>
<title>

The words in the browser tab. Goes inside the head. Lesson 3.1

<title>My First Website</title>

The title shows in the browser tab, not on the page.

<body>

Everything the visitor sees on the page goes inside the body. Lesson 3.1

Code

<body> <h1>Welcome!</h1> <p>This shows on the page.</p> </body>

What the browser shows

Welcome!

This shows on the page.

Text

<h1> to <h6>

Headings from largest (h1) to smallest (h6). Use one h1 for the page title. Lesson 3.1 and 3.3

Code

<h1>Honey Bee</h1> <h2>Life in the Colony</h2> <h3>The Queen</h3>

What the browser shows

Honey Bee

Life in the Colony

The Queen

<p>

A paragraph. The browser puts space above and below it. Lesson 3.1

Code

<p>Bees turn nectar into honey.</p> <p>A hive can hold 50,000 bees.</p>

What the browser shows

Bees turn nectar into honey.

A hive can hold 50,000 bees.

<strong> and <b>

Bold text. Lesson 3.4

Code

<p>This is <strong>very important</strong>.</p>

What the browser shows

This is very important.

<em> and <i>

Italic text. Lesson 3.4

Code

<p>I read <em>Hatchet</em> last week.</p>

What the browser shows

I read Hatchet last week.

<br>

A line break. Starts a new line inside a paragraph. No closing tag. Lesson 3.4

Code

<p>Roses are red,<br>Violets are blue.</p>

What the browser shows

Roses are red,
Violets are blue.

<hr>

A horizontal line across the page. No closing tag. Lesson 3.4

Code

<p>Above the line</p> <hr> <p>Below the line</p>

What the browser shows

Above the line

Below the line

<span>

An inline container. It changes just a few words and does nothing until you style it. Lesson 3.4

Code

<p>My favorite color is <span style="color: tomato;">tomato</span>.</p>

What the browser shows

My favorite color is tomato.

<div>

A block container. It groups tags together so you can style them as one box. Lesson 4.4

Code

<div style="background-color: lightyellow; border: 2px solid gold;"> <h3>Heads up</h3> <p>Everything in this box is grouped.</p> </div>

What the browser shows

Heads up

Everything in this box is grouped.

Links and images

<link>

In the head. It loads something from outside, like a Google font or your style.css file. No closing tag. Lesson 3.5 and 5.1

<head> <link href="https://fonts.googleapis.com/css2?family=Lobster&display=swap" rel="stylesheet"> </head>

The font is loaded, but nothing changes until you use it in a style.

<img>

Shows an image. src is where the picture lives and alt describes it. No closing tag. Lesson 3.7

Code

<img src="dog.jpg" alt="A black puppy" width="150">

What the browser shows

<a>

A link. href is where it goes. Add target="_blank" to open a new tab. It can wrap words, a heading, or an image. Lesson 3.9

Code

<a href="https://www.wikipedia.org" target="_blank">Visit Wikipedia</a> <a href="https://www.wikipedia.org"><img src="dog.jpg" alt="A black puppy" width="120"></a>

What the browser shows

Visit Wikipedia

Lists

<ul> and <li>

An unordered (bulleted) list. Each item is an li. Lesson 3.10

Code

<ul> <li>Spawn point</li> <li>Iron ore</li> <li>Diamonds</li> </ul>

What the browser shows

  • Spawn point
  • Iron ore
  • Diamonds
<ol> and <li>

An ordered (numbered) list. Each item is an li. Lesson 3.10

Code

<ol> <li>Crack the egg</li> <li>Stir</li> <li>Cook</li> </ol>

What the browser shows

  1. Crack the egg
  2. Stir
  3. Cook

Tables

<table>, <tr>, <th>, <td>

A table. tr is a row, th is a header cell (bold), td is a regular cell. Lesson 4.5

Code

<table border="1"> <tr> <th>Name</th> <th>Score</th> </tr> <tr> <td>Ana</td> <td>95</td> </tr> </table>

What the browser shows

NameScore
Ana95

Forms

<form>

Holds the boxes and buttons a visitor fills out. Lesson 9.6

Code

<form> <label>Your name</label> <input type="text"> <button>Send</button> </form>

What the browser shows



Attributes you add to tags

An attribute goes inside the opening tag and gives it extra instructions: name="value". These two are covered above: href, src, alt, target, width. These three are used to style:

style

Holds the CSS for one tag. Goes inside the opening tag.

<p style="color: teal; font-size: 24px;">Teal text</p>
class

A name you give a tag so one CSS rule can style many tags.

<p class="note">Styled by .note { }</p>
id

A name that belongs to just one tag.

<h1 id="title">Styled by #title { }</h1>

Open tag. Content. Close tag.

Most tags come in pairs. The tags with no closing tag are DOCTYPE, br, hr, link, img, and input.
