Text Size, Alignment, and Letter Case

In 3.2 you changed the color of your text and the color behind it. Now you will change how big the text is, where it sits on the page, and how its letters look, all with the same style attribute. Try it, break it, fix it, then read the rules.

Inline Styling
Remember

Same Shell, New Properties

Nothing about the shell changes. Type style=" " first, then fill the box with a property, a colon, a value, and a semicolon. You can chain as many properties as you want, as long as each one ends with a semicolon.

style="property: value;"
New in this lesson:font-size (how big), text-align (where it sits), and text-transform (how the letters look).

Type in the left box and watch the page change. Work through the six steps in order. Each one turns green when you finish it.

You changed the letters without retyping. The page shows capitals, but your code still has the words you typed.

Style a paragraph

Give the paragraph its own style with at least two properties, like a font-size and a text-align.

Every element has its own style. Styling the h1 did not change the paragraph.

The browser got confused. Without the closing quote it cannot tell where the style ends, so your page can break.

You just wrote CSS.Now let's put names to the pieces.
01

Font Size

The font-size property changes how big the text is. Size is measured in pixels, written px. A pixel is one tiny dot on your screen. Regular text is usually 16px.

Code

<p style="font-size: 14px;">Small</p> <p style="font-size: 28px;">Medium</p> <p style="font-size: 56px;">Big</p>

What the browser shows

Small

Medium

Big

  • Always write the number and px together with no space: 28px, not 28 or 28 px.
  • The biggest, most important text should have the biggest size. That is called a visual hierarchy.
02

Alignment and Letter Case

PropertyValuesWhat it does
text-alignleft, center, rightSets where the text sits across the width of the page. Left is the default.
text-transformuppercase, lowercase, capitalizeChanges the letter case. capitalize makes the first letter of every word a capital.

Code

<h2 style="text-align: center; text-transform: uppercase; color: navy;"> breaking news </h2> <p style="text-align: right;">Signed, the reporter</p>

What the browser shows

breaking news

Signed, the reporter

Why use text-transform instead of typing in capitals? If your teacher wants all headings to look normal instead of ALL CAPS, you change one word in the style instead of retyping everything.

03

Chaining It All Together

You already chained a color and a background color in 3.2. You can keep going: put as many properties as you need in one style attribute. Finish each one with a semicolon, and keep them all inside the same pair of quotes.

Code

<p style="color: orange; font-size: 24px;"> Large and colorful text! </p>

What the browser shows

Large and colorful text!

The semicolon is a separator.Every time you finish a property and value, add a semicolon. Then you can start the next one before the closing quote.
04

Common Mistakes

Wrong: no semicolon between properties

<p style="font-size: 20px text-align: center;">

Right

<p style="font-size: 20px; text-align: center;">

Wrong: missing quotes

<p style=color: red;>

Right

<p style="color: red;">

Wrong: forgot px

<p style="font-size: 20;">

Right

<p style="font-size: 20px;">

Wrong: misspelled property

<p style="colour: red;">

Right

<p style="color: red;">

Wrong: style in the closing tag

</p style="color: red;">

Right: opening tag only

<p style="color: red;">text</p>

The Web Editor's Problems to fix list catches most of these and tells you the line number.

05

Vocab You Need

TermPlain-English meaning
AttributeExtra instructions inside an opening tag
Style attributeThe attribute that changes how an element looks
Inline stylingWriting CSS right inside an HTML tag with the style attribute
CSSCascading Style Sheets: the language that controls how a page looks
PropertyThe feature you want to change, like color or font-size
ValueThe setting you give a property, like tomato or 24px
Pixel (px)The unit for size on a screen: one tiny dot
font-sizeThe property that sets how big the text is, written in pixels like 28px
text-alignThe property that sets where text sits across the page: left, center, or right
text-transformThe property that changes letter case: uppercase, lowercase, or capitalize
Visual hierarchyUsing size and color so the most important text stands out
