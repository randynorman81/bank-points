Google Fonts

Every font you see online was chosen by someone. Learn where fonts come from, how to pull a free Google font into your page with one link, and how to use it with font-family so your page looks like it came from a real designer.

link · font-family · fallback families · Google Fonts
01

Every Font Belongs to a Family

There are thousands of fonts, but they all fall into a few families. If a computer does not have the font you asked for, it falls back to the family and picks something similar. That back-up plan is called a fallback, and you will always write one. Click a family to see it.

The family is the back-up plan.You pick a favorite font, then add a family after a comma. If your font cannot load, the family keeps your page looking close to what you planned.
02

Get a Google Font

Your computer only has a few fonts built in. Google Fonts is a free library of hundreds more. To use one, you put a <link> tag in your head. The link tells the browser to download the font before it shows your page.

Want more than one font? You can use one link per font, or put several fonts in one link by adding another family= after an ampersand: ?family=Pacifico&family=Lobster&display=swap. Google's embed code builds this for you when you add more than one font.
Loading a font is not using it.The link only downloads the font. To make text use it, you still have to write font-family in a style. That is the next section.
03

Use It: font-family

Inside a style attribute, write font-family, a colon, the font's name in quotes, a comma, and a fallback family. Pick a font below and see the code change.

serif, sans-serif, monospace, or cursive. No quotes.

Remember the single quotes.The style attribute already uses double quotes, so the font name uses single quotes inside it: style="font-family: 'Pacifico', cursive;"
04

Mix Fonts Like a Designer

More fonts does not mean better design. Real designers stick to a few and give each one a job. Compare these two pages of text.

RuleWhy
Use 2 to 4 fonts per pageToo many fonts makes a page feel messy and slows it down
A bold display font for headingsBig, fancy letters grab attention in short text
An easy-to-read font for paragraphsLong text needs simple letters. A script font is tiring to read
Use a span for a quick accentChange the font on one word for effect, without changing the whole paragraph
The span trick: a span inside a paragraph can have its own font-family, which overrides the paragraph's font for just those words, the same way it can change a color.
05

Common Mistakes

Wrong: link tag in the body

<body>
<link href="https://fonts.googleapis.com/...">

Right: inside the head

<head>
<link href="https://fonts.googleapis.com/...">
</head>

Wrong: no quotes on a name with a space

font-family: Bebas Neue, sans-serif;

Right

font-family: 'Bebas Neue', sans-serif;

Wrong: no fallback family

font-family: 'Pacifico';

Right

font-family: 'Pacifico', cursive;

Wrong: font never linked

font-family: 'Lobster', cursive; (no link tag in the head)

Right: link it first

link tag in the head, then use 'Lobster' in font-family

Wrong: misspelled font name

font-family: 'Pacifco', cursive;

Right: match the link exactly

font-family: 'Pacifico', cursive;

06

Vocab You Need

TermMeaning
FontThe style of the letters, like Pacifico or Georgia
Font familyA group of fonts with a similar look: serif, sans-serif, monospace, or cursive
font-familyThe style property that chooses the font
FallbackThe family you list after your font so the page still looks right if the font cannot load
Google FontsA free library of fonts you can use on your own pages
Link tagA tag in the head that loads a resource, like a font. It has no closing tag
Display fontA bold, decorative font for titles and headings
