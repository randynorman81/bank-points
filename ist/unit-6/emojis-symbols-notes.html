Emojis and Symbols

You have sent thousands of emojis. Now you will learn what they really are, and how to put them (and symbols like © ♥ →) on a web page you built yourself. Grab some from the pad, learn the secret codes, style them, and then build your own page.

Characters & Entities
Rule #1

It Is a Character, Not a Picture

Every emoji you have ever sent was never a photo. Your phone only sent a tiny number, and the other phone looked the number up and drew a face. An emoji is closer to the letter A than to a photograph. That one idea explains everything on this page.

The first two are text, so you put them in a heading, a paragraph, or a list item. The picture is a different thing and needs an img tag.

Because they are text, emojis and symbols follow the text rules you already know. You can put them in an h1, a p, an li, or a span. You size them with font-size and center them with text-align. They never need src, alt, or an upload.

Text or picture?

Decide, then tap to check.

02

HTML Entities: The Secret Codes

Some characters are hard to find on a keyboard, and some mean something special to the browser. For those, HTML gives each one a code name. You write the code, the browser draws the character.

There are two kinds: a name like &copy; and a number like &#169;. Both end with a semicolon.

Find an entity

Type to filter by word (try heart, arrow, or money). Click a code to copy it.

You seeName codeNumber codeWhat it is

Name or number?

A name is easier to remember. A number always works, even for emojis and symbols that have no name (like the star ★, &#9733;). When a name does not work, switch to the number.

Code

<p>&copy; 2027 Pawfect Park &rarr; Open daily</p> <p>Today: 72&deg;F &hearts;</p> <p>Star: &#9733; Smile: &#128512;</p>

What the browser shows

© 2027 Pawfect Park → Open daily

Today: 72°F ♥

Star: ★ Smile: 😀

A space inside

No spaces are allowed inside an entity. The browser prints the letters instead.

&heart;
Tap to reveal

Wrong name

The name is &hearts; with an s. Not sure? Use the number &#9829;.

&rarr;
Tap to reveal

Correct

An ampersand, a name, and a semicolon. It makes a right arrow →.

Start with &, end with ;Leave out the semicolon or add a space and you will see the code itself instead of the symbol.
03

Three Characters You Must Escape

The browser reads every < as the start of a tag. If you want to show one on the page as plain text, you have to tell the browser, "this one is just a character, I promise." Entities are how you promise.

Code

<p>Use &lt;p&gt; to start a paragraph.</p> <p>Salt &amp; pepper</p>

What the browser shows

Use <p> to start a paragraph.

To show

To show

>   type &gt;

A plain > looks like the end of a tag.

To show

&   type &amp;

A plain & looks like the start of an entity.

05

Same Code, Different Drawing

When you send a smiley, you send a code, and every device owns its own artist. Three artists, one code, three slightly different faces. A symbol like © hardly changes at all, but an emoji can.

Illustration: the same code, drawn three ways. This is why you should not depend on one exact look.

Good idea or bad idea?

A menu with a pizza emoji next to the word Pizza
Tap to reveal

Good

The emoji adds to the words. If it looks different on another phone, nothing is lost.

Common Mistakes

Wrong: no semicolon

<p>&copy 2027 Pet Shop</p>

Right

<p>&copy; 2027 Pet Shop</p>

Wrong: space inside

<p>& hearts; &rarr ;</p>

Right

<p>&hearts; &rarr;</p>

Wrong: a plain & in text

<p>Salt & pepper</p>

Right

<p>Salt &amp; pepper</p>

Wrong: an img tag for an emoji

<img src="smile.png" alt="smile">

Right: just text

<p>Hello 😀</p>
Expecting color to change an emoji.It will not. Emojis keep their own colors. Use a symbol when you want to pick the color.
