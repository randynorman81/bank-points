Unit 6 Notes  /  Lesson 6.7

Images

Upload your own pictures, drop them on a page, and resize them without squishing. Then make every one of them a clickable link, the way real websites do it.

img · src · alt · width / height · images as links
01

The Image Tag

A web page is just text. When you see a picture, the page is really pointing at a picture file stored somewhere else. The <img> tag is the pointer: it says where the picture lives and what it shows. It uses the same attribute shell you know from style=" " and href=" ".

<img src="https://.../dog.png" alt="A bulldog in a cowboy hat">
Tag

<img>

The image tag. It is a one-tag tag like <br> and <hr>: there is nothing to wrap, so no closing tag.

Attribute 1

src

The source: the web address of the picture file. No src, no picture.

Attribute 2

alt

The alternative text: words that describe the picture. Screen readers read it aloud, and it shows if the picture cannot load.

Good alt text says what is in the picture.“Rex the bulldog wearing a cowboy hat” is good. “image1” or “picture” is not.
02

Upload Your Own Pictures

The browser can only show a picture that has a web address. A file on your computer does not have one. The Web Editor fixes that: it stores your picture online and gives you the address.

Open Checks in the Web Editor and find the My images section. (Sign in first.)
Upload a picture from your computer. JPG, PNG, GIF, and WEBP work. The editor shrinks big photos for you.
Click your picture's Insert button. The editor types the whole tag into your code, wrapped in a link.
Change the two placeholders: write a real alt description, and change the example link address to a real website (Section 04 explains why).

Will it show?

src="C:\Users\me\Pictures\dog.jpg"
Tap to reveal

No

That file is only on your computer. Nobody else (and no website) can reach it.

src="dog.jpg"
Tap to reveal

No, not here

The editor has no file called dog.jpg. Upload it, then use the address the editor gives you.

The address the editor inserts after you upload
Tap to reveal

Yes

That is a real web address that works for everyone who opens your page.

src="https://images.example.org/cat.png" (a real hosted picture)
Tap to reveal

Yes

Any picture with a web address that starts with https:// works, but for this class, upload your own.

03

Change the Size

Pictures come in all sizes. You set the size with the width style property, in the shell: style="width: 200px;". Drag the slider.

Code

What the browser shows

Set width OR height, not both

A picture has a natural shape (its aspect ratio). If you set only width, the browser works out the height so nothing is distorted. If you set both, you can squish or stretch it.

Code

What the browser shows

Pixels or percent?

WriteMeaningUse it when
width: 200px;Exactly 200 pixels wide, on any screenYou want an exact size, like a thumbnail
width: 50%;Half as wide as the space it sits inYou want it to shrink and grow with the page
Pick one dimension and let the browser do the math.Size the width, and the height follows. It keeps faces looking like faces.
04

Every Image Is a Link

Click almost any picture on the internet and something happens: a product page opens, a bigger version appears, a profile loads. That is because the picture is wrapped in an anchor tag. From now on, every image you add to your pages will be a clickable link.

Code

<a href="https://www.nasa.gov" target="_blank"> <img src=".../rocket.png" alt="A rocket launching" style="width: 200px;"> </a>

Try clicking it

This picture is a link. It opens NASA in a new tab.

Step 1

Start the link

<a href="https://...">, with target="_blank" if it leaves your site.

Step 2

Put the image inside

The whole <img ...> tag goes between the opening and closing anchor tags.

Step 3

Close the link

</a> goes after the image. The image tag itself still has no closing tag.

The editor helps: when you click Insert, it writes the link around your image and puts a placeholder address (example.com) in it. Change that address to a real website that makes sense for the picture. The Checks list will not accept example.com.
The link goes on the outside. The picture goes on the inside.Same rules as before: https:// at the start, target="_blank" for links that leave your site, and no target to stay in the current tab.
05

Images Are Inline

Remember block vs. inline from 6.5? An image is inline, so it sits in the line of text like one giant letter. That is why text lines up next to it at the bottom. To put an image on its own line, switch it to block.

07

Common Mistakes

Wrong: closing the img tag

<img src="..." alt="Dog"></img>

Right: no closing tag

<img src="..." alt="Dog">

Wrong: squished with both sizes

<img style="width: 300px; height: 40px;">

Right: one size only

<img style="width: 300px;">

Wrong: image outside the link

<a href="https://..."></a> <img src="..." alt="Dog">

Right: image inside the link

<a href="https://..."> <img src="..." alt="Dog"> </a>

Wrong: leaving the placeholders

href="https://www.example.com" alt="describe your image here"

Right: real address, real description

href="https://www.nasa.gov" alt="A rocket launching at sunrise"

Wrong: no alt

<img src="...">

Right: always include alt

<img src="..." alt="Rex the bulldog">
08

Vocab You Need

TermMeaning
img tagThe tag that puts a picture on the page. One tag, no closing tag
srcThe attribute holding the picture's web address
altThe attribute that describes the picture in words
UploadSending a file from your computer to the web so it gets a web address
Aspect ratioThe natural shape of a picture (how wide it is compared to how tall)
width / heightStyle properties that set a picture's size. Use one, not both
Image linkAn image inside an anchor tag, so clicking the picture opens a page
border-radiusRounds the corners. 50% on a square makes a circle

A picture is a link waiting to be clicked.
