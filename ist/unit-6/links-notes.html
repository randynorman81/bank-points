Links

The web is just pages connected by links. Learn to build one, decide where it opens, and make it react when someone points at it or clicks it.

a · href · target · :link :visited :hover :active · style block
01

The Anchor Tag

Take every link off the internet and you are left with millions of pages nobody can get to. A link is a door from one page to another. In HTML, that door is the anchor tag, <a>, and the address it opens is stored in an attribute called href.

<a href="https://www.wikipedia.org">Wikipedia</a>

Notice it is the same shell you already know: an attribute name, an equals sign, and a pair of quotes with the value inside. style=" " held design instructions. href=" " holds an address.

Part 1

<a>

The anchor tag. It wraps the clickable text and needs a closing tag.

Part 2

href

The attribute that holds the destination. It stands for hypertext reference.

Part 3

Link text

What people see and click. Say what is behind it: “NASA Mars photos,” not “click here.”

Web addresses start with https://.Leave it off and the browser looks for a file on your own site instead of the internet. Copy the whole address from the browser's address bar.
02

Current Tab or New Tab?

A link can take over the tab you are in, or open the destination in a brand-new tab. You choose with the target attribute.

You wantWriteUse it for
Open in the current tab<a href="https://..."> (nothing extra), or target="_self"Links inside your own site, like Home or Next page
Open in a new tab<a href="https://..." target="_blank">Links to other websites, so people do not lose your page
Rule of thumb: if a link leaves your website, open it in a new tab. If it stays on your website, use the current tab. Two attributes can sit in the same tag; separate them with a space: <a href="..." target="_blank">
Attributes go in the opening tag only, separated by spaces.The closing tag is always plain: </a>.
03

Internal Styling: Style It Once, in the Head

So far, every time you wanted a heading to be tomato red, you typed style="color: tomato;" on that heading. Do that on ten headings and you have typed the same thing ten times. Change your mind about the color and you have ten edits to make. Real designers do not work like that. They write the rule once, in the <head>, and it styles every matching element on the page. That is internal styling, and it is where this unit is heading from here on.

Inline vs. internal

Inline styling: repeat on every tag

<body> <h2 style="color: teal;">Music</h2> <h2 style="color: teal;">Games</h2> <h2 style="color: teal;">Movies</h2> <h2 style="color: teal;">Sports</h2>

4 headings, 4 copies of the same style.

Internal styling: one rule in the head

<head> <style> h2 { color: teal; } </style> </head> <body> <h2>Music</h2> <h2>Games</h2> <h2>Movies</h2> <h2>Sports</h2>

4 headings, 1 rule. The tags stay clean.

Change your mind

You decide teal is boring. Pick a new color and watch how much work each method takes.

Inline: one edit fixes one heading

Internal: one edit fixes all four

Anatomy of a rule

h2 { color: teal; }
Part 1

Selector

Says which elements to style. A tag name like h2, p, or li styles every one of them. a:hover targets a state.

Part 2

Curly braces { }

Hold the styles. Open with { and close with }.

Part 3

Property and value

The same property: value; you already know, with a colon and a semicolon.

No style= and no quotes in a rule.The shell style=" " belongs to the attribute. Inside { }, just write property: value;.

Move your styles to the head

Step through converting an inline page to an internal one.

Inline stylingInternal styling
WhereInside one tag: style=" "Inside <style> in the head
ReachesThat one elementEvery element that matches the selector
Changing itEdit every tagEdit one rule
Best forA one-off exceptionStyles the whole page shares
Can style states like :hover?NoYes
Inline still wins an argument. If a tag has its own style=" " and the head has a matching rule, the inline style takes priority for that tag. That makes inline handy for a single exception, like one red word in a teal heading. The habit to build: put shared styles in the head, and save inline for the exceptions.
From here on, style your pages from the head.Links are the perfect first case: a:link, a:visited, a:hover and a:active can only be written in a style block.
04

Link States and Pseudo-Selectors

A link is not one thing. It is different things at different moments: waiting, already visited, being pointed at, being clicked. Each moment is a state, and CSS gives each state a name that starts with a colon. Those names are pseudo-selectors (also called pseudo-classes).

SelectorWhen it appliesDefault look
a:linkA link nobody has visited yetBlue, underlined
a:visitedA link you already openedPurple
a:hoverThe mouse is pointing at itNo change
a:activeThe moment it is being clickedRed

Try it. This link is styled with all four states. Point at it, click and hold, then let go (it goes to the Wikipedia home page, so it will show as visited next time).

Try me: hover, press, and visit
Memory trick: the order is LoVe HAte: Link, Visited, Hover, Active. Always write them in that order. See why on the next section.
05

Why the Order Matters

A visited link that you are hovering matches both a:visited and a:hover. When two rules match, the one written last wins. Try it: pick the states and the order, and see which color the link ends up with.

Result

If a:hover comes before a:visited, visited links never show the hover effect.That is the bug that trips up the most students. Remember LoVe HAte.
06

Common Mistakes

Wrong: no https://

<a href="www.wikipedia.org">Wikipedia</a>

Right

<a href="https://www.wikipedia.org">Wikipedia</a>

Wrong: forgot the closing tag

<a href="https://...">Wikipedia
The rest of my page...

Right

<a href="https://...">Wikipedia</a>

Wrong: vague link text

<a href="...">click here</a>

Right: say what is behind it

<a href="...">NASA Mars photos</a>

Wrong: quotes and colons in the style block

a:hover { style="color: red" }

Right: plain property and value

a:hover { color: red; }

Wrong: misspelled target

<a href="..." target="blank">

Right: underscore matters

<a href="..." target="_blank">
