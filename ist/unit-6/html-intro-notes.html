01

What Is HTML?

HTML stands for HyperText Markup Language. It is the language that gives every web page its structure: which part is a heading, which part is a paragraph, which part is a list. Think of it as the framing of a house: the walls and rooms, before any paint.

Later in this unit you will add CSS, the language that controls how a page looks (the paint and the furniture). For now, we only build the frame.

03

The HTML Skeleton

In the lab, your page had an <html> tag and a <body> tag around your content. Every web page is built the same way. It is called the HTML skeleton. It is made of container tags: tags that hold other tags.

The box analogy.You open a big box and find a smaller box inside. The small box is nested inside the big box. The skeleton is boxes inside boxes.
<html> The big outer box
<head> Hidden information about the pageNested inside html. Not shown on the page itself.
<body> Everything you can see on the pageAlso inside html, and placed below head.
</html>

In code, we use indentation (extra spaces) to show which box is inside which. Here is the complete skeleton, with the one line you have not seen yet at the very top:

<!DOCTYPE html> <html> <head> <title>My First Page</title> </head> <body> <h1>Hello, world!</h1> <p>I made this page.</p> </body> </html>
  • <!DOCTYPE html> goes on the very first line of every real web page. It tells the browser, "This page uses modern HTML." It is not a box, so it has no closing tag.
  • <html> is the big outer box. Everything else goes inside it.
  • <head> is inside html. It holds information about the page that people do not see on the page itself.
  • <body> is inside html, below head. It holds everything you can see: headings, paragraphs, and more.
You will type this skeleton yourself, every time.The Web Editor does not create it for you. Learn the pattern now: DOCTYPE, html, head with a title, and body. The editor will close your tags to help, but you decide what goes in.
HTML is a series of containers that hold other tags.We will meet many more containers later, like div, section, and footer.
04

The <title> Tag

The <title> tag sets the text on your browser tab. It goes inside <head>, not in the body, because it is information about the page, not part of the page itself.

<head> <title>My Awesome Portfolio</title> </head>
My Awesome Portfolio ×

What the browser tab looks like with that title tag.

  • The title shows in the browser tab, in search results, and as the default name when someone bookmarks your page.
  • Use only one title per page. Think of it as the filename of a Word document.
05

Headings and Paragraphs

You already used two creation tags: tags that add visible content to the page. Every creation tag lives inside a container, and the <body> counts. Here are the two you will use the most.

Tag

<p> Paragraph

Regular body text. It starts on its own line, with space above and below.

Tags

<h1> to <h6> Headings

Titles and section names. h1 is the largest and h6 is the smallest. They are bold by default and also start on their own line.

Headings are an outline

Think about an outline from English class. The h1 is the title of the whole page. Each h2 is a main section. An h3 is a smaller part inside a section. Follow the order and do not skip levels.

<h1>Honey Bee</h1> <h2>Life in the Colony</h2> <h3>The Queen</h3> <h3>Workers and Drones</h3> <h2>Honey</h2>
  • Use one h1 per page: the name of your topic.
  • Use h2 for main sections, like History or How It Works. Use h3 for smaller parts inside a section.
  • Do not skip levels. An h3 without an h2 above it breaks the outline.
  • Choose a heading by meaning (how important it is), not by how big it looks. You will change how big text looks later with CSS.
A heading names a section. A paragraph fills it in.A real encyclopedia page is an h1, then a few h2 sections, each with several paragraphs.
06

HTML Ignores Your Formatting

In step 5 of the lab, the browser ignored your extra spaces and Enter keys. HTML is whitespace insensitive: it does not care how you space out your code.

Rule 01

Extra spaces are ignored

Ten spaces between two words in your code show up as one space on the page.

Rule 02

Line breaks are ignored

Pressing Enter in your code does not start a new line on the page.

Rule 03

Code lines are not page lines

A paragraph can take up four lines in your editor and still show as one line in the browser.

Your code (5 lines)

<p> This text is on line 2 in code, but it will stay on one line in the browser. </p>

What the browser shows

Format your code so you can read it. The browser will ignore it.Use indentation and separate lines to keep your tags easy to read and easy to fix.
