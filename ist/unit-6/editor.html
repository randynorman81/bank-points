How to write a style

RULES
  • Put a space between the tag name and the style attribute.
  • A style always follows this structure: style="property:value;"
  • A style always goes in the opening tag only.
  • If you have more than one property and value, connect them with a semicolon inside the same set of quotation marks.
Tag with one CSS style option
Add the semicolon before you close the quotation marks.
<p style="color: blue;"> this text is blue</p>
Tag with multiple CSS style options
Separate each PROPERTY: VALUE pair with a semicolon.
<p style="color: blue; background-color: red;"> this text is blue and background is red</p>
