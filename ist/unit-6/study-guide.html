LEARNWhat HTML is

HTML (HyperText Markup Language) gives a web page its structure: which part is a heading and which part is a paragraph. Think of it as the frame of a house. The paint (colors, sizes, fonts) comes in the next lessons.

A tag is a word in angle brackets. Most tags come in a pair: an opening tag like <p> and a closing tag with a forward slash like </p>. The opening tag, the words between, and the closing tag together are one element.

Every opening tag needs its closing tag. If you forget one, the browser does not know where the element ends.

LEARNThe skeleton every page starts with

Every page is built from the same skeleton: container tags nested inside each other like boxes inside a bigger box.

  1. <!DOCTYPE html> is the very first line. It tells the browser to use modern HTML. It is not a box, so it has no closing tag.
  2. <html> is the big outer box. Everything else goes between <html> and </html>.
  3. <head> holds information about the page that visitors do not see on the page itself, like the title.
  4. <body> holds everything a visitor can see: headings, paragraphs, and later pictures and links.

The head comes first, then the body, and both sit inside the html tags.

LEARNHeadings and paragraphs

A heading 1 (<h1>) is the biggest, most important heading. Use it once, like the title of a book. A heading 2 (<h2>) is smaller and starts a section. A paragraph (<p>) holds a block of normal text.

A section is a heading with its paragraphs under it. Most pages are a heading 1 followed by several sections.

The browser ignores blank lines and extra spaces in your code. Only the tags decide how the page looks, so you can add blank lines to keep your code easy to read.

LEARNThe tab is not the page

The <title> is typed inside the head, so it does not appear on the page. It shows on the browser tab. The heading 1 is typed inside the body, so it shows on the page. A page can have a title and a heading 1 with different words.

Every web page starts with the same skeleton, the way every house starts with a frame. A tag is a word in angle brackets. Most tags come in a pair: an opening tag like <body> and a closing tag with a slash like </body>.

<!DOCTYPE html>
<html>
<head>
<title>Slice House</title>
</head>
<body>
</body>
</html>
YOU DO

  3. Inside the html tags, type the head tag, <head>. The head holds information about the page that visitors do not see on the page itself. The editor adds </head> and puts your cursor under it.

LEARNThe style attribute

HTML gives a page its structure. CSS changes how it looks. In this class you write CSS inside a tag's style attribute.

The style attribute goes inside the opening tag: the word style, an equals sign, and the styles inside double quotes. Each style is a property, a colon, and a value:

<h1 style="color: tomato">Hello</h1>

Here the property is color (the color of the text) and the value is tomato.

LEARNText color and background color

Two properties change colors:

PropertyWhat it colors
colorthe text itself
background-colorthe box behind the text

To use more than one style, put them all inside the same quotes and separate them with a semicolon:

style="color: white; background-color: black"

Never write two style attributes on one tag. Use one style attribute and separate the styles with semicolons.

LEARNThe 140 color names

A color is a name like red, navy or tomato. HTML knows 140 color names, far more than the basic red, blue and green. You will find colors you have never thought to name, like lightseagreen, darkorange, slategray and mediumpurple.

Four rules for every color name:

RuleRightWrong
One word, no spacesdarkbluedark blue
Spelled exactly rightlightyellowlightyelow
No quotes and no #color: tomatocolor: "tomato"
A real name from the listseagreenoceangreen

Many names come in families. Add dark or light to get a darker or lighter version: blue, darkblue, lightblue. You do not have to memorize the 140. Keep the color list open (schscomputerscience.com/ist/unit-6/html-colors.html) and pick from it.

A color name works after both color: and background-color:. If a name does not work, the browser ignores the style and the text stays black. Check the spelling against the color list.

LEARNStyling the whole page

A style on the body reaches the whole page. Any tag that does not have its own style uses the body's text color. A tag with its own style keeps its own: the tag's style wins.

Make sure the text color and the background are different. Light text on a dark background (or dark on light) is easy to read. The same color for both hides the text.

LEARNFont size

The style font-size sets how big the letters are. The size is a number with px (pixels) written right after it, with no space: font-size: 40px. Every heading has its own default size, and font-size overrides it.

Browser defaults: heading 1 = 32px, heading 2 = 24px, heading 3 = 18.72px (about 19px) and a paragraph = 16px.

font-size: 40 (no unit) and font-size: 40 px (a space) do not work.

LEARNThe heading 3 tag

Headings go from <h1> (biggest) to <h2> to <h3> (smaller). Heading 3 is used for a smaller title inside a section.

LEARNText alignment

text-align moves text inside its row: left, center or right. Text starts on the left until you change it.

<h1 style="text-align: center">Welcome</h1>

LEARNLetter case

text-transform changes the letter case on the page without changing the words you typed:

ValueWhat the page shows
uppercaseEVERY LETTER A CAPITAL
lowercaseevery letter small
capitalizeThe First Letter Of Each Word A Capital

Your code still has the original letters. Only the page changes.

LEARNSeveral styles on one tag

A tag can have all three at once. Keep them in one style attribute, separated by semicolons:

<h1 style="font-size: 48px; text-align: center; text-transform: uppercase">

LEARNBold and italics

Wrap the words you want to change in a tag. <strong> makes them bold and <em> makes them *italic*:

We roast <strong>fresh</strong> beans.

In this class bold is always strong and italics is always em. Do not use b or i. Keep the spaces outside the tags, around the word.

LEARNTags that stand alone: br and hr

Most tags come in pairs, but two tags stand alone and have no closing tag:

  • <br> starts a new line inside a paragraph. A browser ignores pressing Enter in your code, so you need br when you want the words on a new line.
  • <hr> draws a horizontal rule: a line across the page that separates sections.
br and hr never have a closing tag. Write <br>, not </br> or <br></br>.

LEARNSpan: style just a few words

A span marks a few words inside a line so you can style only them. By itself a span does nothing: it looks the same as the text around it. Add a style and only those words change:

Try the <span style="color: green">mint</span> tea.

LEARNNesting tags

Tags can go inside other tags. The last tag you open is the first one you close, like boxes inside boxes:

<p><strong>big <em>tiny</em></strong> new</p>

Here tiny is inside both strong and em, so it is bold and italic. big is only inside strong, and new is plain. Crossing tags, like <strong><em>x</strong></em>, is a mistake.

LEARNEvery font belongs to a family

FamilyThe feel
Seriflittle feet on the letters; classic, like a book

LEARNThe img tag

LEARNThe anchor tag

The web is just pages connected by links. A link is a door from one page to another. In HTML the door is the anchor tag, a, and the address it opens is stored in the attribute href:

<a href="https://www.wikipedia.org">Wikipedia</a>

The words between the opening and closing tags are the link text: the part people click. Web addresses start with https://. Leave it off and the browser looks for a file on your own site instead of the internet. Always close the tag with </a>.

LEARNCurrent tab or new tab?

A link can take over the tab you are in, or open in a new tab. You choose with the target attribute:

You wantWrite
the current tab (the default)<a href="https://..."> with nothing extra (or target="_self")
a new tab<a href="https://..." target="_blank">

Rule of thumb: if a link leaves your website, open it in a new tab. Two attributes sit in the same opening tag, separated by a space. The closing tag is always plain: </a>.

The anchor tag does not care what is inside it. Whatever sits between <a> and </a> becomes the link: a few words, bold words, a whole heading, or a picture. Nest the tags like boxes and close the inside one first:

<a href="https://www.nasa.gov"><strong>NASA</strong></a>

A picture link puts the whole img tag inside the a tags: the link goes on the outside, the picture on the inside.

LEARNGood link text

Say what is behind the link: "NASA Mars photos", not "click here".

LEARNTwo kinds of list

A recipe says "1, 2, 3" because the order matters. A grocery list uses bullets because you can buy the eggs before the milk. HTML makes you choose:

TagMeaningUse it for
<ol>ordered list (numbers)steps, rankings, countdowns
<ul>unordered list (bullets)ingredients, features, favorites
<li>one list itemevery item in either list

The list tag is the wrapper and the li tags are the items. Only li tags go directly inside a ul or ol, and every li has its own closing tag.

LEARNChanging the marker

The bullet or number in front of each item is the marker. Change it with list-style-type, written on the list tag (ul or ol), not on each li:

ListValues you can use
uldisc (the default dot), circle, square, none
oldecimal (1, 2, 3), upper-roman (I, II, III), lower-roman, upper-alpha (A, B, C), lower-alpha

LEARNBlock and inline

Every tag behaves in one of two ways. Block tags (h1 to h6, p, ul, ol, li, hr) start on a new line and take the whole width. Inline tags (span, strong, em, a, img) stay inside the line and only take the room they need, like words.

The style display switches a tag: display: inline makes a block act like a word.

LEARNA menu in a row

Every menu bar on the internet is a list turned sideways. Put list-style-type: none on the ul to remove the bullets, and display: inline on every li so they sit in a row.

BUILD ITGuided Build: Make It Yourself

Follow the steps in order. Type every line yourself: typing is how the tags stick. Check your page against what the browser should show.

A scout troop wants a Camping Trip page with three lists: a packing list with bullets, a numbered list of steps, and a menu that sits in a row.

Step 1: Set up the page

<h1>Camping Trip</h1>
<h2>Pack These</h2>
<h2>Cooking Steps</h2>
<h2>Menu</h2>
YOU DO
  1. From memory, type the skeleton with a title that says Camping Trip, and the body tags
  2. Inside the body type a heading 1 that says Camping Trip, then three heading 2s, in this order: Pack These, Cooking Steps and Menu. Leave room under each one

Step 2: A list with bullets: ul

An unordered list (ul) has bullets, and is used when the order does not matter. Every item is its own li tag. Only li tags go directly inside a ul.

<ul>
<li>Tent</li>
<li>Sleeping bag</li>
<li>Flashlight</li>
</ul>
YOU DO
  1. Right under Pack These, type an unordered list: the ul tags, with three li items inside: Tent, Sleeping bag and Flashlight

Step 3: Change the bullet style

The marker is the bullet or number in front of each item. Change it with list-style-type on the list tag. The values for a ul are disc (the default), circle, square and none.

<ul style="list-style-type: square">
YOU DO
  1. Add the style list-style-type: square to the ul tag (not to the li tags)

Try it: change square to circle and back.

Step 4: A numbered list: ol

An ordered list (ol) is numbered and is used when the order matters, like steps. Its markers are decimal (1, 2, 3, the default), upper-roman, lower-roman, upper-alpha and lower-alpha. Bold and italic tags go inside the li.

<ol style="list-style-type: upper-roman">
<li><strong>Build</strong> <em>a small fire</em></li>
<li>Roast the marshmallows</li>
<li>Eat</li>
</ol>
YOU DO
  1. Right under Cooking Steps, type an ordered list (ol) with three li items: Build a small fire (with the word Build in a strong tag and the words a small fire in an em tag), Roast the marshmallows and Eat
  2. Give the ol the style list-style-type: upper-roman

Step 5: A menu in a row

Some tags are block (they start on a new line and fill the width) and some are inline (they stay in the line, like words). A li is block, so a list stacks. The style display: inline turns a block into an inline tag. Every menu bar on the internet is a list turned sideways: no bullets, and every li inline.

<ul style="list-style-type: none">
<li style="display: inline">Home</li>
<li style="display: inline">About</li>
<li style="display: inline">Contact</li>
</ul>
YOU DO
  1. Right under Menu, type a second ul with three li items: Home, About and Contact
  2. Give the ul the style list-style-type: none so the bullets disappear
  3. Give every li the style display: inline

Try it: remove display: inline from one li. It drops to its own line, and the other two stay in the row.

Step 6: Check and submit

YOU DO
  1. Look at the line numbers on the left of your code. No line number should be red: a red number means a problem on that line, like a tag that is not closed or is misspelled
  2. Choose your class period at the top, then click Submit

br a line break: starts a new line inside a paragraph
character one letter, number, emoji or symbol of text
color list the page of all 140 color names, with a swatch for each

emoji a small picture-like character, like 🍕, that is really text

font family a group of fonts with the same feel: serif, sans-serif, monospace or cursive
font-family the property that picks which font the text uses
font-size the property that sets how big the letters are, written in px

hr a horizontal rule: a line across the page

HTML HyperText Markup Language: the tags that give a page its structure
img the tag that puts a picture on the page; it stands alone
inline a tag that stays inside the line, like a word
li one list item; the only tag allowed directly inside a ul or ol
link tag a tag in the head that loads something for the page, like a font
link text the words between the opening and closing a tag: the part people click
marker the bullet or number in front of each item
nesting putting one tag inside another and closing the inside one first
ol an ordered (numbered) list: order matters
property what you want to change, like color
px pixels: the unit for sizes, like 40px
span marks a few words so you can style only them
src the attribute that holds the web address of the picture
strong makes text bold (in this class bold is always strong)
style attribute holds design instructions for one tag: style="color: red"
symbol a character that is not a letter or number, like © ™ ♥ → ★
tag a word in angle brackets, like <p>
target the attribute that chooses where the link opens
text-align moves text to the left, center or right
text-transform changes the letter case on the page without changing your code
thickness how thick the line is, in px
ul an unordered (bulleted) list: order does not matter

width the style that sets how wide a picture is
