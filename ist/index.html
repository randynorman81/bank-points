Year-Long Pacing Guide

A 36-week plan (two 18-week semesters) for the whole course. Weeks are a target, not a promise — testing days, assemblies, and breaks can shift things a few days either way.

Semester 1

Weeks 1–3
Unit 1: Digital Footprint
  • CIA triad, OSINT, 4th Amendment rights, your phone’s footprint
  • Password strength, online tracking, copyright, hacking ethics, common security problems
  • Unit 1 Study Guide, then Unit 1 Test at the end of week 3
Weeks 4–6
Unit 2: Intro to Programming (Karel)
  • Meet Karel, functions, top-down decomposition, commenting and abstraction
  • For loops, if/else, while loops, debugging, indenting, control-structure review
  • Unit 2 Test at the end of week 6
Weeks 7–9
Unit 3: Computing Basics
  • Internal components, peripheral devices (ports, Bluetooth, NFC), software vs. hardware
  • File and folder management, the birth of the internet (surface, deep, and dark web), future of computing
Weeks 10–12
Unit 4: Operating Systems and Software
  • Four lessons: what an OS does, Windows vs. macOS vs. Linux, OSes beyond the desktop, and software licenses and piracy
Weeks 13–15
Unit 5: Project — IT Professional
  • Build a knowledge base, then star in your own how-to video
Weeks 16–18
Unit 6: Web Design – HTML (part 1)
  • HTML skeleton, creation and editing tags, inline styling, lists, links (6.1–6.6)
Week 18
Semester 1 review and exam Exam

Semester 2

Weeks 19–20
Unit 6: Web Design – HTML (part 2)
  • Images, box model, colors, display, div tag, tables (6.7–6.12)
  • Unit 6 Test (6.13)
Weeks 21–22
Unit 7: Intro to CSS
  • External CSS and classes, CSS by ID, Unit 7 Test
Weeks 23–26
Unit 8: Complete Website Project
  • Plan, build, and polish your first full website using HTML and CSS
Weeks 27–31
Unit 9: Intro to JavaScript
  • Hello World, variables, user input, math, random numbers, functions (JavaScript Basics Quiz)
  • Canvas, graphics, objects, positioning (JavaScript Graphics Quiz)
Weeks 32–33
Unit 10: Intro to Web Dev (jQuery / CMS)
  • The script tag, using the DOM, intro to jQuery
Weeks 34–36
Final review, project showcase, and course final Exam
