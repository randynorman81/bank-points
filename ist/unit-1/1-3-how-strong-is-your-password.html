Key Vocabulary

Entropy
A measure of how unpredictable a password is. More possible characters and more length both raise entropy — and entropy, not "looking complicated," is what actually determines how many guesses an attacker needs.
Brute-force attack
Trying every possible combination of characters, one by one, until one works. Short passwords fall fast because there simply aren't many combinations to try; each extra character multiplies the total.
Dictionary attack
Instead of guessing randomly, the attacker starts from real words (and leaked password lists) and applies predictable tweaks — capitalizing a letter, adding "123," swapping symbols in. Much faster than brute force against passwords based on real words.
Leetspeak substitution
Swapping look-alike characters into a word, like @ for a or 0 for o (e.g. P@ssw0rd!). Feels clever, but cracking tools check these substitutions automatically — it barely slows an attacker down.
Hash & rainbow table
Sites don't store your actual password — they store a scrambled version of it called a hash. But if your password is common, an attacker can pre-compute the hashes of common passwords into a lookup chart (a rainbow table) and find yours instantly.
Credential stuffing
When one site gets breached, attackers try that same username + password on every other site they can think of. Reusing a password turns a single leak into access to all of your accounts.
MFA (multi-factor authentication)
A second proof of identity beyond your password — usually a code sent to your phone or an app. Even if an attacker has your exact password, MFA can still stop them from logging in.
Keylogger
Software that secretly records every key you press, including passwords, and sends the log to an attacker. No password is "strong enough" to beat this, since the attacker never has to guess — they just read what you typed. This is why you should never install software or browser extensions from sources you don't trust.
Passphrase
A string of random, unrelated words (like river-comet-anchor) instead of one word with substitutions. Longer than a typical password, easier to remember, and usually far harder to crack.
Password manager
A tool that generates and remembers a unique, random password for every site behind one master password you memorize. Solves the reuse problem that makes credential stuffing possible.
