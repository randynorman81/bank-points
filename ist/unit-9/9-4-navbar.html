9.4 — Navbar

🔔 Bell Ringer — Think About It
  1. Back in the HTML unit, you built a row of links using divs and display: inline-block, following the 98% rule. What do you think Bootstrap's navbar class does for you automatically that you used to have to build by hand?
  2. Almost every real website has its navigation bar in the exact same spot: top of the page, links on the right or center. Why do you think web design converged on that one layout instead of everyone doing something different?
  3. A navbar built with Bootstrap automatically turns into a "hamburger" menu icon on a small phone screen. Why is that behavior something you'd want built into a framework instead of coding yourself every time?

Notes

A navbar is the navigation bar at the top of a page. Bootstrap builds one from a <nav> tag with a few specific classes:

<nav class="navbar navbar-expand-lg navbar-dark bg-dark"> <div class="container"> <a class="navbar-brand" href="#">My Site</a> <div class="navbar-nav"> <a class="nav-link" href="#">Home</a> <a class="nav-link" href="#">About</a> <a class="nav-link" href="#">Contact</a> </div> </div> </nav>
ClassGoes onWhat it does
navbar<nav>Turns the tag into a Bootstrap navbar
navbar-dark bg-dark<nav>Dark background with light text (leave off for a light navbar)
navbar-brandThe site name/logo linkBigger, bolder styling for the brand link
nav-linkEach linkStandard navbar link spacing and hover color

Notice the navbar uses container inside it, from 9.2 — Bootstrap components are built by combining the same handful of classes in new ways.

Look up these terms if anything above is unclear: navbar, navbar-brand, nav-link.
