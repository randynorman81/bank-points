9.2 — The Grid System

🔔 Bell Ringer — Think About It
  1. Bootstrap's grid splits every row into exactly 12 columns. Why do you think 12 was chosen instead of, say, 10 or 100?
  2. You already built columns with CSS Grid using fr units. Bootstrap's grid uses fixed column counts (like "this box takes up 6 of 12 columns") instead. What's the tradeoff between the two systems?
  3. A 3-column layout on a laptop often needs to become 1 column stacked on a phone. Why would a framework build "shrink to one column on small screens" in by default, instead of leaving that to every developer to figure out?
  4. If you could only pick one, would you rather use CSS Grid (from Unit 8) or Bootstrap's grid for a real client project? What would make you choose one over the other?

Notes

Bootstrap's grid system is built from three nested pieces, always in this order:

ClassGoes onWhat it does
containerA wrapping <div>Centers your content and adds side padding, with a max width
rowA <div> inside the containerStarts one horizontal row of columns
col / col-6A <div> inside the rowOne column. Every row totals 12 columns
<div class="container"> <div class="row"> <div class="col-6">Left half</div> <div class="col-6">Right half</div> </div> </div>
  • col-6 + col-6 = 12, so those two sit side by side, each taking half the row.
  • col-4 three times also equals 12: three equal columns.
  • Plain col (no number) splits the leftover space evenly among however many you use.
  • Responsive versions exist too, like col-md-6: 6 columns wide on medium screens and up, but full width (stacked) on phones. This is why Bootstrap layouts automatically stack on mobile.

Look up these terms if anything above is unclear: container, row, column, responsive breakpoint.
