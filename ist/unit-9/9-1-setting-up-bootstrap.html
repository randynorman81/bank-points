Notes

Bootstrap is a CSS framework: a giant, pre-written stylesheet full of ready-made classes for buttons, layouts, navigation bars, cards, and more. Instead of writing style="..." or your own CSS rules, you just add the right class name to a tag and Bootstrap's styles apply automatically.

  • Bootstrap is loaded the same way you already load any external CSS file: a <link> tag inside <head>, pointing at Bootstrap's file instead of your own.
  • Because Bootstrap is hosted on a CDN (Content Delivery Network), you don't upload any files — you just link to the address Bootstrap publishes.
  • The moment the link is added, default elements like <body> text and spacing already look different, even before you add a single class.
  • Bootstrap classes and your own CSS can be used together on the same page — a class from Bootstrap, and a class you wrote yourself, can both live on the same tag.
Common mistake: forgetting the Bootstrap <link> tag before adding Bootstrap classes. If the classes don't seem to do anything, check the head first.

Look up these terms if anything above is unclear: framework, CDN, Bootstrap.
