9.3 — Typography, Colors + Buttons

🔔 Bell Ringer — Think About It

Notes

Bootstrap ships a set of utility classes: small, single-purpose classes that each do one styling job, meant to be combined.

ClassWhat it does
text-centerCenters text (like text-align: center)
text-mutedLighter gray text, for secondary info
fw-boldBold text
text-primary / text-danger / text-successColors text using Bootstrap's theme colors
bg-primary / bg-dark / bg-lightSets a background color from the same theme

Buttons use the btn class plus one theme color class:

<button class="btn btn-primary">Click Me</button> <a href="#" class="btn btn-danger">Delete</a>
  • btn alone does nothing visible — it always needs a color class like btn-primary or btn-success too.
  • Bootstrap's theme colors: primary (blue), secondary (gray), success (green), danger (red), warning (yellow), info (light blue).
  • A button class works on <button> and <a> tags — useful, since a link styled as a button is still a link underneath.

Look up these terms if anything above is unclear: utility class, theme color, btn.
