LESSON6.1

Setting Up Bootstrap

One link tag turns on a whole stylesheet: no classes needed to see the difference.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson
GOALAdd Bootstrap to a page with one link tag, see what changes before you add a single class, and let your own style.css win by linking it second.
WORDS TO KNOW
framework a big collection of ready-made code; Bootstrap is a CSS framework
Bootstrap a giant pre-written stylesheet full of ready-made classes
CDN a network of servers that hosts files so you only link to their address
link tag the head tag that plugs a stylesheet into the page
ON THE SITENotes: 9-1-setting-up-bootstrap  ·  Walkthrough: Robotics Club  ·  Assignment: Duolingo Study Tips  ·  Quiz game: 6.1

LEARNTwo units of your own CSS, and now a shortcut

You have spent two units writing every style yourself. A framework is a big collection of ready-made code you can reuse. Bootstrap is a CSS framework: a giant, pre-written stylesheet full of ready-made classes for layouts, buttons, navigation bars and forms. Instead of writing rules, you add the right class name to a tag and Bootstrap's styles apply.

Millions of real websites use Bootstrap, which is why a page built with it looks professional by default. The tradeoff: pages built from the same framework can start to look alike.

LEARNLinking Bootstrap

Bootstrap is loaded the same way you load any external CSS file: a link tag in the head. Because Bootstrap is hosted on a CDN (Content Delivery Network), you do not upload any files: you link to the address Bootstrap publishes. This course uses version 5.3.9.

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.9/dist/css/bootstrap.min.css" rel="stylesheet">

PartRule
whereinside the head, under the title
closingno closing tag: it stands alone
addressthe exact https:// address of Bootstrap's css file
official copythe one on getbootstrap.com has two extra attributes, integrity and crossorigin. They are optional: the short link works the same

LEARNWhat changes before you add a class

The moment the link is added, plain tags look different: a modern sans-serif font replaces the serif default, headings get lighter, lists and paragraphs get comfortable spacing. You have written no classes yet. Everything else in this unit is about adding classes to get more.

LEARNYour own CSS and Bootstrap together

Bootstrap and your own rules can live on the same page, even on the same tag. When two rules are equally specific, the one that comes last wins. So link your own style.css under the Bootstrap link:

<link href="...bootstrap.min.css" rel="stylesheet"> then <link rel="stylesheet" href="style.css">

Bootstrap first, your own file second. If you swap them, Bootstrap's rule comes last and wins.

Try it: the heading turns tomato. Now swap the two link lines so style.css is above the Bootstrap link: the heading goes back to Bootstrap's dark color, because Bootstrap's rule is now the later one. Put them back.

LESSON6.2

The Grid System

Twelve columns, three nested pieces, and layouts that adapt to phones by themselves.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson
GOALBuild layouts with Bootstrap's 12-column grid: a container, rows inside it, and columns inside each row, including columns that stack on phones.
WORDS TO KNOW
grid Bootstrap's system for laying out content in rows and columns
container the wrapper that centers your content and adds side padding
row one horizontal line of columns
column a div with a col class; every row has 12 columns to share
breakpoint the screen width where a layout changes (768 pixels for md)
ON THE SITENotes: 9-2-the-grid-system  ·  Walkthrough: Team Dashboard  ·  Assignment: Airbnb Trip Planner  ·  Quiz game: 6.2

LEARNThree nested pieces, always in this order

Bootstrap's grid is built from three pieces that nest in this order:

ClassGoes onWhat it does
containera wrapping divcenters your content and adds side padding, with a maximum width
rowa div inside the containerstarts one horizontal line of columns
col-6a div inside the rowone column; every row has 12 to share
container, then row, then columns. Skip a piece and the grid stops working properly.

LEARNCounting to 12

The number in col-6 says how many of the row's 12 columns that column takes.

WrittenResult
col-6 + col-66 + 6 = 12: two halves
col-4 ×34 + 4 + 4 = 12: three equal columns
col-4 + col-8a narrow and a wide column
plain col (no number)shares the leftover space evenly among however many you use
more than 12 in totalthe extra column wraps to a new line

LEARNColumns that stack on phones

A column like col-6 keeps its share on every screen, even a phone. A responsive column, like col-md-6, takes its share only on medium screens and wider (768 pixels and up). Below that breakpoint it becomes full width, so the columns stack. This is why Bootstrap layouts adapt to phones with no extra work from you.

LEARNRows are separate lines

Each row is its own line. Two rows never affect each other: put a row of col-4 columns under a row of col-6 columns and both rows fill their own 12.

LESSON6.3

Typography, Colors and Buttons

Tiny classes that each do one job: combine them instead of writing CSS.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson
GOALStyle text, backgrounds, spacing and buttons with Bootstrap utility classes: tiny classes that each do one job and combine on a tag.
WORDS TO KNOW
utility class a small, single-purpose class meant to be combined with others
theme color one of Bootstrap's named colors: primary, secondary, success, danger, warning, info
btn the class that makes a tag a Bootstrap button; it needs a color class too
padding and margin utilities p-3 (padding) and mt-3, mb-3 (margin on the top or bottom)
ON THE SITENotes: 9-3-typography-colors-and-buttons  ·  Walkthrough: Pixel Arcade  ·  Assignment: YouTube Channel Hub  ·  Quiz game: 6.3

LEARNOne class, one job

A utility class does one styling job. You combine several on one tag, instead of writing a CSS rule for each.

ClassWhat it does
text-centercenters text
text-mutedlighter gray text for secondary information
fw-boldbold text
text-primary, text-danger, ...colors the text with a theme color
bg-primary, bg-dark, bg-light, ...sets the background to a theme color
text-whitewhite text

LEARNThe six theme colors

Bootstrap limits you to a handful of named colors on purpose, so pages look consistent: primary (blue), secondary (gray), success (green), danger (red), warning (yellow) and info (light blue). They work after text-, bg- and btn-, like btn-warning.

bg-dark only sets the background. It does not change the words, so on a dark box you must add text-white, or the words stay dark and cannot be read.

LEARNSpacing: p, mt and mb

The number 0 to 5 is the size: bigger is more space.

ClassWhat it does
p-3padding on all four sides, inside the box
mt-3margin on the top, outside the box
mb-3margin on the bottom, outside the box

LEARNButtons

A Bootstrap button is the class btn plus one theme color class: btn btn-primary. It works on a button tag and on a link, and a link styled as a button is still a link underneath.

btn alone has padding but no color, so it looks like plain text. A color class alone, like btn-primary, is not a Bootstrap button either.

WORDS TO KNOW
navbar the navigation bar at the top of a page
navbar-brand the class for the site name or logo link

LEARNA plain field looks tiny

A plain browser field is small and cramped. Bootstrap fixes it with two classes: form-control on the field and form-label on its label.

ClassGoes onWhat it does
form-labela labelstandard spacing above the field
form-controlan input or a textareafull width, padded, clean border

LEARNThe shape of one field

LEARNLinking a label to its field

Give the field an id and give the label a for with the same name. Then clicking the label selects the field, and people who use screen readers hear what each field is for. If the names do not match, the link does nothing.

A visible label is better than placeholder text alone, which disappears as soon as you type.

Glossary

Bootstrap a giant pre-written stylesheet full of ready-made classes
breakpoint the screen width where a layout changes (768 pixels for md)
btn the class that makes a tag a Bootstrap button; it needs a color class too
card a flexible content box built from classes on nested divs
card-body the padding around the title, text and button inside a card
card-img-top a picture that fills the width of the card at the top
card-title and card-text the classes for the heading and the paragraph in a card
CDN a network of servers that hosts files so you only link to their address
column a div with a col class; every row has 12 columns to share
container the wrapper that centers your content and adds side padding
form the tag that wraps a group of fields and a submit button
form-control the class that makes an input or textarea full width, padded and clean
form-label the class for the label above a field
framework a big collection of ready-made code; Bootstrap is a CSS framework
grid Bootstrap's system for laying out content in rows and columns
label for and id the pair that links a label to its field
link tag the head tag that plugs a stylesheet into the page
nav-link the class for each link in the menu
navbar the navigation bar at the top of a page
navbar-brand the class for the site name or logo link
navbar-expand-lg puts the links in a row on screens 992 pixels wide and up
padding and margin utilities p-3 (padding) and mt-3, mb-3 (margin on the top or bottom)
row one horizontal line of columns
theme color one of Bootstrap's named colors: primary, secondary, success, danger, warning, info
utility class a small, single-purpose class meant to be combined with others
