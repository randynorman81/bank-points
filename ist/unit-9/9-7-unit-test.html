9.7 — Unit Test

🔔 Bell Ringer — Think About It
  1. Out of everything this unit — the grid, buttons, navbar, cards, and forms — which piece do you think you'll reuse the most on your own future projects?
  2. You started this unit writing zero Bootstrap and ended it with a navbar, a card layout, and a form, almost entirely from class names. How does that compare to how much CSS you had to hand-write for the same result?
  3. Bootstrap can build a professional-looking site fast, but every Bootstrap site risks looking similar to every other one. How would you make a Bootstrap-built site feel more like "yours"?
  4. If you were advising a beginner: write your own CSS first, or learn Bootstrap first? Now that you've done both units, what's your answer, and why?
