For Loops

A for loop repeats a set of commands a fixed number of times, without you typing them over and over. This is how you turn "move four times" into three short lines instead of four.

00

Why Not Just Copy-Paste?

You could write move(); four times in a row to move Karel four squares. It works. But it's easy to miscount, hard to change later, and just plain repetitive to type. A for loop says "do this exact thing, this many times" in one line.

Without a loop

move(); move(); move(); move();

With a loop

for (var i = 0; i < 4; i++) { move(); }

Both do the exact same thing. The loop version is shorter, and if you need to change "4" to "10" later, you only change it in one place.

01

Breaking Down the Loop's First Line

The line for (var i = 0; i < 4; i++) has three parts, separated by semicolons, that control the loop.

PartWhat it means
var i = 0Start counting at 0. i is just a name for the counter — short for "index."
i < 4Keep looping as long as this is true. Once i reaches 4, the loop stops.
i++After each pass through the loop, add 1 to i.
Walk through it: i starts at 0 (true, 0 < 4, run the loop body). i becomes 1 (true, run again). i becomes 2 (true, run again). i becomes 3 (true, run again). i becomes 4 (false, 4 is not less than 4 — stop). That's exactly 4 runs.
02

03

Putting Multiple Commands Inside a Loop

Everything between the loop's curly braces { } runs every single pass — not just one command.

function main() { for (var i = 0; i < 4; i++) { move(); putBall(); } }

This moves Karel forward one square, drops a ball, moves forward one square, drops a ball — four times total. Not "move 4 times, then drop 4 balls" — the two commands are grouped together and repeated as a pair.

Combining with functions: a for loop can also call your own functions, like turnRight();, the exact same way it calls built-in commands.
04

Common Mistakes

Mistake 1

Off-by-one errors

Writing i <= 4 instead of i < 4 runs the loop 5 times instead of 4. Double-check your comparison.

Mistake 2

Forgetting a semicolon between the three parts

for (var i = 0, i < 4, i++) // wrong

The three parts of a for loop are separated by semicolons, not commas.

Mistake 3

Running Karel into a wall

A loop just repeats faster — it doesn't check if the repeated command is actually safe. If move(); would crash on its own, it'll crash inside a loop too.

A for loop repeats a fixed number of times. Three parts control it: start, stop condition, and how much to count by.
