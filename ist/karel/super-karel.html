KAREL NOTES  /  LESSON 8

Super Karel

A second, upgraded version of Karel that already comes with some of the functions you'd otherwise have to build yourself — including the turn_right() you wrote back in Lesson 4.

00

What's Different About Super Karel?

Super Karel is the exact same robot, in the exact same kind of world — it just comes with a few extra built-in commands that regular Karel doesn't have, because they're common enough that CodeHS decided to build them in for you.

CommandBuilt into regular Karel?Built into Super Karel?
move()YesYes
turn_left()YesYes
turn_right()No — you had to write itYes, already built in
turn_around()No — you had to write itYes, already built in
Notice: turn_right() and turn_around() are exactly the two functions you already know how to build yourself, from Lessons 3 and 4. Super Karel just saves you from writing them again.
01

Same Idea, Less Setup

Compare the same program, written for regular Karel vs. Super Karel:

Regular Karel

def turn_right(): turn_left() turn_left() turn_left() def main(): move() turn_right() move()

Super Karel

def main(): move() turn_right() move()

Same result. Super Karel just skips the step of writing turn_right() yourself, since it already exists.

02

Why Learn to Build It First, Then Use the Shortcut?

This is on purpose. If CodeHS had given you turn_right() from day one, you'd never have learned what a function actually is or how to build your own. Now that you understand it, Super Karel is a reasonable shortcut — not a mystery.

Real-world parallel: this happens constantly in programming. You learn how something works by building a simple version yourself, and later you're handed a ready-made, more powerful version — because by then you actually understand what it's doing.
03

Common Mix-Ups

Mix-up 1

Assuming every extra command exists

Super Karel adds turn_right() and turn_around() — not an unlimited set of new commands. If you need something else, you still write your own function.

Mix-up 2

Forgetting how turn_right() actually works

Even though it's built in now, it's still doing the same three turn_left() calls underneath — that's still abstraction from Lesson 7 at work.

Super Karel isn't magic — it's the exact functions you already learned to build, just built in ahead of time.

That's every concept lesson in this unit. From here, it's for loops, if/else, while loops, and putting it all together.
