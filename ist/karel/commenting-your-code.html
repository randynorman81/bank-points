Commenting Your Code

A comment is a note in your code that the computer completely ignores. It's not for Karel — it's for you, and for anyone else who ever reads your program.

00

What Is a Comment?

In Python, anything after a # symbol on a line is a comment. Karel (and Python) skips right over it — it has zero effect on what the program does. It exists purely so a human reading the code understands what's going on.

def build_tower(): # This function stacks 4 balls on one corner put_ball() put_ball() put_ball() put_ball()
Think of it like a sticky note: you're leaving yourself (or a teammate, or your teacher grading it) a quick explanation, right next to the code it's talking about.
01

Two Ways to Write a Comment

On its own line

A comment that takes up the whole line, usually right above the code it explains.

# Move to the second tower spot move() move()

At the end of a line

A short comment tacked onto the end of a line of real code, explaining just that one line.

move() # walk past the first wall
02

Good Comments vs. Bad Comments

A comment should explain something that isn't obvious just from reading the code — usually the why, not just the what.

Not very useful

# move forward right above move() — the code already says that. This comment repeats the obvious instead of adding anything.

Genuinely useful

# skip the 2nd corner, it already has a ball right above move() — this explains a reason a reader couldn't guess just by looking at the command.

03

When to Comment

Do

Label each function's job

One line above a function explaining what it's for, especially once you have several functions in one program.

Do

Explain a tricky part

If a section of code isn't obvious at a glance, a short note saves the next reader (including future you) real time.

Skip

Restating the obvious

You don't need a comment above every single line — that just adds clutter without adding information.

Good habit: write the comment for build_tower() at the same time you write the function — not days later when you've forgotten what it does.

The computer ignores comments completely. Humans don't — that's who they're for.
