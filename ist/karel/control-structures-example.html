Control Structures Example

A review, not a new idea: one real program that uses everything from this unit together — functions, loops, and conditionals — the way a real Karel program usually looks.

00

The Goal

Karel starts at one end of a street of unknown length. Walk forward, and for every corner: if there's a ball, pick it up. If there isn't, leave one. When Karel hits the wall at the end, turn around and stop.

Notice this goal is written in plain English first, before any code — exactly the top-down design habit from Lesson 5.
01

Breaking It Into Pieces

Plain English stepControl structure needed
Keep going until the wallwhile loop, checking frontIsClear()
At each corner, check for a ballif / else, checking ballPresent()
Turn around at the endYour own turnAround() function (or Super Karel's built-in one)
02

The Full Program

function main() { while (frontIsClear()) { if (ballPresent()) { takeBall(); } else { putBall(); } move(); } turnAround(); }

Read it top to bottom like a paragraph: "While the front is clear: if there's a ball, take it, otherwise put one down, then move. Once you hit the wall, turn around."

Notice what's doing what: the while loop controls how long this repeats (until a wall). The if/else controls which action happens each time (take vs. put). They're solving two different problems, working together.
03

Every Control Structure From This Unit

Lesson 4

Functions

A named, reusable block of commands — like turnRight() or the whole main() function itself.

Lesson 9

For loops

Repeat a fixed, known number of times.

Lessons 10–11

If / else

Choose between two paths based on a condition.

Lesson 12

While loops

Repeat until a condition becomes false — the number of times isn't known in advance.

Nearly every real program you write from here on will combine several of these — exactly like the example above.

Functions, loops, and conditionals aren't separate topics — real programs combine all of them together.

That's every Karel Notes lesson. From here, it's practice: build your own programs and see how these pieces fit together.
