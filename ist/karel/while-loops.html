While Loops

A for loop repeats a fixed number of times. A while loop repeats for as long as a condition stays true — perfect for when you don't actually know the number in advance.

00

When You Don't Know "How Many"

A for loop needs an exact count: "do this 4 times." But what if you just want Karel to walk forward until it hits a wall — and you don't know how many squares that'll take? That's exactly what a while loop is for.

function main() { while (frontIsClear()) { move(); } }

Read it as: "while the front is clear, keep moving." Karel checks the condition, and if it's true, runs the loop body, then checks again — over and over, until the condition finally becomes false.

01

For Loop vs. While Loop

for loopwhile loop
Use when…You know the exact number of repeatsYou're repeating "until something happens"
Stops when…The counter reaches its limitThe condition becomes false
Karel example"Move 4 times""Move until you hit a wall"
Rule of thumb: if you can count exactly how many times before you even run the program, use a for loop. If it depends on what Karel actually finds, use a while loop.
02

A Realistic Example

Walk forward, picking up every ball along the way, until hitting a wall.

function main() { while (frontIsClear()) { if (ballPresent()) { takeBall(); } move(); } }

This works no matter how long the street is — 3 squares or 30. The while loop keeps going exactly as long as it needs to.

03

The Danger: Infinite Loops

If a while loop's condition never becomes false, the loop never stops — the program hangs forever. This is called an infinite loop, and it's the single most common while loop bug.

Example of a bug: while (ballPresent()) { move(); } — if move(); never actually affects whether there's a ball present, the condition might never change, and Karel just keeps running forever.
Fix

Make sure something inside the loop changes the condition

Every while loop needs something inside it that eventually makes the condition false — moving toward a wall, picking up the last ball, etc.

Fix

Trace it by hand first

Before running a while loop, walk through the first few passes on paper. If you can't picture how it would ever stop, it probably won't.

A while loop repeats until its condition goes false. Make sure something inside it actually gets you there.
