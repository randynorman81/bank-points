File & Folder Management

Every photo, document, app, and song on your computer is a file, and every file has an exact address. Here's how your computer actually creates, finds, saves, and (not really) deletes them — and why the file nobody wanted to keep is sometimes the one that gets someone caught.

00

Everything Starts at the Root

Picture your computer's storage as a tree, flipped upside down. The trunk is at the top — one single starting point called the root. Every folder branches off it, every file hangs off a folder, and no matter how deep you go, you can always trace a path back to that one trunk.

Folders (also called directories) are just labeled buckets. A file path is the full set of directions from the root to one exact file — like a street address, except every step of the way is a folder name.

Operating SystemWhat "Root" Looks LikeExample Path
WindowsEach drive has its own root: a letter + backslash (C:\, D:\). C:\ is usually where Windows itself lives.C:\Users\Randy\Documents\report.docx
macOS / LinuxJust one root for everything, written as a single forward slash: //Users/randy/Documents/report.docx

01

The Four Things Computers Do With Files

Every single interaction you have with a file — ever — is one of exactly four actions.

ActionWhat Happens Behind the ScenesHow You Do It
CREATEThe OS reserves a spot on the drive, writes the file's data, and adds an entry to the file system index (like adding a book to a library catalog).Save a new doc, take a photo, download something
USE (Open)The OS looks up the file in the index, finds where it lives on disk, and loads its contents into RAM so a program can read or edit it.Double-click an icon, open a project
STORE (Save)Changes held in RAM get written back to the disk. Until you save, your edits live only in temporary memory and vanish if power is lost.Ctrl+S / Cmd+S
DELETEMost systems just remove the index entry and mark the space "available." The actual data often stays until something new overwrites it.Drag to Trash, then empty it

Why "Save" Feels Instant: the Pantry & the Counter

You don't keep every can of food on your kitchen counter — you store it in the pantry, and only pull out what you're using right now.

Pantry — Storage (HDD/SSD)

Permanent. Everything stays here, organized on shelves, until you actually need it.

↔

Counter — RAM

Temporary workspace. Fast to use, but whatever's on it disappears when the power goes out.

Open a file and it gets copied from the pantry onto the counter. Edit it and only the counter version changes. Save and the updated counter version gets copied back into the pantry, replacing the old one — that half-used box of noodles goes back on the shelf.

HDD vs. SSD — Why One Feels Faster

HDD (Hard Disk Drive)

Takes longer, because a physical needle has to scrape along a spinning disk, physically searching for where the file was stored.

SSD (Solid State Drive)

All digital, no moving parts. The computer knows exactly where the file is instantly — which is why SSDs are so much faster.

02

The Deletion Mystery: Ghost Files

A suspect deletes a search history, a photo, a document — confident it's gone. It isn't. Not yet, and maybe not for a long time. This exact mistake is how a lot of real criminals get caught.

When you delete a file, the drive doesn't actually erase the data. It just marks that space as "available for reuse." The old file is still physically sitting there — recoverable with the right software — until something new happens to get written into that exact spot.

vacation_receipt.pdf — DELETED

Emptied from the Recycle Bin three weeks ago. Click to check if it's really gone.

Still recoverable.

The index entry is gone, and the icon disappeared from view — but the actual 1s and 0s are still sitting on the drive, untouched, waiting for new data to overwrite that exact spot. Forensic software can read them directly off the disk, no icon required.

Click to check
Forensic computing has tools that find these "ghost" files even when regular people can't. Your digital trail is almost always longer than you think — you can't choose which new file overwrites the old one, so there's no way to know for sure if a deleted file can still be recovered.
03

The Anatomy of a File Name

Every file name has two parts, split by a dot — and each part is written for a completely different reader.

project_proposal_v2.docx
Base name

The descriptive part you choose. Tells you what the file contains.

Extension

Tells the operating system what type of file it is, so it knows which app should open it.

✓ Do

  • Be descriptive but short — a name should answer "what is this?" at a glance
  • Use underscores or hyphens instead of spaces (my_essay.docx)
  • Use dates as YYYY-MM-DD so files sort correctly (2026-05-07_notes)
  • Use version numbers for drafts: _v1, _v2, _final
  • Stay consistent — one style, every file, every time
  • Group related files into clearly labeled folders

✕ Don't

  • Don't use spaces or symbols like / \ : * ? " < > | — the OS reserves these
  • Don't use vague names like doc1.docx or final_FINAL_v3.docx
  • Don't change the extension by hand — renaming .docx to .pdf doesn't convert it, just confuses the OS
  • Don't make names too long — some systems cap paths at 255 characters
  • Don't dump everything on the desktop — build folders
Build folders like a filing cabinet. Group by subject (School\CS_Principles\Unit4\) or by file type (Photos, Videos, Documents) — whichever helps you find things faster later.

The Extensions You'll Actually See

When you double-click a file, the OS reads its extension to decide which program should open it. That's the whole reason Windows sometimes asks "what app do you want to use?" — the extension was missing or unfamiliar. Pick a category:

ExtensionWhat It Is
.txtPlain text, no formatting. Opens in Notepad or any text editor — the simplest file type that exists.
.docxMicrosoft Word document. Holds formatted text, images, tables.
.pdfPortable Document Format — locks the layout so it looks identical on every screen.
.xlsxMicrosoft Excel spreadsheet. Rows, columns, formulas, charts.
.pptxMicrosoft PowerPoint slides.
.csvComma-separated values — a spreadsheet in its simplest plain-text form.
ExtensionWhat It Is
.jpg / .jpegCompressed photo format. Small file size, slight quality loss — used for nearly every photo online.
.pngLossless, with transparency support. Best for screenshots, logos, graphics.
.gifSupports simple animation — the format behind every meme reaction.
.svgMath-based, scalable vector image — stays sharp at any size. Common in web design and icons.
ExtensionWhat It Is
.mp3Compressed audio — the standard for music files for over 25 years.
.wavUncompressed, high-quality audio. Big file sizes — used by audio engineers and game developers.
.mp4The most common video format — plays in browsers, phones, almost everywhere.
.movApple's QuickTime format. iPhone videos save as .mov by default.
ExtensionWhat It Is
.htmlHyperText Markup Language — the structure of every web page.
.cssCascading Style Sheets — tells HTML what to look like: colors, fonts, layout.

ExtensionWhat It Is

.exeWindows executable — an actual program. Only run .exe files from sources you trust.

Every file has an address, a name with two jobs, and a past it doesn't fully let go of.

The path traces it back to the root. The base name is for you; the extension is for the OS. And "deleted" almost never means gone — just marked as space somebody else can use eventually. Future-you (and possibly a forensic investigator) will thank present-you for naming things clearly.
