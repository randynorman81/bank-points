3.4 — File and Folder Management

🔔 Bell Ringer — Think About It
  1. Search bars can find any file instantly now. Does that mean organizing files into folders is basically pointless in 2026, or is there still a reason to do it?
  2. A file extension like .jpg or .mp3 tells your computer how to open a file — but what would actually happen if someone secretly renamed a video file's extension to .txt?
  3. Everyone in this class probably names files differently ("essay," "essay2," "essay_FINAL," "essay_FINAL_v3"). Why does messy file naming become a real problem once you're working on a team?
  4. Your Downloads folder is famous for turning into total chaos. What does the way someone organizes (or doesn't organize) their files say about how they think?
