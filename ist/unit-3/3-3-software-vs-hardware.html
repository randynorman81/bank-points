3.3 — Software vs Hardware

🔔 Bell Ringer — Think About It
  1. You can update software with a download, but updating hardware usually means buying a new device. Is that a fair trade, or does it feel like companies benefit more than you do?
  2. An operating system is technically software, but it controls all the hardware underneath it. If the OS crashes, is that a hardware problem or a software problem?
  3. Could a piece of software exist with zero hardware to run it, even in theory? Could hardware be useful with zero software installed? What does that tell you about which one actually "matters" more?
  4. Old phones often get slower over time even though the hardware never physically changes. What does that tell you about how much power software really has over hardware?
