DNS (Domain Name System)

Computers only understand numbers. You only want to remember words. DNS is the translator that makes both sides happy.

DNS · domain name · IP lookup · caching
01

The Internet's Phonebook

An old phonebook let you look up a person's name to find their phone number — you never had to memorize the number itself. DNS does exactly that for the internet: you type a name like google.com, and DNS looks up the actual IP address behind it, like 142.250.80.46, so your device knows where to actually send the request.

02

Why the Second Visit Is Faster

Looking something up takes a little time. So your device, your router, and your ISP all keep a short-term memory of recent lookups — this is called caching. The next time you visit the same site (often for hours afterward), your device can skip the lookup entirely and reuse the answer it already has.

If DNS goes down, "the whole internet" can feel broken — even though it isn't.Every server could be running perfectly, but if nothing can look up the IP address behind a name anymore, no one can reach anything by typing a normal web address.
03

Vocab You Need

TermMeaning
DNSDomain Name System — translates domain names into IP addresses
Domain nameThe human-readable website name, like google.com
DNS lookupThe process of asking "what IP address goes with this name?" and getting an answer
CachingTemporarily remembering a recent lookup's answer so it doesn't have to be looked up again right away
