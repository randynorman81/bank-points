🔔 Bell Ringer — Think About It
  1. Computers only actually understand IP addresses, like 142.250.80.46 — not words. So why does typing "google.com" into a browser work at all?
  2. A phonebook lets you look up a person's name to find their phone number. What's the "phonebook of the internet" doing that's exactly the same idea?
  3. The very first time you visit a brand-new website, it usually loads slightly slower than the second time you visit it that same day. What do you think is being saved (cached) in between those two visits?
  4. If a company's DNS system goes down, people say "the website is down" — even though the actual website server might be running perfectly fine. Why would that happen?
