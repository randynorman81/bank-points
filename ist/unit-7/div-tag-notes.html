The Div Tag

The most used, and most important, tag in the world — and it does absolutely nothing visible on its own. A div's entire job is to group things together into one invisible box.

div · container · inline-block · vertical-align
01

Amazon Is Built Entirely of Divs

Open Amazon's homepage and you don't see raw text and images floating around — you see clean, organized sections. Every one of those sections is an invisible box: a div. The nav bar is a div. Inside it, the search box is its own smaller div. Every single product card is wrapped in a div to keep it separate from the others.

<div> nav bar: logo, search box, cart </div>
<div> hero banner </div>
<div class="card">
product 1
<div class="card">
product 2
<div class="card">
product 3
A div does nothing by itself — that's the whole point.It has zero style of its own. It exists purely to group other tags so you can style, move, or arrange them as one unit.
02

Mass Styling: Style the Box, Style Everything Inside

Put one style attribute on a div, and everything inside it inherits that look — instead of styling a heading, three paragraphs, and a list separately.

Code

<div style="background-color: #131921; color: white; padding: 14px;"> <h3>Box Heading</h3> <p>Both turn white automatically.</p> </div>

Output

Box Heading

Both turn white automatically.

03

Block by Default, Elastic Height

A div is a block element: it takes 100% width and starts a new line, exactly like a paragraph. But its height is elastic — it automatically stretches to fit whatever is inside it. You never set a height for a div full of content.

The exception: an empty div (no text, no images) collapses to 0 pixels tall and disappears completely. Give an empty div an explicit height (and usually a background color, so you can see it) if you need it to show up on its own.
<div style="height: 60px; background-color: #f97316;"></div>
04

Side-by-Side Columns (and the Baseline Bug)

Two divs in a row stack vertically by default. Give both display: inline-block; to sit them side by side. But watch what happens when one column has more text than the other:

Output

Two inline-block divs align by their text baseline, not their tops.Add vertical-align: top; to both columns to lock their top edges flush with each other.
05

Multi-Row Layouts: the 98% Rule

Building more than one row of columns takes three rules:

Rule 1

Stay at 98% or less

Combined widths on one line must leave a safety gap for built-in spacing.

Rule 2

Add an <hr> after the row

A horizontal rule (or any block tag) forces the next divs onto a fresh line.

Rule 3

Repeat for each row

New divs, same inline-block + vertical-align: top; pattern.

Skipping the <hr> is the most common mistake here — without it, the next row's divs just squeeze onto the end of the current row instead of starting fresh.
06

Common Mistakes

Wrong: width in px for a responsive layout

width: 400px;

Stays exactly 400px even on a tiny phone screen.

Right: width in % for columns

width: 45%;

Resizes automatically with the screen. Use px for height instead.

Wrong: two columns over 98%

width: 50%; /* + another 50% */

100% plus built-in spacing overflows — the second div drops to a new line.

Right: leave a safety gap

width: 48%; /* + another 48% */
07

Vocab You Need

TermMeaning
divA generic block container with no style of its own, used to group content
Container / grouping elementAnother name for what a div does: wraps related tags together
inline-blockThe display value that lets divs sit side by side while keeping a settable width/height
vertical-align: topLocks side-by-side columns to the same top edge
98% ruleKeep combined column widths at 98% or less to avoid overflow
