The Style Attribute

Plain black text on a white page gets old fast. In this lesson you will learn the one tool that changes how anything looks: the style attribute. Start by styling a page, then break your styles on purpose, then read the rules.

Inline Styling
Try it

Style It, Break It, Fix It

Type in the left box and watch the page change. Work through the six steps in order. Each one turns green when you finish it.

0 OF 6 STEPS DONE

Your code

The page

1

Add a color

Change <h1> to <h1 style="color: tomato;">. Then try other color names, like teal, navy, or hotpink.

You just used the style attribute. The style attribute goes inside the opening tag and changes how that one element looks.
2

Change the size

Add a second property to the h1: font-size: 48px; right after the color, inside the same quotes.

Two properties, one style attribute. Each property ends with a semicolon, which lets you chain as many as you want.
3

Style a paragraph

Give the paragraph its own style with at least two properties, like a color and a font-size.

Every element has its own style. Styling the h1 did not change the paragraph. You style each element you want to change.
4

Break it

Delete the semicolon between two of your properties. Look at the page. What happened to the second property?

The browser got confused. Without the semicolon it cannot tell where one property ends and the next begins, so it may ignore the whole style.
5

Fix it

Put the semicolon back. Both properties should work again.

Fixed. Debugging styles is mostly checking for a missing colon, semicolon, or quote.
6

Align and change the case

Add text-align: center; and text-transform: uppercase; to the h1.

You changed alignment and letter case. Neither one needed you to retype the words.
You just wrote CSS.Now let's put names to the pieces.
01

The Style Attribute Formula

An attribute gives an HTML tag extra instructions. The style attribute changes how an element looks. Using it inside a tag is called inline styling. It always follows this formula:

<h1 style="color: tomato;">Hello</h1>
Part 1

style

The attribute name. It tells the browser, "design instructions are coming."

Part 2

property

The feature you want to change, like color or font-size.

Part 3

value

The setting, like tomato or 48px.

Three punctuation rules

Rule 01

A colon :

Goes between the property and the value.

Rule 02

A semicolon ;

Goes after every value. It locks the setting in and lets you add more.

Rule 03

Double quotes " "

Wrap the whole style value.

The style attribute goes in the opening tag only.Put it after the tag name and one space. Never put it in the closing tag.
02

03

Font Size

The font-size property changes how big the text is. Size is measured in pixels, written px. A pixel is one tiny dot on your screen. Regular text is usually 16px.

Code

<p style="font-size: 14px;">Small</p> <p style="font-size: 28px;">Medium</p> <p style="font-size: 56px;">Big</p>

What the browser shows

Small

Medium

Big

  • Always write the number and px together with no space: 28px, not 28 or 28 px.
  • The biggest, most important text should have the biggest size. That is called a visual hierarchy.
04

Chaining Properties

You can put many properties in one style attribute. Finish each one with a semicolon, and keep them all inside the same pair of quotes.

Code

<p style="color: orange; font-size: 24px;"> Large and colorful text! </p>

What the browser shows

Large and colorful text!

The semicolon is a separator.Every time you finish a property and value, add a semicolon. Then you can start the next one before the closing quote.
05

Alignment and Letter Case

PropertyValuesWhat it does
text-alignleft, center, rightSets where the text sits across the width of the page. Left is the default.
text-transformuppercase, lowercase, capitalizeChanges the letter case. capitalize makes the first letter of every word a capital.

Code

<h2 style="text-align: center; text-transform: uppercase; color: navy;"> breaking news </h2> <p style="text-align: right;">Signed, the reporter</p>

What the browser shows

breaking news

Signed, the reporter

Why use text-transform instead of typing in capitals? If your teacher wants all headings to look normal instead of ALL CAPS, you change one word in the style instead of retyping everything.

06

Common Mistakes

Wrong: no semicolon between properties

<p style="color: red font-size: 20px;">

Right

<p style="color: red; font-size: 20px;">

Wrong: missing quotes

<p style=color: red;>

Right

<p style="color: red;">

Wrong: forgot px

<p style="font-size: 20;">

Right

<p style="font-size: 20px;">

Wrong: misspelled property

<p style="colour: red;">

Right

<p style="color: red;">

Wrong: style in the closing tag

</p style="color: red;">

Right: opening tag only

<p style="color: red;">text</p>

The Web Editor's Problems to fix list catches most of these and tells you the line number.
