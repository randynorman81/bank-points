Named Colors & Hex Codes

140 built-in names get you started fast. Hex codes unlock 16.7 million exact shades. This page shows you how to read a hex code, how to use one, where to find one, and how to build your own from scratch.

color · background-color · named colors · #RRGGBB
01

Two Ways to Name a Color

You could describe a color with a word almost anyone understands, like "red." Or you could describe it with exact numbers a computer can reproduce perfectly, down to the last shade. HTML lets you do both — the syntax never changes, only what you type after the colon.

color: tomato; /* a name */ color: #FF6347; /* the exact same color, as hex */
Both lines produce the identical color.Names are easy to read. Hex codes are exact and unlimited. Professionals use hex almost everywhere it matters.

03

What the 6 Characters Do

A hex code is a # followed by 6 characters. Those 6 characters are really three pairs, and each pair is the amount of one light: Red, Green, then Blue, always in that order.

#1BRED2AGREEN4ABLUE
Chars 1–2

Red

How much red light the screen shines. 00 = none, FF = as much as possible.

Chars 3–4

Green

How much green light. Same scale: 00 to FF.

Chars 5–6

Blue

How much blue light. Same scale: 00 to FF.

Your screen is made of tiny red, green and blue lights. A hex code tells every pixel how bright to make each of the three. Mix the three lights and you get every color you can see on a screen.

Order matters: Red, Green, Blue.Swap the pairs and you get a different color. #FF0000 is red, #0000FF is blue, and the only difference is which pair holds the FF.

Try some real ones and watch the swatch update. The three bars show how much of each light is in the color:

Reading trick: the closer a pair is to FF, the more of that light is mixed in. The closer to 00, the less. #FF0000 is pure red, #00FF00 is pure green, #FFFFFF is white (all three at max), #000000 is black (none of any).
04

Why Letters? Counting in Hexadecimal

"Hex" is short for hexadecimal, which means base 16. We normally count with 10 digits (0–9). Hexadecimal uses 16 digits. Since we only have ten number symbols, the extra six are the letters A through F.

Hex digit0123456789ABCDEF
Value0123456789101112131415

Why two characters per color? One hex digit only counts 0 to 15. Two hex digits side by side count 0 to 255 — that is 256 different brightness levels for each light. With three lights, that is 256 × 256 × 256 = 16,777,216 possible colors. That is where the "16.7 million" comes from.

How to turn one pair into a number

The left character is worth 16 each. The right character is worth 1 each. Multiply the left digit by 16 and add the right digit.

pair = (left digit × 16) + right digit 1B = 1 × 16 + 11 = 16 + 11 = 27 (B is 11) 2A = 2 × 16 + 10 = 32 + 10 = 42 (A is 10) 4A = 4 × 16 + 10 = 64 + 10 = 74 FF = 15 × 16 + 15 = 240 + 15 = 255 (the biggest pair) 00 = 0 × 16 + 0 = 0 = 0 (the smallest pair)

So #1B2A4A means 27 red, 42 green, 74 blue out of 255 each. Almost no red or green, a little more blue: a very dark blue.

You do not need to do this math to use a hex code. You copy one from a tool. The math only helps you read a code ("this one is mostly blue") and build one yourself.

06

Reading Hex Codes: Patterns to Know

ColorHexRedGreenBlueWhy
Red#FF000025500only red is on
Lime#00FF0002550only green is on
Blue#0000FF00255only blue is on
Yellow#FFFF002552550red + green light make yellow
Cyan#00FFFF0255255green + blue make cyan
Magenta#FF00FF2550255red + blue make magenta
White#FFFFFF255255255all three at full
Black#000000000all three off
Gray#808080128128128all three equal
Pattern 1

Same pair 3 times = gray

When red, green and blue are equal, no color wins, so you get a gray. #333333 is dark gray, #CCCCCC is light gray.

Pattern 2

Bigger pairs = lighter

Raise all three pairs and the color gets lighter. Lower all three and it gets darker. #800000 is dark red, #FF0000 is red, #FF8080 is light red.

Pattern 3

The biggest pair names the color

In #1B2A4A the blue pair (4A) is the biggest, so the color leans blue. In #E50914 the red pair (E5) is far bigger, so it leans red.

Darker, same hue (watch the red pair drop): #FF0000 → #800000 → #400000. Lighter (the other two pairs rise): #FF0000 → #FF8080 → #FFC0C0.

07

Using a Hex Code in Your HTML

A hex code goes anywhere a color name can go: after color: (text), after background-color:, or inside a border.

<h1 style="color: #FF6347;">Tomato Soup</h1> <p style="color: #FFFFFF; background-color: #1B2A4A;">Night mode</p> <h3 style="border: 3px solid #1DB954;">A green frame</h3>

The rules, every time

RuleRightWrongWhat the browser does with the wrong one
Start with ##FF6347FF6347ignores the whole color
Exactly 6 characters (3 pairs)#FF6347#FF634 or #FF63477ignores the whole color
Only 0–9 and A–F#1DB954#1DG954ignores the whole color
No spaces inside#FF6347#FF 6347ignores the whole color
No quote marks around itcolor: #FF6347;color: "#FF6347";ignores the whole color
Finish with a semicolon between stylescolor: #FF6347; font-size: 20px;color: #FF6347 font-size: 20px;ignores the broken style
"Ignores" means the style simply does not happen. There is no error message. The text just stays the normal color. If your color is not showing up, count the characters, check for the #, and look for a letter past F.
Upper or lower case? Both work. #ff6347 and #FF6347 are the same color. This course writes them in capitals so they are easy to read.

A 3-character shortcut you will see on other sites

If each pair is two identical characters, a code can be written with just one of each. The browser doubles every character: #F60 means #FF6600, and #0AF means #00AAFF. It only works when all three pairs are doubled characters. #FF6347 has no shorter form. In this class always write all 6 so your work is easy to check.

08

Finding a Hex Code

Nobody memorizes hex codes. You find them. Here are four ways, from easiest to most powerful.

Way 1

Google's color picker

Search color picker. Google shows a picker right in the results. Drag the rainbow slider for the base color, click in the square for the shade, and copy the HEX value (like #3B82F6).

Way 2

A color name's hex code

Looking at the 140 named colors? Every one has a hex code. The color name list in the 4.2 lesson shows both. tomato is #FF6347, gold is #FFD700, teal is #008080.

Way 3

Brand color databases

Companies have official colors. Sites like brandcolors.net list them. Spotify green is #1DB954, Netflix red is #E50914.

Way 4

Steal from any website (Chrome)

Right-click a page, choose Inspect, find the color in the Styles panel, and click the small colored square next to it. A picker opens with an eyedropper you can click on anything on screen. The code appears right there.

Guess a few brand colors, then click to reveal their hex codes:

Always paste the whole code, including the #. Pickers sometimes show the code without the #. Add it back before pasting it into your HTML.
09

Create Your Own Hex Code

You can build any color yourself by choosing how much red, green and blue you want, then writing each amount as a pair. Use the mixer to see it happen.

RED255FF
GREEN9963
BLUE7147
#FF6347
background-color: #FF6347;

Method 1: Build it from the three amounts

Step 1

Decide the three amounts

Pick a number from 0 to 255 for red, green and blue. (The sliders do this.)

Step 2

Turn each into a pair

Divide the number by 16. The whole-number answer is the left character. The remainder is the right character. (10 = A, 11 = B, 12 = C, 13 = D, 14 = E, 15 = F.)

Step 3

Write # then the pairs

Put the pairs in order: red, green, blue.

Make a bright orange: red 255, green 140, blue 0 RED 255 ÷ 16 = 15 remainder 15 → F and F → FF GREEN 140 ÷ 16 = 8 remainder 12 → 8 and C → 8C (12 is C) BLUE 0 ÷ 16 = 0 remainder 0 → 0 and 0 → 00 Hex code: #FF8C00
Make a sea green: red 32, green 178, blue 170 RED 32 ÷ 16 = 2 remainder 0 → 20 GREEN 178 ÷ 16 = 11 remainder 2 → B and 2 → B2 (11 is B) BLUE 170 ÷ 16 = 10 remainder 10 → A and A → AA (10 is A) Hex code: #20B2AA

Method 2: Start from a color you like and tweak it

This is how most designers really do it. Pick a hex code close to what you want, then change one pair at a time and look at the result.

You want…Change thisExample
more redraise the first pair #406080 → #C06080
less greenlower the middle pair #40A080 → #402080
more blueraise the last pair #406040 → #4060E0
a lighter shaderaise all three pairs a little #306090 → #70A0D0
a darker shadelower all three pairs a little #306090 → #102040
a duller, grayer colormove the three pairs closer together #E03020 → #A06050
Tip for matching colors that go together. Pick one main color, then make a lighter version for backgrounds and a darker version for text by raising or lowering all three pairs by the same amount. The page will feel like one family of colors.
