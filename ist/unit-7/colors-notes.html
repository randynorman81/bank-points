Named Colors & Hex Codes

140 built-in names get you started fast. Hex codes unlock 16.7 million exact shades. Same property, same syntax — just a different way of naming the color.

color · background-color · named colors · #RRGGBB
01

Two Ways to Name a Color

You could describe a color with a word almost anyone understands, like "red." Or you could describe it with exact numbers a computer can reproduce perfectly, down to the last shade. HTML lets you do both — the syntax never changes, only what you type after the colon.

color: tomato; /* a name */ color: #FF6347; /* the exact same color, as hex */
Both lines produce the identical color.Names are easy to read. Hex codes are exact and unlimited. Professionals use hex almost everywhere it matters.

03

How a Hex Code Actually Works

A hex code is # followed by 6 characters, split into three pairs: Red, Green, Blue. Each pair runs from 00 (none of that color) to FF (the max).

#1B2A4A
RED

Try a few real ones and watch the swatch update:

Reading trick: the closer a pair is to FF, the more of that color is mixed in. #FF0000 is pure red, #00FF00 is pure green, #FFFFFF is white (max of all three), #000000 is black (none of any).
04

Finding a Hex Code: Google Color Picker

Step 1

Search "color picker"

Google shows a full interactive picker right in the search results.

Step 2

Pick a shade

Click the gradient square, drag the hue slider for the base color.

Step 3

Copy the HEX field

Copy the code (like #3B82F6) and paste it after color: or background-color:.
