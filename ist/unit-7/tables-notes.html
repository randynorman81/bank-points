Tables

A table is a storage shelf split into rows and slots. You don't build columns directly — you build one row at a time, top to bottom, dropping items into each row left to right.

table · tr · th · td
01

Four Tags, Nested Like Dolls

Sports sites like ESPN use tables for player stats. Shopify uses them for pricing plans. Any time information truly belongs in rows and columns — not just "looks nice in a grid" — a table is the right tag.

<table> — the outer grid boundary
<tr> — one row, left to right
<th> or <td> — one cell
Tag 01

<table>

The master wrapper. Everything else lives inside it.

Tag 02

<tr> table row

One horizontal line of the grid. Only cells go directly inside a row.

Tag 03

<th> table header

A bold, centered title cell — usually the whole first row.

Tag 04

<td> table data

A normal content cell. Most of your table is made of these.

03

The Golden Rule of Alignment

Every row must have the same number of cells. If row 1 has 4 header cells, rows 2 and beyond must each have exactly 4 data cells — leave one out, and the table's borders distort and break.

04

Putting Other Tags Inside a Cell

A <td> can hold any other tag — links, images, even a whole list.

<td><a href="https://amazon.com">View Store</a></td> <td><img src="headphones.jpg" style="width: 50px;"></td> <td><ul><li>Noise Cancelling</li></ul></td>
Real sites do exactly this: ESPN's stat tables hold plain text, but a Shopify pricing table often has a link or button inside the last cell of every row.
