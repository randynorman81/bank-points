7.12 — Tables

Today's work is due by 11:59pm.

🔔 Bell Ringer — Think About It
  1. Web developers today are told never to use tables just to lay out a whole webpage — only to hold actual tabular data. Why would using the "correct" tag in the wrong situation still be considered bad practice?
  2. A table forces information into strict rows and columns, unlike a div which can hold anything in any shape. What kind of information would actually get harder to understand if you tried to force it into a table?
  3. th (table header) and td (table data) look nearly identical when rendered, but they mean very different things to a screen reader. Why does that invisible difference matter even if a sighted user could never tell?
  4. Think of a real table you've seen recently (a class schedule, a sports scoreboard, a grade report). What would be lost if that information had to be crammed into regular paragraphs instead?
