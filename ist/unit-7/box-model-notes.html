Unit 7 Notes  /  Lesson 7.1

The Box Model

Every single element on a webpage — no matter how round or oddly shaped it looks — is secretly a rectangular box underneath. Learn the four layers every box is built from, and why a border isn't as free as it looks.

content · padding · border · margin
01

Four Layers, Like a Framed Photo

Picture a photo you're getting ready to hang on an art room wall. The photo itself is the picture. Around it sits a cardboard matte — clean spacing between the photo and the frame. Around the matte sits the wooden frame itself. And around the whole framed piece is empty wall space, keeping it from touching the next picture over. Every box on a webpage is built exactly the same way.

Layer 1

Content → the photo

The actual text or image. You size it with width.

Layer 2

Padding → the cardboard matte

Space inside the frame. It takes on the element's own background-color.

Layer 3

Border → the wooden frame

The outline that wraps the padding and content: thickness, style, color.

Layer 4

Margin → the wall space

Space outside the frame. Always transparent — it can never take a background color.

Try it: pick a layer below and watch it grow around the photo.

Content Padding Border Margin (transparent)
Padding takes the background color. Margin never does.That single fact is how you can tell them apart in a screenshot, even with no code in front of you.
02

All Four Sides, Two Ways to Write It

Padding and margin are active on all four sides: top, right, bottom, left. You can set them one at a time, or all at once with a shortcut.

Method A: one side at a time

padding-top: 10px; padding-right: 20px; padding-bottom: 15px; padding-left: 25px;

Method B: the shorthand

padding: 16px; /* same 16px on all 4 sides */
One value = all four sides equally. If you only write padding: 16px;, the browser applies 16px to the top, right, bottom, and left all at once.
03

The Surprise: Borders Add Real Size

A border isn't just a decoration drawn on top of your box — it takes up actual physical space, exactly like padding does. Most beginners assume a border is "free," but the browser disagrees.

width: 100px; border: 5px solid black;
100px box + 5px border on each side = 110px total width.The border adds its thickness on both sides of the box, so a 5px border adds 10px to the total width, and 10px to the total height.
04

Common Mistakes

Wrong: expecting margin to show a color

margin: 20px; background-color: yellow;

The yellow fills the padding area, never the margin. Margin is always see-through.

Right: color goes with padding

padding: 20px; background-color: yellow;

Now the yellow visibly fills the space around the content, inside the frame.

Wrong: forgetting the border adds width

width: 200px; border: 10px solid navy; /* actually renders 220px wide */

Right: plan for it

width: 180px; border: 10px solid navy; /* renders 200px wide, as planned */
05

Vocab You Need

TermMeaning
ContentThe text or image itself, sized with width
PaddingSpace inside the border, around the content. Takes the background color
BorderThe outline between padding and margin: thickness, style, color
MarginSpace outside the border, between this element and the next. Always transparent
Box modelThe idea that every element is these four layers, nested like a photo in a frame

Content, padding, border, margin — every box, every time.
