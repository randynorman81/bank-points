Unit 7 Notes  /  Lesson 7.5

Lists

Top 10s, recipes, packing lists, and playlists all run on the same three tags. Learn how ordered and unordered lists work, how to change their markers, and how to lay out a whole page that looks great.

ul · ol · li · list-style-type
01

Two Kinds of List

A recipe says “1, 2, 3” because the order matters. If you bake the cake before you mix the batter, you get soup. A grocery list uses bullets because you can buy the eggs before the milk. Same idea, two different tags. HTML makes you choose because the choice tells readers whether order matters.

Code

What the browser shows

Tag 01

<ol> ordered list

Numbered. Order matters: steps, rankings, countdowns. “ol” stands for ordered list.

Tag 02

<ul> unordered list

Bulleted. Order does not matter: ingredients, features, favorites. “ul” stands for unordered list.

Tag 03

<li> list item

One entry in the list. Every item gets its own <li> with an opening and a closing tag.

The list tag is the wrapper. The li tags are the items.Only <li> tags go directly inside a <ul> or <ol>. Text placed straight inside the wrapper breaks the list.
02

Change the Marker: list-style-type

The bullet or number in front of each item is called the marker. Change it with the list-style-type property, written in the shell on the list tag (<ul> or <ol>), not on each li.

Code

What the browser shows

List tagValues you can use
<ul>disc (the default dot), circle, square, none
<ol>decimal (1, 2, 3), upper-roman (I, II, III), lower-roman, upper-alpha (A, B, C), lower-alpha
Type the shell first.<ul style="">, then list-style-type: square; between the quotes. It is a style property, so it needs the shell just like color.
03

Make a List Look Good

A list is an element like any other, so everything you already know works on it. Put styles on the list tag to style the whole list. Put <strong> and <em> inside the items.

Plain

<ol> <li>Mix the batter</li> <li>Bake it</li> </ol>
  1. Mix the batter
  2. Bake it

Styled

<ol style="list-style-type: upper-roman; background-color: #ECFCCB; border: 2px solid #65A30D;"> <li><strong>Mix</strong> <em>the batter</em></li> </ol>
  1. Mix the batter
  2. Bake until golden
Pro tip: put a bold name and an italic description in every item, like <li><strong>Pepperoni</strong> - <em>the classic</em></li>. Readers can skim the bold words and read the italic ones if they want more.
04

Design the Whole Page

A page with every tag thrown on it looks like a junk drawer. A page with a plan looks professional. For the 7.5 assignment you will build a two-section guide page. Follow this blueprint and every tag gets a job.

<h1> Title bannerColored background, light text, centered, big font, fancy border-bottom
<p> Tagline (centered)An <em> phrase with <span> highlights, and a <br> to break the line
<hr> Divider #1Styled with a border
<h2> Section 1Same color family as the banner
<p> Short introOne or two sentences
<h3> label + <ol> ranked listBorder + background + list-style-type. Bold name + italic description in each item
<h3> label + <ul> bullet listA different list-style-type, same border and background colors
<hr> Divider #2
<h2> Section 2
<p> Short intro
<h3> label + <ol> steps list
<h3> label + <ul> things-you-need list
<p> FooterTwo lines separated by a <br>, small centered text
Rule 01

Pick a palette

Use 2 main colors plus a neutral. Repeat them: the banner, the h2s, and the list borders all share the palette.

Rule 02

Pick 2 fonts

One family for headings (like serif) and another for body text (sans-serif). Two is a pair. Three is a mess.

Rule 03

Size shows importance

Biggest: h1. Medium: h2. Small caps-style: h3. Body: 16 to 20px.

Rule 04

Center the top, left-align the rest

Center the banner and tagline. Keep lists and paragraphs left-aligned so they are easy to read.

05

Common Mistakes

Wrong: text directly in the list

<ul> Pepperoni </ul>

Right: use li

<ul> <li>Pepperoni</li> </ul>

Wrong: style on the li

<li style="list-style-type: square;">

Right: style on the ul or ol

<ul style="list-style-type: square;">

Wrong: forgot the closing li

<li>Pepperoni <li>Sausage

Right

<li>Pepperoni</li> <li>Sausage</li>

Wrong: roman numerals on a ul

<ul style="list-style-type: upper-roman;">

Right: roman numbers belong to ol

<ol style="list-style-type: upper-roman;">

Vocab You Need

TermMeaning
Ordered list (ol)A numbered list, used when order matters
Unordered list (ul)A bulleted list, used when order does not matter
List item (li)One entry in a list. The only tag allowed directly inside a ul or ol
MarkerThe bullet or number in front of each item
list-style-typeThe style property that changes the marker. Goes on the ul or ol
