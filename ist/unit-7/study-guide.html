LESSON4.1

Box Model

Every element is a box with four layers. Learn padding, margin, and why a border makes a box bigger.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson
GOALDescribe every box with four layers (content, padding, border, margin) and work out how much room a box really takes.
WORDS TO KNOW
box model the idea that every element is a box built from four layers
content the text or picture itself, sized with width
padding space inside the border; it takes the background color
border the line around the padding
margin space outside the border; always see-through
ON THE SITENotes: box-model-notes  ·  Walkthrough: Postcard Studio  ·  Assignment: Etsy Shop Cards  ·  Quiz game: 4.1

LEARNFour layers, like a framed photo

Every element on a page, however round it looks, is secretly a rectangular box. Think of a photo on a wall. The photo is the content. The cardboard matte around it is the padding: space inside the frame. The wooden frame is the border. The empty wall space around the frame is the margin: space outside it.

LayerWhat it isTakes the background color?
contentthe text or picture, sized with widthyes
paddingspace inside the borderyes
borderthe outline: thickness, style, colorhas its own color
marginspace outside the bordernever (always see-through)

LEARNPadding and margin on four sides

Padding and margin work on all four sides: top, right, bottom, left. There are two ways to write them:

  • One side at a time: padding-top: 10px, padding-right: 20px, padding-bottom: 15px, padding-left: 25px (and the same with margin-).
  • The shortcut: padding: 16px puts 16px on all four sides. With two values, like padding: 10px 30px, the first is the top and bottom and the second is the left and right.

Always write the unit: 20px, never just 20.

LEARNThe surprise: a border adds size

A border is not free. It takes real space, just like padding. The width you write is only the content. The box on the page is wider:

total width = content + padding (both sides) + border (both sides)

For example, width: 200px; padding: 10px; border: 5px solid black is 200 + 10 + 10 + 5 + 5 = 230px wide on the page. The same goes for the height.

To make a box exactly 200px wide in all, plan for it: width: 180px; border: 10px solid navy.

LEARNPadding takes the color, margin never does

Put padding: 20px; background-color: yellow on a paragraph and the yellow fills the space around the words, inside the frame. Put margin: 20px on it and the 20px of space around it stays empty and see-through, even if you give the paragraph a background color. That one fact is how you can tell padding from margin in a picture, with no code in front of you.

Postcard Studio wants a page of postcards. Every box on a web page is built from four layers: the content, the padding inside the border, the border, and the margin outside it. You will use all four.

Step 1: Set up the page

<h1>Postcard Studio</h1>
<p>Greetings from Hawaii!</p>
<p>Wish you were here.</p>
<p>See you soon!</p>
<p>Box total: 230 pixels wide.</p>
YOU DO
  1. From memory, type the skeleton with a title that says Postcard Studio, and the body tags
  2. Inside the body type a heading 1 that says Postcard Studio and four paragraphs: Greetings from Hawaii! / Wish you were here. / See you soon! / Box total: 230 pixels wide.

Step 2: Padding: space inside the box

Padding is the space inside the box, between the content and the border. It takes on the element's own background color. padding: 20px puts 20 pixels on all four sides (top, right, bottom and left).

<p style="padding: 20px; background-color: lightyellow">Greetings from Hawaii!</p>
YOU DO
  1. Give paragraph 1 the style padding: 20px; background-color: lightyellow

Try it: the yellow fills the space all around the words. Change 20px to 50px and watch the yellow box grow, then put it back.

Step 3: Margin: space outside the box

Margin is the space outside the box, between this box and the next one. Margin is always see-through: it can never take a background color.

<p style="margin: 30px; background-color: lightpink">Wish you were here.</p>
YOU DO
  1. Give paragraph 2 the style margin: 30px; background-color: lightpink

Try it: the pink color covers only the words, not the 30px of empty space around them. Padding takes the color; margin never does.

Step 4: One side at a time

You can set one side at a time with padding-top, padding-right, padding-bottom and padding-left (margin works the same way). A shortcut with two values, like padding: 10px 30px, means top and bottom first, then left and right.

<p style="border: 4px solid navy; padding-left: 40px; padding-top: 10px">See you soon!</p>
YOU DO
  1. Give paragraph 3 the style border: 4px solid navy; padding-left: 40px; padding-top: 10px

Try it: the words sit 40px from the left of the border and 10px from the top, but touch the other sides.

Step 5: A border adds size

A border is not free: it takes up real space, just like padding. The width is only the content. The box is wider than that: 200px content + 10px padding on each side + 5px border on each side = 230px in all.

<p style="width: 200px; padding: 10px; border: 5px solid black">Box total: 230 pixels wide.</p>
YOU DO
  1. Give paragraph 4 the style width: 200px; padding: 10px; border: 5px solid black

Try it: the black box is 230 pixels wide on the page, even though you wrote width: 200px.

Step 6: Check and submit

YOU DO
  1. Look at the line numbers on the left of your code. No line number should be red: a red number means a problem on that line, like a tag that is not closed or is misspelled
  2. Choose your class period at the top, then click Submit

LESSON4.2

Colors (Names and Hex)

Two ways to name any color, and how to read a hex code as red, green and blue.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson
GOALName colors with words or hex codes, and read a hex code as three pairs: red, green and blue.
WORDS TO KNOW
named color a color with a name, like tomato or navy
hex code # plus 6 characters that give an exact shade
RGB pair two characters of a hex code that control red, green or blue (00 to FF)
color picker a tool that gives you the hex code for any shade you pick
ON THE SITENotes: colors-notes  ·  Walkthrough: Brand Colors  ·  Assignment: Duolingo Colors  ·  Quiz game: 4.2

LEARNTwo ways to name a color

You can describe a color with a word almost everyone understands, like red, or with exact numbers a computer can copy perfectly. HTML lets you use both and the style does not change. Only what you type after the colon changes:

color: tomato; and color: #FF6347; give the identical color.

Names are easy to read. Hex codes are exact and unlimited: they give 16.7 million shades.

LEARNNamed colors

HTML has more than 140 built-in color names, like tomato, navy, gold, teal, crimson and slateblue. Type the name directly: no # and no quotes. You do not have to memorize them, only spell correctly the ones you use. The full list is on the HTML Color Names page.

LEARNHow a hex code works

A hex code is # followed by 6 characters (0 to 9 and A to F), split into three pairs: Red, Green, Blue. Each pair runs from 00 (none of that color) to FF (the most).

Hex codeMeaning
#FF0000all red, no green, no blue: pure red
#00FF00pure green
#0000FFpure blue
#FFFFFFthe most of all three: white
#000000none of any: black

Reading trick: the closer a pair is to FF, the more of that color is mixed in.

LEARNFinding a hex code

Search "color picker" on Google, click a shade, then copy the HEX field (like #3B82F6) and paste it after color: or background-color:. Real brands have official hex codes too.

A hex code must start with # and have exactly 6 characters. FF6347 (no #), #FF634 (5 characters) and #FF63G7 (a G) are all ignored by the browser.

LESSON4.3

Display (Block vs Inline)

Does a tag start a new line? The idea that builds menus, buttons and columns.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson
GOALTell block, inline and inline-block apart, and use the display style to build menus and buttons.
WORDS TO KNOW
block a tag that starts a new line and takes the whole width
inline a tag that stays inside the line and is only as wide as its content
inline-block sits in the line like inline but keeps its width, height and padding
display the style that changes how a tag behaves
ON THE SITENotes: display-notes  ·  Walkthrough: Snack Bar  ·  Assignment: Instagram Menu  ·  Quiz game: 4.3

LEARNSeat savers and friendly neighbors

Every tag is born with a display type. A block tag is like a person who lays coats across a whole row of seats: it starts on a new line and takes the whole width. An inline tag is like a moviegoer who slides in shoulder to shoulder: it stays in the line and only takes the room it needs.

TypeTags
blockhtml, body, h1-h6, p, div, ul, ol, li, hr
inlinespan, strong, em, a, img

This one idea (does a tag start a new line?) is the concept the rest of the unit depends on.

LEARNSpan: the inline label

A span is the inline version of a paragraph: it groups or styles a few words without breaking the line. That is why you can color a single word inside a sentence with <span style="color: red">.

LEARNChanging the costume: display

The display style lets a tag act like another type:

ValueEffect
blocktakes 100% width and starts a new line
inlinesits in the line, only as wide as its content; ignores width and height
inline-blocksits in the line like inline, but you can still set its width, height and padding

LEARNThe navigation bar trick

A menu made of divs stacks in a tall column, because divs are block. Give every div display: inline-block and they sit in a row. That one style is the fix behind almost every horizontal menu on the internet.

A plain link is inline and tiny. Give it display: block (plus padding and a background color) and it becomes a full-width button.

Div Tag

The most used tag on the web: group, style and arrange tags with invisible boxes.

Read the notesWalkthroughAssignmentQuiz gameParsons puzzlesPrintable PDF for this lesson
GOALGroup tags with the div, style a whole group at once, and build side-by-side columns and multi-row layouts.
WORDS TO KNOW
div a generic block container with no style of its own; it groups other tags
container another name for a tag that wraps related tags together
inline-block lets divs sit side by side while keeping a width
vertical-align: top locks side-by-side columns to the same top edge
98% rule the widths in one row should add up to 98% or less

LEARNA box that does nothing by itself

The div is the most used tag on the web, and it does nothing visible on its own. Its whole job is to group other tags into one invisible box. Real sites are built from divs: the nav bar, the search box and every product card are divs.

A div has zero style of its own. It exists to group tags so you can style, move or arrange them as one unit.

LEARNMass styling

Put one style on a div and everything inside it inherits that look, instead of styling a heading, three paragraphs and a list separately:

<div style="background-color: navy; color: white; padding: 14px"> ... the heading and paragraph inside both turn white. A tag that has its own color keeps it.

LEARNBlock by default, elastic height

A div is a block tag: it takes 100% width and starts a new line. Its height is elastic: it stretches to fit what is inside, so you never set a height for a div full of content.

The exception: an empty div (no text, no pictures) collapses to 0 pixels tall and disappears. Give it an explicit height (and a background color so you can see it) and it shows up as a bar.

LEARNSide-by-side columns

Two divs stack by default. Give both display: inline-block to sit side by side, and give both vertical-align: top: without it, two inline-block divs line up by their text baseline, so a column with more text drags the other one down.

Use percent for width (width: 45%) so the columns resize with the screen, and px for height.

LEARNRows of columns: the 98% rule

  1. Keep the widths of one row at 98% or less. The spaces between divs need room, so 50% + 50% overflows and the second div drops to a new line.
  2. Put an hr (or any block tag) after the row so the next divs start on a fresh line.
  3. Repeat the same pattern for each row.

Tables

Rows, cells and the golden rule: every row has the same number of cells.

table the outer wrapper that starts a data grid
tr table row: one horizontal line of the grid
th table header: a bold, centered title cell
td table data: a normal content cell

LEARNFour tags, nested like dolls

Any time information truly belongs in rows and columns, like player stats or pricing plans, a table is the right tag. You do not build columns directly. You build one row at a time, top to bottom, dropping cells into each row, left to right.

TagJob
<table>the outer grid: everything lives inside it
<tr>one row; only cells go directly inside a row
<th>a header cell: bold and centered by default, usually the whole first row
<td>a data cell: most of your table is made of these

Only tr tags go directly inside a table, and only th or td tags go directly inside a tr.

LEARNThe golden rule of alignment

Every row must have the same number of cells. If row 1 has 4 header cells, every row after it needs exactly 4 data cells. Leave one out and the table's columns break.

LEARNOther tags inside a cell

A td can hold any other tag: a link, a picture, bold words, even a whole list. Put the tag inside the cell:

<td><a href="https://www.espn.com">View</a></td>

Real sites do this all the time, like a link in the last cell of every pricing row.

LEARNStyling a table

A table takes styles like any other tag. Put them in the style attribute of the table, or of individual cells:

  • border: 3px solid navy; width: 80%; text-align: center on the table (the centered text is inherited by every cell)
  • background-color: #1B2A4A; color: white on each header cell

Use th for column titles even when td would look the same: screen readers announce a header differently.

Glossary

98% rule the widths in one row should add up to 98% or less
block a tag that starts a new line and takes the whole width
border the line around the padding
box model the idea that every element is a box built from four layers
color picker a tool that gives you the hex code for any shade you pick
container another name for a tag that wraps related tags together
content the text or picture itself, sized with width
display the style that changes how a tag behaves
div a generic block container with no style of its own; it groups other tags
hex code # plus 6 characters that give an exact shade
inline a tag that stays inside the line and is only as wide as its content
inline-block lets divs sit side by side while keeping a width
margin space outside the border; always see-through
named color a color with a name, like tomato or navy
padding space inside the border; it takes the background color
RGB pair two characters of a hex code that control red, green or blue (00 to FF)
table the outer wrapper that starts a data grid
td table data: a normal content cell
th table header: a bold, centered title cell
tr table row: one horizontal line of the grid
vertical-align: top locks side-by-side columns to the same top edge
