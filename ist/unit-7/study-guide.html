7.1

Intro to HTML and the HTML Skeleton

Open lesson →

The three languages of the web

LanguageJobHouse analogy
HTML (HyperText Markup Language)The structure: what the content isFraming, walls, foundation
CSS (Cascading Style Sheets)The presentation: how it looksPaint, wallpaper, floor tiles
JavaScriptThe behavior: what it doesDoorbell, light switches, plumbing

Python usually runs on the server (a far-away computer). HTML, CSS, and JavaScript work inside your browser. This unit focuses on HTML and CSS.

The HTML skeleton

A container tag holds, creates, or edits other tags. The skeleton is container tags nested inside each other, like a box inside a bigger box.

<html> <head> <title>My Page</title> </head> <body> <!-- Everything you see goes here --> </body> </html>
  • <html> is the big outer box.
  • <head> is inside html. It holds hidden page information.
  • <body> is inside html, below head. It holds everything you can see.
  • Indentation shows which box is inside which.

Tags, elements, and attributes

  • Most tags come in pairs: an opening tag <p> and a closing tag </p> (always has a forward slash).
  • Opening tag + content + closing tag = an element.
  • Attributes live in the opening tag and give extra instructions, like src on an image or href on a link.
  • Always look at the opening tag first.

HTML ignores your formatting (whitespace insensitive)

  • Extra spaces are ignored: ten spaces show as one.
  • Line breaks are ignored: pressing Enter does not make a new line on the page (use <br>).
  • Lines of code are not lines on the page.

The <title> tag

  • Goes inside <head>. Text appears in the browser tab, search results, and bookmarks.
  • Only one title tag per page. Think of it as the filename of a Word document.
HTML builds the furniture. CSS is the paint.Inline styling puts the CSS right inside the HTML tag with the style attribute.

Creation Tags + Inline Styling

Open lesson →

Creation tags

HTML has three types of tags: container, creation, and editing. Creation tags add visible content to the page, usually text. Every creation tag must live inside a container. The <body> always counts.

TagPurposeNotes
<p>Paragraph / body textNormal browser size, not bold
<h1> to <h6>Titles and headingsh1 is largest, h6 is smallest. All are bold by default. Use only one h1 per page

Code

<h1>Heading 1</h1> <h2>Heading 2</h2> <h3>Heading 3</h3> <p>Paragraph text.</p>

What the browser shows

Heading 1

Heading 2

Heading 3

Paragraph text.

  • Headings are for hierarchy, like an outline in English class.
  • Creation tags are block elements: they start on their own line with space above and below.

How text really behaves

  • Extra spaces between words collapse to one space.
  • Spaces between letters show up exactly: <p>C O D E</p> shows C O D E.
  • Text wraps based on the width of the container, not on where you pressed Enter in your code.
  • For a gap or new line, use tags, not the spacebar.

The style attribute (inline styling)

The style attribute changes how an element looks. Using it inside a tag is called inline styling.

<p style="property: value;">Text</p>
  • Colon : between the property and the value.
  • Semicolon ; after the value.
  • Whole thing wrapped in double quotes.
  • Goes in the opening tag only, after the tag name and one space. Never in the closing tag.
  • Chain properties in the same quotes, separated by semicolons.
PropertyWhat it doesExample
colorChanges the text colorcolor: orange;
font-sizeChanges the text size, usually in pixels (px)font-size: 28px;
text-transformuppercase, lowercase, or capitalize (first letter of every word)text-transform: uppercase;
text-alignleft (default), center, or righttext-align: center;

Code

<h2 style="text-align: center; text-transform: uppercase; color: #2563eb; font-size: 18px;">pro developer mode</h2>

What the browser shows

pro developer mode

Editing Tags + Span + Font Families

Editing tags

The third type of tag. After a container (the room) and creation tags (the furniture), editing tags polish the content.

TagWhat it doesClosing tag?
<strong>Bold (strong emphasis)Yes
<em>Italic (emphasis)Yes
<br>Line break: new line without a new paragraphNo (empty tag)
<hr>Horizontal rule: a line separating sectionsNo (empty tag)

Code

<p>Normal, <strong>bold</strong>, and <em>italic</em>.</p> <p>Roses are red,<br>Violets are blue.</p> <hr> <p>The poem is over.</p>

What the browser shows

Normal, bold, and italic.

Roses are red,
Violets are blue.

The poem is over.

Never close br or hr.Wrong: <br>...</br>. Right: <br>

Nesting: mirror your tags

Order of thinking: container (outer box) then creation (content) then editing (style modifier). Editing tags are sealed inside creation tags. The last tag you open is the first one you close.

<body> <p>this is <em><strong>italic and bold</strong></em></p> </body>

The span tag

  • <span> is a generic inline container for text: the inline version of the paragraph tag.
  • <p> takes the WHOLE line (greedy). <span> takes only its own width (friendly).
  • Use it as a label to style part of a paragraph, like just one word.
  • Spans can sit side by side, while paragraphs stack.

Code

<p>This is black, but <span style="color: red;">THIS WORD</span> is red.</p>

What the browser shows

This is black, but THIS WORD is red.

Font families

A font family is a group of fonts sharing a design style. CSS has three built in generic families. If your first choice font is unavailable, the browser falls back to the family.

FamilyLooks likeBest forReal examples
serifLittle "feet" on letters. Traditional, formalLong articles, formal headingsTimes New Roman, Georgia; NYT, Wikipedia
sans-serifClean, no feet ("sans" is French for "without"). ModernWebsites, apps, most on-screen textArial, Roboto; Google, Apple, YouTube
monospaceEvery character is the same width. TechnicalCode, file paths, dataCourier New, Consolas; GitHub, VS Code, CodeHS
<p style="font-family: sans-serif; font-size: 18px; color: teal;">My styled paragraph</p>

Common mistakes

  • Missing the semicolon: font-family: serif color: red;
  • Forgetting the quotes around the style value.
  • Misspelling: san-serif. It is sans-serif with an s and a hyphen.
  • Capital letters: use lowercase serif.

7.6

Links

Open lesson →

The anchor tag and href

Links use the <a> (anchor) tag. Without href, nothing happens; it just looks like text.

<a href="https://www.google.com">Search on Google</a>
  • href = Hypertext Reference: the destination address (URL). It lives in the starting tag.
  • The text between <a> and </a> is the only thing visible. It turns blue and underlined automatically.
  • Always include the full https:// prefix.

Every attribute follows the same formula

tagname attribute-name="value"
  • One space between the tag name and the attribute name.
  • An equals sign with no spaces around it.
  • Double quotes wrapping the value.

Opening in a new tab

By default a link opens in the same tab. Add a second attribute to open a new tab.

<a href="https://www.google.com" target="_blank">Search on Google</a>
  • The value must be exactly _blank, including the underscore.
  • Separate multiple attributes with a single space. No commas. No semicolons between attributes (semicolons only live inside the style quotes).

Pseudo-classes (link states)

A pseudo-class styles a temporary interactive state. It is written with a colon after the tag name.

Pseudo-classWhen it applies
a:linkAn unvisited, normal link
a:visitedA link the user already clicked
a:hoverThe mouse is on top of the link
a:activeThe split second the link is clicked
LVHA: Love, Visit, Hate, AlwaysWrite them in this order: :link, :visited, :hover, :active. Browsers read top to bottom, so the order matters.

Internal styling

Pseudo-classes cannot be written inline. They go in an internal style block: a <style> tag inside the <head>. It is also called an embedded style sheet.

<head> <style> a:link { color: #2563eb; } a:visited { color: #4b5563; } a:hover { color: #ea4335; } a:active { color: #eab308; } </style> </head>
Part of a CSS ruleMeaning
SelectorWhich tag to style (p, h1, ul). No angle brackets
Curly braces { }Wrap the instructions for that selector
Declarationproperty: value;, same as inline. Always end with a semicolon
  • Mass updates: change one line and every matching element changes.
  • Cleaner HTML: less repeated code in the body.
  • Advanced abilities: pseudo-classes like a:hover are impossible inline.
7.7

Images

Open lesson →

The professional image workflow

Download, Upload, Link.Never just copy an image link from Google Images. If you do not host it yourself, it will eventually break.
  • Right-click the image and choose Save image as... (this downloads the file). Do not use "Copy image address", which points to someone else's server.
  • In CodeHS, click New +, choose Upload, select your image, and click Add File.
  • Copy the link CodeHS gives you and paste it into the src attribute.
  • HTML does not store images; it only points to them.

The img tag

<img src="link_to_image.jpg" alt="A golden retriever playing with a blue ball">
  • <img> is empty and self-closing: no end tag.
  • src = source: where the image file lives.
  • alt = alternative text: a description. It helps screen readers (blind users), shows if the image breaks, and helps Google understand your page.
  • You can style it like other tags: style="border: 10px solid gold;".

Aspect ratio

Aspect ratio links an image's width and height. Stretch one side without the other and the image distorts, like a balloon.

Golden rule: choose ONE, width or height.The browser calculates the other one for you.
HTMLWhat the browser does
<img>Shows the native size
<img width="600">Auto-calculates height
<img height="250">Auto-calculates width
<img width="500" height="200">Forces an exact box and distorts the image
  • Percentages work too: width: 100%; height: auto; scales on any screen without distortion.
  • Fix a stretched image: decide if width or height is your constraint, then delete the other one.

border-radius

Browsers treat everything as a box with sharp 90 degree corners. border-radius curves them, like a digital wood sander.

ValueResult
0pxSharp corners
12pxSmooth corners (cards, buttons)
30pxDeep curve
50%Perfect circle if the element is a perfect square (same width and height). Different width and height makes an oval
35px 0px 35px 0pxCorners go clockwise: top-left, top-right, bottom-right, bottom-left
<img src="profile.jpg" style="width: 100px; height: 100px; border-radius: 50%;">

Box Model

Open lesson →

The browser treats every item on a page as a rectangular box: the CSS box model. Picture a framed photo, from the inside out.

LayerPicture frameWhat it does
ContentThe photoThe actual element. Sized with width
PaddingThe cardboard matteSpace inside the frame. Takes the element's background color
BorderThe wooden frameThe outline between padding and margin
MarginThe wall spaceSpace outside the border. Always 100% transparent. Separates elements from each other

Code

<img src="photo.jpg" style="width: 150px; background-color: #ffffff; padding: 16px; border: 8px solid #451a03; margin: 24px;">

Picture in a frame

Spacing on all four sides

  • Padding and margin work on top, right, bottom, and left.
  • One value applies to all four sides: padding: 16px;.
  • Or name a side: padding-top, padding-right, padding-bottom, padding-left, margin-top, margin-bottom.

Borders

border: 2px solid black; /* thickness, style, color */
  • A pixel (px) is the smallest dot on your screen. About 96 pixels fit in one inch.
  • Styles: solid, dashed, dotted, double, groove, ridge.
  • Color can be a name or a hex code.
  • Borders add width: a 100px box with a 5px border is 110px wide (5px on each side).

How hex codes work

A hex code is 6 characters after a #. It is three pairs: Red, Green, Blue (RGB). Each pair is a hexadecimal number from 00 (none of that color) to FF (maximum). In hexadecimal the digits are 0 to 9 then A to F, so 00 = 0 and FF = 255.

# 1B 2A 4A Red Green Blue
HexColorWhy
#FF0000Pure redRed at max, no green or blue
#00FF00Pure greenGreen at max
#0000FFPure blueBlue at max
#FFFFFFWhiteAll three at max
#000000BlackAll three at zero
#1B2A4ADark navy blueLow red, low green, a bit more blue
  • The closer the first pair is to FF, the more red. The second pair is green. The third pair is blue.
  • Good to know: the same color can be written with RGB numbers, rgb(255, 99, 71), where each channel is 0 to 255. That is #FF6347 (tomato) in hex.

Every HTML element is born with a "Display DNA": block or inline.

Block ("seat savers")Inline ("friendly neighbors")

WidthClaims 100% of the parent, even with little contentShrinks tightly around its content
Side by side?No, they stackYes, if there is room

What the browser shows

I am a block

I am also a block

Bold Italic Normal

The costume rule

The CSS display property is a costume. The tag keeps its name but acts like a different type.

ValueEffect
blockClaims 100% width and starts a new line
inline-blockSits on one line and lets you set width and height
inlineFlows with the text
  • Block to inline-block: p or div boxes can sit side by side.
  • Inline to block: an <a> link with display: block fills the row and looks like a button.
  • Nav bar: give your divs display: inline-block to sit in a row.
  • Use inline-block when you want things side by side but still control their size in pixels.
<div style="display: inline-block; background: purple;">Home</div> <div style="display: inline-block; background: purple;">About</div>
7.11

Div Tag

Open lesson →

<div> (short for division) is the most important tag in web design: a generic container that groups parts of a page. Think of an empty cardboard box. Almost all other tags should live inside div containers. Websites like Amazon are made of many nested divs.

Mass styling

Put one style on a div and everything inside it changes at once.

Code

<div style="background-color: lightblue; color: navy;"> <h1>Welcome</h1> <p>Same blue box!</p> </div>

What the browser shows

Welcome

Same blue box!

Behavior

  • A div is a block element: full width, then a line break.
  • Auto-height: a div stretches to be as tall as its content, like an elastic bag.
  • An empty div collapses to 0px tall and is invisible. Give it a height and a temporary background-color to see it.
  • Width: use percentages (width: 80%), which adapt to any screen. Height: use pixels (height: 200px) because a page scrolls down forever.
<div style="width: 80%; height: 200px; background-color: #e2e8f0;"></div>

Side-by-side columns

Divs stack because they are blocks. Change them to display: inline-block; to make columns. Add vertical-align: top; to both so the tops line up (otherwise the browser lines up text baselines and one drops down).

<div style="display: inline-block; width: 45%; vertical-align: top;">Left</div> <div style="display: inline-block; width: 45%; vertical-align: top;">Right</div>

Multi-row layouts: three rules

  • The 98% rule: widths on one line must add up to no more than 98%, to leave room for hidden spacing between inline-blocks.
  • The line-breaker rule: put an <hr> (or another block tag) after the last div of each row.
  • The reset: start the next row below the break the same way. (Flexbox and grid are the advanced ways.)
Summary: div = the box. style = the paint. inline-block = side-by-side columns.

Tables

Open lesson →

Think of a table as a storage shelf. You build it row by row, top to bottom, dropping cells into each row from left to right. Tags nest like Russian dolls.

TagMeaningNotes
<table>The outer boundary of the grid
<tr>Table RowOne horizontal line
<th>Table HeaderBold, centered title cell at the top of a column
<td>Table DataA normal content cell
<table> <tr> <th>Name</th> <th>Score</th> </tr> <tr> <td>Ava</td> <td>95</td> </tr> </table>

Code

<table border='1'> <tr><th>Name</th><th>Score</th></tr> <tr><td>Ava</td><td>95</td></tr> </table>

What the browser shows

NameScore
Ava95

Steps to build a 5 x 5 table

  • Open with <table>.
  • Header row: one <tr> with exactly 5 <th> cells.
  • Rows 2 to 5: a new <tr> each, with exactly 5 <td> cells.
  • Close with </table>.
Golden rule of alignment.Every row must have the same number of cells. If Row 1 has 5 headers, rows 2 to 5 need exactly 5 data cells or the table breaks.

Tags inside a cell

A <td> can hold other tags: links, images, and lists.

<td><a href="https://amazon.com">View Store Page</a></td> <td><img src="headphones.jpg" style="width: 100%; height: auto; max-width: 50px;"></td> <td><ul><li>Noise Cancelling</li><li>40hr Battery</li></ul></td>
  • Real world: ESPN uses tables for player stats. Shopify uses them for pricing grids.
