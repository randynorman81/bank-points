Display: Block vs. Inline

Every tag is born with a display type baked in. This one idea — whether a tag starts a new line or not — is the concept the rest of this unit depends on.

block · inline · display
01

Seat Savers vs. Friendly Neighbors

Picture a movie theater. One person walks in and lays coats across an entire row of 10 seats. Even though they only need one seat, nobody else can sit in that row — it's blocked off. That's a block element. Now picture other moviegoers sliding in shoulder to shoulder, taking only the exact space they need. That's an inline element.

Click to see each type "claim" its seats:

Block tags

Always start a new line

html, body, h1–h6, p, div, ul, ol, li, hr

Inline tags

Stay in the sentence

span, strong, em, a (links), img (images)

02

span: The Inline Label

A span is the inline version of a paragraph — it groups or styles a piece of text without breaking the line around it. That's why you've been using it to color a single word inside a sentence.

03

Changing the Costume: the display Property

Every tag is born with a display type — its DNA. But display lets you put a costume on it: the tag keeps its name, but behaves like a different type entirely.

Code

What the browser shows

ValueEffect
blockClaims 100% width, starts a new line
inlineSits inside the line, only as wide as its content
inline-blockSits in a row like inline, but you can still set its width and height
04

Real World: the Navigation Bar Trick

Menu links are naturally block-level divs, so they stack in a tall column by default. Every navigation bar you've ever seen uses this one fix:

Before: display: block (default)

Home
About
Contact

After: display: inline-block

Home
About
Contact
display: inline-block is the single fix behind almost every horizontal menu on the internet.It's also how a plain link (naturally inline and tiny) gets turned into a big, full-width button with display: block;.
