Intro to HTML and the HTML Skeleton

Every website you have ever visited is built from a few simple pieces. This page has everything for 7.1 in one place: the three languages of the web, tags, the skeleton, and the title tag.

HTML Foundations
01

The Three Languages of the Web

Every website is built from a combination of three languages. Think of building a house.

🧱

HTML: the structure

HyperText Markup Language. Like the wood framing, walls, and foundation of a house. It defines what the content is.

🎨

CSS: the presentation

Cascading Style Sheets. Like the paint, wallpaper, and floor tiles. It defines how the content looks.

💡

JavaScript: the behavior

Like the doorbell, light switches, and plumbing. It makes the page do things.

🐍

Python: the server

Unlike the others, Python usually runs on the server (the computer far away). HTML, CSS, and JavaScript work inside your browser. Python handles logic like checking your password or searching a database.

This unit focuses on HTML and CSS.They rely on each other. HTML is the skeleton (the frame of the house), and CSS is the styling (the paint, the siding, and the interior design). We learn both at the same time.
02

Tags, Elements, and Attributes

HTML is built with tags. Most tags come in pairs that wrap around content.

TypeSyntaxPurpose
Opening tag<tagname>Starts the element
Closing tag</tagname>Ends the element (always has a forward slash /)

When you put tags and content together, you create an element.

<p> Hello, World! </p>
  • Opening tag: tells the browser, "A paragraph starts here."
  • Content: the actual text or image visible to the user.
  • Closing tag: tells the browser, "The paragraph is finished."

Attributes live in the opening tag

Opening tags do more than name the element. They are where you give extra instructions, called attributes. An image tag does not work without a source, so the file path goes in the opening tag.

<img src="logo.png" alt="Company Logo"> <a href="https://google.com">Click Me</a>
Always look at the opening tag first.That is where the ID, class, and source will live when we start making sites interactive.
03

Rules HTML Does Not Follow

HTML is whitespace insensitive, which means it ignores much of how you format your code.

Rule 01

Extra spaces are ignored

Ten spaces between words in your code show up as one space on the page.

Rule 02

Line breaks are ignored

Pressing Enter in your code does not make a new line on the page. You need a specific tag, like <br>.

Rule 03

Code lines are not page lines

A paragraph might span lines 4 to 10 in your editor but look like one single line in the browser.

Your code

1 <p> 2 This text is on line 2 in code, 3 but it will stay on one line 4 in the browser. 5 </p>

What the browser shows

This text is on line 2 in code, but it will stay on one line in the browser.

04

The HTML + CSS Duo

HTML defines what the content is. CSS defines how it looks. With inline styling, you put the CSS right inside the HTML tag using the style attribute.

1. HTML only (the skeleton)

<p> Hello! This is a plain paragraph. </p>

Hello! This is a plain paragraph.

It uses the browser's default black text and standard font.

2. HTML + inline CSS (the style)

<p style="color: white; background-color: navy; border: 4px solid orange; padding: 15px; border-radius: 15px;"> Hello! </p>

Hello! This is a styled paragraph.

HTML builds the furniture. Inline CSS is the paint you apply directly to it.The HTML tag stays the same in both examples. The style attribute completely transforms the result.
05

The HTML Skeleton

A container tag is a tag designed to hold, create, or edit other tags. Its primary job is to provide structure by wrapping around other elements.

The box analogy.You open the main box and find the product, plus a smaller box holding the charger and accessories. The small box is nested inside the bigger box. The HTML skeleton is a combination of container tags nested inside each other.
<html> The Master Box (the big outer box)
<head> Container #1: hidden page dataNested inside html.
<body> Container #2: visible contentAlso nested inside html, placed below head.
</html>

In code, we use indentation (extra space) to show that one box is inside another.

<html> <!-- Outer box opens --> <head> <!-- Nested inside html --> <!-- Info about the page goes here --> </head> <body> <!-- Also nested inside html, below head --> <!-- Everything you see goes here --> </body> </html> <!-- Outer box closes -->
  • The <head> tag is always inside the <html> tags.
  • The <body> tag is also inside the <html> tags, but it is placed below the head.
  • Coming later: more container tags like <div>, <section>, and <footer>.
HTML is a series of containers that hold other tags.
06

The <title> Tag

The <title> tag defines the text that appears in the browser tab and in search engine results. It is the only part of the <head> that a user actually interacts with regularly.

<head> <title>My Awesome Portfolio</title> </head>
My Awesome Portfolio ×

What the browser tab looks like with that title tag.

Where 01

Browser tabs

It provides the name on the tab so users can find your site when they have many tabs open.

Where 02

Search results (SEO)

The big blue link you click in a Google search is usually pulled from the title tag.

Where 03

Bookmarks

When someone saves your site as a favorite, the default name is the text inside the title tag.

The title is like the filename of a Word document.If the <head> is the Page Setup menu, the <title> is the filename you give the document before you save it. It identifies the page but is not part of the essay content. Rule: only one title tag per page.
