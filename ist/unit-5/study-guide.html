Operating Systems and Software
5.1

What Does an Operating System Do?

An operating system (OS) is software that manages a computer's hardware and gives every other program a safe, fair way to use it. Apps never talk to the hardware directly. Apps ask, the OS decides. Think of the OS as a manager who decides who gets what, and when.

The six jobsWhat it means
Process managementA process is a program that is running right now. The OS switches between processes thousands of times a second so fast it looks simultaneous. That is multitasking (music playing while you type an essay while a file downloads).
Memory managementThe OS gives each program its own slice of RAM and makes sure no program reads or overwrites another's. When RAM fills up, the OS moves the least-used data from RAM to storage. That is virtual memory, and it is why a laptop slows down with 40 tabs open.
File managementThe OS keeps the index of every file and folder, remembers where each one lives on the drive, and controls who can open, edit, or delete it.
Device managementDrivers translate between the OS and one specific piece of hardware. That is why a printer from a brand you have never used still prints right away.
User interfaceHow you talk to the computer. A GUI (graphical user interface) uses windows, icons, and a mouse or touch. A CLI (command-line interface) uses typed commands.
SecurityUser accounts, passwords, admin vs. standard users, and permission prompts like "Allow this app to use your camera?" The OS is the gatekeeper.

The kernel is the core of the OS, the part that talks directly to hardware. Web hosting is not one of the six jobs.

5.2

Windows vs. macOS vs. Linux

Three operating systems, one job. No single one has won because each was built around a different answer to "who is this for?"

WindowsmacOSLinux
Made byMicrosoft (1985)AppleA worldwide community. Started in 1991 by Linus Torvalds
CostUsually included in the price of the PCIncluded with the Apple computerFree
Source codeClosed (secret)Mostly closedOpen source: every line is readable and changeable
Runs onAlmost any brand of PCApple's own computers onlyAlmost anything
Software libraryLargest: best for games and businessLarge: strong in creative appsSmaller for consumers, huge for servers and developers
TradeoffIt runs on so many different machines and is so widely used that it is the most common target for viruses, with driver headachesYou have to buy Apple hardware. Less choice, less gamingFewer mainstream apps and games. Expects you to troubleshoot
  • Distro: Linux itself is just the kernel. A distribution (distro) bundles the Linux kernel with a desktop, apps, and an installer. Examples: Ubuntu (beginner-friendly), Linux Mint, Fedora, Debian.
  • Windows is the best fit for games and the widest choice of hardware, including upgradable graphics cards.
  • macOS is the best fit for video and creative work, especially when you already own other Apple devices like an iPhone and AirPods.
  • Linux runs most web servers, is free, stable, and has no per-server license fees. It is the standard platform for learning cybersecurity, because you can read and change the OS itself.
  • The app decides the OS: a hospital billing department with a Windows-only program needs Windows.
No OS is "best." The right one fits the software, the budget, and the people.

The OS didn't disappear, it multiplied. Wherever a chip needs to be managed, some OS is managing it: phones, watches, TVs, and cars.
5.4

Who Owns Software? Licenses, Piracy & Open Source

You never actually buy most software. You buy permission. Software is protected by copyright the moment it is written. A software license is a rulebook that says who can use the software, on how many devices, for how long, and whether you can change or share it.

License typeWhat it meansExamples
ProprietaryYou pay to use it, the source code is secret, and you can't copy or modify it.Microsoft Office, Adobe Photoshop, most console games
Shareware / FreemiumFree to try, then pay to keep using it or unlock more.A 30-day trial, a free game with paid upgrades
FreewareCosts nothing, but the code is still owned and closed.Zoom's free tier, small utilities
Open sourceThe source code is public. You can read, change, and share it under the license's conditions (MIT and GPL are two famous ones).Linux, Firefox, Python
Public domainNo owner, no rules. The rarest category for modern software.
  • Software piracy is using, copying, or distributing software without permission. It is a form of copyright infringement.
  • Installing your one-device license on five computers violates the license terms.
  • A cracked copy of paid software (even "just for school") is still piracy, and cracked installers often hide malware.
  • A 30-day trial that you uninstall afterward is okay. That is exactly what a trial is for.
  • Downloading Linux and sharing copies with your class is okay, because open source explicitly allows sharing.
  • Not piracy: free trials, student licenses, open-source downloads from the official site, and legitimate free tiers.
  • Copying open-source code: read the license. MIT lets you reuse it if you keep the notice. GPL requires your project to stay open too.
Read the license before it reads you.
