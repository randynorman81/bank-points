The Developer's Toolkit

Professional developers rarely start with code. They start with a sketch, a text editor, and a way to undo mistakes. Here's the toolbox behind every app you use.

Plan Before You Type

Before a movie is filmed, someone draws every shot on a storyboard. Before software is written, developers do the same, using three planning tools. They're cheap, fast, and they catch mistakes when fixing them is free.

Flowchart

A diagram of steps and decisions. Ovals = start/end, rectangles = actions, diamonds = yes/no decisions, arrows = flow.

Pseudocode

Plain-English steps written like code, but with no strict rules. See the example below.

Storyboard

A row of sketches showing what the user sees on each screen as they move through the app. Great for designing before building.

Where the Code Gets Written

Text editor

Lightweight. Lets you write and save code with helpful color-coding. Examples: Notepad++, Sublime Text, Vim.

IDE (integrated development environment)

An editor plus a compiler/runner, debugger, and project tools, all in one window. Examples: Visual Studio, IntelliJ IDEA, PyCharm, Android Studio. VS Code sits in between: an editor you extend into an IDE.

Key words in the toolchain: a compiler translates your code into something the computer can run, a debugger lets you pause and inspect a running program to find a bug, and a toolchain is the set of tools chained together to turn code into a finished program.

Ctrl+Z for a Whole Project: Version Control

You and three teammates edit the same file. Someone breaks it at 11 p.m. Who did it? Which version worked? Version control solves all of this by saving a snapshot (a commit) each time you make a meaningful change — so nothing is ever truly lost.

This website is version-controlled. Every change to it is a commit on GitHub, so any mistake can be undone.
