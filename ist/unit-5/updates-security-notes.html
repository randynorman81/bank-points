Updates, Patches & Staying Safe

“Remind me tomorrow” is the most dangerous button on your computer. Here's what's actually inside an update, and why attackers love people who click it.

Georgia IT-IST-5.3 · IT-IST-6.2 · IT-IST-6.3
00

The Unlocked Window

In May 2017, a worm called WannaCry locked up hospitals, shipping companies, and factories in over 150 countries in a single weekend. The hole it used had already been fixed by Microsoft — two months earlier. The victims hadn't installed the update. The door was repaired; nobody walked through the repaired door.

A vulnerability is a flaw in software that an attacker can exploit. A patch is a fix for it. Software is written by humans, so flaws are guaranteed — what matters is how fast the fix reaches you.

Day 0Flaw is discovered
Day XPatch is released
Day X+?You install it
The danger zone is the gap between the patch being published and you installing it. Publishing a patch also tells attackers exactly where the flaw was — so they race to hit everyone who hasn't updated yet.
01

What's Inside an Update?

Security patch

Closes a known hole. Highest priority. Install these as soon as possible.

Bug fix

Fixes crashes, glitches, and things that just don't work right. Not an attack risk, but it makes software more reliable.

Feature update

Adds new things: a redesigned menu, a new tool, AI features. Bigger, less urgent, and occasionally introduces new bugs of its own.

Driver update

A new translator for your hardware (graphics card, Wi-Fi, printer). Often improves speed or fixes hardware problems.

03

Your Five-Habit Defense

Habit 1

Turn on auto-update

Let the OS, browser, and apps patch themselves.

Habit 2

Only install from trusted sources

Official stores and developer sites (Lesson 5.5).

Habit 3

Use security software

Windows Security is built in and solid. Don't stack five antivirus programs.

Habit 4

Back up what matters

3 copies, 2 kinds of storage, 1 somewhere else. Ransomware can't hold a copy hostage that it can't reach.

Habit 5

Think before you click

Phishing tricks the human, not the software.

Software support has an expiration date.When Windows 10 support ended in October 2025, it stopped receiving free security patches — an “end-of-life” system is an unlocked window with a sign on it.

Patches only protect the people who install them.
