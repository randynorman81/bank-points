Compatibility: Why Won't It Run?

You download the perfect program and get an error message instead. Compatibility is the unglamorous reason behind a huge share of every “it doesn't work” help-desk ticket.

Georgia IT-IST-5.3 · IT-IST-6.1
00

What “32-bit” and “64-bit” Really Mean

Think of RAM as a street of mailboxes. Every mailbox has an address, and the processor has to be able to write that address down. A 32-bit processor has 32 digits (all 0s and 1s) to write addresses with. A 64-bit processor has 64. It sounds like double — it's actually incomprehensibly more.

Compatibility means whether two things can work together: a program and an OS, an OS and a processor, a device and a computer. Click a bit size to see how many memory addresses it can reach.

Pick a size above
Each extra bit doubles the number of addresses. That's why 32 to 64 isn't “twice as much” — it's 2³² times as much.
This is why 32-bit computers max out around 4 GB of RAM. The processor simply can't write down an address past 4,294,967,296. Once computers needed more memory than that, 64-bit became the standard.
01

The Compatibility Checker

Compatibility usually only works in one direction. Try the combinations.

Why one direction? A 64-bit system can include a translation layer for older 32-bit programs (Windows does). A 32-bit system has no way to write 64-bit addresses, so the newer program is simply speaking a language it can't understand. Note: Apple went further — macOS dropped 32-bit app support entirely in 2019.
02

Four Kinds of “Won't Run”

Type 01

Bits

A 64-bit app on a 32-bit OS. Almost never happens on modern computers, but it's the classic textbook case.

Type 02

Processor architecture

Intel/AMD chips (x86-64) and ARM chips (phones, Apple's M-series, some laptops) speak different machine languages. Apps must be rebuilt — or translated, like Apple's Rosetta 2.

Type 03

Operating system

A Windows-only program will not launch on a Mac or Chromebook, no matter how powerful the machine is.

Type 04

Drivers & versions

An old printer with no driver for your new OS, or a game that needs a newer OS version than you have.

TermMeaning
Backward compatibleNew system still works with old programs/devices
Processor architectureThe design/instruction set of a CPU (x86-64, ARM)
Emulation / translationSoftware that lets one architecture run another's programs — usually slower
System requirementsThe minimum OS, RAM, storage, and processor a program needs
Find yours: Windows → Settings → System → About shows “64-bit operating system, x64-based processor.” Mac → Apple menu → About This Mac shows your chip (Apple M-series or Intel).
Before you download or buy: check the system requirements.Thirty seconds of checking beats an afternoon of troubleshooting — and it's exactly what a help desk does first.
