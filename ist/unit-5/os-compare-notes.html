Windows vs. macOS vs. Linux

Three operating systems, one job. So why hasn't one of them won? Because each was built around a different answer to the question “who is this for?”

Georgia IT-IST-5.3 · IT-IST-6.1
00

Three Philosophies

In the 1980s, three very different bets were placed. Microsoft: “let our OS run on every company's hardware.” Apple: “we'll make the hardware and the software so they fit perfectly.” And in 1991, a Finnish student named Linus Torvalds: “I'll write one and give the code away.” Forty years later, all three bets are still paying off.

Windows — the one that runs on everything

Made by: Microsoft (first released 1985). Current version: Windows 11.

Superpower: runs on almost any brand of PC, and has the biggest library of software and games. Most business software is built for it first.

Tradeoff: because it runs on so many different machines, it's the most common target for viruses and the most likely to have driver headaches.

macOS — the one built as a matched set

Made by: Apple. Runs only on Apple's own computers.

Superpower: Apple controls both hardware and software, so they work smoothly together. Very popular for video, music, and design work. Built on Unix, so it's also a favorite of programmers.

Tradeoff: you have to buy Apple hardware, and there's less choice (and less gaming) than on Windows.

Linux — the one anyone can change

Made by: a worldwide community. Free and open source: anyone can read, modify, and share the code.

Superpower: free, customizable, and rock-solid. It runs most of the web's servers, every one of the world's top 500 supercomputers, and Android phones are built on the Linux kernel.

Tradeoff: fewer mainstream apps and games, and it expects you to be comfortable troubleshooting.

What's a distro? Linux itself is just the kernel. A distribution (distro) bundles that kernel with a desktop, apps, and an installer. Popular ones: Ubuntu (beginner-friendly), Linux Mint (looks like Windows), Fedora, and Debian. Same core, different flavors.
