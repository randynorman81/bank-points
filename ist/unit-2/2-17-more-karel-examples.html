2.17 — Control Structures Example

🔔 Bell Ringer — Think About It
  1. "Climbing Karel" is taught through live coding instead of a finished example you just read. What do you think you learn by watching someone write and fix code in real time that you wouldn't learn from only seeing the final, working version?
  2. "Opposite Corner" and "Move Tennis Balls Back" both sound like they reverse something Karel already knows how to do forward. Is writing the reverse version of a solved problem actually easier than solving it fresh, or does reversing your own thinking turn out to be its own kind of hard?
  3. By this point you've learned functions, loops, conditionals, decomposition, and abstraction. Which of those tools do you think you'd miss the most if you suddenly had to solve a brand-new Karel problem without it?
  4. If you had to explain "climbing" to Karel using only the tools from this entire unit, would you reach for a while loop, a for loop, or a mix of both — and what would make you choose one over the other before you even start typing?

A review of all of our control structures (for loops, while loops, if statements).
