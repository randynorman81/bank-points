2.16 — Control Structures Example

🔔 Bell Ringer — Think About It
  1. By now you've learned for loops, while loops, and if statements separately. What's harder: learning each one on its own, or figuring out which one to actually reach for when a new problem doesn't tell you which tool to use?
  2. "Cleanup Karel" and "Random Hurdles" both involve situations where Karel doesn't know exactly what it will find. Why would combining a while loop with an if statement handle that uncertainty better than either one alone?
  3. If you could only keep one of the three control structures — for loops, while loops, or if statements — and had to solve every future Karel problem without the other two, which would you keep, and what kinds of problems would you be stuck on?
  4. Predict this: in a program combining a for loop, a while loop, and an if statement all together, which one do you think is most likely to be the source of a bug, and why?

A review of all of our control structures (for loops, while loops, if statements).
