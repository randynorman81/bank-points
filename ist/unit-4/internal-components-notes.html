COMPUTING BASICS NOTES  /  SUBJECT: WHAT'S ACTUALLY INSIDE THE BOX

Internal Components

Eight parts, eight jobs. Learn what each one actually does and you can diagnose almost any "my computer is acting weird" problem from the symptoms alone.

00

Definition

A computer isn't one thing — it's several specialized parts wired together through one central board, each handling a completely different job. Take any one of them out and the whole machine either stops working, or works badly.

Motherboard

The circuit board everything else plugs into — it's what physically connects every other component to every other component.

BIOS

The self-test that runs the instant you hit power — it checks that every other part is actually working before anything else is allowed to start.

CPU

Executes instructions one at a time, extremely fast — the general-purpose "brain" that runs almost everything.

GPU

Built to do thousands of simple calculations at once instead of one at a time — originally for graphics, now also gaming, video editing, and AI.

RAM

Temporary, ultra-fast memory holding whatever the computer is actively working on right now — wiped clean every time the power turns off.

Storage (HDD / SSD)

Permanent memory that keeps your files, programs, and OS even when the power is off.

Cooling system

Fans, heatsinks, sometimes liquid — keeps every other component from overheating and shutting down or getting damaged.

Network / wireless card

Connects the computer to a network — Wi-Fi, Bluetooth, or a wired Ethernet port.

01

Examples

Four of these components make a lot more sense side by side than in isolation.

Two brains, working together — CPU and GPU

These aren't rivals and it isn't a choice between them — a working computer needs both, at the same time, doing two different jobs.

CPU: a few things, very fast

A handful of powerful cores, each great at doing one complicated task after another in sequence — running your operating system, opening apps, handling logic.

GPU: thousands of things, at once

Thousands of small, simpler cores built to do the same basic math over and over in parallel — perfect for the millions of pixels on a screen, or the repetitive math behind AI.

A computer that only had a CPU could still technically draw a screen, just painfully slowly, one pixel at a time. A computer that only had a GPU couldn't run your operating system at all — it's not built for that kind of one-thing-after-another logic. Every modern computer needs both, working at the same time, each covering what the other one is bad at.

RAM: your computer's kitchen counter

RAM is temporary workspace, not storage — think of it as the counter space you actually have to cook on, not the pantry where ingredients live long-term.

Small RAM — a 2×2 ft table

Trying to cook Thanksgiving dinner on a card table. There's barely room for one dish — add a second, and something has to get pushed off the edge. That's exactly what a low-RAM computer does to your open apps.

Big RAM — a 20×20 ft table

The whole Thanksgiving spread laid out at once — turkey, sides, dessert, all with room to spare. A high-RAM computer can keep way more apps open and switch between them instantly, with nothing getting shoved off.

The bigger the table (RAM), the more dishes (apps) you can have out at the same time. Run out of table space and the computer has to start clearing things away just to make room — which is exactly what "running slow because too many tabs are open" actually is.

Storage: HDD vs. SSD

HDD (Hard Disk Drive)

Stores data on a spinning physical disk, read by a moving arm with a tiny needle-like head — like a record player. Cheaper per gigabyte, but slower, and because it has real moving parts, dropping or bumping it hard enough can actually break it.

SSD (Solid State Drive)

Stores data electronically, with no moving parts at all — nothing spinning, no needle that can be knocked out of place. Faster to read and write, and far more durable against being dropped or bumped.

BIOS: the test that runs before anything else

BIOS's entire job is to run a self-test — officially called POST (Power-On Self-Test) — the instant you press the power button. It checks that the CPU, RAM, storage, and every other part are actually present and working. Only if everything passes does it hand control over to your operating system.

If a computer won't boot up, it's because BIOS found a problem. That's not a guess — it's literally what BIOS is there to check. A blank screen at power-on almost always means the self-test failed before your operating system ever got the chance to start loading.
02

Common Misconceptions

"More RAM always makes it faster"

Only if RAM was actually the bottleneck — only if the "table" was too small in the first place. If the CPU or storage is what's slow, a bigger table doesn't help; the cooking itself was the slow part, not the counter space.

"A better GPU speeds up everything"

Only tasks built to use the GPU (games, video rendering, AI) benefit. Opening a spreadsheet leans almost entirely on the CPU — the "second brain" just sits idle.

"SSDs can't fail — no moving parts"

They fail differently, not never. Every memory cell in an SSD has a limited number of times it can be rewritten before it wears out — it just won't break from being bumped the way an HDD's needle can.

"The CPU does all the thinking"

Not anymore. The CPU and GPU are two separate brains working at once — and graphics, AI, and even some security tasks increasingly lean on the GPU or other dedicated chips instead.

03

Reading a Real Spec Sheet

Every one of these terms is just one of the components above, dressed up in marketing language. Here are three real-world listings — notice how differently each one presents the exact same information.

Amazon — structured & scannable

"HP 17.3″ Touchscreen HD+ Business Laptop, Core i7-1355U, 32GB RAM, 1TB SSD, HDMI, Fingerprint Reader, Wi-Fi 6, Windows 11 Home" — $999.00

i7-1355U = CPU  •  32GB RAM = RAM  •  1TB SSD = Storage  •  HDMI = a port on the motherboard  •  Wi-Fi 6 = network card

Best Buy — broken into its own fields

"HP OMEN 16″ 165Hz 2.5K OLED Gaming Laptop — AMD Ryzen 9 8940HX — 16GB Memory — NVIDIA GeForce RTX 5060 — 1TB SSD" — $2,299.99

Ryzen 9 8940HX = CPU  •  16GB Memory = RAM  •  RTX 5060 = GPU  •  1TB SSD = Storage. A dedicated GPU line item like this is the clue it's built for gaming.

Facebook Marketplace — casual, no structure at all

"Selling my old gaming pc, works great just upgrading. i5 9600k, 16gb ram, 1tb hdd + 256gb ssd, gtx 1660. $350 obo, pickup only in Social Circle"

i5 9600k = CPU  •  16gb ram = RAM  •  1tb hdd + 256gb ssd = two storage drives, an HDD and an SSD together  •  gtx 1660 = GPU. No labels, no bullet points — you have to already know the vocabulary to even find the specs buried in the sentence.
This is the real skill: Amazon and Best Buy do the organizing for you. A Marketplace seller won't — and neither will a friend describing their computer out loud. Knowing what hdd, ssd, gtx, and ram actually mean is what lets you translate casual language into real specs, every time.
04

Everyday Examples (5)

Five real "something's wrong with my computer" symptoms — and which component is actually behind each one.

Cooling

Fans loud, laptop hot during a game

The cooling system is working overtime to keep the CPU and GPU from overheating under load.

Storage

An old laptop takes 3 minutes to boot

Almost always an HDD, not an SSD — that's one of the most noticeable HDD-vs-SSD differences there is.

BIOS / Motherboard

Totally blank screen at power-on, not even a logo

BIOS's self-test found a problem before the operating system ever got a chance to load — points to a motherboard or BIOS-level failure.

GPU

A game looks choppy, but the CPU seems fine

The GPU is the likely bottleneck, not the CPU — check its usage, not just the processor's.

RAM

Closing browser tabs makes everything faster

The table was full. Every open tab was taking up counter space, and closing some finally freed room to work.

Symptoms point to components. That's the whole game.4.1.4 Forensic Computer Analyst is exactly this — you'll be handed symptoms and have to name the part responsible, the same way as every example above.
