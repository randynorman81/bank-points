Internal Components

Seven parts, seven jobs. Learn what each one actually does and you can diagnose almost any "my computer is acting weird" problem from the symptoms alone.

00

Definition

A computer isn't one thing — it's several specialized parts wired together through one central board, each handling a completely different job. Take any one of them out and the whole machine either stops working, or works badly.

ComponentWhat it actually does
MotherboardThe circuit board everything else plugs into — it's what physically connects every other component to every other component.
BIOSThe very first software that runs the instant you hit the power button — before your operating system even starts loading.
CPU (Central Processing Unit)Executes instructions one at a time, extremely fast — the general-purpose "brain" that runs almost everything.
GPU (Graphics Processing Unit)Built to do thousands of simple calculations at once instead of one at a time — originally for graphics, now also gaming, video editing, and AI.
RAMTemporary, ultra-fast memory holding whatever the computer is actively working on right now — wiped clean every time the power turns off.
Storage (HDD / SSD)Permanent memory that keeps your files, programs, and OS even when the power is off.
Cooling systemFans, heatsinks, sometimes liquid — keeps every other component from overheating and shutting down or getting damaged.
Network / wireless cardConnects the computer to a network — Wi-Fi, Bluetooth, or a wired Ethernet port.
01

Examples

Four of these components make a lot more sense side by side than in isolation.

Why two "brains"? CPU vs. GPU

CPU: a few things, very fast

A handful of powerful cores, each great at doing one complicated task after another in sequence — running your operating system, opening apps, handling logic.

GPU: thousands of things, at once

Thousands of small, simpler cores built to do the same basic math over and over in parallel — perfect for the millions of pixels on a screen, or the repetitive math behind AI.

Neither one is "better" — they're built for opposite kinds of problems. A computer with a great CPU and a weak GPU can still lag badly in a video game, and a great GPU won't make a slow web browser open any faster.

Storage: HDD vs. SSD

HDD (Hard Disk Drive)

Stores data on a spinning physical disk, read by a moving arm — like a tiny record player. Cheaper per gigabyte, but slower, and the moving parts can eventually wear out or fail.

SSD (Solid State Drive)

Stores data electronically, with no moving parts at all — much faster to read and write, and more durable against physical shock (like being dropped).

BIOS: booting before the OS exists

Your operating system (Windows, macOS) has to be loaded off of storage before it can run — but something has to do that loading. That's the BIOS's entire job: the instant you press power, BIOS runs a quick self-check (POST — Power-On Self-Test), then hands control over to the operating system's own loader.

This is why a truly dead motherboard shows a blank screen, not an error message. If BIOS itself can't run, the computer never even gets far enough to know an operating system exists.
02

Common Misconceptions

"More RAM always makes it faster"

Only if RAM was actually the bottleneck. If the CPU or storage is what's slow, adding RAM won't help — it's like buying a bigger desk when the problem is that you're a slow writer.

"A better GPU speeds up everything"

Only tasks built to use the GPU (games, video rendering, AI) benefit. Opening a spreadsheet leans almost entirely on the CPU.

"SSDs can't fail — no moving parts"

They fail differently, not never. Every memory cell in an SSD has a limited number of times it can be rewritten before it wears out.

"The CPU does all the thinking"

Less true every year — graphics, AI, and even some security tasks are increasingly handled by dedicated chips (like the GPU) instead of the CPU.

Reading a Real Spec Sheet

Every one of these terms from a real laptop listing is just one of the components above, dressed up in marketing language.

What the ad saysWhich component
Intel Core i7-1355UCPU — the model name/number
NVIDIA RTX 4060GPU — a dedicated graphics chip
16GB DDR5 RAMRAM — how much active working memory
512GB NVMe SSDStorage — solid-state, no moving parts
Wi-Fi 6ENetwork / wireless card
A laptop with zero mention of a dedicated GPU in its spec sheet almost always means it's relying on a smaller graphics chip built directly into the CPU — fine for browsing and video, not built for gaming.
04

Everyday Examples (5)

Five real "something's wrong with my computer" symptoms — and which component is actually behind each one.

Cooling

Fans loud, laptop hot during a game

The cooling system is working overtime to keep the CPU and GPU from overheating under load.

Storage

An old laptop takes 3 minutes to boot

Almost always an HDD, not an SSD — that's one of the most noticeable HDD-vs-SSD differences there is.

BIOS / Motherboard

Totally blank screen at power-on, not even a logo

Points to a motherboard or BIOS-level failure — the machine never got far enough to load an operating system.

GPU

A game looks choppy, but the CPU seems fine

The GPU is the likely bottleneck, not the CPU — check its usage, not just the processor's.

RAM

Closing browser tabs makes everything faster

RAM was running low — every open tab was holding onto a slice of it.

Symptoms point to components. That's the whole game.4.1.4 Forensic Computer Analyst is exactly this — you'll be handed symptoms and have to name the part responsible, the same way as every example above.
