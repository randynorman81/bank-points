What Does an Operating System Actually Do?

You tap an icon and an app opens in half a second. Behind that half-second, dozens of decisions get made for you. Meet the thing making them.

Georgia IT-IST-5.3 · IT-IST-6.1
00

The Middle Manager Nobody Sees

Imagine a huge company where every employee (your apps) wants something: a desk, a phone line, some cash, a key to a locked room. None of them are allowed to just grab it. Everything goes through one manager who decides who gets what, when. That manager is the operating system.

An operating system (OS) is the software that manages a computer's hardware and gives every other program a safe, fair way to use it. Apps never talk to the hardware directly — they ask the OS.

01

The Six Jobs of Every OS

Every operating system, on every device, does these six things. Click through them.

Process & CPU management

A process is a running program. You have dozens open at once, but a CPU core can only run one thing at a time. The OS switches between them thousands of times a second so fast it looks simultaneous — that's multitasking.

Real example: music playing while you type a paper while a download runs.

Memory (RAM) management

The OS hands each program its own slice of RAM and makes sure no program reads or overwrites another's. When RAM fills up, it moves the least-used data to storage (called virtual memory) — which is why a computer with too many tabs gets slow.

File management

The OS keeps the index of every file and folder, remembers where each one physically lives on the drive, and controls who can open, edit, or delete it. (You met this in Unit 3.)

Device management

Every keyboard, mouse, printer, and screen speaks its own language. The OS uses small programs called drivers as translators, so an app can just say “print this” without knowing which printer brand you own.

User interface

How you talk to the computer. A GUI (graphical user interface) uses windows, icons, and a mouse or touch. A CLI (command-line interface) uses typed commands. Most people live in the GUI; most IT professionals also live in the CLI.

Security & permissions

User accounts, passwords, admin vs. standard users, and permission prompts (“this app wants your camera”) all come from the OS. It's the gatekeeper deciding what each app and each person is allowed to touch.

Vocab You Need

TermPlain-English meaning
Operating systemSoftware that manages hardware and runs every other program
KernelThe core of the OS — the part that talks directly to hardware
ProcessA program that is currently running
MultitaskingRapidly switching between processes so many seem to run at once
DriverA translator that lets the OS control one specific piece of hardware
GUI / CLIGraphical interface (click) vs. command-line interface (type)
The OS is why a program you've never seen can run on hardware its author never touched.Apps ask, the OS decides. That one rule is the whole unit.
