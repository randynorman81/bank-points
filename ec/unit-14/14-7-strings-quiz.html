Notes

Look up these definitions:

  • Review: indexing, slicing, immutability, string iteration, in keyword, string methods

Key idea: This quiz covers the full Strings module: indexing individual characters, slicing out substrings, immutability, looping through a string character by character, the in keyword, and built-in string methods like upper(), lower(), and replace(). Strings show up constantly in real programs — processing user input, working with files, building text-based tools — which is why this module is one of the largest in the course.
