14.3 — Immutability

🔔 Bell Ringer — Think About It
  1. Immutable means a string's individual characters can't be changed once created. If you wanted to "replace" one letter, what do you think you'd actually have to do instead?
  2. Why might a language deliberately make strings unchangeable, rather than allowing you to edit them in place?
  3. You can reassign a whole new string to the same variable name. How is that different from changing one character of the existing string?
  4. Can you think of a reason immutability might make a program safer or more predictable?

Notes

Look up these definitions:

  • Immutability
  • Reassignment vs. mutation

Key idea: Immutability means that once a string is created, its individual characters can never be changed — you can't do word[0] = "X" to edit one letter. What you can do is reassign the whole variable to a brand new string, which is different from mutating (changing) the original. This might feel like a limitation, but it makes strings predictable: once you have a reference to a string, you know its content can never quietly change underneath you.
