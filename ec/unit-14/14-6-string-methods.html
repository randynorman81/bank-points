14.6 — String Methods

🔔 Bell Ringer — Think About It
  1. A method is a function you call on a specific value, like my_string.upper(). How is that different from calling a regular function like print(my_string)?
  2. What do you think my_string.upper() and my_string.lower() do to a string's text?
  3. my_string.replace("a", "b") swaps every "a" for a "b". What real task could you imagine using replace() for?
  4. Why do you think Python bundles so many ready-made string methods instead of making you write that logic yourself every time?

Notes

Look up these definitions:

  • Method
  • Common string methods (upper(), lower(), replace(), strip())

Key idea: A method is a function that belongs to a specific value and is called with dot notation, like my_string.upper() — different from a regular function like print(my_string), which takes the value as an argument instead. Python strings come with many built-in methods: upper() and lower() change case, replace(old, new) swaps text, and strip() removes extra whitespace from the ends. These exist so you don't have to write common text-processing logic from scratch every time you need it.
