14.1 — Indexing

🔔 Bell Ringer — Think About It
  1. A string is really just a sequence of characters, and each character has a position (an index), starting at 0. If word = "CODE", what character do you think word[0] is?
  2. Why do you think programming languages almost universally start counting at 0 instead of 1?
  3. If word has 4 characters, what index would the last character be at?
  4. Where else this year have you already used 0-based indexing (hint: arrays and vectors)?

Notes

Look up these definitions:

  • Index
  • String indexing (word[i])

Key idea: A string is a sequence of individual characters, and each character has a position called an index, starting at 0 — so in "CODE", C is at index 0, O is at index 1, and so on. This is the exact same 0-based indexing you already used with arrays in Arduino C++ and vectors in Codecademy's C++, just applied to the characters inside a string instead of items in a list.
