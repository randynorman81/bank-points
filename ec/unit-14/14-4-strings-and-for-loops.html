14.4 — Strings and For Loops

🔔 Bell Ringer — Think About It
  1. Since strings are indexed like arrays, you can loop through every character with a for loop. What real task might need you to check every character in a string one at a time?
  2. for character in my_string: is a different for loop style than for i in range(n):. What do you think character represents on each pass through the loop?
  3. Why might looping character by character be useful for something like counting how many vowels are in a word?
  4. Which style of for loop (using an index, or using "for character in string") do you think is easier to read, and why?

Notes

Look up these definitions:

  • for character in string
  • Character-by-character iteration

Key idea: Because a string's length matches len(my_string) and its characters are indexed starting at 0, just like an array, a for loop can walk through every character one at a time — either with an index (for i in range(len(my_string))) or more directly with for character in my_string:, which hands you each character in turn without needing an index at all. This is useful anytime you need to examine or process every character in a string, like counting vowels or checking for a specific letter.
