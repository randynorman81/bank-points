14.2 — Slicing

🔔 Bell Ringer — Think About It
  1. Slicing lets you pull out multiple characters at once, like word[1:3]. How is that different from indexing, which only grabs one character?
  2. If word = "CODEHS" and you wanted just "CODE", what slice range do you think would give you that?
  3. Why might slicing be useful for a real task, like pulling just the area code out of a phone number string?
  4. Predict what happens if you try to slice past the end of a string — does Python error, or handle it gracefully?

Notes

Look up these definitions:

  • Slicing (word[start:end])
  • Substring

Key idea: Slicing pulls out a range of characters at once, using word[start:end], instead of indexing which only grabs a single character — the substring returned includes the start index but stops right before the end index. This is genuinely useful for real tasks, like pulling the area code out of a phone number string, or the file extension off the end of a filename.
