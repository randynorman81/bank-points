14.5 — The in Keyword

🔔 Bell Ringer — Think About It
  1. The in keyword checks whether a value exists inside something else, like "a" in "cat". What do you think that expression evaluates to?
  2. How is in different from looping through every character yourself to check for a match?
  3. Where might you use in to check if a user's password contains a required character, like a number or symbol?
  4. Why might a built-in shortcut like in be preferable to writing your own loop to do the same check?

Notes

Look up these definitions:

  • in keyword

Key idea: The in keyword checks whether a value exists somewhere inside a string (or later, inside a list), returning True or False — "a" in "cat" is True, "z" in "cat" is False. This does in one line what would otherwise take a full for loop with a conditional inside it to check every character by hand. It's especially useful combined with an if statement, like if "@" in email: to do a very basic check that an email address looks valid.
