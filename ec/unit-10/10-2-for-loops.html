10.2 — For Loops

🔔 Bell Ringer — Think About It
  1. Python's for loop is written for i in range(n):. How is that different from C++'s for (int i = 0; i < n; i++)?
  2. You used i as a counter variable in Arduino C++ and Codecademy's C++. What job does i do inside a Python for loop?
  3. If you wanted a loop to run exactly 10 times, what would you write inside range()?
  4. Why might range() be considered simpler to read than C++'s three-part for loop header?

Notes

Look up these definitions:

  • for loop (Python syntax)
  • range()
  • Counter variable (i)

Key idea: Python's for loop, written for i in range(n):, repeats its block n times, with i automatically counting 0, 1, 2, ... up to n-1. This does the same job as C++'s for (int i = 0; i < n; i++), just with less to write — range() handles the starting value, the stopping condition, and the increment all in one call. i is still just a counter variable you can use inside the loop, the same role it played in every for loop you've written in C++ so far.
