10.1 — While Loops

🔔 Bell Ringer — Think About It
  1. A while loop repeats as long as a condition stays true. You've now seen this in Arduino C++, Codecademy's C++, and Python. What stays exactly the same about the concept across all three?
  2. If a while loop's condition never becomes false, what happens to the program? Why is this called an infinite loop?
  3. Describe a real situation that works like a while loop: "keep doing X while Y is true."
  4. What's the difference between a for loop (which you'll see next lesson) and a while loop, in terms of when you'd choose one over the other?

Notes

Look up these definitions:

  • while loop (review)
  • Infinite loop (review)
  • Loop condition

Key idea: A while loop repeats its block of code for as long as its condition stays true, checking that condition again at the top of every pass. This is the identical concept from Arduino C++ and Codecademy's C++ — only the Python syntax (while condition: followed by an indented block) is new. The same danger applies too: if nothing inside the loop ever makes the condition false, you get an infinite loop, and the program never moves on.
