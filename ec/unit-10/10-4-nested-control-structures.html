10.4 — Nested Control Structures

🔔 Bell Ringer — Think About It
  1. A loop inside another loop is called a nested loop. What's a real-world example of a repeated task that itself contains another repeated task inside it (like checking every row and every column of a grid)?
  2. If an outer loop runs 3 times and an inner loop runs 4 times each time, how many total times does the inner loop's code run?
  3. Why might a nested if statement inside a loop make a program's logic harder to follow, and what could you do about that?
  4. Which control structures (if, while, for) have you now combined together in a single program this year?

Notes

Look up these definitions:

  • Nested loop
  • Nested conditional

Key idea: A nested control structure is one control structure (a loop or an if) placed inside another. A loop inside a loop is common when working with grid-like data — an outer loop for rows, an inner loop for columns — and the inner loop's total repetitions multiply: an outer loop of 3 with an inner loop of 4 runs the inner code 12 times total. Combining ifs and loops, and loops inside loops, is where programs start to genuinely solve complex problems, but it's also where code can get hard to read if it's not organized carefully.
