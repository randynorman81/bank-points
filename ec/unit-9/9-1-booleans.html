9.1 — Booleans

🔔 Bell Ringer — Think About It
  1. A boolean can only ever be True or False — nothing in between. Give a real-life yes/no question that a boolean could represent.
  2. You used booleans in Arduino C++ (bool locked = true;) and in Codecademy's C++ course. What's different about how Python writes True and False compared to C++?
  3. Why might a program want to store a boolean in a variable instead of just checking the condition fresh every time it's needed?
  4. If isRaining = True, what do you think print(isRaining) actually displays on screen?

Notes

Look up these definitions:

  • Boolean
  • True / False (capitalized in Python)

Key idea: A boolean is a value that can only be True or False — the same concept as bool in Arduino C++ and Codecademy's C++ course, just with Python capitalizing True and False since they're special keywords. Booleans are how a program represents a yes/no, on/off, or true/false fact, and they're the foundation everything in this unit (comparisons, logical operators, if statements) builds on. Storing a boolean in a named variable, like isRaining or gameOver, makes code that reads it later much clearer than a bare condition.
