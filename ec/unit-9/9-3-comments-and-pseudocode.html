9.3 — Comments & Pseudocode

🔔 Bell Ringer — Think About It
  1. Why is it helpful to write a short plan in plain English before you write any code?
  2. A comment is a note in your code that the computer ignores. Who is a comment written for, and when would you be glad you wrote one?
  3. A light switch is either on or off, but a dimmer can be anywhere in between. Which one is digital and which one is analog?
  4. How could an Arduino make an LED look dim when its pin can only be turned on or off?

Notes

Look up these definitions:

  • Comment
  • Pseudocode
  • Analog vs. digital
  • analogWrite()
  • PWM (pulse width modulation)

Key idea: Pseudocode is a plan for your program written in plain English before you write real code, and comments are notes inside your code. Both make programs easier to organize and read. This lesson also introduces analog output with analogWrite(), the same PWM idea you used for LED brightness in Unit 2.
