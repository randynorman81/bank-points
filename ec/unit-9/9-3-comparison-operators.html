9.3 — Comparison Operators

🔔 Bell Ringer — Think About It
  1. List the six comparison operators (<, <=, >, >=, ==, !=) and, for each, describe a real situation where you'd use it.
  2. Why do you think == (double equals) is used for comparison and = (single equals) for assignment, instead of using the same symbol for both?
  3. If age >= 13 evaluates to True, what type of value does that expression produce?
  4. Predict what 5 != 5 evaluates to, and explain your reasoning.

Notes

Look up these definitions:

  • Comparison operators (<, <=, >, >=, ==, !=)

Key idea: Comparison operators take two values and produce a boolean result — true or false — which is exactly what an if statement's condition needs. Python's six comparison operators (<, <=, >, >=, ==, !=) work the same way they did in Codecademy's C++ course, including the same easy mistake of confusing == (compare) with = (assign). Every condition you write in an if statement is ultimately built from one or more of these six operators, sometimes combined with the logical operators from the next lesson.
