9.1 — Welcome to Arduino!

🔔 Bell Ringer — Think About It
  1. Think about devices that sense something or move something, like an automatic door or a smart thermostat. What do you think is inside them?
  2. Physical computing means programs that interact with the real world through parts like LEDs, buttons, and sensors. How is that different from programs that only print text to a screen?
  3. Tinkercad lets you build and test a circuit without any real hardware. What are the advantages of testing a circuit virtually before building it for real?
  4. You already built circuits in Tinkercad in Units 2 and 3. Which part of building a circuit do you remember best, and which part still feels confusing?

Notes

Look up these definitions:

  • Physical computing
  • Arduino
  • Tinkercad Circuits
  • Component

Key idea: This lesson reintroduces Tinkercad, where you will build and test virtual circuits for the rest of this course, and gets you thinking about what physical computing is. You have already worked in Tinkercad in Units 2 and 3, so treat this as a fresh start with new goals: this time the code you write controls the circuit.
