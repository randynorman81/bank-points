9.2 — If Statements

🔔 Bell Ringer — Think About It
  1. You already used if and if/else in Arduino C++, Codecademy's C++, and Tracy's turtle graphics. What's the same about how if statements work no matter the language?
  2. Python uses indentation (spaces) instead of curly braces { } to show what's inside an if block. Why do you think that's an intentional design choice rather than an accident?
  3. If your indentation is inconsistent in a Python program, what do you think happens when you try to run it?
  4. Describe a rule from a game you play that works like an if/else statement ("if you roll a 6, you get an extra turn, else your turn ends").

Notes

Look up these definitions:

  • if / else (review)
  • Indentation (whitespace as code structure)

Key idea: if and if/else work exactly the way they did in Arduino C++ and Codecademy's C++ — run this code only if a condition is true, and optionally run something else if it's false. The one real difference in Python: instead of curly braces { } marking what's inside the if block, Python uses indentation itself, so getting the spacing wrong isn't just messy, it actually breaks the program or changes what it does. This is a deliberate design choice in Python meant to force code to stay readable, but it takes some adjusting to after C++'s braces.
