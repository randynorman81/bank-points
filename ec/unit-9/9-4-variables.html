9.4 — Variables

🔔 Bell Ringer — Think About It
  1. What is a variable, and why would a program use one instead of typing the same number everywhere?
  2. A potentiometer is a dial that gives a different reading as you turn it. How could a program use that reading to control something?
  3. analogRead() returns a number from 0 to 1023, but analogWrite() only accepts 0 to 255. What problem does that create, and how could you fix it?
  4. What is a breadboard, and why is it useful when you build a circuit?

Notes

📄 Notes: Variables (everything you need for the lesson)

Look up these definitions:

  • Variable
  • Breadboard
  • analogRead()
  • map()
  • Potentiometer

Key idea: This lesson combines variables with a real circuit on a breadboard. analogRead() reads a value from a sensor or dial, a variable stores it, and map() rescales it into the range another command needs. The same analogRead and map idea appeared in Unit 3 when a dial controlled a servo.
