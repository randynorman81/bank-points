13.4 — Final Project

🔔 Bell Ringer — Think About It
  1. This is a fully open final project — your own idea, built with everything you've learned this year. What's one idea you're excited to try?
  2. Scoping a project means cutting features that don't fit in the time you have. What's one thing you'd be willing to cut from your idea if you ran out of time?
  3. Working alone versus with a partner or group each have tradeoffs. Which would you prefer for this project, and why?
  4. When you present this project to the class, what's the one thing you most want them to understand about what you built?

Notes

Look up these definitions:

  • Project scoping
  • Final presentation

Key idea: This is a fully open final project: design and build something of your own choosing using everything from this entire year — Arduino Foundations, Outputs, C++, Python, and Sensors — working individually or with a partner or group. Scoping matters here: an ambitious idea that gets cut down to something achievable and finished is a better project than an overambitious one that never works. You'll present the finished project and explain how you built it.

Assignment

  • 13.4 — Final Project. Complete Lesson 12.4 in CodeHS (Intro to Programming in Python with Arduino course) — in Tinkercad: design, build, and present your own final project.
