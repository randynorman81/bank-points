Notes

📄 Notes: Functions (More Sensors) (everything you need for the lesson)

Look up these definitions:

  • Internal sensors (review)
  • Functions with/without parameters (review)

Key idea: This lesson uses Arduino's internal sensors and has you organize your code with functions, both with and without parameters, the same skills from the Functions and Exceptions module now applied to sensor code specifically. Wrapping a sensor reading in a function, like readDistance() or isTooClose(), makes the rest of your program easier to read — you call the function by name instead of repeating the raw sensor-reading code everywhere you need that value.
