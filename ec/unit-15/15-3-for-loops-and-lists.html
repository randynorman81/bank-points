15.3 — For Loops and Lists

🔔 Bell Ringer — Think About It
  1. You already looped through every character in a string with a for loop. How do you think looping through every item in a list would be similar?
  2. for item in my_list: hands you each item directly. Why might that be more convenient than using an index to fetch each item one at a time?
  3. If you wanted to add up every number in a list of scores, how would a for loop help you do that?
  4. Which do you think is more common in real code: looping through a list by index, or looping through it directly with "for item in list"?

Notes

Look up these definitions:

  • for item in list
  • List iteration

Key idea: Just like looping through a string character by character, you can loop through a list item by item, either with an index (for i in range(len(my_list))) or more directly with for item in my_list:, which hands you each value in turn. This pattern — loop through a list, do something with each item — is one of the most common things a program does, whether that's adding up scores, searching for a specific value, or checking every item against a condition.
