15.4 — List Methods

🔔 Bell Ringer — Think About It
  1. Just like strings have methods (upper(), replace()), lists have their own methods. What do you think my_list.append(5) does?
  2. my_list.remove(3) removes the value 3 from the list. What do you think happens if that value appears more than once, or not at all?
  3. Why might Python provide built-in methods for common list operations instead of making you write that logic yourself every time?
  4. What's one list method you'd guess exists that you haven't been told about yet, based on what you know lists need to do?

Notes

Look up these definitions:

  • List methods (append(), remove(), sort(), etc.)

Key idea: Like strings, lists come with built-in methods you call with dot notation: append(value) adds an item to the end, remove(value) deletes the first matching item, and sort() reorders the list, among several others. These exist for the same reason string methods do — common operations on a data structure are needed constantly, so the language provides tested, ready-made tools instead of making every programmer rewrite the same logic.
