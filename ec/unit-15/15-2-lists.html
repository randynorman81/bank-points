15.2 — Lists

🔔 Bell Ringer — Think About It
  1. A list is Python's mutable version of an ordered sequence — you can add, remove, and change items after creating it. How is that different from the tuple you just learned about?
  2. You used vectors in Codecademy's C++ for exactly this kind of flexible, growable list. What do you expect to be similar about Python lists?
  3. If you wanted to store a growing list of high scores in a game, would a tuple or a list be the right choice? Why?
  4. What real data would you want to store in a list specifically because you expect it to change over time?

Notes

Look up these definitions:

  • List
  • Mutable data structure

Key idea: A list is Python's ordered, mutable sequence — you can add items, remove items, and change existing items after the list is created, unlike a tuple. This is the direct equivalent of the vectors you used in Codecademy's C++ course, just with Python's simpler syntax (my_list = [1, 2, 3]). Lists are the right choice anytime your data needs to grow, shrink, or change while the program is running, like a running list of scores or a shopping cart.
