Unit 5: Input Systems

You shift from sensing the world to structured human input. You'll build a keypad-based PIN entry system, meet I2C serial communication, combine input and output into one working interface, and get a first look at finite state machines. This unit also formally introduces the Scrum framework — sprint, standup, backlog, retrospective — through two real cases about input devices becoming attack vectors (the Target data breach, Stuxnet).
