5.3 — Functions Challenge Project

🔔 Bell Ringer — Think About It
  1. This project asks you to combine vectors and functions. Which do you think should come first in your plan — building the vector of data, or writing the functions that use it?
  2. A Tic-Tac-Toe board can be represented as a vector. What would each item in that vector need to store?
  3. When a function isn't behaving the way you expect, is the bug more likely in how you're calling the function or in what's written inside it? How would you tell the difference?
  4. What's one function you'd want to write first for a Tic-Tac-Toe program, and what would its one job be?

Notes

Look up these definitions:

  • Board representation
  • Function decomposition

Key idea: This project puts vectors and functions to work together by building a Tic-Tac-Toe game — a great real test of whether you can decompose a problem into small functions (checking a win, printing the board, taking a move) that each do one clear job and share data through a vector. Plan the functions you'll need before writing code: what does each one take in, and what does it hand back?
