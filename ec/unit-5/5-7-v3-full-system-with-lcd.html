Notes

Look up these definitions:

  • System integration
  • Pin budget
  • Status display

Key idea: this is 4.6's integration challenge again, one component larger. Plan your pin budget before wiring anything: RC522 needs SS, RST, MOSI, MISO, SCK + power/ground (5 signal pins); servo needs 1 PWM pin + power/ground; LCD needs dedicated SDA/SCL + power/ground. Write out every pin every component uses first — this catches conflicts before they become confusing bugs. Recommended order: RC522 + LCD together first (confirm the LCD shows a scanned UID), then add the servo + whitelist logic on top. Your LCD's status display should show "Scan Card" while waiting, then briefly "Access Granted"/"Access Denied," then return to waiting.

Assignments

  • 5.7 — V3: Full System with LCD. Write out your complete pin budget first. Wire RC522 + LCD and confirm a scanned card's UID displays correctly — no whitelist or servo logic yet. Then add the servo and integrate your V1 whitelist logic, replacing LED/Serial feedback with LCD status messages, with the servo locking/unlocking based on the access decision. Test the complete system thoroughly: authorized cards, unauthorized card, LCD messages, servo movement, and auto-relock all working together. Submit your fully annotated code and a photo or video of the complete working system.
