5.7 — V3: Full System with LCD

Two-period lesson — the unit's primary sprint deliverable and most complex build of the year so far. Every piece (RC522, whitelist, servo, LCD) is review; integrating all three at once is what's new. Revisit what you wrote for "what would you do differently for V3" in your 5.6 retrospective before starting.

Intro

Ask AI these questions; look over the answers.

  1. What strategy would you use to combine three separate working systems into one, rather than just trying to merge all the code at once?
  2. Explain to a middle schooler why combining three things that each work alone is generally harder than combining just two.
  3. Create a simple checklist for planning pin assignments before wiring a complex system with multiple components.
  4. What specific information should a real access control system's display show a user — what's actually useful feedback versus unnecessary detail?
  5. Connect today's three-way integration challenge to a real engineering project you might recognize that combines multiple distinct subsystems into one product.
  6. Why might engineers build and test components separately before integration, even when they already know roughly how the final combined system should behave?

Notes

Look up these definitions:

  • System integration
  • Pin budget
  • Status display

Key idea: this is 4.6's integration challenge again, one component larger. Plan your pin budget before wiring anything: RC522 needs SS, RST, MOSI, MISO, SCK + power/ground (5 signal pins); servo needs 1 PWM pin + power/ground; LCD needs dedicated SDA/SCL + power/ground. Write out every pin every component uses first — this catches conflicts before they become confusing bugs. Recommended order: RC522 + LCD together first (confirm the LCD shows a scanned UID), then add the servo + whitelist logic on top. Your LCD's status display should show "Scan Card" while waiting, then briefly "Access Granted"/"Access Denied," then return to waiting.

Assignments

  • 5.7 — V3: Full System with LCD. Write out your complete pin budget first. Wire RC522 + LCD and confirm a scanned card's UID displays correctly — no whitelist or servo logic yet. Then add the servo and integrate your V1 whitelist logic, replacing LED/Serial feedback with LCD status messages, with the servo locking/unlocking based on the access decision. Test the complete system thoroughly: authorized cards, unauthorized card, LCD messages, servo movement, and auto-relock all working together. Submit your fully annotated code and a photo or video of the complete working system.
