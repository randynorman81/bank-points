5.1 — Vectors

🔔 Bell Ringer — Think About It
  1. A vector is C++'s version of a list that can grow or shrink while your program runs. Why might a fixed-size list (like an array) not be flexible enough for some programs?
  2. You've already used arrays in Arduino code (like a 7-segment digit lookup table). What do you think a vector can do that a plain array can't?
  3. Vectors are indexed starting at 0, same as arrays. If a vector has 5 items, what is the index of the last one?
  4. push_back() adds an item to the end of a vector. Why is being able to grow a list while the program is running useful?

Notes

Look up these definitions:

  • Vector
  • Index
  • push_back()
  • size()

Key idea: A vector stores an ordered list of values, just like the arrays you used in Arduino code, but it can grow or shrink while the program runs — push_back() adds a new item to the end, and size() tells you how many items are currently there. Like arrays, vectors are indexed starting at 0, so the last item in a 5-item vector is at index 4, not 5. Vectors are the tool of choice in C++ whenever you don't know in advance exactly how many items you'll need to store.
