5.3 — RC522 Wiring Lab: SPI Serial Communication

⚠ Safety: the RC522 module connects to 3.3V — NEVER 5V. Using 5V can permanently damage the module. Double-check you're on the Uno's dedicated 3.3V pin before uploading any code.

Notes

Look up these definitions:

  • SPI (Serial Peripheral Interface)
  • MOSI (Master Out, Slave In)
  • MISO (Master In, Slave Out)
  • SCK (Serial Clock)
  • SS (Slave Select)

Key idea: SPI is the course's second named communication protocol, contrasting with I2C from Unit 4. Where I2C shares one wire (SDA) for data in both directions and uses an address system, SPI uses 4 dedicated wires — MOSI (master→slave data), MISO (slave→master data), SCK (shared clock, like I2C's SCL), and SS (identifies which slave device, instead of an address number). More wires, but generally faster — a good fit for RFID's relatively fast, frequent communication. Same master/slave pattern as I2C: the Arduino is master, the RC522 is slave.
