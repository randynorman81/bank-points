Unit 6: Multi-Sensor Design Projects

No new hardware, no new programming concept, no case studies — this is the year's first fully open-ended design unit. Framed by the real story of how the Nest Thermostat was built (V1→V2→V3), you propose, design, and build your own original multi-sensor project using any combination of components from the full kit you've built up across Units 2–5, across two sprints with formal retrospectives, ending in a live Demo Day.
