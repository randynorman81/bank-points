01

The 5-Step Debugging Method

Reflections 2 + 3

A detective doesn't arrest the first suspect they see. They list what should have happened, what did happen, collect evidence, and test one theory at a time. Debugging is exactly that. Click each step.

Never change several things at once. If it starts working, you won't know which change fixed it. If it gets worse, you won't know which change broke it.
02

Two Tools, Two Questions

Every bug lives in one of two places: the code or the circuit. Each tool looks into one of them.

Serial Monitor: what the code sees

Prints numbers while the program runs. It answers "what value is the program working with?" It only prints if communication was opened in setup(), the same way as in 2.4 and 3.6.

Multimeter: what the circuit does

Measures the actual voltage between two points. It answers "is electricity really getting where it should?"

Which tool would you reach for?

03

Concept Refreshers

Part 3 hints

Each hint in your assignment points back to something you've already learned. Here's that idea again, so you can check the broken circuit and code against it yourself.

Printing needs setup

The Serial Monitor shows nothing unless Serial.begin(9600); runs in setup() first (2.4).

Which pin, really?

The code reads whatever pin it names. The wire has to be on that same pin. A0 and A1 are different pins (3.6).

LED direction

Current flows one way through an LED: anode (long leg) toward the pin, cathode (short leg) toward GND. Backwards, it blocks (2.2).

What protects an LED

Every LED needs something in line to limit its current (2.2, 2.7).

Pin modes

INPUT means the pin listens. OUTPUT means the pin drives power out. A pin that should light something must be set to drive (2.3).

Try your own detective work first, as the assignment says. Use these only when you're stuck, and when you find a bug, fix only that one, then restart the simulation and test.
04

Using the Multimeter

Part 4

A multimeter is a voltage detective. Touch its two probes to two points, and it tells you the voltage difference between them. In Tinkercad it's in the components panel, like any other part.

Setting it up in Tinkercad

  1. Drag a Multimeter in from the components panel.
  2. Click it and set its mode to Voltage (DC).
  3. Connect its two probes to the two points you want to compare. Red goes to the higher (+) side, black to the lower (−) side.
  4. Start the simulation and read the number.

What to expect

  • Across a lit LED + its resistor: the 5 volts from the pin gets split between them. The two readings together add up to about the pin's voltage.
  • The dial's middle leg to GND: it slides between the voltages on the two outer legs as you turn it (3.6).
