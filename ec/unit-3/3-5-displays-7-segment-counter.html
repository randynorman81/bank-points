3.5 — Displays: 7-Segment Counter

🔔 Bell Ringer — Think About It
  1. A 7-segment display has seven tiny LEDs. How can seven on/off lights show every digit from 0 to 9?
  2. Each segment needs its own pin. What problem does that create as displays get bigger?
  3. Would you rather write ten separate if statements for the ten digits, or store them in a table? Explain.
  4. Where have you seen 7-segment digits in real life?

Notes

Look up these definitions:

  • 7-segment display
  • Segment (a to g)
  • Lookup table
  • 2D array

Key idea: A 7-segment display is seven LEDs labeled a through g (a is the top bar, g is the middle bar). The Tinkercad one is common cathode, so the shared leg goes to GND and each segment gets a 220 Ω resistor and its own pin. Rather than writing separate code for every digit, store the pattern for each digit in a lookup table, a 2D array: digits[3] is the list of seven on/off values that draws a 3. Then one function, showDigit(n), can draw any number.
