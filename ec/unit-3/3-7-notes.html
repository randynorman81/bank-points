01

Arrays and Indexes

Part 2 + Reflections 1, 3

Five LEDs could mean five variables and five copies of every line. An array puts all five pin numbers in one list with one name, and a for loop reaches each one by its position number.

const int ledPins[] = {2, 3, 4, 5, 6}; const int NUM_LEDS = 5;

Click an index to look it up

Indexes start at 0. An array with 5 items has indexes 0, 1, 2, 3, 4. There is no index 5. That's why a loop over it runs while i < NUM_LEDS. Think about what i <= NUM_LEDS would try to do on its last pass (Reflection 3).

Wiring and setup()

Parts 1 + 2

Five LEDs in a row, each wired the way you've wired LEDs since 2.2. Then one short for loop sets up all five pins at once.

LED12345
Pin23456

Pin → 220 Ω resistor → LED long leg (anode). Short leg (cathode) → GND. Optional: a potentiometer (3.6) for a speed dial.

setup() with a loop

A for loop with i from 0 up to (but not including) NUM_LEDS that calls pinMode(ledPins[i], OUTPUT);. One line of work, done 5 times, once for each pin in the list.

03

Functions: Name It Once, Use It Everywhere

Part 3

A function is a recipe card. You write the steps once, give the card a name, and from then on you just say the name. Some recipes need an ingredient handed to them first: that's a parameter.

Anatomy

void showLed(int index) { // steps go here }
  • void: hands nothing back.
  • showLed: its name.
  • int index: a parameter, filled in when it's called. showLed(3) runs it with index = 3.

Your three functions (you write the insides)

FunctionJob
void allOff()Loops through every LED and sets it LOW.
void showLed(int index)Calls allOff(), then turns only the LED at that index HIGH.
void scan(int speed)LEDs 0 to 4 with showLed(i) then delay(speed), then back from 3 down to 1 the same way.

Then in loop(): scan(100);

Functions calling functions: scan() calls showLed(), and showLed() calls allOff(). Each one does one small job and trusts the others to do theirs. Put all three above loop(), and a comment above each saying what it does.
04

Functions That Hand Something Back

Part 4 + Reflection 2

A parameter goes into a function. A return value comes out. It's the difference between handing a calculator a number and reading the answer off its screen.

The example shape from your assignment

int speedFromDial(int reading) { return map(reading, 0, 1023, 20, 300); }

int in front (instead of void) means it hands back a whole number. return is the line that hands it back. Then: int speed = speedFromDial(analogRead(A0)); and scan(speed);

Watch it go in and come out

reading (parameter in):

No dial? The assignment lets you return something else, like a random speed, instead.

A second pattern: for example blinkAll(int times) turns all 5 LEDs on together, waits, turns them off, and repeats that many times. Call it from loop() after scan(). Part 4 needs: a function with a parameter, a function that returns a value, and a second pattern.
