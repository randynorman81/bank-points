3.6 — Inputs Drive Outputs

🔔 Bell Ringer — Think About It
  1. A digital input is on or off. What is an example of something you control by turning a dial instead of flipping a switch?
  2. A dial gives numbers from 0 to 1023 but a servo wants 0 to 180. What do you need to do to the number in between?
  3. Every electronic device follows input, then thinking, then output. Pick a device and name each of the three parts.
  4. Why might it be useful to print the dial's value on screen while you build?

Notes

Look up these definitions:

  • Potentiometer
  • analogRead()
  • map()
  • Input, process, output

Key idea: A potentiometer is a dial that gives a voltage from 0 to 5 V. analogRead(A0) turns that into a number from 0 to 1023. map(value, 0, 1023, 0, 180) rescales it to whatever range the output needs (an angle, a pitch, a brightness). Nearly every embedded system is input, process, output: read something, decide or scale, then act. Print the value with Serial.println() to see what the program sees.
