3.3 — Servo: Angles and Sweeps

🔔 Bell Ringer — Think About It
  1. A normal motor just spins. A servo can move to a chosen angle and hold it. Name one machine where holding an exact position matters.
  2. A servo can only turn about 180 degrees. Why might that be enough for most jobs?
  3. Why do you think Arduino provides a Servo library instead of making you write the timing code every time?
  4. Imagine a door lock controlled by a servo. What would the two positions (angles) represent?

Notes

Look up these definitions:

  • Servo motor
  • Library
  • #include
  • attach() and write()

Key idea: A servo moves to a specific angle from 0 to 180 degrees and holds it. Add #include <Servo.h> at the top, create a servo object with Servo myServo;, connect it with myServo.attach(9); in setup, then move it with myServo.write(angle);. Under the hood the library sends tiny pulses roughly 1–2 milliseconds wide; the width of the pulse is the angle. A for loop that changes the angle a little at a time gives a smooth sweep instead of a jump.
