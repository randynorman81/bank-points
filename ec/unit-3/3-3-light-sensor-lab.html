Notes

Look up these definitions:

  • Photoresistor
  • analogRead()
  • map()
  • Calibration

Key idea: a photoresistor's resistance drops as light increases — it's an analog sensor, reporting a continuous range, not just light/dark. analogRead(pin) returns a number 0–1023. map(value, fromLow, fromHigh, toLow, toHigh) converts that into a more useful range — e.g. map(lightLevel, 0, 1023, 0, 255) converts a raw reading into the 0–255 range analogWrite() expects. Calibration matters because the exact raw values a photoresistor produces depend on the room's actual lighting — a program tested in one location may need adjustment in another.

Assignments
