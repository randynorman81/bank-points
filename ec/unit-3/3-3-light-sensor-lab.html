3.3 — Light Sensor Lab

Two-period lesson, TinkerCAD simulation only — the one sensor this unit we don't use real hardware for.

Intro

Ask AI these questions; look over the answers.

  1. What is a photoresistor and how does its resistance change based on light level? Explain it to a middle schooler.
  2. Why does an Arduino need to convert an analog sensor reading into a different range of numbers before using it? What does the map() function actually do?
  3. Create a simple diagram showing how light hitting a photoresistor eventually becomes a number the Arduino can use in code.
  4. What real products automatically respond to light levels the way we're about to build today? List at least 3.
  5. Connect today's light sensor project to a real engineering challenge — where does getting light measurement wrong in a real product cause a real problem?
  6. Why might a company choose to simulate a circuit like this instead of building it with real hardware first, even after they're confident in the design?

Notes

Look up these definitions:

  • Photoresistor
  • analogRead()
  • map()
  • Calibration

Key idea: a photoresistor's resistance drops as light increases — it's an analog sensor, reporting a continuous range, not just light/dark. analogRead(pin) returns a number 0–1023. map(value, fromLow, fromHigh, toLow, toHigh) converts that into a more useful range — e.g. map(lightLevel, 0, 1023, 0, 255) converts a raw reading into the 0–255 range analogWrite() expects. Calibration matters because the exact raw values a photoresistor produces depend on the room's actual lighting — a program tested in one location may need adjustment in another.

Assignments

  • 3.3 — Light Sensor Lab. In TinkerCAD, build a circuit with a photoresistor, a fixed resistor (voltage divider), and an LED. Read the raw value with analogRead() and print it to Serial Monitor, adjusting the simulated light level to see it change. Then use map() to convert the raw reading into a 0–255 brightness range and drive the LED with analogWrite() so it responds to light level (e.g. dimmer room = brighter LED, like an automatic night light). Submit your annotated code and a screenshot of your working, light-responsive circuit.
