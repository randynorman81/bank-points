03

Test the Wiring First

Part 2

Fourteen wires means fourteen chances to swap two. Finding that mistake now takes a minute. Finding it after you've written a lookup table takes an hour, because you won't know if the problem is the wires or the table.

What the test does

Turns on pin 2, waits half a second, turns it off; then pin 3; and so on through pin 8. Each bar should light in order a, b, c, d, e, f, g. If the wrong bar lights, or none does, fix that wire now.

You build this test. Think about what you learned in 2.3 (digitalWrite, delay) and 3.2 (for loops).

The Lookup Table

Part 3

Ten digits could mean ten separate blocks of code. Instead, store all ten patterns in one table, like a cheat sheet, and write just one function that looks up the row it needs. That's a lookup table, one of the most useful tricks in programming.

A 2D array: a table of rows

const byte digits[10][7] = { {1,1,1,1,1,1,0}, // 0 {0,1,1,0,0,0,0}, // 1 // your rows for 2 to 9 go here };

[10][7] means 10 rows (digits 0–9), 7 columns (segments a–g). Rows are separated by commas, and the whole thing ends with };

Reading a cell

digits[n][s] means "row n, column s." digits[1][1] is row 1 (the digit 1), column 1 (segment b), which is 1: on.

Paired with segPins[] = {2,3,4,5,6,7,8}, column s of the table and position s of segPins always mean the same segment.

PieceWhat it does
void showDigit(int n)Between setup() and loop(). A for loop with s from 0 to 6 calls digitalWrite(segPins[s], digits[n][s]); so each segment gets its on/off value from row n.
In setup()A for loop with s from 0 to 6 calls pinMode(segPins[s], OUTPUT);
In loop()A for loop with n from 0 to 9 calls showDigit(n); then delay(1000);
05

The Button Counter

Part 4 + Reflections

Every press adds one. After 9, it has to go back to 0, because there's no single-digit 10. Then the lookup table does the rest: showDigit(count).

What Part 4 needs

  • A count variable that starts at 0.
  • In setup(): pinMode(9, INPUT_PULLUP); and showDigit(count);
  • In loop(): if the button is pressed (digitalRead(9) == LOW), add 1 to count, wrap it to 0 if it goes past 9, call showDigit(count), then delay(300);
  • The delay(300) stops one press from counting many times (like the lock in 3.3).
