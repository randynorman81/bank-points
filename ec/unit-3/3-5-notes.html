01

Why This Display Only Needs 4 Wires

Step 1

Every number on a microwave or a scoreboard is built from 7 little bars. A raw 4-digit display needs a wire for every bar plus a wire to pick the digit, and your code has to flip between digits so fast they all look lit. This one hides all of that behind a small chip. Click to compare.

11 wires

Trade-off: a little extra code (a library) in exchange for far fewer wires and far less code to write and debug. That is a common deal in real hardware.

03

Set the Display Up in Code

Steps 3 and 4

The library for this display is already built into the editor. You load it with two #include lines at the very top.

#include <Wire.h> // the I2C library (2-wire talking) #include "Adafruit_LEDBackpack.h" // the display's library Adafruit_7segment matrix = Adafruit_7segment(); // make a display called matrix int count = 0; // the number to show void setup() { matrix.begin(0x70); // start talking to address 0x70 pinMode(2, INPUT_PULLUP); // the button }

What is 0x70?

The display chip's I2C address: the "name" it listens for. 0x means the number is written in hexadecimal (base 16). 0x70 is 112 in everyday numbers.

Don't forget

  • No semicolon after #include lines.
  • <angle brackets> for built-in libraries, "quotes" for added ones.
  • matrix.begin(0x70) goes in setup().

05

Count Up with the Button

Step 6 + Reflections

Add this above the two display lines, so the display always shows the most recent count. After 9999 there is no 5-digit number, so it wraps back to 0.

if (digitalRead(2) == LOW) { // button held down? count++; // add 1 if (count > 9999) count = 0; // wrap around delay(150); // one press = one count }
