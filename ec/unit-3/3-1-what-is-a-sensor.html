3.1 — What Is a Sensor? Full Classification

🔔 Bell Ringer — Think About It
  1. Every sensor has some margin of error — no sensor is perfectly accurate. Should a hospital heart monitor and a school thermostat be held to the same accuracy standard, or does the stakes of what a sensor is used for change how accurate it needs to be?
  2. Your phone probably has a dozen sensors you never think about. Pick one you didn't know was there — what would actually break in your daily life if it silently stopped working?
  3. An analog sensor reports a whole range of values; a digital sensor just reports on or off. Why would an engineer ever choose the "dumber" digital option when the analog one gives more information?
  4. If you were designing a device on a tight budget, would you rather it have one very accurate sensor or three cheaper, less accurate ones? What's the real tradeoff there?

Notes

Look up these definitions:

  • Sensor
  • Transducer
  • Analog sensor
  • Digital sensor
  • Sensor accuracy

Key idea: a sensor measures something physical and converts it into data an embedded system can use — it's a type of input, and no sensor is perfectly accurate. Full classification: temperature (DHT11), distance/proximity (HC-SR04), light (photoresistor), sound, contact/touch (buttons), pressure, GPS, encoder, potentiometer, gyroscope, accelerometer. Digital sensors output only HIGH/LOW (like a PIR motion sensor); analog sensors output a continuous range (like a photoresistor) and need an analog input pin. This unit's four hardware sensors: photoresistor (simulation only, 3.3), HC-SR04 (3.5), PIR (3.7), DHT11 (3.9).
