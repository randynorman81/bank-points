Key idea: a sensor measures something physical and converts it into data an embedded system can use — it's a type of input, and no sensor is perfectly accurate. Full classification: temperature (DHT11), distance/proximity (HC-SR04), light (photoresistor), sound, contact/touch (buttons), pressure, GPS, encoder, potentiometer, gyroscope, accelerometer. Digital sensors output only HIGH/LOW (like a PIR motion sensor); analog sensors output a continuous range (like a photoresistor) and need an analog input pin. This unit's four hardware sensors: photoresistor (simulation only, 3.3), HC-SR04 (3.5), PIR (3.7), DHT11 (3.9).
