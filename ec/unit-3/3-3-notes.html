Servo: Angles and Sweeps

Everything you need for the 3.3 assignment: what a servo is, wiring it, libraries, the three angles, how a counting loop makes a smooth sweep, and how a variable remembers whether the lock is locked.

01

A Motor That Knows Where It Is

Reflection 1

A regular motor is like a car with only a gas pedal: it just spins. A servo is like a driver who parks in an exact spot and stays there. Robot arms, camera mounts, and door locks all need that exact spot.

Servo

Turns to whatever angle you tell it, from 0° to 180°, and holds that position. It has 3 wires: power, ground, and a signal wire that tells it where to turn.

03

Libraries and the Three Angles

Part 2

Telling a servo exactly where to go takes carefully timed pulses. Somebody already wrote that code, tested it, and packed it up so you don't have to. That pack of ready-made code is a library.

#include <Servo.h> // very first line: bring in the Servo library Servo myServo; // make a servo object named myServo void setup() { myServo.attach(9); // its signal wire is on pin 9 } void loop() { myServo.write(0); delay(1000); myServo.write(90); delay(1000); myServo.write(180); delay(1000); }

The dot

myServo.write(90) means "tell myServo to write (move to) 90 degrees." The part before the dot is which servo; the part after is what to do. You could have two servos with two names.

Watch the three angles

The arm jumps between positions; it doesn't glide.

04

The Smooth Sweep

Part 3 (you write it)

A jump is one big write(). A glide is 181 tiny ones: 0, then 1, then 2, all the way to 180, with a pause so short you can't see the steps. You don't type 181 lines. You let a for loop count for you.

A for loop, piece by piece

for (int x = 0; x <= 10; x++) { ... }
  • int x = 0: start the counter here
  • x <= 10: keep going while this is true
  • x++: add 1 after each pass
  • To count down, start high, keep going while it's >= the low end, and use x--.

Your clues from the assignment

  • One for loop counts an angle variable up from 0 to 180; inside it, myServo.write(angle); then delay(15);
  • A second for loop does the same thing counting down from 180 to 0.

The for loop above counts to 10 on purpose. Adapting it is your job.

Jump vs. glide

Each step moves 1 degree, then waits 15 ms.

05

Lock and Unlock

Part 4 + Reflections 2, 3

A door lock has to remember something: is it locked right now? Each press flips the answer. The Arduino remembers with a true/false variable, the same kind of boolean you flipped in 2.4.

What your code needs

  • bool locked = true; above setup(): the memory.
  • In setup(): the button pull-up and start the arm at 0.
  • In loop(): if (digitalRead(2) == LOW) { (button pressed)
  • You write this: if locked is true, move to 90 and set locked to false. Otherwise, move to 0 and set locked to true.
  • Last line inside the first if: delay(400);

An if inside an if

if (something) { if (anotherThing) { ... } else { ... } }

The outer if asks "was the button pressed?" The inner if/else asks "which way should it go?"

Try the lock

A human press lasts about a fifth of a second. loop() runs thousands of times in that time.

Test it for real (Reflection 2): delete the delay(400) in Tinkercad, press the button several times, and describe exactly what you see. Reflection 3: think about things around you that lock, latch, or open on command.

Test yourself

write() says where. A for loop says how smoothly. A boolean says what to do next.

Put the three together and a button becomes a door lock.
