3.1 — RGB LEDs and Color Mixing

🔔 Bell Ringer — Think About It
  1. Your phone screen only has red, green, and blue lights, yet it can show yellow, orange, and white. How can three colors of light make so many?
  2. Mixing paint gets darker the more you add, but mixing light gets brighter. Why do you think they behave in opposite ways?
  3. Each color in an RGB LED gets a value from 0 to 255. How many different colors is that in total, and why might a designer still not need all of them?
  4. Name one place you have seen a color-changing light used to send a message (not just to look cool).

Notes

Look up these definitions:

  • RGB LED
  • Common cathode
  • Additive color mixing
  • Function (custom)

Key idea: An RGB LED is three LEDs (red, green, blue) in one package that share a single leg. In Tinkercad the shared leg is the common cathode and goes to GND; each color leg gets its own resistor and its own PWM pin (9, 10, 11). analogWrite(pin, 0–255) sets how bright each color is, and light mixes additively: red + green = yellow, green + blue = cyan, red + blue = magenta, all three = white. Writing your own function like setColor(r, g, b) means you change three pins with one line.
