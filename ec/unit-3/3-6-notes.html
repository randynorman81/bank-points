01

New Parts and Commands

Until now, your outputs followed a timer: on, wait, off. Today they follow your hand. That's how a thermostat, a volume knob, and a gas pedal all work: read something, figure out what it means, then act.

Potentiometer (pot)

A dial with 3 legs. The middle leg (wiper) gives a voltage from 0V to 5V depending on where the dial is turned.

analogRead(A0)

Reads that voltage and gives a number from 0 to 1023. Only works on the analog pins A0 to A5. (You met it in 2.1.)

map()

Rescales a number from one range to another: map(value, fromLow, fromHigh, toLow, toHigh). map(512, 0, 1023, 0, 180) gives about 90.

Serial Monitor

A text window where your Arduino prints numbers so you can see what it's thinking. Serial.begin(9600); in setup, Serial.println(x); to print. In Tinkercad it's at the bottom of the code panel.

03

Turn the Dial

Parts 2 + 3, Reflections 1 + 2

The dial gives 0 to 1023. A servo wants 0 to 180. A pitch might want 200 to 2000. Nothing matches, so map() stretches or squeezes one range to fit the other. Turn the dial and follow the number through every step.

The dial (drag it)

int reading = analogRead(A0);

int angle = map(reading, 0, 1023, 0, );

int pitch = map(reading, 0, 1023, 200, 2000);

Serial Monitor (Serial.println(angle);)

Try changing the 180 in map() to something else, like 500, and watch what the servo arm does. Then test the same change in Tinkercad (Reflection 2).

// Part 2 at a glance #include <Servo.h> Servo myServo; void setup() { myServo.attach(9); Serial.begin(9600); } void loop() { int reading = analogRead(A0); int angle = map(reading, 0, 1023, 0, 180); myServo.write(angle); Serial.println(angle); delay(15); }
Part 3: in a new sketch (or with the servo lines commented out with //), read the dial, map it to a pitch from 200 to 2000, then tone(8, pitch); and delay(20);. In Tinkercad, click the dial and drag it to turn it.

05

The Challenge: One Dial, Two Outputs

Challenge (required)

Nothing says one reading can only be used once. You read the dial one time, then map that same reading two different ways: once for the servo, once for the buzzer.

Planning it

  • One analogRead() into reading.
  • Two map() lines: one into angle, one into pitch.
  • Two outputs: myServo.write() and tone().
  • Keep Serial.println() so you can see what's happening.

Reflection 3

Think of devices around you with a knob, a dial, or a slider: in the car, the kitchen, a game controller, a music app. What does each one's input control?

Test yourself

Read it, map it, use it.

analogRead() turns your hand into a number, map() turns that number into the range you need, and the output does the rest.
