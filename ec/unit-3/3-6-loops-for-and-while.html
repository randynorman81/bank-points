Notes

Look up these definitions and add them to your living glossary:

  • for loop
  • while loop
  • Iteration
  • Infinite loop

Key idea: a for loop repeats a known number of times — for (int i = 0; i < 5; i++) { ... }. A while loop repeats until a condition becomes false — use it when you don't know in advance how many repeats you need. Each single pass through a loop is an iteration. An infinite loop happens when a while loop's condition can never become false (often from forgetting to update the variable it depends on) — it freezes the rest of the program. Today's application: take several sensor readings in a for loop, sum them, divide by the count — averaging smooths out noisy outliers from Lesson 3.5.
