Notes

Look up these definitions:

  • Systematic debugging
  • Infinite loop
  • Logic error
  • Interrupt

Note: race condition is not a new term today — you first saw it back in Lesson 1.2 (Therac-25). Now that you've written real code, revisit it: does it make more sense to you now than it did then?

Debugging checklist: (1) did the code actually upload, or is an old version still running? (2) any syntax error the IDE is flagging? (3) print the relevant variable's value right before the problem — is it what you expected? (4) check comparison operators — == not =? (5) check wiring matches your code's pin references. (6) if a sensor needs warm-up time, has it had it? A logic error is code that compiles and runs but does the wrong thing — harder to find than a syntax error since nothing crashes. An interrupt lets a microcontroller instantly pause and respond to something (like a button press) without waiting for the current loop to finish — useful for anything needing an instant response; you won't write interrupt code this course, just understand why it exists.
