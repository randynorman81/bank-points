3.4 — if/else: Making Decisions

Intro

Ask AI these questions; look over the answers.

  1. What is if/else logic in programming? Explain it to a middle schooler using a decision you make every day, like deciding what to wear based on the weather.
  2. What is the difference between = and == in programming? Why does mixing these up cause so many bugs?
  3. Create a simple flowchart showing an if/else decision — for example, "if it's raining, bring an umbrella, else don't."
  4. List all the comparison operators used in programming (==, !=, <, >, <=, >=) and explain what each one checks.
  5. Connect if/else logic to a real embedded system I might use — where does a device make a yes/no decision based on a sensor or input?
  6. What happens in code if you write a single = instead of a double == when you meant to compare two values?

Notes

Look up these definitions:

  • Conditional statement
  • Comparison operator
  • Boolean expression
  • Assignment operator

Key idea: if (condition) { ... } else { ... } runs different code depending on whether a condition is true or false. Comparison operators: == equal to, != not equal, < less than, > greater than, <=, >=. The most important bug to avoid: = sets a value (int x = 5;), == asks a question (if (x == 5)). Writing if (x = 5) by mistake actually sets x to 5 instead of comparing — a real, confusing bug. With INPUT_PULLUP (from 2.7), a button reads HIGH when not pressed and LOW when pressed, so: if (digitalRead(buttonPin) == LOW) { // pressed }.
