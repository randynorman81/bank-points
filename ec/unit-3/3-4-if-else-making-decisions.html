3.4 — if/else: Making Decisions

Extra Credit Quiz

Today we'll take the 3.4 Quiz — 10 questions for extra credit. The first 5 cover earlier material; the last 5 cover this unit.

Notes

Look up these definitions:

  • Conditional statement
  • Comparison operator
  • Boolean expression
  • Assignment operator

Key idea: if (condition) { ... } else { ... } runs different code depending on whether a condition is true or false. Comparison operators: == equal to, != not equal, < less than, > greater than, <=, >=. The most important bug to avoid: = sets a value (int x = 5;), == asks a question (if (x == 5)). Writing if (x = 5) by mistake actually sets x to 5 instead of comparing — a real, confusing bug. With INPUT_PULLUP (from 2.7), a button reads HIGH when not pressed and LOW when pressed, so: if (digitalRead(buttonPin) == LOW) { // pressed }.
