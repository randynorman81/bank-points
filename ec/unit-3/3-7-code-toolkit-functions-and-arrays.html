3.7 — Code Toolkit: Functions and Arrays

🔔 Bell Ringer — Think About It
  1. If you copy the same five lines of code in ten places and then find a bug, how many places do you have to fix?
  2. A function can take in a value and hand one back. Describe a real-life job that works like that (something goes in, something comes out).
  3. An array is like a row of numbered lockers. Why might a list of pin numbers be handier than five separate variables?
  4. What makes a function name good or bad?

Notes

Look up these definitions:

  • Function
  • Parameter
  • Return value
  • Index

Key idea: A function is a named chunk of code you can reuse. A parameter is a value you hand in (scan(100)), and return hands a value back (int speedFromDial(int reading)). An array of pin numbers plus a for loop replaces five copies of the same line. Arrays start at index 0, so an array of 5 items has indexes 0 to 4; looping to 5 reads past the end. Give each function one clear job and a clear name.
