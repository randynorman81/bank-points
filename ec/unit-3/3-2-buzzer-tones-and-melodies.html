3.2 — Buzzer: Tones and Melodies

🔔 Bell Ringer — Think About It
  1. Sound is vibration. If a buzzer vibrates faster, do you think the sound gets higher or lower? Explain how you know.
  2. A piano has different keys for different notes. What is the Arduino version of pressing a different key?
  3. If you wanted to store a whole song in a program, would you write one line per note or use a list? Why?
  4. Name two everyday devices that use a simple beep to tell you something (a warning, a confirmation, a timer).

Notes

Look up these definitions:

  • Piezo buzzer
  • Frequency (Hz)
  • tone() and noTone()
  • Array

Key idea: A piezo buzzer makes sound when its pin switches on and off quickly. tone(pin, frequency) chooses how fast (the pitch, in hertz) and noTone(pin) stops it. Higher frequency means higher pitch (middle C is about 262 Hz, A is 440 Hz). An array stores a list of values under one name, so one for loop can walk through a whole melody: int notes[] = {262, 294, 330}; then notes[0] is 262. Arrays count from 0.
