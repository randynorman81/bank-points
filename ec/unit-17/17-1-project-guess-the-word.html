17.1 — Project: Guess the Word

🔔 Bell Ringer — Think About It
  1. This project builds a full word-guessing game using everything from Strings, Lists, and Conditionals. Before starting, what do you think the very first piece you'd need to build is?
  2. A game like this needs to track which letters have been guessed already. What data structure from this unit would you use for that, and why?
  3. Big projects get built in pieces, tested one at a time. What's the first small piece of this game you'd want to get working before adding anything else?
  4. What's one part of this project you expect to be the trickiest to get right?

Notes

Look up these definitions:

  • Project planning
  • Incremental development

Key idea: This project builds a complete word-guessing game (like Hangman), pulling together strings (checking guessed letters against the word), lists (tracking guesses), loops (repeating until the game ends), and conditionals (checking win/lose) into one finished program. Build it in pieces, testing each part as you go, rather than trying to write the whole thing at once — the same incremental approach that made your Unit 3 circuits and your earlier CodeHS lessons manageable.
