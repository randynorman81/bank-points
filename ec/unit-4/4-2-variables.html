4.2 — Variables

🔔 Bell Ringer — Think About It
  1. A variable is a labeled box that holds a value. Why would a programmer bother naming a value instead of just typing the number directly wherever it's needed?
  2. In C++ you have to say what type of value a variable will hold before you use it (int, double, string...). Why might a language want to know that in advance?
  3. If int age = 16; and later you write age = "sixteen";, C++ refuses to compile. Why do you think it's strict about that instead of just allowing it?
  4. You've already used variables in Arduino sketches (int ledPin = 9;). What's different about using a variable in a program versus using one in a physical circuit?

Notes

Look up these definitions:

  • Variable
  • Data type (int, double, string, bool, char)
  • Declaration
  • Assignment operator (=)

Key idea: A variable stores a value under a name so your program can use and change it later. In C++, every variable is declared with a type — int for whole numbers, double for decimals, string for text, bool for true/false, char for a single character — and once declared, it can only hold that type. This is the same idea you already used in Arduino (int ledPin = 9;), just without hardware attached. Declaring the type up front lets the compiler catch mistakes, like accidentally storing text in a number variable, before the program ever runs.
