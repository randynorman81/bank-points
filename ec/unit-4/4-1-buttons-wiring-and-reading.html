Notes

Look up these definitions:

  • Scrum
  • Sprint
  • Standup
  • Backlog

Starting today, this course uses real Scrum vocabulary: a sprint is a focused build period with a goal (this unit's sprint goal: a working keypad + LCD PIN entry system, built across 4.3–4.6); standup is a brief check-in at the start of build periods — three questions only: what did I do last time, what am I doing today, any blockers? Keep it to seconds per pair, not minutes. A backlog is planned-but-not-yet-built features (used in 4.9). For today's build: each button needs its own pinMode() and digitalRead() — track and respond to each independently. This directly preps you for the keypad in 4.3, which is really just many buttons read more efficiently.
