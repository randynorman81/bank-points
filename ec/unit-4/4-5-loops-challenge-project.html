4.5 — Loops Challenge Project

🔔 Bell Ringer — Think About It
  1. Before you start coding a challenge project, what's the value of reading the entire problem description first instead of jumping straight into writing code?
  2. This project asks you to combine conditionals and loops in the same program. Which do you think you'll write first, and why?
  3. When a loop-based program doesn't produce the output you expected, what's the first thing you'd check?
  4. After you finish this project, what's one part of your code you'd want to go back and clean up or simplify?

Notes

Look up these definitions:

  • Debugging
  • Pseudocode
  • Nested logic

Key idea: This is a practice project, not a new concept — it's built specifically to make you combine everything from Conditionals & Logic and Loops in one program. Before writing any code, sketch out the steps in plain English (pseudocode) so you know your plan before you're fighting syntax. If your output doesn't look right, isolate the problem: comment out parts of your loop or add a temporary cout to print a value and see what your program actually thinks is happening.
