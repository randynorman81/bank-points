4.1 — Hello World

🔔 Bell Ringer — Think About It
  1. Every programming language needs a way to say "start here." In C++, that's a function called main(). Why might a language need one obvious starting point instead of just running code top to bottom?
  2. C++ has to be compiled — turned into a finished program — before it runs at all. Some languages instead run one line at a time. What's one advantage you'd guess compiling gives you?
  3. cout << "Hello, world!"; ends with a semicolon, and nearly every line of C++ does. What job do you think that semicolon is doing?
  4. "Hello, World!" is the traditional first program in almost every programming language. Why do you think that tradition exists?

Notes

Look up these definitions:

  • Compiler
  • Syntax
  • main() function
  • cout
  • Semicolon (statement terminator)

Key idea: A C++ program always starts running inside a function called main() — that's the one spot the compiler looks for first. cout << "text"; prints text to the screen, and the << arrows show the direction the text is flowing (into the output). Every statement in C++ ends with a semicolon, the same way every sentence in English ends with a period — leave it off and the compiler doesn't know where one instruction ends and the next begins. C++ code has to be compiled before it runs, which catches a lot of mistakes before the program ever executes, unlike a language that just runs line by line and fails partway through.
