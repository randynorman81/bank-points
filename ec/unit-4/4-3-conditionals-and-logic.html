4.3 — Conditionals & Logic

🔔 Bell Ringer — Think About It
  1. An if statement makes your program act differently depending on the situation. Describe a decision you made today that depended on a condition ("if it's raining, I'll bring an umbrella").
  2. C++ uses == to compare two values and = to assign a value. Mixing them up is one of the most common beginner bugs. Why do you think reusing a similar symbol for two different jobs causes confusion?
  3. Logical operators (&&, ||, !) let you combine conditions. Write a sentence describing a rule from your life that needs two conditions joined with "and" or "or."
  4. An else branch runs only when the if condition is false. Why is having a "the alternative" branch usually better than writing two separate, unconnected if statements?

Notes

Look up these definitions:

  • if / else if / else
  • Comparison operators (==, !=, <, >, <=, >=)
  • Logical operators (&&, ||, !)
  • Boolean expression

Key idea: An if statement lets a program choose which code to run based on a condition that evaluates to true or false. Comparison operators (==, !=, <, >) build that condition, and logical operators (&&, ||, !) let you combine multiple conditions into one rule. C++ is strict about == (compare) versus = (assign) — mixing them up is a classic bug, since age = 16 secretly assigns 16 to age and always evaluates as true. An else (or else if) branch gives your program a planned alternative instead of just skipping the if block.
