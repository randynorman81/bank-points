4.4 — Loops

🔔 Bell Ringer — Think About It
  1. A for loop repeats code a set number of times; a while loop repeats code as long as a condition stays true. Give an example of a real task that fits each pattern.
  2. If a while loop's condition never becomes false, the program runs forever (an infinite loop). Why is this an easy mistake to make by accident?
  3. You already wrote for loops in Arduino code (like fading an LED). What's the same about a for loop in C++, and what's different about the syntax?
  4. Loops let you repeat code without copying and pasting it. What's one downside of copy-pasting the same block of code five times instead of using a loop?

Notes

Look up these definitions:

  • for loop
  • while loop
  • Loop counter / iterator variable
  • Infinite loop

Key idea: A for loop is best when you know exactly how many times to repeat something (for (int i = 0; i < 5; i++)), while a while loop repeats for as long as a condition stays true, which is better when you don't know the exact count in advance. Both need a way to eventually stop — a for loop's counter or a while loop's condition changing — or you get an infinite loop that never ends. This is the same for loop you already used to fade an Arduino LED or count 0 to 9 on a 7-segment display, just running in a plain C++ program instead of on a board.
