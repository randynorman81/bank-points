12.1 — Loops (Servo)

🔔 Bell Ringer — Think About It
  1. You already built a servo lock/unlock button in Unit 3. What do you remember about the Servo library and the write() command?
  2. This lesson uses for and while loops to control a servo's movement. Why might a loop be useful for a servo instead of one single write() command?
  3. Arduino libraries (like Servo) package up complicated work into simple commands. Why do you think this saves you from writing that complexity yourself?
  4. What's different about writing this code in Tinkercad again after weeks of plain Python and C++, and what feels familiar?

Notes

Look up these definitions:

  • Servo library (review)
  • write() command (review)
  • For / while loop control (review)

Key idea: This lesson is back in Tinkercad, connecting and controlling a servo motor using for and while loops — the exact same Servo library and write() command from your Unit 3 lock/unlock build, now combined with the loop skills you've spent the last several units sharpening in plain Python and C++. Libraries like Servo exist so you don't have to write the low-level timing code yourself; you just call write(angle) and the library handles the rest.
