1.6 — The Double Life of a Raspberry Pi

🔔 Bell Ringer — Think About It
  1. A Raspberry Pi can run a full desktop operating system with a browser and file manager — or it can boot straight into one dedicated program and never show a desktop at all. Same board, same chip. What actually makes something "an embedded system" if it's not the hardware itself?
  2. If you built a security camera using a Raspberry Pi that recognizes faces using a model running entirely on the Pi's own chip, versus one that sends every frame to a cloud server to check — which one would you trust more in your own house, and why?
  3. A single-board computer like the Pi can multitask: run a game server, a file share, and a website all at once. An embedded system is built to do exactly one job, forever. Why would an engineer ever choose the "worse," single-job version on purpose?
  4. Think of 3 smart devices in your own home. Could any of them have been built around a full computer instead of a cheap dedicated chip? What would the company gain by doing that — and what would they lose?
