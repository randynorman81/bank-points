Same board, same chip, ten completely different real-world jobs. Click each project to see how it's classified — single-board computer or embedded system, and Edge AI, Cloud AI, Hybrid, or no AI at all — and why.

Role: SBC Embedded AI: Edge Cloud Hybrid None

Notice what's missing: no "SBC + Cloud AI" card, and only one "SBC + Edge AI" card.

That's not an accident of this list — when a project already has a full computer's worth of power sitting right there, there's usually less reason to send anything to the cloud at all. Cloud AI shows up far more often on the embedded side, wired into one small dedicated job. Keep that pattern in mind while you write your own Build Proposal Dossier.
