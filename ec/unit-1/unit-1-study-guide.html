1.1 — What Is an Embedded System?

Embedded system
A computer system built into a larger device to perform one specific, dedicated task — not a general-purpose computer. The control board inside a microwave oven is a good example.
Microcontroller vs. microprocessor
A microcontroller has memory and I/O built in on one chip — used in embedded systems. A microprocessor (like the one in a laptop) needs separate memory and peripheral chips built around it.

1.2 — Forensic Auditing & the Therac-25

Purpose of a forensic audit
To determine what technically went wrong, and who is responsible for it.
Therac-25
A computer-controlled radiation therapy machine used to treat cancer patients in the 1980s.
What went wrong
A software bug caused it to deliver massive radiation overdoses to patients.
Race condition
A bug where the outcome depends on the timing or order of two things happening — like an operator typing faster than the software could check.
The removed safety feature
Earlier radiation machines had hardware safety interlocks (physical safeguards). The Therac-25 removed them and relied on software instead.

1.3 — Embedded Systems All Around Us

Arduino
An umbrella term for a board, its software, and its community — the microcontroller is the actual chip on the board. They are two different things.
Raspberry Pi vs. Arduino
A Raspberry Pi is a small full computer that can run an operating system. An Arduino is a simpler microcontroller board built to run one program at a time.
IoT
Stands for Internet of Things.
Pacemaker
An example of an embedded system where a software failure could be life-threatening, since it directly controls a person's heart rhythm.

1.5 — Take a Stand: GPS Ankle Monitor Failures

GPS ankle monitor
Tracks a supervised person's real-time location and alerts officials if they leave an approved zone.
The three parties in the scenario
Meridian Trace Technologies — the device manufacturer. GuardLine Monitoring Services — the monitoring company. Millbrook County Office of Community Supervision — the government supervision agency.
Real-world precedent cited
The 2015 Fitbit murder case — wearable device data used as courtroom evidence.
Civil liability
Legal responsibility for causing harm or loss to another person, which can require paying damages.

1.7 — AI in Embedded Computing and IoT

Edge AI vs. cloud AI
Edge AI processes data directly on the device itself. Cloud AI sends data over the internet to be processed on remote servers.
Advantage of edge AI
It can work without sending data over the internet — often faster and more private (e.g. a smart camera recognizing a face on-device).
Machine Learning
A method where a computer improves at a task by learning patterns from data, rather than being explicitly programmed with fixed rules for every case.
Embedded AI
Artificial intelligence that runs directly on a small, dedicated device rather than on a general-purpose computer or in the cloud.
