11.4 — Functions and Return Values

🔔 Bell Ringer — Think About It
  1. A function can return a value using the return keyword, handing a result back to whatever called it. Why is a function that returns a value more flexible than one that just prints something?
  2. If def square(n): return n * n, what do you think result = square(4) stores in result?
  3. You used a function that returns a value in Codecademy's C++ (like speedFromDial()). What's the Python syntax difference for return compared to C++?
  4. Why might you want to chain functions together, using one function's return value as another function's input?

Notes

Look up these definitions:

  • return keyword
  • Return value (review)

Key idea: return hands a value back to whatever called the function, which is different from just printing something — a returned value can be stored in a variable, used in a calculation, or passed straight into another function. This is the same return concept from Codecademy's C++ functions, using Python's return keyword instead of C++'s. Chaining functions together, where one function's return value feeds directly into another function, is how larger programs get built out of small, tested pieces.
