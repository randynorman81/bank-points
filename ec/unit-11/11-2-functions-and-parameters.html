11.2 — Functions and Parameters

🔔 Bell Ringer — Think About It
  1. A parameter lets a function behave slightly differently depending on what's passed in. Why is a function with a parameter more useful than one that always does exactly the same thing?
  2. If you wrote def greet(name):, what do you think print("Hello, " + name) would output when you call greet("Ada")?
  3. How is a parameter in Python similar to a parameter in the C++ functions you wrote in Codecademy?
  4. Describe a function you'd want that takes in one piece of information and uses it to customize what it does.

Notes

Look up these definitions:

  • Parameter (review)
  • Argument

Key idea: A parameter is a placeholder variable a function accepts so it can behave differently depending on what's passed in when it's called — the actual value passed in is called an argument. This is the exact same idea as the parameters you used in Arduino C++'s setColor(r, g, b) and Codecademy's C++ functions, just written in Python's syntax. A function without parameters can only ever do one fixed thing; a function with parameters can be reused for many different situations.
