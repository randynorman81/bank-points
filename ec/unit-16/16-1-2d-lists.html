16.1 — 2D Lists

🔔 Bell Ringer — Think About It
  1. A 2D list is a list of lists — useful for anything shaped like a grid. What real-world data is naturally shaped like rows and columns (like a spreadsheet or a game board)?
  2. If you had a 2D list representing a tic-tac-toe board, how do you think you'd access the item in row 1, column 2?
  3. Why might a single flat list not be a good fit for grid-shaped data?
  4. Where in this course have you already worked with grid-like data (hint: a lookup table from Unit 3)?

Notes

Look up these definitions:

  • 2D list (list of lists)
  • Row / column indexing

Key idea: A 2D list is a list where each item is itself another list, which naturally represents grid-shaped data like rows and columns — access an item with two indexes, grid[row][col]. This is exactly the same shape as the digit lookup table you built in Unit 3 for the 7-segment display (const byte digits[10][7]), just in Python's list-of-lists syntax instead of a C++ 2D array.
