16.2 — List Comprehensions

🔔 Bell Ringer — Think About It
  1. A list comprehension lets you build a new list from an existing one in a single line, instead of writing a full for loop. Why might a shorter way to write a common pattern be valuable?
  2. If you wanted a new list with every number doubled, which do you think is more readable: a full for loop, or a one-line list comprehension?
  3. Why do you think Python offers this shortcut for such a common pattern (loop through a list, transform each item, build a new list)?
  4. Is a shorter piece of code always a better piece of code? What's a case where the longer for loop version might actually be clearer?

Notes

Look up these definitions:

  • List comprehension

Key idea: A list comprehension, like [x * 2 for x in my_list], builds a new list by applying an operation to every item in an existing list, all in one line — doing in one line what would otherwise take a full for loop with an empty list and repeated append() calls. It's a genuinely useful shortcut for a very common pattern, though it's worth knowing when a full for loop is actually more readable, especially once the logic inside gets more complicated than a simple transformation.
