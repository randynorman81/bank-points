16.3 — Packing and Unpacking

🔔 Bell Ringer — Think About It
  1. Unpacking lets you assign multiple variables from a list in one line, like x, y = coordinates. Why might that be more convenient than accessing coordinates[0] and coordinates[1] separately?
  2. Packing is the reverse — combining separate values into one list or tuple. When might you want to bundle values together instead of keeping them separate?
  3. If coordinates = (3, 5) and you wrote x, y = coordinates, what do you think x and y equal afterward?
  4. Why do you think Python offers this shortcut instead of requiring index-by-index assignment every time?

Notes

Look up these definitions:

  • Unpacking
  • Packing

Key idea: Unpacking lets you assign multiple variables at once directly from a list or tuple, like x, y = coordinates instead of writing coordinates[0] and coordinates[1] separately, which reads more like plain English. Packing is the reverse process, bundling separate values together into a single list or tuple. Both are conveniences that make code handling structured, multi-part data noticeably cleaner to read.
