7.4 — How Devices Connect: Cloud Architecture

Entirely conceptual today — direct preparation for Lesson 7.6's hands-on cloud lab. Today is the map; 7.6 is the trip.

Intro

Ask AI these questions; look over the answers.

  1. What is "the cloud," really? When people say a device sends data to the cloud, what does that actually mean technically?
  2. Explain to a middle schooler the journey a single piece of data takes from a sensor to appearing on a phone app or website dashboard.
  3. Create a simple diagram showing the path: sensor → embedded device → local network → internet → cloud server → dashboard/app.
  4. What is an API, and why does an IoT device need one to communicate with a cloud service?
  5. Connect today's cloud architecture concept to your own RFID access control project from Unit 5 — if that system needed to send data to the cloud, what would need to be added to make that happen?
  6. What happens if an IoT device loses its internet connection? Does it stop working entirely, or can it still function locally?

Notes

Look up these definitions and add them to your living glossary:

  • Cloud server
  • Cloud architecture
  • API (Application Programming Interface)
  • Dashboard

Key idea: "the cloud" is just remote computers (servers), owned and maintained by a company, accessed over the internet — not some abstract, mysterious concept. Full path: sensor measures something → embedded device (Arduino) reads it → local network (WiFi) → internet (via your router) → cloud server (stores/processes it) → dashboard/app (a person actually sees it). An API is a defined, structured way for a device to request or send data to a cloud service — like a very specific form the device fills out every time, so the service knows exactly what to expect. None of this year's builds (traffic light, alarm, PIN entry, RFID lock) sent data anywhere beyond the local board — adding connectivity means a network connection plus code using an API. A well-designed IoT device should keep some local functionality even if its cloud connection drops.
