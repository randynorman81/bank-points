7.7 — Artistic Effects

🔔 Bell Ringer — Think About It
  1. Tracy can now draw in color, with different pen thicknesses, and can fill in shapes. What's one drawing you'd want to try making with these new tools?
  2. begin_fill() and end_fill() work as a pair, wrapping around the shape you want filled in. Why do you think a fill command needs a clear start and stop, instead of just "fill everything"?
  3. How is choosing a pensize() similar to choosing a pen or marker in real life?
  4. If you were designing a company logo using only Tracy commands, what shapes and colors would you start with?

Notes

Look up these definitions:

  • color()
  • pensize()
  • begin_fill() / end_fill()

Key idea: These commands don't change what Tracy can draw structurally — they change how it looks. color() sets the pen (and fill) color, pensize() controls how thick the line is, and begin_fill() / end_fill() wrap around a shape to fill its interior with the current color once it's fully drawn. This is the same idea as the artistic choices you made in Unit 3 picking RGB values for a color — here it's applied to drawing instead of lighting an LED.
