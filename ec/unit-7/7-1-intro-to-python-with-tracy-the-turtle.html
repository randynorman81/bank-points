7.1 — Intro to Python with Tracy the Turtle

🔔 Bell Ringer — Think About It
  1. Today you'll control a turtle on screen using typed commands instead of a mouse or a game controller. What do you think the very first command you type should do?
  2. You already know how to write instructions for an Arduino in C++. Python looks different, but "a sequence of commands" is still the idea underneath. What do you think stays the same when you switch languages, and what do you think changes?
  3. A program is just a sequence of commands carried out in order. Think of a non-computer example of following steps in order, like a recipe. What happens if you do the steps out of order?
  4. Tracy the Turtle only does exactly what you tell her, nothing more. Why might that be frustrating at first, and why is it actually a useful trait for a computer to have?

Notes

Look up these definitions:

  • Program
  • Command
  • Sequence
  • Tracy (CodeHS's turtle graphics tool)

Key idea: A program is a sequence of commands a computer carries out one at a time, in the exact order you write them. Today that computer is Tracy the Turtle — you'll type commands and watch her draw on screen immediately, which makes it easy to see exactly what each command does. This is the same core idea as writing an Arduino sketch: both are just sequences of instructions, carried out in order, with no room for the computer to guess what you meant. The language and the target are different (Python and a screen turtle instead of C++ and a circuit), but "write exact steps, in order" is the skill underneath both.
