7.6 — Individual Arduino Cloud Lab

The payoff lesson for this unit's whole conceptual arc since 7.1 — the first true IoT device you'll build this year. Requires working internet access and an Arduino Cloud account set up in advance.

What you're doing

Choose any sensor from your accumulated kit (photoresistor, HC-SR04, PIR, or DHT11 all work well). Wire it, then create an Arduino Cloud "Thing" with a variable representing your sensor reading, link it to your board, and build a simple dashboard widget to display it — following the live walkthrough demonstrated in class. Write code that reads your sensor and sends the reading to your cloud variable, and confirm it appears live on your dashboard.

If Arduino Cloud itself has issues on the day, that's a legitimate, real part of working with cloud platforms — document your sensor wiring and code, and describe in writing what the next steps to connect to the cloud would be.

Notes

Look up these definitions:

  • Thing (Arduino Cloud)
  • Cloud variable
  • Live data

A "Thing" is Arduino Cloud's term for a connected device project, holding the variables and configuration that link your physical board to the cloud platform. A cloud variable syncs between your device and the cloud, letting a sensor reading display remotely as live data. This is the exact device-to-cloud path from Lesson 7.4, now hands-on: sensor → Arduino → local network → internet → cloud server → your dashboard.
