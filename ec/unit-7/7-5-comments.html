7.5 — Comments

🔔 Bell Ringer — Think About It
  1. A comment is a note in your code that the computer ignores completely. If the computer never reads it, who is it actually for?
  2. You already used comments in your Arduino sketches. What's one comment you remember writing, and why did you write it?
  3. If you came back to a 100-line program you wrote six months ago with zero comments, what do you think that experience would be like?
  4. When do you think a comment is actually necessary, versus code that's clear enough to not need one?

Notes

Look up these definitions:

  • Comment
  • # (single-line comment in Python)

Key idea: A comment is text in your code that the computer skips entirely — it exists purely for the humans reading the code, including your future self. In Python, a single-line comment starts with #. This is the same idea as the comments you already added to your Arduino sketches in Unit 3, just with different comment syntax in a different language. Good comments explain why code does something, not just what it does, since the code itself already shows the "what."
