The Six Data Types

Section 1 + Section 2

A variable is a labeled box in the Arduino's memory. The data type decides what shape of thing fits in the box and how much memory it takes. The Arduino Uno only has 2,048 bytes of memory for variables, so picking the right size box is a real engineering decision.

Box height = memory used. 1 byte = 8 bits.

02

Global Variables vs. Variables Inside loop()

Section 2 + Question 1

Where you create a variable decides who can use it and how long it lasts. Create it at the top, and it lives for the whole program. Create it inside loop(), and it's rebuilt from scratch every single trip.

Global: above setup() and loop()

byte blinkCount = 0; // created once void loop() { blinkCount = blinkCount + 1; }

Any function can use it, and it keeps its value between trips through loop(): 1, 2, 3, 4...

Local: inside loop()

void loop() { byte blinkCount = 0; // re-created every trip blinkCount = blinkCount + 1; }

Only loop() can use it, and it's reset every time loop() starts over: 1, 1, 1, 1...

The ! (NOT) Operator

Section 2 + Question 2

In 2.3, turning the LED off and on took two separate digitalWrite() lines. A boolean and one exclamation point can do both jobs with a single line that flips back and forth.

ledState = !ledState;

! means NOT: it gives the opposite of a true/false value. !false is true, and !true is false. Putting the result back into ledState flips it. Then digitalWrite(ledPin, ledState); turns the LED on when it's true (HIGH) and off when it's false (LOW).

ledState = false

05

The Serial Monitor

Section 5: Part 2

Right now blinkCount is counting, but it's invisible. The Serial Monitor is a window where the Arduino can print messages back to you while it runs. It's the Arduino's version of print().

LineWhat it does
Serial.begin(9600);Goes in setup(). Opens communication with the computer at 9600 baud (bits per second). Nothing prints without it.
Serial.print(x);Prints x and stays on the same line. Text goes in double quotes: Serial.print("LED ");
Serial.println(x);Prints x and then starts a new line. Use it for the last thing on each line.

Open the Serial Monitor before you run: in the Arduino IDE it's the magnifying glass icon or Tools > Serial Monitor; in Tinkercad, click Code, then Serial Monitor at the bottom of the code panel. The six Serial.print lines plus the println build one line of output per blink, like this:

LED A blink count: 1 total blinks: 1 0.50 LED A blink count: 2 total blinks: 2 0.50 LED A blink count: 3 total blinks: 3 0.50

Order in loop(): the 4 lines from Part 1, then totalBlinks = totalBlinks + 1;, then the 7 Serial lines in the order listed in your assignment.
