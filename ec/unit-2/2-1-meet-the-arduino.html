2.1 — Meet the Arduino

Intro

Ask AI these questions; look over the answers.

  1. What is an Arduino and what is it commonly used for? Give me three real projects that use one.
  2. Explain to a middle schooler what "open source hardware" means and why it matters that Arduino is open source.
  3. Create a simple labeled diagram of an Arduino Uno board showing its main parts — digital pins, analog pins, power pins, USB port.
  4. What is the difference between the Arduino IDE and the Arduino board itself? Explain it like I've never heard of either one.
  5. Connect using an Arduino to a movie or TV show I might know — where has a character built or used something like this?
  6. What companies or industries actually use Arduino or similar microcontroller boards in real products, not just hobby projects?

Notes

Look up these definitions:

  • Arduino Uno
  • Open source hardware
  • Arduino IDE
  • Digital pin
  • Analog pin

Key idea: the Arduino IDE and the Arduino board are two separate things — the IDE is software you write code in, the board is the physical hardware the code runs on. Today you'll get a real board in hand and go through its parts: digital pins (0–13, HIGH/LOW only), analog input pins (A0–A5, read a range of voltage), power pins (5V, 3.3V, GND), the USB port, barrel jack, reset button, and the built-in LED on pin 13. This connects back to Unit 1 — the Arduino Uno contains a microcontroller (the ATmega328P), it isn't the microcontroller itself.
