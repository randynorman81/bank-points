01

The Translation Idea

You have a book written in French and you want it in English. You can have a friend translate it out loud, one sentence at a time, while you listen. Or you can translate the whole book first, cover to cover, and then read it straight through. That's the entire difference.

Interpreted (Python)

An interpreter reads and runs your code line by line, translating each line right when it's needed, every time the program runs. Like the friend reading aloud.

Compiled (Arduino C++)

A compiler translates the whole program into machine code before it runs. The finished machine code then runs fast, with no translating left to do. Like translating the whole book first.

Why Arduino is compiled: an Arduino has a tiny amount of memory and no operating system helping it out. Translating ahead of time means the program on the board is small and fast, and it never wastes time or memory translating while it's supposed to be doing its real job.

03

What Happens When You Click Upload

Asked for both languages

Upload feels like one button, but it does two separate jobs, one right after the other.

Almost every "my code won't work" moment this unit happened at step 1 (compiling), not step 2 (uploading). Python has no separate compile step you run: when you run a Python program, the interpreter starts reading and running it right away.

Uploading as unlisted

  1. YouTube only takes video files, so turn your audio into a video (for example, add a still image in a video editor or use a slideshow tool).
  2. In YouTube, click Create > Upload video and choose the file.
  3. On the Visibility step, choose Unlisted. Only people with the link can watch.
  4. Copy the link and paste it in Google Classroom. Stuck? Come see Mr. Norman.

Writing a script that sounds natural

  • Open with a hook: why should anyone care how code is translated?
  • Take turns. Let the other person react and ask questions.
  • Use the book-translation comparison, then go deeper.
  • Cover every question on your list; check them off as you write.
  • Read it out loud and time it before you record.

Test yourself
