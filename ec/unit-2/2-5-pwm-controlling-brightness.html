2.5 — PWM: Controlling Brightness

🔔 Bell Ringer — Think About It
  1. PWM brightness is actually an illusion — the LED is always either fully on or fully off, just switching fast enough to trick your eyes into seeing "dim." Does it matter that it's a trick, if the result looks and works exactly like real dimming?
  2. Only some pins on the Arduino Uno can do PWM, and they're the ones marked with a ~. Why do you think a manufacturer would limit a feature like this to a few pins instead of building every pin with that ability?
  3. This same on/off switching trick that dims an LED also controls motor speed and servo position later in this course. Why do you think one simple technique shows up in so many different uses across electronics?
  4. If duty cycle is the percent of time a signal is "on," what do you think happens to an LED at exactly 1% duty cycle versus 0%? Would you even be able to tell the difference with your eyes?

Notes

Look up these definitions:

  • PWM (Pulse Width Modulation)
  • analogWrite()
  • PWM-capable pin
  • Duty cycle

Key idea: PWM is not true analog output — a pin is still only ever fully on or fully off, it just switches so fast the LED (or your eye) perceives an average brightness. Duty cycle is the percent of each cycle spent "on": 0% = off, 100% = full brightness, 50% = half brightness. analogWrite(pin, value) takes 0–255 to set duty cycle, but only works on PWM-capable pins — on the Uno, these are marked with a ~ (commonly 3, 5, 6, 9, 10, 11). This same technique controls motor speed and servo position later in the course.
