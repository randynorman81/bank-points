2.5 — PWM: Controlling Brightness

Two-period lesson. Day 1: move your LED to a PWM pin and try fixed brightness levels. Day 2: build a smooth fade effect.

Intro

Ask AI these questions; look over the answers.

  1. What is PWM (Pulse Width Modulation) and how does it let a digital pin simulate an analog effect like dimming a light?
  2. Explain to a middle schooler how flicking a light switch on and off extremely fast could make a light look dimmer, even though it's technically only ever fully on or fully off.
  3. Create a simple visual showing a PWM signal — what it looks like when a pin is rapidly switching on and off at different rates to create different brightness levels.
  4. What is the difference between digitalWrite() and analogWrite() on an Arduino? Why can't digitalWrite() create a dimming effect?
  5. Connect PWM to a real product I might use — where else besides LEDs is this same on/off-rapidly technique used to control something?
  6. Why is PWM useful for controlling things like motors and servos later on, not just LEDs?

Notes

Look up these definitions and add them to your living glossary:

  • PWM (Pulse Width Modulation)
  • analogWrite()
  • PWM-capable pin
  • Duty cycle

Key idea: PWM is not true analog output — a pin is still only ever fully on or fully off, it just switches so fast the LED (or your eye) perceives an average brightness. Duty cycle is the percent of each cycle spent "on": 0% = off, 100% = full brightness, 50% = half brightness. analogWrite(pin, value) takes 0–255 to set duty cycle, but only works on PWM-capable pins — on the Uno, these are marked with a ~ (commonly 3, 5, 6, 9, 10, 11). This same technique controls motor speed and servo position later in the course.
