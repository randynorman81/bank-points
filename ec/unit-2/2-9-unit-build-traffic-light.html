2.9 — Unit Build: Morse Code Flasher

🔔 Bell Ringer — Think About It
  1. This is the first project this unit where using AI to write your actual solution defeats the point, even though using it to understand an error is fine. What's the real difference between those two uses, and why does that line matter for what you're actually being graded on?
  2. You already built a three-LED red/yellow/green sequence back in 2.6. Today's version adds one new twist — a smooth PWM fade on the green light instead of a plain on/off snap — and you're building it independently, without step-by-step directions. Which part of that feels like the bigger jump: adding the fade, or working without instructions?
  3. A real embedded engineer never gets a lesson page walking them through their own project. If you got stuck today with no directions to fall back on, what's the first thing you'd actually try before asking for help?
  4. Your traffic light works even though nobody is grading whether the timing is "realistic" down to the second. Why might building something that just works still not be good enough for a real engineer shipping a product?
