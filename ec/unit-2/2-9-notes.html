Stage 1

Your Word and Its Morse Code

Morse code was sent by telegraph and flashlight long before anyone had a screen: every letter is a short pattern of dots (short flashes) and dashes (long flashes). Pick a real word, at least 7 letters, and write its whole pattern on paper before you touch code.

International Morse code. Check each of your letters against it; don't guess.

Stage 2

Planning Your Timing

All of Morse timing is built from one basic unit of time. A dot is 1 unit, and a dash is always exactly 3 units. The gaps are what let a viewer tell where one symbol, one letter, and one word ends.

PieceLEDStandard Morse lengthYour job
DotON1 unitRequired: 1 unit
DashON3 unitsRequired: exactly 3× a dot
Gap between symbols (inside one letter)OFF1 unitYou decide: the shortest gap
Gap between lettersOFF3 unitsYou decide: clearly longer than the symbol gap
Gap before the word repeatsOFF7 unitsYou decide: the longest gap

Stage 3

Your Circuit

This is a single-LED circuit, the same kind you've built since 2.3. The questions in the assignment are about remembering why it's built that way.

Keeping one LED safe

Look back at 2.2 (what the resistor does) and 2.7 (Ohm's law and pin limits). What part must be in line with the LED, and what would happen without it? Which leg goes toward the pin?

Which pin?

PWM (~) pins are only needed for analogWrite() dimming (2.5). Morse is only fully on or fully off. Which command will you actually use, and does it need a ~ pin?

Stages 4–5

Variables and setup()

In 2.4 and 2.6 you saw why timings belong in variables: change one number at the top, and the whole program changes with it. A Morse program has a lot of on/off timings, so this matters even more here.

Planning your variables

  • Which value will you want to adjust later without hunting through the whole program?
  • One timing variable, or several (a dot, a dash, each kind of gap)? If you use several, how could they all be based on the one unit?
  • Which data type fits a number of milliseconds? (2.4)
  • Requirement 5: at least one timing variable, with a comment explaining it.

Stage 6

loop(): Flashing the Whole Word

Every dot and every dash is the same three-step idea you've used all unit: turn the LED on, wait, turn it off. The only thing that changes is how long you wait, and how long you pause afterward.

StepWhat your code needs to do
1. Each symbolLED on, wait the right on-time (dot or dash), LED off.
2. Inside a letterBetween symbols of the same letter, pause the shorter gap.
3. Between lettersAfter a letter's last symbol, pause the longer letter gap.
4. End of the wordPause the longest gap. loop() then starts the word over automatically (Requirement 4).
Staying organized: write one comment line above each letter's group of lines, like // letter A: dot dash, and a comment on every line (Requirement 6). Build and test one letter at a time instead of the whole word at once.
This is not a day to have AI write your code. Using it to understand a specific error message is fine; having it write your solution defeats the point of the unit build.
