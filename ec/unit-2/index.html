Unit 2: Arduino Foundations

This unit lives in our own Circuit Editor — drag parts onto a breadboard, wire them up, write real Arduino code, and run it in your browser. You'll get comfortable with the Arduino Uno's parts and code entirely in simulation on the way to more advanced circuits. Build up core programming concepts — variables, data types, PWM, timing — and close with circuit fundamentals and a programming-language comparison before your independent unit build: a simulated traffic light. Unit 3 then builds on it with color, sound, motion, and displays.
