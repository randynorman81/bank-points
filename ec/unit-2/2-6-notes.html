01

Wiring Three LEDs

Step 1

A traffic light is three separate lights that take turns. For your code to control each one on its own, each LED needs its own connection to the Arduino.

Why one shared GND is fine

GND is just the shared return path back to the Arduino. Every LED's current ends up there, so they can all use one connection. Each LED's own pin is what lets your code switch it separately.

No ~ pin needed

You're only turning lights fully on and fully off, not dimming. Any regular digital pin works. The example uses red = 8, yellow = 9, green = 10.

02

The Sequence, Line by Line

Steps 2, 3, 5

A sequence is just on, wait, off, repeated in a deliberate order across different pins. The order of the lines is the order things happen.

int redPin = 8; int yellowPin = 9; int greenPin = 10; int greenTime = 5000; // how long green stays on (ms) int yellowTime = 1500; int redTime = 4000; void setup() { pinMode(redPin, OUTPUT); pinMode(yellowPin, OUTPUT); pinMode(greenPin, OUTPUT); } void loop() { digitalWrite(greenPin, HIGH); delay(greenTime); digitalWrite(greenPin, LOW); digitalWrite(yellowPin, HIGH); delay(yellowTime); digitalWrite(yellowPin, LOW); digitalWrite(redPin, HIGH); delay(redTime); digitalWrite(redPin, LOW); }

Shown 3 to a line here to fit; in your code, put each command on its own line, in this exact order, with a comment above each one (Step 5).

A pin remembers. Once you set a pin HIGH, it stays HIGH until a line sets it LOW. The Arduino never turns a light off for you. That's why every color needs its own LOW line before the next color turns on.

04

Timing Variables

Questions 6 + 7

greenTime, yellowTime, and redTime are just names for numbers. The code works exactly the same whether you use the name or type the number itself. The difference is how easy the code is to read and change.

With a variable

int waitTime = 2000; ... delay(waitTime);

The number lives in one place at the top, with a name that says what it's for.

Without a variable

delay(2000);

The number goes straight into the delay(), wherever that variable was used. The variable line at the top disappears.

Thinking about pros and cons: imagine you need to change a timing. How many places would you edit each way? What if you missed one? Which version tells the next reader what the number means? Which version is shorter?
05

Real Traffic Light Timing

Step 4

Real traffic engineers don't pick timings at random. Yellow is set from the road's speed limit so drivers have time to stop safely, and green and red depend on how busy each direction is.

Search ideas

  • "traffic light yellow time by speed limit"
  • "how long is a red light at an intersection"
  • "traffic signal cycle length"

Seconds → your code

delay() uses milliseconds, so multiply seconds by 1000.

Watch the int limit

An int only goes up to 32,767. A timing longer than about 32 seconds won't fit in an int. Use long for bigger numbers.

Test yourself

A light stays on until your code turns it off. Order is everything.

On, wait, off, next. That's the whole traffic light, and the pattern behind every sequence you'll build.
