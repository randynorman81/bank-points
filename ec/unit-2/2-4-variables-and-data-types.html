Notes

Look up these definitions:

  • Variable
  • int
  • float
  • boolean
  • byte

Key idea: a variable is a named container for a value that can change — e.g. int blinkSpeed = 500; then delay(blinkSpeed); means changing one line at the top changes the timing everywhere it's used. The six data types this unit: int (whole numbers), float (decimals, like a sensor reading), boolean (true/false only), char (a single character), byte (0–255, less memory than int), long (bigger whole numbers than int allows). Microcontrollers have limited memory, so picking the smallest data type that still does the job is a real engineering skill. Naming convention: camelCase, descriptive names like ledPin or isButtonPressed, not x or a.
