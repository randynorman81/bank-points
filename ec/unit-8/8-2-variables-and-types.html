8.2 — Variables and Types

🔔 Bell Ringer — Think About It
  1. In C++ you had to declare a variable's type (int age = 16;). In Python you just write age = 16. What do you think Python is doing behind the scenes to know that's a number?
  2. Python has three types you'll use constantly: strings, integers, and floats. Which of the three would best store a student's exact test average, and why?
  3. If age = 16 and then later age = "sixteen", does Python complain the way C++ did? What does that tell you about how flexible Python variables are?
  4. Now that you've used variables in Arduino C++, plain C++ (Codecademy), and Python, what feels the same across all three, and what feels different?

Notes

Look up these definitions:

  • Variable (review)
  • String / integer / floating point number
  • Dynamic typing

Key idea: A variable in Python works the same way it did in C++ — a name that stores a value — but Python figures out the type automatically instead of making you declare it, which is called dynamic typing. The three types you'll use constantly are strings (text), integers (whole numbers), and floating point numbers (decimals). Unlike C++, Python lets a variable change type across a program without complaint, which is more flexible but also means Python won't catch a type mistake for you the way C++'s compiler would.
