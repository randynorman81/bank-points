8.4 — Mathematical Operators

🔔 Bell Ringer — Think About It
  1. Python supports the usual math operators (+, -, *, /) plus a couple new ones: ** for exponents and % for remainder (modulo). Where might you use a remainder in real life, like figuring out if a number is even or odd?
  2. Order of operations (PEMDAS) applies in code the same as in math class. Why does a computer need to follow a strict, agreed-upon order instead of just evaluating left to right?
  3. If you wrote a program that takes user input and does a calculation on it, why would you need the type conversion skills from the last lesson?
  4. Give an example of a simple program that takes a number as input and does something useful with basic math.

Notes

Look up these definitions:

  • Arithmetic operators (+, -, *, /)
  • Exponent operator (**)
  • Modulo operator (%)
  • Order of operations

Key idea: Python supports the standard math operators plus two worth knowing well: ** for exponents (2 ** 3 is 8) and % (modulo), which gives you the remainder of a division — useful for things like checking if a number is even (n % 2 == 0). Python follows the same order of operations as math class (PEMDAS), so multiplication and division happen before addition and subtraction unless parentheses say otherwise. Combined with the type conversion from the last lesson, this is enough to build a program that takes a number from the user and computes something useful with it.
