8.6 — Comments

🔔 Bell Ringer — Think About It
  1. You already used comments in Arduino C++, plain C++, and Tracy's turtle graphics. Has your opinion on when a comment is actually useful changed since the first time you learned about them?
  2. Python comments start with #, same as the ones you just used in the Turtle Graphics unit. Why do you think CodeHS revisits the exact same concept again here?
  3. If you were grading someone else's code, what would a well-placed comment tell you that the code alone couldn't?
  4. Write a one-line comment (in words, not code) that would help explain a tricky part of a program you've written this year.

Notes

Look up these definitions:

  • Comment (review)

Key idea: This is the same # comment syntax from the Turtle Graphics unit, showing up again because comments matter in every context, not just one. A comment explains your reasoning to a future reader (including future you), especially on a line where the why isn't obvious just from reading the code. At this point you've now used comments in four different languages and tools this year — Arduino C++, plain C++, Tracy's turtle graphics, and now standard Python — which is a good sign of how universal the habit is.
