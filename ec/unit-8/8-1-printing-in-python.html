8.1 — Printing in Python

🔔 Bell Ringer — Think About It
  1. In C++ you print with cout << "text";. In Python it's print("text"). What do you notice is simpler about the Python version?
  2. Why does a string need quotation marks around it, but a number typically doesn't?
  3. If you forgot a closing quotation mark in a print statement, what do you think would happen when you tried to run the program?
  4. Printing text to the screen seems simple, but it's the very first thing almost every language teaches. Why do you think that is?

Notes

Look up these definitions:

  • print()
  • String
  • Quotation marks (' or ")

Key idea: print() displays text on the screen — the most basic way a Python program can communicate with the person running it. Text has to be wrapped in quotation marks (either single or double) to tell Python "this is a string, not a command," and leaving one off is one of the most common first-day errors. Compared to C++'s cout << "text";, Python's print("text") does the same job with noticeably less punctuation — one of the reasons Python is a popular first (or second) language.
