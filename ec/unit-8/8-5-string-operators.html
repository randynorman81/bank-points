8.5 — String Operators

🔔 Bell Ringer — Think About It
  1. In Python, + on two strings joins them together (concatenation) instead of adding numbers. Why do you think the same symbol was reused for a totally different job on a different type?
  2. If first = "Ada" and last = "Lovelace", what do you think first + last prints, and what's missing compared to what you'd actually want?
  3. Why might you need to explicitly add a space (" ") when combining two strings, instead of it happening automatically?
  4. Can you combine a string and a number directly with +, like "Score: " + 100? Predict what happens, then think about why.

Notes

Look up these definitions:

  • String concatenation
  • Type mismatch

Key idea: When + is used on two strings, it concatenates them — joins them end to end — rather than adding numbers, so "Ada" + "Lovelace" produces "AdaLovelace" with no space unless you add one yourself ("Ada" + " " + "Lovelace"). Trying to concatenate a string directly with a number causes an error, because Python won't silently guess whether you meant to add them as numbers or join them as text — you have to convert the number to a string first with str(). This is the same operator (+) doing a completely different job depending on the type of the values around it.
