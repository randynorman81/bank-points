Arduino Cheat Sheet SCHS Computer Science · Embedded Computing

1. The skeleton of every program

// notes to yourself (the Arduino skips this)
const int ledPin = 8;      // global: name your pins
void setup() {            // runs ONCE at the start
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}
void loop() {             // runs OVER AND OVER
  digitalWrite(ledPin, HIGH);
  delay(1000);            // 1000 ms = 1 s
  digitalWrite(ledPin, LOW);
  delay(1000);
}
WhereWhat goes there
setup()pinMode(...), Serial.begin(9600), starting values: things that happen once
loop()reading buttons/sensors, if statements, digitalWrite, analogWrite, tone, delay, Serial.print: things that repeat
  • Every statement ends with ;   Blocks use { }   Values go in ( )
  • Capital letters matter: digitalWrite works, digitalwrite does not.

6. When something goes wrong

LED will not lightNo pinMode(OUTPUT)? Wrong pin number? Leg dots red? LED backwards? No wire to GND?
LED burned (black X)No resistor. Add 220 Ω, then click Reset.
Button does nothingAcross the gap? One side to GND? INPUT_PULLUP? Check for == LOW.
Random 0s and 1sFloating input: use INPUT_PULLUP.
Serial Monitor emptyForgot Serial.begin(9600); in setup().
Red error boxRead the line number. Usual cause: missing ; or }, a misspelled name, or wrong capital letters.

4. Decisions and loops

if (digitalRead(2) == LOW) {
  digitalWrite(8, HIGH);   // pressed
} else {
  digitalWrite(8, LOW);
}

for (int i = 0; i < 5; i++) {
  // runs 5 times: i is 0,1,2,3,4
}
while (x < 10) { x++; }   // repeats while true

int pins[] = {2, 3, 4};   // array: pins[0] is 2
  • No ; after if ( ), for ( ) or while ( ).
  • delay() freezes everything. millis() lets you time things without freezing.

5. Building circuits

LEDanode (+) = long, bent leg → toward the pin / 5V.
cathode (−) = short, straight leg (flat edge) → toward GND.
ResistorNo polarity. Use 220 Ω (red-red-brown) in series with every LED, or it burns out. I = V / R: (5 − 2) / 220 ≈ 14 mA.
ButtonNo polarity. Put it across the center gap. Wire one side to a pin, the other to GND, and use INPUT_PULLUP: LOW = pressed.
Buzzer+ leg to a pin, − leg to GND. Play it with tone(pin, 440).
BreadboardThe 5 holes in a column (a-e or f-j) are connected. The center gap splits the halves. The long red (+) and blue (−) rows are power rails (whole row connected).
PinsD0-D13 digital (pins 0/1 are used by Serial). ~ pins do PWM. A0-A5 analog. 5V = +, GND = −. The orange L light is pin 13.
