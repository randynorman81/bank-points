Number Systems

You count in base 10 because you have ten fingers. A computer counts in base 2, because a bit has two states. Once you see the pattern, you can switch between the two in your head.

00

Place Value, Again

In decimal, each place is worth 10 times the place to its right. In binary, each place is worth 2 times the place to its right.

Place values (right to left)Digits allowed
Decimal (base 10)1, 10, 100, 1000 ...0 to 9
Binary (base 2)1, 2, 4, 8, 16, 32, 64, 128 ...only 0 and 1

Quick check: a binary number that ends in 1 is odd, and one that ends in 0 is even. The last place is worth 1, so it decides odd or even.
02

Decimal to Binary

Two methods give the same answer. Use whichever one feels easier.

Method 1: take away the biggest place value you can

Click through: write 77 in binary

Start with the place values 128, 64, 32, 16, 8, 4, 2, 1. We need them to add up to 77.

128 is too big, so put a 0. 64 fits, so put a 1. 77 - 64 = 13 left.

32 is too big (13 left), so 0. 16 is too big, so 0.

8 fits in 13, so put a 1. 13 - 8 = 5 left.

4 fits in 5, so put a 1. 5 - 4 = 1 left.

2 is too big for 1, so 0. 1 fits, so 1. Nothing left over. 77 = 01001101.

Method 2: divide by 2 again and again

Read the remainders from bottom to top: 1101. That is 13 in binary.

How Big Can It Get?

With n bits, you can write 2 to the n different numbers, from 0 up to 2 to the n, minus 1.

BitsSmallestLargestWhy
40000 = 01111 = 152^4 - 1
800000000 = 011111111 = 2552^8 - 1
16065,5352^16 - 1
A number that needs more bits than you have causes an overflow error. In 8 bits, 255 is the largest. 256 needs a 9th bit.

Leading zeros do not change a value: 00001101 and 1101 are both 13. We often write them so every number has the same number of bits.

04

Python Does It Too

Python can convert for you, which is great for checking your own work. Learn to do it by hand too, because the exam gives no calculator.

print(bin(13)) # 0b1101 (the 0b just means binary) print(int("1101", 2)) # 13 (read the text as base 2) print(format(13, "08b")) # 00001101 (8 bits, with leading zeros)
On the AP examExpect small conversions (up to about 8 bits), questions about how many bits are needed, and comparing which of two binary numbers is larger. You will not be asked to use bin(), but it is a fine way to check your answers here.
