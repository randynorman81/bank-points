What Is an IP Address?

An IP address (Internet Protocol address) is a unique number that identifies one device on a network. It works like the address on a house: the post office needs it to know where to deliver. Phones, laptops, game consoles, and the school server each have one.

Every chunk of data you send carries two addresses: the source (who sent it) and the destination (where it is going). Routers read the destination to decide where to send it next.

Example: 192.168.1.10 is an IPv4 address. 2001:0db8:85a3::8a2e:0370:7334 is an IPv6 address.
01

IPv4: Four Numbers, 32 Bits

An IPv4 address has four numbers called octets, each from 0 to 255. Each octet is 8 bits (one byte), so the whole address is 4 × 8 = 32 bits.

Try it: the address inspector

Type an IPv4 address. It checks that it is valid, shows the 32 bits, and says whether it is private, public, or loopback.

Why 0 to 255? One byte is 8 bits, and 8 bits make 28 = 256 patterns, which count from 0 up to 255. This is the same idea as the Unit 8 notes.
02

Running Out of Addresses: IPv6

With 32 bits there are 232 = 4,294,967,296 IPv4 addresses. That sounds like a lot, but there are more devices than that, so the world ran out.

The exam idea: a longer address means many more possible addresses. Every extra bit doubles the count, so IPv6 is not four times bigger, it is vastly bigger.
03

Binary by Hand

How does 192 become 11000000? Each bit is worth a power of 2, from left to right: 128, 64, 32, 16, 8, 4, 2, 1. A 1 means add that place value.

1286432168421Total
11000000128 + 64 = 192
10101000128 + 32 + 8 = 168

Try the inspector above with 192.168.1.10. The first octet is 11000000 and the second is 10101000.

Private addresses are not secret. They are just not routable from the Internet. The next lesson shows how a router lets private devices share one public address.
05

Who Hands Out Addresses?

Addresses are given out in layers. A global group (IANA) hands big blocks to regional registries, which hand them to ISPs. Your ISP gives your router a public address.

Check yourself

Answer each one. You see why right away, so read the explanation even when you are right.

How many bits are in an IPv4 address?

Four octets × 8 bits = 32 bits. IPv6 has 128 bits.

Which of these is a private IPv4 address?

192.168.x.x is one of the three private ranges. The others are public.

Which could not be an IPv4 address?

Each octet is one byte, so the biggest is 255. 256 does not fit in 8 bits.

Why was IPv6 created?

32 bits give only about 4.3 billion addresses. IPv6 uses 128 bits.

What does the address 127.0.0.1 mean?

Loopback means "this device". Data sent there never leaves your machine.
AP

On the AP Exam

These are the ideas the exam asks about. Be ready to explain each one in your own words.

  • An IP address is a unique number that identifies a device. Data carries a source and a destination address.
  • IPv4 is 32 bits (four octets). IPv6 is 128 bits. IPv6 exists because IPv4 ran out.
  • n bits can make 2n different addresses.
  • Private addresses work only inside a network. Public addresses are unique on the Internet.
  • ISPs get blocks of addresses and give your router a public one.

An address is a number, and a number is just bits.
