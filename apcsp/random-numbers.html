Random Numbers

import random — the first time this course asks you to bring in extra code Python didn't hand you automatically, to make a program stop being 100% predictable.

00

Definition

Python's core language doesn't include randomness — you have to explicitly bring in the random module with an import statement before any of its functions become available.

import random number = random.randint(1, 6) print(number) # a random whole number from 1 to 6, inclusive

What is import, exactly?

A module is a bundle of pre-written code someone else already built. import random tells Python "load the tools from the module named random and make them available in this file." Without that line, Python has no idea what random.randint even means.

Notice the dot in random.randint(1, 6) — it's the same dot notation from Mouse Events and Key Events: module_name.function_name(). random is the module; randint is one function that lives inside it.

The two functions you'll use most

FunctionReturnsExample
random.randint(a, b)A random integer, from a to b — both ends includedrandom.randint(1, 6) → could be 1, 2, 3, 4, 5, or 6
random.random()A random float from 0.0 up to (not including) 1.0random.random() → something like 0.7284
randint() is inclusive on both ends — this is the opposite of range(), which stops before its second number. random.randint(1, 6) can actually return 6; range(1, 6) never reaches 6 at all. Mixing these two up is the most common bug on this page.
01

Examples

Randomness plugs directly into everything else in this section — conditions, loops, all of it.

basic roll

Simulating a die

import random roll = random.randint(1, 6) print(roll)

A different result nearly every time the program runs.

with an if

A coin flip

flip = random.randint(0, 1) if flip == 0: print("Heads") else: print("Tails")

Two possible outcomes, roughly equally likely.

picking from a list

random.choice()

colors = ["red", "blue", "green"] pick = random.choice(colors)

A second handy function: picks one random item straight out of a list.

in a loop

Rolling until a 6 shows up

rolls = 0 roll = 0 while roll != 6: roll = random.randint(1, 6) rolls = rolls + 1

Combines random numbers with the while-loop pattern — there's no way to know rolls ahead of time.

02

Common Problems / Errors

Forgetting the import: using random.randint() without import random at the top of the file crashes immediately — Python has no idea what random refers to.
number = random.randint(1, 10) NameError: name 'random' is not defined

randint() vs. range() boundaries

Assuming random.randint(1, 6) stops before 6, the way range(1, 6) does. It doesn't — randint() is inclusive on both sides, so a 6-sided die is correctly random.randint(1, 6), not random.randint(1, 5).

Expecting "truly" even odds

random.randint(0, 1) isn't guaranteed to alternate or balance out over a handful of runs — it's genuinely independent each time. Getting the same result 5 times in a row is unlikely, but not a bug.

03

Python Code vs. Pseudocode

This is one of the few places the AP Reference Sheet's pseudocode lines up almost exactly with a real function name.

ConceptAP CSP PseudocodePython
Random integer, inclusive both endsRANDOM(a, b)random.randint(a, b)
The Reference Sheet's RANDOM(a, b) is explicitly defined as inclusive on both ends — the exact same rule as random.randint(a, b). This is genuinely one of the more reliable one-to-one matches between the pseudocode and real Python you'll find in this whole course.
04

Spotify Examples (5)

Five real features from a music app that only work because of randomness.

random.choice()

Shuffle play

import random next_song = random.choice(playlist)

The entire feature is one function call, once the module is imported.

randint()

"Discover" recommendations

genres = ["pop", "jazz", "rock", "lofi"] index = random.randint(0, len(genres) - 1) suggested = genres[index]

len(genres) - 1 because randint() is inclusive — using len(genres) alone would risk an index that's one too high.

random()

Occasional ad insertion

if random.random() < 0.2: play_ad()

Roughly a 20% chance each time this check runs — random.random() is uniformly spread between 0 and 1.

loop and a half

A shuffle that avoids repeats

while True: pick = random.choice(playlist) if pick != last_played: break last_played = pick

Keeps re-rolling until it lands on something different from the last song.

randint() in a loop

Generating a queue of five songs

queue = [] for i in range(5): queue.append(random.choice(all_songs))

Five independent random picks, built with a plain range() for loop.
