Basic Math

Every math operator AP CSP expects you to know — including the two that don't exist in ordinary math class: floor division and modulus.

00

Definition

Seven operators cover the entire AP CSP math toolkit. Five behave exactly like ordinary math class; two — floor division and modulus — are new.

OperatorNameExampleResult
+Addition7 + 29
-Subtraction7 - 25
*Multiplication7 * 214
/Division7 / 23.5
**Exponent7 ** 249
//Floor division7 // 23
%Modulus (remainder)7 % 21

Floor division (//) keeps only the whole number of times one value fits into another. Modulus (%) gives you the remainder left over after that division. They're almost always taught together.

01

Examples

Python follows the same order of operations as math class — parentheses, then exponents, then * / // % left to right, then + - left to right.

result = 2 + 3 * 4 print(result) # 14 -- multiplication happens first result2 = (2 + 3) * 4 print(result2) # 20 -- parentheses force the addition first
// alone

How many whole times

print(17 // 5)

Output: 3 — 5 fits into 17 three whole times.

% alone

Even or odd?

n = 8 print(n % 2 == 0)

Output: True — any number's remainder after ÷ 2 is only ever 0 or 1.

% alone

Wrapping back around

position = 11 next_pos = (position + 1) % 8

Output: 4 — wraps back into the 0–7 range instead of running off the end.

// and % together

Seconds into minutes:seconds

total = 200 minutes = total // 60 seconds = total % 60

Output: 3 and 20 — the classic pairing.

Mixing integers and floats

The moment a float is involved anywhere in an expression, the whole result becomes a float — even if it could have come out as a whole number.

total = 10 + 2.0 print(total) # 12.0, not 12

Compound assignment operators

A shortcut for "take a variable, do math on it, save the result back into itself" — the x = x + 1 pattern from the Variables page, just shorter to type.

score = 0 score += 10 # same as score = score + 10 score += 10 print(score) # 20
Every operator has a compound version: += -= *= /= //= %= **=.
02

Common Problems / Errors

The one that surprises people: / always returns a float in Python, even when both numbers are integers and it divides evenly. 10 / 2 is 5.0, not 5. Need a whole-number result? Use // instead.
Order-of-operations mistake: 10 + 6 // 2 is 13, not 8 — // and % share priority with * and /, not addition. If you want the addition to happen first, you need parentheses: (10 + 6) // 2.
Good to know: with a negative number, // rounds down (toward negative infinity), not toward zero — -7 // 2 is -4, not -3. AP CSP problems almost always stick to positive numbers, but it's worth knowing this isn't the same as just chopping off the decimal.
03

Python Code vs. Pseudocode

Most of these operators look almost identical in both — except for one that pseudocode doesn't even have a symbol for.

ConceptAP CSP PseudocodePython
Add / Subtract / Multiplya + b, a - b, a * ba + b, a - b, a * b
Dividea / ba / b
Remaindera MOD ba % b
Whole-number-only divisionno separate symbol — described in wordsa // b
Add and reassigna ← a + 1a += 1
MOD and % are the exact same idea, just spelled differently. // is a Python-only convenience — on the exam, "give me just the whole-number part" is something pseudocode has to describe in a sentence, not write as one symbol. Pseudocode also has no shortcut for reassignment — it always spells out a ← a + 1 in full; Python's += family is purely a Python convenience too.
04

Spotify Examples (5)

Five different real features, five different operators — this is the kind of math actually running behind a music app.

// and %

Formatting a song's duration

duration_sec = 200 minutes = duration_sec // 60 seconds = duration_sec % 60

Turns one raw number of seconds into the 3:20 you actually see under a song.

/

Averaging a song's rating

r1, r2, r3, r4 = 4.5, 5.0, 3.5, 4.0 average = (r1 + r2 + r3 + r4) / 4

Output: 4.25. Four listener ratings become the one number shown on the song page.

%

Looping to the next song

playlist_length = 12 current_index = 11 next_index = (current_index + 1) % playlist_length

Output: 0. Reaching the last song wraps back around to the first instead of crashing.

//

How many full plays fit in an hour

song_length_sec = 210 plays_per_hour = 3600 // song_length_sec

Output: 17. Useful for anything estimating "how many times could this play in a set window."

* and round()

Estimating a royalty payout

streams = 125000 rate_per_stream = 0.004 payout = round(streams * rate_per_stream, 2)

Output: 500.0. Multiplication does the real work; round() keeps it to a clean two decimal places, like a dollar amount.

Every one of these is the exact same handful of operators from the top of this page.Real products don't use fancier math than a classroom — they just apply the same +, -, *, /, //, and % to problems that actually matter to someone.

Seven operators. That's the entire math toolkit AP CSP asks you to know.

The only two that feel new are // and % — and both of them just answer "how many whole times" and "what's left over."
