For Loops

for i in range(n): — the exact same syntax you already used to make Karel repeat a move, now repeating any Python code a set number of times.

00

Definition

A for loop repeats a block of code once for every value produced by range(...). It's the go-to choice whenever you know exactly how many times something needs to happen.

for i in range(5): print(i) # output: # 0 # 1 # 2 # 3 # 4

range(5) produces five numbers — 0, 1, 2, 3, 4 — and i is a variable that holds one of them each time through the loop. Two things trip people up immediately: it starts at 0, not 1, and it stops before reaching the number you gave it, not on it. range(5) runs exactly 5 times, but the last value it hands you is 4.

You already did this — in Karel

If you've done the Karel unit, this exact line should look familiar: for i in range(4): is precisely how Karel repeated move() four times. The only thing that's new here is that the loop body can be any Python code, not just Karel commands.

range() has three forms

FormProducesExample
range(stop)0 up to (not including) stoprange(5) → 0,1,2,3,4
range(start, stop)start up to (not including) stoprange(2, 6) → 2,3,4,5
range(start, stop, step)start to stop, counting by steprange(0, 10, 2) → 0,2,4,6,8
The variable name i is just a convention (short for "index") — you can call it anything, like count or day. If you never actually use the loop variable inside the body, i is still fine to keep — it's just there to make the loop run the right number of times.
01

Examples

The loop body follows the same indentation rule as an if statement — everything one level deeper belongs to the loop.

just repeating

Nothing needs the counter

for i in range(3): print("Hello!")

Prints "Hello!" three times — i exists but is never used.

using the counter

Building a countdown

for i in range(5, 0, -1): print(i) print("Liftoff!")

A negative step counts down: 5, 4, 3, 2, 1.

accumulating

Adding up a total

total = 0 for i in range(1, 6): total = total + i print(total)

Output: 15 — 1+2+3+4+5. total has to be created before the loop starts.

nested

A loop inside a loop

for row in range(3): for col in range(3): print(row, col)

The inner loop runs completely, 3 times, for every single pass of the outer loop — 9 lines total.

02

Common Problems / Errors

Off-by-one: expecting range(5) to include 5, or to start at 1. It does neither — it's 5 values starting at 0, so the last one is always 4.

Forgetting range() entirely

for i in 5: TypeError: 'int' object is not iterable

A plain number can't be looped over — range() is what turns it into a sequence of numbers Python can step through.

Re-creating a total inside the loop

for i in range(1, 6): total = 0 total = total + i print(total) # 5, not 15

total = 0 was accidentally placed inside the loop, so it resets every single pass instead of accumulating.

A negative or backwards range with no step (like range(5, 0), missing the -1) doesn't error — it just silently produces zero values, and the loop body never runs at all. If a loop seems to be doing nothing, check whether range() is actually counting in the direction you think it is.
03

Python Code vs. Pseudocode

Pseudocode has its own repeat-a-set-number-of-times block, with its own name.

ConceptAP CSP PseudocodePython
Repeat n timesREPEAT n TIMES
    <block>		for i in range(n):
    <block>
Pseudocode's REPEAT n TIMES doesn't even give you a counter variable — it assumes you don't need to know which repetition you're on. Python's for i in range(n): always hands you i too, whether you end up using it or not.

Spotify Examples (5)

Five real "do this N times" moments from a music app.

basic repeat

Drawing five volume bars

for i in range(5): bar = Rectangle(10, 20) bar.set_position(i * 15, 100) add(bar)

i is used to space each bar out horizontally.

countdown

Skip-limit warning

for skips_left in range(3, 0, -1): print(str(skips_left) + " skips left")

Counts down from 3 to 1 instead of up.

accumulating

Total playlist duration

total_seconds = 0 for i in range(len(durations)): total_seconds = total_seconds + durations[i]

len(durations) makes the loop run exactly once per song, whatever the playlist's size.

nested

Building a grid of album covers

for row in range(3): for col in range(3): place_album(row, col)

A 3×3 grid of covers, 9 placements total.
