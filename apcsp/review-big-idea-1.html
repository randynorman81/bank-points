Review: Big Idea 1, Creative Development

How programs get made: collaboration, purpose, incremental and iterative development, and the four kinds of errors. Review the terms, then test yourself.

The Summary

Big Idea 1: Creative Development is about how programs get made. See the notes in Unit 19 (and the Create Task units) for the full story.

TermMeaning
Collaborationworking with others; diverse perspectives find more problems and make better programs
Pair programminga driver types, a navigator reviews; they swap roles
Purpose vs functionpurpose = the problem it solves; function = what it does with input to make output
Event-drivencode runs when something happens (a click, a key press)
Incrementalbuild and test in small pieces
Iterativerepeat the design, build, test, improve cycle with feedback
Syntax errorbreaks language rules; the program will not run
Logic errorruns but gives the wrong result; no error message
Run-time errorcrashes while running (divide by zero, index out of range)
Overflow errora number is too big for its bits
Documentationcomments that say what the program or procedure is for

Check yourself

Answer each one. You see why right away, so read the explanation even when you are right.

Which two are benefits of collaboration on a software project? select TWO
Collaboration brings diverse viewpoints and code review. It never guarantees there are no bugs, and testing is still needed.
A recipe app lets users save recipes and search by ingredient. Which describes the app's purpose?
Purpose is the problem it solves for users. The other choices describe how it is built.
