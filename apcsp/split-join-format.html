Split: Text Into a List

split() breaks a string into a list of words. With no argument it splits on spaces. With an argument it splits on that text, which is perfect for data separated by commas.

CodeResult
"the quick fox".split()["the", "quick", "fox"]
"Ana,16,GA".split(",")["Ana", "16", "GA"]
len("the quick fox".split())3 (a word count)

After splitting you have a normal list, so everything from Unit 7 works: indexing, loops, len, append.

Everything that comes out of split is still text. "16" is not the number 16. Use int(parts[1]) before doing math.
01

Join: A List Into Text

join is the opposite. It glues a list of strings together with a separator you choose. The separator comes first.

words = ["red", "green", "blue"] print("-".join(words)) # red-green-blue print(", ".join(words)) # red, green, blue print("".join(words)) # redgreenblue

02

Formatting Output

An f-string (a string with an f in front) puts values straight into text. Add a format code after a colon to control how it looks.

FormatMeaningExample
{x}insert the valuef"Score: {x}"
{x:.2f}2 decimal places3.14159 becomes 3.14
{x:>8}right-align in 8 spacesgood for columns of numbers
{x:<12}left-align in 12 spacesgood for names
{x:,}thousands commas1234567 becomes 1,234,567

On the AP Exam

These are the ideas the exam asks about. Be ready to explain each one in your own words.

  • split() turns text into a list of strings. join() turns a list of strings into text, with the separator first.
  • Split items are still strings. Convert numbers with int() or float().
  • f-strings insert values and format them (.2f, alignment, commas).
  • Text processing combines split, loops, methods, and join.
