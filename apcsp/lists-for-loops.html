For Loops and Lists

The real power of a list is that one loop can do the same work on every item, no matter how long the list is. This is called traversing a list, and it is on every AP exam.

00

Visit Every Item

for item in list takes the items one at a time, in order, and puts each in a variable for the loop body to use.

scores = [80, 95, 70, 100] total = 0 for score in scores: total = total + score print(total) # 345

Click through the loop: watch score and total

Before the loop, total is 0.

Pass 1: score is 80. total = 0 + 80, so total is 80.

Pass 2: score is 95. total = 80 + 95, so total is 175.

Pass 3: score is 70. total is 245.

Pass 4: score is 100. total is 345. The list has no more items, so the loop ends.

The loop runs once for each item. A list with 4 items makes 4 passes, and a list with 4,000 items makes 4,000 passes, with the same code.
01

Two Ways to Loop Over a List

There are two common patterns. Both visit every item, but they give you different things to work with.

Loop over the items

for score in scores: print(score)

The variable is the item. Use this when you only care about the values.

Loop over the indexes

for i in range(len(scores)): print(i, scores[i])

The variable is the position, and scores[i] is the item. Use this when you need the position or two lists at once.

PythonAP exam pseudocode
for score in scores:FOR EACH score IN scores
for i in range(len(scores)):REPEAT LENGTH(scores) TIMES` (with a counter you keep yourself)
The exam's FOR EACH item IN list is the same as Python's for item in list. Remember the exam list counts from 1, but FOR EACH never needs an index, so there is nothing to convert.

Four Patterns You Must Know

Almost every list question on the exam is one of these four patterns. Learn the shape of each one.

PatternStart withInside the loopAfter the loop
Sumtotal = 0total = total + itemtotal is the sum
Countcount = 0if item > 50:` then `count = count + 1count is how many matched
Largestbest = items[0]if item > best:` then `best = itembest is the largest
Average(sum first)(the sum loop)total / len(items)
nums = [3, 9, 4, 7] best = nums[0] for n in nums: if n > best: best = n print(best) # 9

Finding the largest: watch best change

best starts as the first item, 3.

Check 9. Is 9 > 3? Yes, so best becomes 9.

Check 4. Is 4 > 9? No, so best stays 9.

Check 7. Is 7 > 9? No. The loop ends and best is 9.

Why start best with the first item and not 0? If every number is negative, best = 0 would give the wrong answer. Starting with an item from the list is always safe.
03

Practice Reading Exam Pseudocode

This is exactly the shape of an exam question. Trace it, then click for the answer.

nums ← [2, 5, 1, 8] count ← 0 FOR EACH n IN nums { IF (n > 3) { count ← count + 1 } } DISPLAY(count)

Trace it

n is 2. 2 > 3 is false, so count stays 0.

n is 5. 5 > 3 is true, so count becomes 1.

n is 1. 1 > 3 is false. count stays 1.

n is 8. 8 > 3 is true, so count becomes 2. The loop ends and DISPLAY(count) shows 2.

One loop, any size list: sum, count, largest, and average.
