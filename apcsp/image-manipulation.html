Image Manipulation

Photo filters are not magic. A picture is a list of pixels, a pixel is three numbers, and a filter is a loop that changes the numbers. You already know every tool you need.

00

An Image Is a List of Pixels

In Python we can store pixels as a list of tuples, one (red, green, blue) tuple per pixel.

pixels = [(255, 0, 0), (0, 128, 255), (100, 100, 100)] print(pixels[0]) # (255, 0, 0), the first pixel: pure red print(pixels[1][2]) # 255, the blue value of the second pixel

Try it: run a filter on five pixels

Each pixel is just three numbers. A filter changes the numbers.

01

Filter 1: Invert

Flip every value to its opposite: 255 minus the value. Black becomes white, and red becomes cyan.

def invert(pixels): result = [] for (r, g, b) in pixels: result.append((255 - r, 255 - g, 255 - b)) return result print(invert([(255, 0, 0), (0, 128, 255)])) # [(0, 255, 255), (255, 127, 0)]

for (r, g, b) in pixels unpacks each tuple into three variables so you can use the red, green, and blue values by name. result.append(...) adds the new pixel to the end of the new list.

02

Filter 2: Grayscale

A gray pixel has equal red, green, and blue. Averaging the three values gives a gray of about the same brightness.

def grayscale(pixels): result = [] for (r, g, b) in pixels: average = (r + g + b) // 3 result.append((average, average, average)) return result print(grayscale([(255, 0, 0), (0, 128, 255)])) # [(85, 85, 85), (127, 127, 127)]
// divides and drops the decimal, so the new values stay whole numbers. Colors must be whole numbers from 0 to 255.
03

Filter 3: Brighten (and Stay in Range)

Add to every value to brighten. But a value can never go above 255, so the code must cap it.

def brighten(pixels, amount): result = [] for (r, g, b) in pixels: result.append((min(255, r + amount), min(255, g + amount), min(255, b + amount))) return result print(brighten([(250, 100, 0)], 20)) # [(255, 120, 20)] <- 250 + 20 would be 270, so it is capped at 255
Go out of range and the data is invalid. 270 does not fit in one byte. This is the overflow idea from Lesson 8.1, and min(255, ...) is how we prevent it. To darken, use max(0, ...) so a value never drops below 0.
FilterWhat happens to (r, g, b)
Invert(255 - r, 255 - g, 255 - b)
Grayscale(avg, avg, avg) where avg = (r + g + b) // 3
Brighten(min(255, r + n), ...)
Darken(max(0, r - n), ...)
04

On the AP Exam

The exam will not ask about pixel filters by name, but it asks about the ideas behind them.

  • Digital data like images is processed by an algorithm that works on every item.
  • A loop over a list, with the same change applied to each item, is the pattern you have used all unit.
  • Changing the numbers changes what you see, because the numbers are the picture.
  • A filter keeps the original safe if it builds a new list instead of changing the old one.

Every filter is a loop.
