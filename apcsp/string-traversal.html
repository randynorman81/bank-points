A Loop Over a String

A string is a sequence, so a for loop can visit every character, one at a time, in order. This is the same traversal pattern you used for lists.

word = "robot" for ch in word: print(ch)

The loop variable ch holds one character on each pass. The loop ends after the last character.

01

Two Ways to Loop

You can loop over the characters directly, or over the positions.

02

The Accumulator Pattern

Most string jobs follow one recipe: start with an empty result, loop, and add to the result.

JobStartInside the loop
Count somethingcount = 0if ch in "aeiou": count = count + 1
Copy / filterresult = ""if ch != " ": result = result + ch
Reverseresult = ""result = ch + result (new letter goes in front)
Transformresult = ""result = result + ch.upper()
result + ch and ch + result are different. The first appends to the end. The second puts the new letter at the front, which is how you reverse a word.

What does this code display?

The loop checks every letter and counts the as.
What does this code display?
result = "" for ch in "cat": result = ch + result print(result)
Each new letter is put in front, so the word is reversed.
Which loop header gives you both each character and its position?
Looping over range(len(word)) gives the indexes, and word[i] gives the characters.
What does this code display?
result = "" for ch in "a b c": if ch != " ": result = result + ch print(result)
The loop keeps every character except spaces.
A program should report whether a word reads the same forward and backward. Which approach works?
Reverse it, then compare: that is a palindrome check.
