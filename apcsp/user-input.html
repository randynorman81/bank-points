User Input

Every form of input() you'll need for AP CSP — what it actually returns, why that trips people up, and how to combine it with everything else you know.

00

What Is input()?

input() pauses your program, shows the user a prompt, and waits. The instant they type something and press Enter, whatever they typed gets handed back to you.

name = input("What's your name? ") print("Hello, " + name)

The text inside the parentheses — "What's your name? " — is the prompt. It's shown to the user so they know what to type, but it is not part of what gets stored. Only what the user actually types ends up in name.

01

input() Always Returns a String

This is the single most important fact about input() for AP CSP: no matter what the user types — even if it's only digits — Python stores it as a string. Always. There is no exception.

What the user types

15

What Python actually stores

"15" — a string containing the characters 1 and 5, not the number fifteen

Try to do math on it directly, and it breaks — the exact same TypeError from the Concatenation page:

age = input("How old are you? ") # user types: 15 print(age + 1) TypeError: can only concatenate str (not "int") to str
The sneaky version of this bug: if you take in two numbers and add them without converting, Python doesn't crash — it just gives you the wrong answer, silently.
num1 = input("Enter a number: ") # user types: 4 num2 = input("Enter another: ") # user types: 5 print(num1 + num2) # "45" -- concatenation, not addition. Never 9.
02

Converting Input to a Number

To do real math with what the user typed, convert it the moment you receive it — wrap the whole input() call directly in int() or float().

Whole numbers

int(input())

age = int(input("Age? ")) print(age + 1)

Output (user types 15): 16 — real math now

Decimal numbers

float(input())

price = float(input("Price? ")) print(price * 1.08)

Output (user types 10): 10.8 — 8% tax added

Wrapping it directly — int(input(...)) — is the standard pattern. It converts before storing, so the variable is already a real number, not a string you have to remember to fix later.
03

Concatenating Input With Other Types

Since input() hands you a string, joining it with other strings — including more input() calls — works immediately with +. The moment you bring a converted number back into the mix, you're back to the exact same rule from the Concatenation page: convert it to a string first with str().

first = input("First name? ") last = input("Last name? ") full_name = first + " " + last # works directly -- both strings print("Hello, " + full_name) age = int(input("Age? ")) # now a real int print("You are " + str(age) + " years old.") # str() needed again

The rule never changes, only which values need it: every non-string piece of a + expression needs its own str(), whether that piece came from a variable, a calculation, or an int(input(...)) call.

05

f-strings With Input

Same shortcut as before — once a value is converted to the right type, an f-string can drop it straight into a message with no str() needed.

age = int(input("Age? ")) print(f"You are {age} years old.")
f-strings don't skip the int() conversion — you still need a real number to do math with. They only skip the extra str() when you go to display it.
06

Real World: How Spotify Would Use This

This is the exact pattern — ask, convert, concatenate — behind a real "Add to Playlist" or "Rate This Song" feature.

song = input("Song title: ") artist = input("Artist: ") rating = float(input("Rate this song (1-5): ")) plays = int(input("How many times have you played it today? "))

Four calls to input(), and already two different types are in play: song and artist are strings, straight from the user. rating and plays were converted the moment they came in, so they're a real float and a real int — ready for math, not ready to concatenate yet.

The bug, if you forget to convert back:
summary = "\"" + song + "\" by " + artist + " -- rated " + rating + "/5" TypeError: can only concatenate str (not "float") to str

The fix is the same str() rule from every example on this page — wrap every non-string piece:

summary = ("\"" + song + "\" by " + artist + " -- rated " + str(rating) + "/5, played " + str(plays) + " times today") print(summary) # "Blinding Lights" by The Weeknd -- rated 4.5/5, played 3 times today
Or, the f-string version — the way it would actually get written in a real codebase: f'"{song}" by {artist} -- rated {rating}/5, played {plays} times today'

Everything the user types starts as a string. What it becomes next is entirely up to you.Convert it if you need to do math. Leave it alone if you're just displaying text. Either way, the moment you mix types in a +, someone needs a str().

Ask. Convert if you need to. Concatenate with str(). That's the whole pattern.

Every real "type something in, see a result" feature you've ever used runs on exactly these three steps.
