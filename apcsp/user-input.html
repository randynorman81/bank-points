User Input

Every form of input() you'll need for AP CSP — what it actually returns, why that trips people up, and how to combine it with everything else you know.

00

Definition

input() pauses your program, shows the user a prompt, and waits. The instant they type something and press Enter, whatever they typed gets handed back to you.

name = input("What's your name? ") print("Hello, " + name)

The text inside the parentheses — "What's your name? " — is the prompt. It's shown to the user so they know what to type, but it is not part of what gets stored. Only what the user actually types ends up in name.

The most important fact about input() for AP CSP: no matter what the user types — even if it's only digits — Python stores it as a string. Always.
01

Examples

To do real math with what the user typed, convert it the moment you receive it — wrap the whole input() call directly in int() or float().

Whole numbers

int(input())

age = int(input("Age? ")) print(age + 1)

Output (user types 15): 16 — real math now

Decimal numbers

float(input())

price = float(input("Price? ")) print(price * 1.08)

Output (user types 10): 10.8 — 8% tax added

Concatenating input with other types

Since input() hands you a string, joining it with other strings — including more input() calls — works immediately with +. The moment a converted number comes back into the mix, the same rule from the Concatenation page applies: convert it to a string first with str().

first = input("First name? ") last = input("Last name? ") full_name = first + " " + last # works directly -- both strings print("Hello, " + full_name) age = int(input("Age? ")) # now a real int print("You are " + str(age) + " years old.") # str() needed again
Same shortcut applies here too: print(f"You are {age} years old.") — an f-string converts age automatically, no str() needed to display it.
02

Common Problems / Errors

Try to do math on raw input, and it breaks — the exact same TypeError from the Concatenation page:

age = input("How old are you? ") # user types: 15 print(age + 1) TypeError: can only concatenate str (not "int") to str
The sneaky version of this bug: if you take in two numbers and add them without converting, Python doesn't crash — it just gives you the wrong answer, silently.
num1 = input("Enter a number: ") # user types: 4 num2 = input("Enter another: ") # user types: 5 print(num1 + num2) # "45" -- concatenation, not addition. Never 9.

03

Python Code vs. Pseudocode

This is where Python and AP CSP pseudocode really part ways — in a way that explains exactly why input() behaves the way it does.

AP CSP Pseudocode

DISPLAY("What's your name?") name ← INPUT()

Python

name = input("What's your name? ")

Pseudocode's INPUT() doesn't take a prompt — you DISPLAY one first, as its own separate step. Python's input() does both at once: show the prompt, then wait for an answer.

What you're doingAP CSP PseudocodePython
Get a value from the userINPUT()input("prompt")
What type comes backNot specifiedAlways a string
Using it as a numberUsed directlyMust convert: int(input(...))
That last row is the whole reason the Common Problems section above exists. AP CSP's pseudocode never has to deal with INPUT() returning "the wrong type," because it never promises a type at all. Python does promise one — always a string — which is exactly why you have to convert it yourself.
04

Spotify Examples (5)

The exact pattern — ask, convert if needed, concatenate — behind a real "Add to Playlist" or "Rate This Song" feature.

01 · String, no conversion

Getting the song title

song = input("Song title: ")

Stored exactly as typed — already a string, ready to concatenate.

02 · float(input())

Getting a rating

rating = float(input( "Rate this song (1-5): "))

Converted immediately, so it's ready for math — not ready to concatenate yet.

03 · int(input())

Getting today's play count

plays = int(input( "Plays today? "))

A real integer now, not the string "3".

04 · Concatenating input directly

Welcoming the user by name

artist = input("Artist: ") print("Now playing " + artist)

No conversion needed — artist is already a string.

05 · Putting it all together

Building the full summary

summary = ("\"" + song + "\" by " + artist + " -- rated " + str(rating) + "/5, played " + str(plays) + " times today")

Output: "Blinding Lights" by The Weeknd -- rated 4.5/5, played 3 times today

Ask. Convert if you need to. Concatenate with str(). That's the whole pattern.

Every real "type something in, see a result" feature you've ever used runs on exactly these three steps.
