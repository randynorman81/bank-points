Booleans

The data type behind every decision your program makes — and the exact thing every if statement, while loop, and mouse click handler you've written has secretly been built on.

00

Definition

A boolean is a data type with exactly two possible values: True or False — capitalized, always, in Python. Comparing two values with a relational operator (==, !=, >, <, >=, <=) is what produces one.

is_raining = True print(is_raining) # True print(type(is_raining)) # <class 'bool'> score = 85 passed = score >= 60 print(passed) # True -- the comparison itself IS the boolean

This is what your if statements have been running on

Every if you've written — back in Karel, and again with mouse clicks — needs its condition to boil down to exactly one True or False. You can write the comparison directly inside the if, or compute it ahead of time and store it in a variable. Both do the exact same thing.

Comparison written inline

if score >= 60: print("Passed")

Comparison stored first

passed = score >= 60 if passed: print("Passed")

The second version should look familiar — it's exactly the pattern from Mouse Events, where is_playing got flipped with is_playing = not is_playing and then checked with a plain if is_playing:. No comparison needed inside the if at all once a variable is already holding a boolean.

This is also what a while loop condition is doing every single time it checks whether to keep going — while is_running: re-evaluates a boolean before every trip through the loop, exactly like an if does once.

strings compare too

Not just numbers

name = "Karel" print(name == "Karel")

Output: True. == and != work on strings, not just numbers.

function return value

A function can hand back a boolean

def is_even(n): return n % 2 == 0 print(is_even(8))

Output: True. The returned value is itself a boolean.

while loop

Controlling a loop

beepers_left = True while beepers_left: # ... pick up a beeper ... beepers_left = beeper_count > 0

The loop keeps running as long as this boolean stays True.

printing directly

No if statement needed at all

is_admin = False print(is_admin)

A boolean is a real value — you can print it, store it, or pass it around just like a number or string.

02

Common Problems / Errors

Lowercase true/false: Python's boolean values are True and False — capitalized, no exceptions. Lowercase versions aren't booleans at all, they're undefined names.
is_ready = true NameError: name 'true' is not defined

= vs ==

One equals sign assigns a value. Two equals signs compare two values. Using = inside a condition is an immediate syntax error in Python — it won't silently do the wrong thing, it just won't run.

if score = 100: SyntaxError: invalid syntax

Redundant comparison

if is_playing == True: works, but it's redundant — is_playing is already a boolean. Just write if is_playing:. Comparing a boolean to True or False is a style flag, not a bug, but it's worth breaking the habit early.

Comparing two floats with == can surprise you — tiny rounding errors mean 0.1 + 0.2 == 0.3 is actually False in Python. This rarely comes up in AP CSP problems, but it's a real thing that trips up beginners the first time they see it.

The values themselves are written differently — the comparison operators mostly aren't.

The one that trips people up on the multiple-choice exam: pseudocode's = means equal to (a comparison), not assignment — pseudocode assignment is written with an arrow, a ← 5. Python flips this: = assigns, == compares. Read pseudocode's = as Python's ==, every time.

Spotify Examples (5)

Five real on/off switches from a music app, each one just a boolean.

a stored flag

Premium account status

is_premium = True if is_premium: print("Ad-free")

One boolean gates an entire feature.

a comparison

Has this song been liked?

song_likes = 3 is_liked = song_likes > 0

Output: True. The heart icon fills in based on this one value.

flipped by a click

Shuffle toggle

is_shuffle_on = False def toggle_shuffle(x, y): global is_shuffle_on is_shuffle_on = not is_shuffle_on add_mouse_click_handler(toggle_shuffle)

Same pattern as the play/pause button from Mouse Events.

comparing to a limit

Has the song ended?

is_song_over = current_time >= song_duration

Once current_time catches up to song_duration, this flips to True and the next track can start.

a returned boolean

Checking explicit content

def is_explicit(song): return song.rating == "explicit"

The function's entire job is to answer one true/false question.
