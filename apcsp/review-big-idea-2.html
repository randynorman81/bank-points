The Summary

Big Idea 2: Data covers how data is stored as bits, how it is compressed, and how information is extracted from it.

TermMeaning

n bitsmake 2n patterns, counting from 0 to 2n - 1
Overflow / round-offtoo big for the bits / cannot be stored exactly
Analog vs digitalsmooth values vs separate numbers; analog is sampled to become digital

01

Practice Set (10 questions)

Work out numbers on paper.

Check yourself

Answer each one. You see why right away, so read the explanation even when you are right.

A game needs to give each of 40 different characters its own unique binary code. What is the minimum number of bits needed for each code?
5 bits make only 32 patterns, which is too few. 6 bits make 64, so 6 bits.
What is the decimal value of the binary number 10110?
16 + 4 + 2 = 22.
What is the binary representation of the decimal number 37?
37 = 32 + 4 + 1, so the bits for 32, 4, and 1 are on: 100101.
In many programs 0.1 + 0.2 displays 0.30000000000000004. This is an example of
Some decimal numbers cannot be stored exactly in a fixed number of bits.
Which two statements about lossy compression are true? select TWO
Lossy throws away detail for good, and that is what lets the file shrink more.
A medical office stores scans that must be reproduced exactly. Which is the best choice?
When every detail matters, use lossless.
A sound is recorded by measuring its volume 44,000 times per second. What happens if the number of measurements per second is increased?
A higher sampling rate gives a closer copy, but needs more data.
A pixel stores 3 bytes (one each for red, green, and blue). How many different colors can one pixel show?
3 bytes = 24 bits, so 224 = 16,777,216 colors.
An image is 100 pixels wide and 100 pixels tall with 24 bits per pixel. About how many bytes is it before compression?
100 × 100 × 24 = 240,000 bits. Divide by 8: 30,000 bytes.
A study finds that cities with more ice cream shops have more sunburn cases. Which conclusion is best supported?
A correlation does not show causation. Look for a confounding variable.
