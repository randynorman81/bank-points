Return Values with Decisions and Loops

Inside a function you can use everything you already know: if statements, loops, and variables. The function does the thinking and returns the answer.

00

Definition

A function body can contain selection (if, else), iteration (loops), and sequencing (steps in order). The function uses its parameters in those instructions and then returns a result: a number, some text, or True or False.

def bigger(a, b): if a > b: return a # leaves right here when a is bigger else: return b print(bigger(8, 3)) # 8 print(bigger(2, 9)) # 9

Which return runs?

Three patterns to know

PatternWhat it doesExample
Return True or Falseanswers a yes-or-no questionreturn n % 2 == 0
Return one of two valuesan if decides which value comes backreturn a` or `return b
Loop, then returna loop builds an answer, return sends it back after the looptotal = 0 ... return total
def is_even(n): return n % 2 == 0 # the comparison itself is True or False if is_even(7): # use the answer to decide print("even") else: print("odd") # prints odd
Because return ends the function immediately, a return inside an if is a common way to stop early. The rest of the function never runs once a return has happened.
01

Examples

Each function takes data in, makes a decision or repeats a step, and hands back an answer.

yes or no

Is it even?

def is_even(n): return n % 2 == 0 print(is_even(8)) # True print(is_even(7)) # False

A comparison is already True or False, so you can return it directly.

pick one

The smaller of two

def smaller(a, b): if a < b: return a return b print(smaller(4, 9)) # 4

If the if returns, the function ends. Otherwise the last line runs.

loop then return

Add 1 up to n

def sum_to(n): total = 0 for i in range(1, n + 1): total = total + i return total print(sum_to(4)) # 10

The loop builds total. The return is after the loop, not inside it.

average

Average of three

def average(a, b, c): return (a + b + c) / 3 print(average(70, 80, 90)) # 80.0

Brackets make the addition happen before the division.

use the answer

Call it in an if

def passed(score): return score >= 60 if passed(75): print("You passed")

A function that returns True or False can be used directly as the condition.

02

Common Problems / Errors

Where the return goes matters. A return inside a loop ends the whole function the first time it runs.

Return inside the loop

def sum_to(n): total = 0 for i in range(1, n + 1): total = total + i return total # ends after the first pass! print(sum_to(4)) # 1

The return is indented under the loop, so it runs on the very first pass.

Return after the loop

def sum_to(n): total = 0 for i in range(1, n + 1): total = total + i return total # not indented under the loop print(sum_to(4)) # 10

The loop finishes first, then the answer is returned once.

Returning in only some cases

def label(n): if n > 0: return "positive" print(label(-5)) # None: no return ran

If no return runs, the function gives back None. Make sure every path returns something.

True and False are not text

return True sends back the Boolean value. return "True" sends back the word. Comparing with == already gives a Boolean, so return n > 5 is enough.
