Multiple Parameters

A function can take as many parameters as it needs. The arguments in the call are matched to the parameters by position, first to first, second to second, so the order matters.

00

Definition

List several parameters in the definition, separated by commas. When you call the function, give the same number of arguments in the same order. The first argument goes into the first parameter, the second argument into the second parameter, and so on.

def describe(name, age): print(name, "is", age, "years old") describe("Ana", 16) # name is "Ana", age is 16 describe("Ben", 15) # name is "Ben", age is 15 # output: # Ana is 16 years old # Ben is 15 years old

Arguments are matched by position

Order matters

Python does not look at the names in the call. It only looks at the positions. Swapping the arguments swaps what goes into each parameter, which can change the answer or break the program.

Arguments in the right order

def subtract(a, b): print(a - b) subtract(10, 3) # a is 10, b is 3 # prints 7

a gets 10 and b gets 3, so a - b is 7.

Arguments swapped

subtract(3, 10) # a is 3, b is 10 # prints -7

Same function, same numbers, but a different answer because the order changed.

Tracing tip: write the parameters on one line and the arguments right under them, matched by position. Then follow the instructions using those values.
01

Examples

More parameters means one function can handle more kinds of jobs.

two numbers

Add two numbers

def add(a, b): print(a + b) add(2, 3) # 5 add(10, 25) # 35

Each call has two arguments for the two parameters.

area

Area of a triangle

def triangle_area(base, height): print(base * height / 2) triangle_area(6, 4) # 12.0 triangle_area(10, 3) # 15.0

The parameter names say what each value means. Good names make the code easy to read.

text and number

Mixed types

def contact(name, phone): print(name + ": " + phone) contact("Mom", "555-0100")

The parameters can hold different kinds of values. Just call with the right kind in each position.

three parameters

Average of three

def average(a, b, c): print((a + b + c) / 3) average(80, 90, 100) # 90.0

There is no limit to the number of parameters, but each call must supply all of them.

variables as arguments

Use variables

w = 5 h = 8 rectangle(w, h) # w is copied into the first parameter, h into the second

The variable names in the call do not have to match the parameter names. Only the position matters.

02

Common Problems / Errors

Count them first: the number of arguments in every call must equal the number of parameters in the definition.

Too few or too many

def add(a, b): print(a + b) add(5) # TypeError: missing 1 required argument add(1, 2, 3) # TypeError: takes 2 arguments but 3 were given

Python tells you how many it expected and how many it got.

Same name twice

def add(a, a): # SyntaxError print(a + a)

Every parameter needs its own different name.

Names in the call do not matter

In add(width, height) the argument width goes into the first parameter whatever that parameter is called. Position decides, not the name.

Wrong type, wrong result

contact("555-0100", "Mom") runs without an error but prints the phone number first. Swapped arguments often give a wrong answer with no error message.
