What Is Big Data?

Big data is data that is too large or too complex for one ordinary computer to store or process in a reasonable time. Every video watched, every purchase, every sensor reading, and every location ping adds to it.

The "three Vs"MeaningExample
Volumea huge amountbillions of search queries each day
Varietymany kinds: text, images, numbers, videoa hospital's notes, scans, and sensor readings
Velocityit arrives fast and keeps comingtraffic sensors reporting every second

Scale: Why One Computer Is Not Enough

Scalability is how well a system copes when the amount of data or number of users grows. A system that works for 100 users but falls over at 100,000 does not scale.

Big data is processed by splitting it across many computers working at the same time. This uses the ideas from Unit 10: parallel and distributed computing, and speedup.

ProblemOne computerMany computers
Count words in a billion web pagesweeksminutes (each machine counts a slice, then the totals are added)
Store 5 PB of photosimpossiblespread across thousands of drives, with copies in case one fails
02

Metadata: Data About Data

Metadata is data that describes other data: the date a photo was taken, who sent a message, how long a song is. Metadata makes big data searchable and organized, because it is much smaller than the data itself.

Try it: find photos using only metadata

Each photo has metadata: the date, place, and camera. You can find photos without looking at a single pixel.

Metadata can also be private. A set of photos' dates and places could show where you live and when you travel, even if no one ever sees a picture.

More Insight From Combining Data

Two data sets that mean little alone can mean a lot together.

Combine……with……to learn
a store's daily salesthe weather reporthow rain changes what people buy
bus GPS positionsridership countswhich routes need more buses
health records (names removed)air-quality readings by zip codewhether pollution is linked to asthma
The same trick is a privacy risk. Joining two "anonymous" data sets can re-identify people (see the privacy notes).

AP

On the AP Exam

These are the ideas the exam asks about. Be ready to explain each one in your own words.

  • Big data is too large or complex for one computer. It is processed with parallel and distributed computing.
  • Scalability means a system keeps working as the data or number of users grows.
  • Metadata is data about data. It helps find and organize data, but can also reveal private information.
  • Combining data sets can reveal new information, and can threaten privacy.

Big data needs many hands, and good labels.
