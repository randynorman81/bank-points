General For Loops

for item in a_list: — the same for loop, minus range() entirely, walking straight through the actual values in a list or a string instead of just counting.

00

Definition

A general for loop runs once for every item in something that holds multiple values — a list, a string, or anything else Python calls an iterable. No range(), no counting; the loop variable becomes each actual item in turn.

songs = ["Blinding Lights", "As It Was", "Flowers"] for song in songs: print(song) # output: # Blinding Lights # As It Was # Flowers

Compare that to the range() version from the last page: there, i held a number you'd have to use to look something up. Here, song is the actual value — the string itself, not an index pointing at it.

The same loop works on strings too

A string is just a sequence of characters, and Python lets you loop over it exactly the same way — one character per pass.

for letter in "Karel": print(letter) # K # a # r # e # l

range() vs. general — when to use which

Use range()

When you need a specific count of repetitions, or the actual index number matters (like spacing shapes apart mathematically using i).

Use a general for loop

When you just need the values themselves, one at a time, and don't care what position they're at.

Examples

Everything from If Statements and Logical Operators still works fine inside the loop body.

with a condition

Filtering while looping

grades = [85, 92, 58, 71] for grade in grades: if grade >= 60: print(grade)

The if runs fresh, once, for every single grade.

accumulating

Summing a list

prices = [9.99, 4.50, 12.00] total = 0 for price in prices: total = total + price

Same accumulator pattern as range() loops — total still has to start before the loop.

index + value together

enumerate() gives you both

for i, song in enumerate(songs): print(i, song)

When you need the index and the value, enumerate() hands you both without writing range(len(...)).

characters

Counting vowels

word = "computer" count = 0 for letter in word: if letter in "aeiou": count = count + 1

The in keyword here checks membership — "is this one character inside this string of vowels."

02

Common Problems / Errors

Trying to use the loop variable as an index: in for song in songs:, song is already the actual song — not a position. Writing songs[song] inside that loop is almost always a mistake.
songs = ["A", "B", "C"] for song in songs: print(songs[song]) TypeError: list indices must be integers or slices, not str

Modifying a list while looping over it

Adding or removing items from a list during a for item in list: loop over that same list can skip items or cause unexpected behavior. Build a new list instead, or loop over a copy.

Forgetting strings are looped by character

for x in "cat": gives you "c", "a", "t" one at a time — not the whole word once. If you need the whole string, don't loop over it at all.

Python Code vs. Pseudocode

Pseudocode's version is written specifically around lists.

ConceptAP CSP PseudocodePython
Loop over each item in a listFOR EACH item IN list
    <block>		for item in list:
    <block>
This one lines up almost word-for-word — pseudocode's FOR EACH ... IN ... reads almost exactly like Python's for ... in ...:. This is the version of a loop you'll see most often paired with list questions on the multiple-choice exam.
04

Spotify Examples (5)

Five real "for every song in this list" moments.

filtering

Finding explicit tracks

for song in playlist: if song.is_explicit: print(song.title)

Prints only the songs where that one flag is True.

accumulating

Total playlist duration

total_seconds = 0 for song in playlist: total_seconds = total_seconds + song.duration

No range() or len() needed — just loop the songs directly.

enumerate

Numbering a queue

for position, song in enumerate(queue): print(position + 1, song.title)

Shows "1. Song Title", "2. Song Title" — + 1 because enumerate() starts at 0.

strings

Building initials from a display name

initials = "" for word in display_name.split(): initials = initials + word[0]

.split() breaks the name into words; the loop grabs just the first letter of each.
