01

The Pseudocode Reference Sheet

You do not write code on the exam, and you do not need to remember Python syntax. Programs on the exam use pseudocode, and a reference sheet is provided. Learn how it works now.

IdeaPseudocodeWatch out for
assigna ← expressionthe arrow means store, not "equals"
displayDISPLAY(expression)(no extra text)
remaindera MOD b17 MOD 5 is 2
comparea = b, a ≠ b, a ≥ ba single = compares here
repeatREPEAT n TIMES, REPEAT UNTIL (cond)UNTIL keeps going while the condition is false
listlist[1], LENGTH(list), APPEND, INSERT, REMOVEindexes start at 1
randomRANDOM(a, b)includes both a and b
procedurePROCEDURE name(p) { ... RETURN(x) }RETURN ends the procedure right away
The two most common traps: list indexes start at 1 (not 0), and REPEAT UNTIL stops when the condition becomes true.
02

How to Work Through Questions

Use the same moves every time.

1

Read the question first

Know what is being asked before you read the code. "Which is TRUE" and "which is NOT" need opposite thinking.

2

Trace on paper

For any code question, write each variable in a small table and update it line by line.

3

Eliminate

Cross out answers that are clearly wrong. Words like always and never are often wrong.

4

Select-two questions

Decide each of the four answers true or false on its own. Exactly two will be true.

5

Do not stay stuck

Mark it, move on, and come back. Every question is worth the same.

6

Use the units

Bits and bytes, Mbps and MB: check the units before you calculate.

Try it: am I on pace?

Section I has 70 questions in 120 minutes. That is about 1.7 minutes per question, and it is smart to keep about 10 minutes at the end to go back.

03

Practice: Tracing Pseudocode

Work each one on paper first. Then check.

Check yourself

Answer each one. You see why right away, so read the explanation even when you are right.

What is displayed?
x ← 5 y ← 3 x ← x + y y ← x - y DISPLAY(x * y)
x becomes 8. Then y becomes 8 - 3 = 5. x * y = 8 * 5 = 40.
What is displayed?
count ← 0 REPEAT 4 TIMES { count ← count + 3 } DISPLAY(count MOD 5)
count ends at 12. 12 MOD 5 is the remainder of 12 ÷ 5, which is 2.
What is displayed?
nums ← [10, 20, 30, 40] DISPLAY(nums[2] + nums[4])
Indexes start at 1, so nums[2] is 20 and nums[4] is 40. 20 + 40 = 60.
What is displayed?
n ← 1 REPEAT UNTIL (n > 20) { n ← n * 3 } DISPLAY(n)
n goes 1, 3, 9, 27. After 27 the condition n > 20 is true, so it stops: 27.
A list is [3, 8, 6, 2, 9]. Which two code segments set count to 3, the number of items greater than 5? (count starts at 0.)
A: FOR EACH item IN list { IF (item > 5) { count ← count + 1 } } B: FOR EACH item IN list { IF (item < 5) { count ← count + 1 } } C: FOR EACH item IN list { IF (item > 5) { count ← count + item } } D: FOR EACH item IN list { IF (item ≥ 6) { count ← count + 1 } }
select TWO
A counts 8, 6, 9 = 3. D also counts 8, 6, 9 = 3. B counts 3 and 2 = 2. C adds up the values (23).
AP

On the AP Exam

These are the ideas the exam asks about. Be ready to explain each one in your own words.

  • Know the structure: 70 multiple-choice questions plus the Create Task.
  • Learn the pseudocode: indexes start at 1, MOD, RANDOM(a, b) includes both ends, REPEAT UNTIL stops when true.
  • Trace every code question. Eliminate. Move on when stuck.
  • For select-two questions, judge each choice on its own.

Trace it, eliminate, move on.
