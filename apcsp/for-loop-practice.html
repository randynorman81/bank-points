For Loop Practice

You know how to write a for loop. This page is the toolbox: the five patterns that show up again and again, in assignments and on the AP exam.

00

Quick Review

A for loop repeats its indented block once for every value range() hands it. The loop variable (usually i) holds the current value each time through.

You writeValues of iHow many times
for i in range(5):0, 1, 2, 3, 45
for i in range(1, 6):1, 2, 3, 4, 55
for i in range(0, 20, 5):0, 5, 10, 154
for i in range(10, 0, -1):10, 9, … 110
Remember: the stop number is never included. range(1, 6) stops before 6.
01

The Five Patterns

Almost every for loop you'll write is one of these. Learn to spot which one a problem needs.

pattern 1 · repeat

Do something N times

for i in range(3): print("Hip hip hooray!")

The loop variable isn't even used. You just need the repeat.

pattern 2 · count

Use the number itself

for i in range(1, 6): print(i * 10)

Prints 10, 20, 30, 40, 50. The loop variable does the work.

pattern 3 · accumulate

Add up a running total

total = 0 for i in range(1, 11): total = total + i print(total)

Prints 55. Start the total at 0 before the loop, add inside, print after.

pattern 4 · ask each time

Input inside the loop

total = 0 for i in range(3): score = int(input("Score: ")) total = total + score print("Average:", total / 3)

Asks 3 times, then uses all three answers.

pattern 5 · decide each time

An if inside the loop

for i in range(1, 11): if i % 2 == 0: print(i, "is even")

Only the even numbers print. The if checks every value.

03

Common Problems / Errors

Resetting the total inside the loop

If total = 0 is indented inside the loop, it goes back to 0 every trip. Put it above the loop.

Printing inside instead of after

An indented print(total) prints every running total. Un-indent it to print only the final answer.

Off by one

Want 1 through 10? That's range(1, 11), not range(1, 10). The stop value is left out.

Forgetting the colon or indent

for i in range(5) with no : is a SyntaxError. Every line that repeats must be indented under it.

04

Python Code vs. Pseudocode

IdeaAP CSP PseudocodePython
Repeat 5 timesREPEAT 5 TIMES { … }for i in range(5):
Add to a totaltotal ← total + itotal = total + i
Pseudocode's REPEAT n TIMES has no loop variable. When the exam needs a counter, it creates one before the loop and adds 1 to it inside.

Pick the pattern, then write the loop.
