String Concatenation

Every combination you'll ever need — string to string, number to string, string to number, and chaining it all together — in one walkthrough.

00

Definition

Concatenation means joining two or more strings into one longer string, end to end, using +. It's the same + symbol used for addition — which job it does depends entirely on what types you're combining. Two strings? Concatenate. Two numbers? Add.

first = "Social" second = "Circle" print(first + second) # SocialCircle print(first + " " + second) # Social Circle
Concatenation never adds anything for you — not a space, not a comma. If you want one between two pieces, you type it yourself as its own string, like " " above.
01

Examples

str() converts whatever's inside its parentheses into a string, so a number can safely join other strings — on either side of the +, whether it's an int or a float.

Int → String

Number on the right

age = 15 print("I am " + str(age))

Output: I am 15

Int → String

Number on the left

age = 15 print(str(age) + " years old")

Output: 15 years old

Float → String

Number on the right

price = 4.99 print("Price: $" + str(price))

Output: Price: $4.99

Float → String

Number on the left

price = 4.99 print(str(price) + " dollars")

Output: 4.99 dollars

Chaining several pieces together

Real programs rarely join just two things. Chain as many +s together as you need — string literals, string variables, and converted numbers, all in one expression.

name = "Alex" age = 15 gpa = 3.8 report = "Name: " + name + ", Age: " + str(age) + ", GPA: " + str(gpa) print(report) # Name: Alex, Age: 15, GPA: 3.8
A cleaner way to write all of this: an f-string. Put f before the opening quote and drop variables straight into { } — f"Name: {name}, Age: {age}, GPA: {gpa}" gives the exact same result with no str() anywhere. Know both: + concatenation is what AP CSP pseudocode maps onto, f-strings are what you'll actually reach for in real Python.
02

Common Problems / Errors

Python decides what + means by looking at both sides at once. One string and one number, with no conversion, and it refuses to guess which one you meant.

age = 15 # print("Age: " + age) TypeError: can only concatenate str (not "int") to str

This isn't a bug to work around — it's Python protecting you from an ambiguous instruction. The fix is always the same idea: make both sides the same type before you combine them, using str().

Common mistake in a long chain: converting some numbers but forgetting just one. "Age: " + age + str(gpa) still crashes, even with the second number converted correctly — every non-string piece needs its own str().
03

Python Code vs. Pseudocode

Careful with this one — string concatenation is a Python-specific skill. It won't show up as an official pseudocode operator on the multiple-choice exam, because AP CSP's pseudocode is deliberately written to work no matter what language a class actually uses.

What you're doingAP CSP PseudocodePython

Show textDISPLAY(name)print(name)
Combine two pieces of textnot defined in pseudocode"Hello, " + name
On the exam, if a question needs you to reason about combined output, it's described in plain English, not written with a concatenation symbol. + for joining text is a real skill for your Create Performance Task and your Python coursework — just don't expect to see it written as pseudocode.

Spotify Examples (5)

Five different pieces of a real "Now Playing" screen, each built by joining strings together.

01

The "Now Playing" line

song = "Blinding Lights" artist = "The Weeknd" "Now Playing: " + song + " — " + artist

Output: Now Playing: Blinding Lights — The Weeknd

02

Displaying the stream count

streams = 3800000000 song + " has " + str(streams) + " streams"

Output: Blinding Lights has 3800000000 streams

03

Showing the star rating

rating = 4.8 "Rating: " + str(rating) + " / 5.0"

Output: Rating: 4.8 / 5.0

04

Formatting the duration

minutes = 3 seconds = 20 str(minutes) + ":" + str(seconds)

Output: 3:20

05

Naming a user's playlist

username = "jordan23" playlist_name = username + "'s Daily Mix 1"

Output: jordan23's Daily Mix 1

One side a string, the other side not — that's always the error.Make both sides strings with str(), or let an f-string do it for you, and the exact same join works every time.

Same types join. Different types need a conversion first. That's the whole rule.
