String Concatenation

Every combination you'll ever need — string to string, number to string, string to number, and chaining it all together — in one walkthrough.

00

What Concatenation Is

Concatenation means joining two or more strings into one longer string, end to end, using +. It's the same + symbol used for addition — which side you land on depends entirely on what types you're combining.

first = "Social" second = "Circle" print(first + second) # SocialCircle print(first + " " + second) # Social Circle
Concatenation never adds anything for you — not a space, not a comma. If you want one between two pieces, you type it yourself as its own string, like " " above.
01

The Rule That Breaks Everything

Python decides what + means by looking at both sides at once. Two strings? Concatenate. Two numbers? Add. One of each? Error — Python refuses to guess which one you meant.

Same type — works

"5" + "3" → "53" (two strings, concatenates)
5 + 3 → 8 (two integers, adds)

Mixed type — fails

"Age: " + 15 raises TypeError: can only concatenate str (not "int") to str

age = 15 # print("I am " + age) TypeError: can only concatenate str (not "int") to str

This isn't a bug to work around — it's Python protecting you from an ambiguous instruction. The fix is always the same idea: make both sides the same type before you combine them.

02

The Fix: str()

str() converts whatever's inside its parentheses into a string, so it can safely sit next to other strings in a + expression. This works no matter which side of the + the number is on, and no matter whether it's an int or a float.

Int → String

Number on the right

age = 15 print("I am " + str(age))

Output: I am 15

Int → String

Number on the left

age = 15 print(str(age) + " years old")

Output: 15 years old

Float → String

Number on the right

price = 4.99 print("Price: $" + str(price))

Output: Price: $4.99

Float → String

Number on the left

price = 4.99 print(str(price) + " dollars")

Output: 4.99 dollars

Same fix, every direction. It doesn't matter if the number comes first or last, or whether it's an int or a float — str() is always the tool that lets it join a string.
03

Starting From a String Instead

Sometimes the number starts out as text — anything typed into input() is always a string, even if it looks like a number. Converting it the other way, from string to a real number, uses int() or float() instead of str().

age_text = "15" # a string, from input() age = int(age_text) # now a real integer print("Next year you'll be " + str(age + 1))

Notice both conversions show up in one line here: int() to turn the input into a number you can do math with, then str() again to turn the math result back into text so it can concatenate. Going from string to number and from number to string are two separate, opposite tools — keep them straight:

DirectionFunctionExample
Number → String (to concatenate)str()str(15) → "15"
String → Integer (to do math)int()int("15") → 15
String → Float (to do math)float()float("4.99") → 4.99
This is exactly what happens every time you use input() — see the full User Input walkthrough for every form of it.
04

Chaining Several Pieces Together

Real programs rarely join just two things. Chain as many +s together as you need — string literals, string variables, and converted numbers, all in one expression.

name = "Alex" age = 15 gpa = 3.8 report = "Name: " + name + ", Age: " + str(age) + ", GPA: " + str(gpa) print(report) # Name: Alex, Age: 15, GPA: 3.8

Read it piece by piece, left to right: "Name: " (literal) + name (string variable) + ", Age: " (literal) + str(age) (int, converted) + ", GPA: " (literal) + str(gpa) (float, converted). Every single piece has to be a string, or the whole line fails.

Common mistake: forgetting to convert just one number in a long chain. "Age: " + age + str(gpa) still crashes, even with the second number converted correctly — every non-string piece needs its own str().
05

A Cleaner Way: f-strings

AP CSP mostly cares that you understand + concatenation and why type conversion is needed — but it's worth knowing real Python has a shortcut that skips str() entirely: an f-string. Put f right before the opening quote, and drop any variable straight into the text inside { }.

name = "Alex" age = 15 gpa = 3.8 report = f"Name: {name}, Age: {age}, GPA: {gpa}" print(report) # Name: Alex, Age: 15, GPA: 3.8 -- same result, no str() anywhere
f-strings automatically convert whatever's inside { } to text for you — ints, floats, anything. They're not a different concept from concatenation, just a shorter way to write it. Know both: + concatenation is what AP CSP pseudocode maps onto directly, but f-strings are what you'll actually reach for once you're writing real Python.
06

Real World: How Spotify Would Use This

This isn't just a classroom exercise. The exact ideas on this page are what actually builds the "Now Playing" bar you see every time you open a music app.

song = "Blinding Lights" artist = "The Weeknd" streams = 3800000000 duration_sec = 200 rating = 4.8
String + String

The "Now Playing" line

"Now Playing: " + song + " — " + artist

Output: Now Playing: Blinding Lights — The Weeknd

Int → String

Displaying the stream count

song + " has " + str(streams) + " streams"

Output: Blinding Lights has 3800000000 streams

Float → String

Showing the star rating

"Rating: " + str(rating) + " / 5.0"

Output: Rating: 4.8 / 5.0

The song length is stored as one plain number — total seconds — because that's what's easiest for the app to do math with. But nobody wants to see "200 seconds" under a song. This is exactly the job of // and % from the Integer page:

minutes = duration_sec // 60 # 3 -- how many whole minutes seconds = duration_sec % 60 # 20 -- seconds left over duration_display = str(minutes) + ":" + str(seconds) print("Duration: " + duration_display) # Duration: 3:20

Now put every piece from this page together into the one line that would actually build a real "Now Playing" bar — string concatenation, int-to-string, float-to-string, floor division, and modulus, all at once:

now_playing = (song + " — " + artist + " | " + str(minutes) + ":" + str(seconds) + " | " + str(rating) + "★ | " + str(streams) + " streams") print(now_playing) # Blinding Lights -- The Weeknd | 3:20 | 4.8* | 3800000000 streams
Or, the f-string version — the same bar, the way it would actually get written in a real codebase: f"{song} — {artist} | {minutes}:{seconds} | {rating}★ | {streams} streams"
