What Is Code, and What Do Programs Do?

3.1–3.2

Before any Python syntax, Unit 3 opens with two conceptual lessons: what code actually is, and the four things every program is ultimately doing underneath.

What is code?

Code is a set of instructions written in a programming language that a computer can follow, step by step, in order. A programming language is a formal language — unlike English, it has strict, unambiguous rules (its syntax) so a computer never has to guess what you meant.

Program vs. algorithm

An algorithm is the plan — a finite list of steps to solve a problem, which could be written in plain English. A program is that algorithm actually written in a language a computer can run. Every program implements an algorithm; not every algorithm has been turned into a program yet.

The four things every program does

The AP CSP framework groups everything a program does into four categories. Nearly any line of code you write this year is doing one of these:

CategoryWhat it meansPython example
InputGetting data from outside the program (a user, a sensor, a file)input()
OutputSending data back out (screen, speaker, file)print()
StorageKeeping data around to use latera variable
Computation / ProcessingDoing something with the data — math, decisions, repetitionan operator, an if, a loop
Test tip: if a question describes a real program (an ATM, a thermostat, a video game score) and asks you to identify input/output/storage/computation, match the plain-English description to these four categories — don't overthink it. "The screen shows your balance" is output. "It remembers how many lives you have left" is storage.
01

Hello World: Your First Python Program

3.3

Every program in this unit starts the same way: print something to the screen. This is also the first time this year you're writing real Python instead of dragging Karel commands.

print("Hello, world!")

print()

Displays whatever is inside the parentheses to the console. Text (a string) must be wrapped in quotation marks — either "double" or 'single', as long as you're consistent on both ends.

Comments: #

Anything after a # on a line is ignored by Python entirely — it's a note for humans reading the code, not an instruction. Used to explain why code does something, not just restate what it does.

print("Score: 100") # prints the text Score: 100 print(100) # prints the number 100 (no quotes needed for numbers) print("Line one") print("Line two") # each print() starts on a new line automatically
Common mistake: forgetting a closing quotation mark, or mixing " and ' to open and close the same string. Python reads to the end of the line looking for the matching quote and throws a SyntaxError if it never finds one.
02

Variables

3.4

A variable is a named box that holds a piece of data. Instead of typing a value over and over, you store it once under a name and reuse the name.

name = "Ada" age = 16 print(name) print(age)

The = sign

In Python, = is the assignment operator — it only flows one direction. It means "take whatever is on the right, and store it in the name on the left." It is not the same as = in math class.

Naming rules

A variable name can contain letters, numbers, and underscores (_) — but can't start with a number and can't contain spaces or punctuation like - @ !.

The three types you need cold

TypeHoldsExampleWritten with quotes?
string (str)Textname = "Ada"Yes
integer (int)Whole numbersage = 16No
floatDecimal numbersgpa = 3.75No

Python figures out a variable's type automatically from what you assign it — you never declare the type yourself, unlike some other languages.

str() and int(): Python's + can join two strings (concatenation) or add two numbers, but never mix a string and a number. Convert a number to text with str(), or text to a number with int(), before combining them.
name = "Alex" age = 15 print(name + " is " + str(age) + " years old") # str() lets age join the string

User Input

3.5

input() pauses the program, shows the person a prompt, and waits for them to type something before continuing.

name = input("What's your name? ") print("Hello, " + name)
The #1 fact to know cold: input() always returns a string — even if the user types a number. If you need to do math with it, you must convert it first with int() or float().
age_text = input("How old are you? ") # age_text is a string, like "15" age = int(age_text) # now it's a real number you can add to next_year = age + 1 print(next_year)

Basic Math in Python

3.6

Seven operators. Five work exactly like math class; two are new.

OperatorNameExampleResult
+Addition7 + 29
-Subtraction7 - 25
*Multiplication7 * 214
/Division (always returns a float)7 / 23.5
**Exponent7 ** 249
//Floor division (whole number only)7 // 23
%Modulus (the remainder)7 % 21
The trap that catches everyone: / always returns a float in Python, even 10 / 2 gives 5.0, not 5. Need a clean whole number? Use //.
Order of operations matches math class: parentheses, then **, then * / // % left to right, then + - left to right. 10 + 6 // 2 is 13, not 8.

Using Graphics in Python

3.7

CodeHS's graphics library: size a canvas, then create, position, color, and add() a shape to it.

set_size(400, 300) # canvas always comes first circle = Circle(50) # create a circle, radius 50 circle.set_position(100, 100) # place it circle.set_color(Color.blue) # color it add(circle) # now it actually shows up on screen
The #1 mistake: creating and positioning a shape, then forgetting add(shape). The shape exists in the program's memory, but nothing appears on the canvas — and Python won't throw an error, so it's easy to miss.

Coordinates

The canvas uses (0, 0) at the top-left corner. X increases to the right; y increases downward — the opposite of a normal math graph.

Not on the AP multiple-choice exam

Graphics is real, testable content for this unit and your CodeHS coursework, but it isn't part of the official AP CSP Exam Reference Sheet used on the multiple-choice exam in May. Know it cold for 3.9 anyway.

06

Mouse Events: Mouse Clicked

3.8

Makes a shape react to a click — one function that takes the click's x and y, registered with add_mouse_click_handler().

def callback(x, y): circle.set_position(x, y) # runs every time the canvas is clicked add_mouse_click_handler(callback)

Dot notation

circle.set_position(x, y) — everything before the dot is which object; everything after is the method, an action that object knows how to do. Compare to add(circle), a plain function that isn't tied to one object.

Parameter count matters

A click handler must accept exactly the parameters the canvas passes it — x and y. def callback(): with none will crash the instant a click happens, whether you use the values or not.

Self-Check Questions

The style of question the 3.9 test actually asks: predict the output, or spot the bug. Cover the answer before you look.

Predict the output

x = "5"
y = 3
print(x + y)

Show answer
Error (TypeError). x is a string ("5"), y is an integer. Python won't guess whether you meant to add them as numbers or join them as text — you'd need int(x) + y or x + str(y).
Predict the output

print(10 // 3)
print(10 % 3)

Show answer
3, then 1. 3 fits into 10 three whole times (//), with 1 left over (%).
Find the bug

circle = Circle(30)
circle.set_position(50, 50)
circle.set_color(Color.red)

Show answer
Missing add(circle). The circle is created and configured but never added to the canvas, so nothing appears — and Python won't raise an error for it.
Predict the output

age = input("Age: ")
print(age + 1)

Show answer
Error. input() always returns a string, even if the user types a number, so age is text and can't be added to the integer 1 without converting it first: int(age) + 1.
Identify the category

A thermostat app displays the current temperature on screen. Which of the four program categories (input / output / storage / computation) is that?

Show answer
Output — the program is sending data (the temperature) out to the screen.
Predict the output

def callback():
    print("clicked")

add_mouse_click_handler(callback)

Show answer
Crashes on the first click. The canvas always passes x and y to the handler function; callback() needs to accept them, even if it never uses them: def callback(x, y):
