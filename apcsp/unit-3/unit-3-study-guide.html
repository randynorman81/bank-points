The Basics: Code, print(), and Comments

3.1–3.3

A program is an algorithm written in a language a computer can run. Every program does some mix of four things: input (get data), output (show data), storage (remember data in variables), and computation (do math or make decisions with data).

print("Hello, world!") # output: shows text in the console print(100) # numbers don't need quotes # Python ignores everything after a # on a line. That's a comment.

Variables: Naming, Updating, and Constants

3.4

A variable is a named container for a value. You store a value once and reuse the name instead of retyping the value. Every variable has a name, a value, and a type.

player_name = "Ada" # string lives = 3 # integer (int) speed = 2.5 # float

Naming rules (Python enforces these)

NameLegal?Why
total_scoreYesLetters and an underscore. This is the preferred style, called snake_case.
player1YesNumbers are fine, just not at the start.
_countYesA name may start with an underscore.
1st_placeNoCan't start with a number.
high scoreNoNo spaces allowed.
high-scoreNoPython reads - as subtraction: high minus score.
print, input, ifAvoid / Noif, for, def, True are keywords and are illegal. Naming a variable print or input is allowed, but it breaks that built-in function for the rest of the program.
Case-sensitive: score, Score, and SCORE are three different variables. Using Score when you created score gives a NameError.

Updating a variable: the = sign flows right to left

= is the assignment operator, not "equals" from math class. Python works out everything on the right side first, using the variable's current value, and then stores the result in the name on the left. The old value is gone.

score = 10 score = score + 5 # right side first: 10 + 5 = 15, then store 15 in score score += 5 # shortcut for score = score + 5 -> 20 score -= 3 # score = score - 3 -> 17 score *= 2 # score = score * 2 -> 34

AP questions love tracing. Keep a table with a column for each variable and update it one line at a time:

a = 4 b = a a = a + 6 b = b * 2 print(a, b)
Lineab
a = 44—
b = a44
a = a + 6104
b = b * 2108
Key idea: b = a copies the value 4 into b at that moment. Changing a later does not change b. Output: 10 8.

Constants: values that should never change

What a constant is

A constant is a variable you promise not to change after you set it. In Python you mark one by writing the name in ALL_CAPS, and you put your constants at the top of the program.

Python doesn't enforce it

Python will not stop you or throw an error if you reassign a constant. ALL_CAPS is a convention: a signal to people reading the code that this value is fixed.

RADIUS = 40 NUM_LIVES = 3 BALL_COLOR = Color.red ball = Circle(RADIUS) # use the name, not the number 40 ball.set_color(BALL_COLOR)
Why use constants? (1) If 40 appears five times and you want 60, you change one line instead of five and can't miss one. (2) Circle(RADIUS) explains itself; Circle(40) is a "magic number" nobody understands later.

Strings, Concatenation, and Type Conversion

3.4–3.5

A string is text in quotes. "42" is a string and 42 is an integer. They look alike when printed, but Python treats them completely differently.

Concatenation: gluing strings together with +

Concatenation means joining strings end to end with +. Python adds no spaces for you, so you have to put them inside the quotes yourself.

first = "Ada" last = "Lovelace" print(first + last) # AdaLovelace (no space!) print(first + " " + last) # Ada Lovelace

Converting between types

FunctionConverts toWhen to use itExample
str(x)stringYou want to concatenate a number into a message."Age: " + str(16) → "Age: 16"
int(x)integerYou need to do math with text that holds a whole number, like input.int("16") + 1 → 17
float(x)floatYou need math with text that may hold a decimal.float("3.5") * 2 → 7.0
age = 16 print("You are " + age) # TypeError: can only concatenate str (not "int") to str print("You are " + str(age)) # You are 16 print("Next year: " + str(age + 1)) # Next year: 17 (math first, then convert)
Conversion traps: int("3.5") is a ValueError, because that text isn't a whole number. int("hello") is a ValueError too. int(3.9) works but gives 3: it cuts off the decimal and does not round.
Shortcut that avoids converting: print("You are", age) uses a comma. print puts a space between the items and handles any type. That's printing several items, though, not concatenation.

A method is a function that belongs to a value, called with dot notation: value.method(). String methods never change the original string (strings are immutable). They hand back a new string, which you have to store or print.

User Input

3.5

input("prompt") shows the prompt, waits for the user to type, and gives back what they typed.

input() ALWAYS returns a string.Even if the user types 25, you get back the text "25". Python never guesses that you meant a number.

Don't convert when…

you only display or compare text: names, colors, yes/no answers. name = input("Name? ") is already correct as a string.

Convert when…

you'll do math with it. Use int() for whole numbers (age, count, quantity) and float() for decimals (price, temperature, GPA).

# Two-step version age_text = input("How old are you? ") # "15" (string) age = int(age_text) # 15 (int) # One-line version (most common): input runs first, int() converts its result age = int(input("How old are you? ")) price = float(input("Price? ")) print("In 5 years you'll be " + str(age + 5)) # back to str to concatenate
Classic bugs with input:
• num = input("Number: ") → num + 1 is a TypeError (str + int).
• User types 7, and num * 2 gives "77": string repetition, not 14. No error, just the wrong answer.
• int(input(...)) when the user types 3.5 or ten gives a ValueError.
• input(int("Age? ")) puts the conversion on the wrong side: it tries to turn the prompt text into a number and crashes.

Basic Math: /, //, %, and Floats

3.6

A float is a number with a decimal point, like 3.5, 2.0, or -0.25. An int is a whole number with no decimal point. 5 is an int; 5.0 is a float, even though they're equal.

OperatorNameExampleResultType
+ - *add, subtract, multiply7 * 214int (float if either side is a float)
/Regular division7 / 23.5always float, even 10 / 2 → 5.0
//Floor division: how many whole times it fits7 // 23int (drops the remainder)
%Modulus: the remainder7 % 21int
**exponent2 ** 38int

Think of long division from 3rd grade: 17 ÷ 5 = 3 remainder 2. // gives you the 3, % gives you the 2, and / gives you the full decimal 3.4. Try any numbers:

and
17 / 5
float

int

What modulus is actually used for

even / odd

n % 2

0 means even, 1 means odd.

divisible by

n % 5

0 means n divides evenly by 5.

last digit

n % 10

472 % 10 → 2. (472 // 10 → 47 drops it.)

convert units

// 60 and % 60

135 seconds: 135 // 60 = 2 minutes, 135 % 60 = 15 seconds.

Traps: 7 % 10 is 7, because 10 fits zero times and all 7 is left over. 12 % 3 is 0, not 3 or 4. Dividing by zero with /, //, or % gives a ZeroDivisionError.

Order of operations

Parentheses first → then ** → then * / // % left to right → then + - left to right.

2 + 3 * 4 # 14, not 20 (2 + 3) * 4 # 20 2 + 3 * 4 ** 2 # 4**2=16, 3*16=48, 2+48 = 50 10 - 7 % 4 # 7%4=3, 10-3 = 7 5 + 2.0 # 7.0: any float in the math makes the result a float

Graphics: Canvas, Shapes, and Sizes

3.7

Every graphics program follows the same recipe: create the shape → set it up (position, color) with dot methods → add() it to the canvas.

The canvas: finding its size

set_size(400, 300) # optional: make the canvas 400 wide, 300 tall w = get_width() # 400: canvas width (NO dot, it's not a shape) h = get_height() # 300: canvas height (NO dot)
Always use get_width() / get_height() instead of typing 400 and 300. Then your drawing still lands in the center or the corner if the canvas size changes.
(0, 0) is the top-left. A bigger y means lower on the screen, the opposite of a math graph.

Creating each required shape

ShapeCreate itParametersset_position anchors the…Ask its size
Circleball = Circle(30)radiuscenterball.get_radius() → 30 (full width = 60)
Rectanglebox = Rectangle(100, 50)width, height (that order)top-left cornerbox.get_width(), box.get_height()
Squaresq = Rectangle(60, 60)same number twicetop-left cornersq.get_width()
There is no Square() in this library. Square(60) gives a NameError. A square is Rectangle(side, side).

Common shape methods (all use a dot)

ball.set_position(x, y) # move it to an exact spot ball.move(dx, dy) # shift it BY an amount from where it is now ball.set_color(Color.red) # fill color ball.get_x() ball.get_y() # where it is now ball.set_radius(50) # circles only box.get_width() # the SHAPE's width, not the canvas's

Requirements to make a shape appear

Must do

  • Create the shape and store it in a variable before calling any methods on it.
  • Give the constructor the right arguments: Circle takes 1, Rectangle takes 2.
  • Call add(shape), or nothing shows up.

The silent bug

Forget add(ball) and the program runs with no error, but the canvas stays blank. The shape exists in memory and nobody ever put it on screen.

# Center a circle ball = Circle(40) ball.set_position(get_width() / 2, get_height() / 2) add(ball) # Center a rectangle: shift back by HALF its own size (because it anchors top-left) box = Rectangle(100, 60) box.set_position(get_width() / 2 - box.get_width() / 2, get_height() / 2 - box.get_height() / 2) add(box) # Bottom-right corner rectangle box.set_position(get_width() - box.get_width(), get_height() - box.get_height())
