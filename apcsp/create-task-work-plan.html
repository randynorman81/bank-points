Create Task Work Plan and Final Checklist

Time to build your own program. Use this work plan to spend your days well and this checklist to know when each of the six points is truly ready.

00

Where You Are Now

You have practiced the Create Task three times. Now you build your own. The rules and the scoring are in the earlier notes (The Create Task: Rules and Scoring). This page is the work plan: how to spend your time and how to know you are done.

Six points. One each for the video, the program requirements, and the four written responses.You earn each point only by meeting every part of its row.
01

A Work Plan

Adjust the days to the schedule your teacher gives you. The order is what matters.

WhenFinishCheck yourself
Day 1Choose your idea. Write the four plan comments (purpose, input, output, functionality).Could a friend tell what the program does from those four lines?
Days 2 to 3Write the list, the input, and the procedure with at least one parameter that changes the result.Run it with two different inputs and get two different outputs.
Day 4Add selection and iteration inside the procedure. Call it. Show the output.Is there an if and a loop inside your procedure?
Day 5Test: two different calls, plus a call that could break it. Fix bugs.Can you say what each call returns and why?
Day 6Record the video. Make the reference sheet (four segments, no comments).Play the video with the sound off. Is it clear?
Day 7Draft answers to all six written prompts about your program. Add credit comments.Does every answer name a real line or value from your code?
Last dayFinal checks. Export the program PDF. Upload the files.Everything below is ticked.
02

Are You Ready?

Be honest. If you cannot show it, it is not ready.

Try it: how many of the six points are you ready for?

Tick each one only when you could show it right now. This is a self-check, not a score.

03

The Final Checks

Do these after you think you are finished.

Program code PDF

All of the code is in one document. Comments explain each part. Any code you did not write is credited in a comment. It is the same program as in the video.

Video

60 seconds or less. 30 MB or less. An allowed file type. No voice, no real names. Input, functionality, and output are all visible and readable.

Reference sheet

Four segments: procedure (i), the call (ii), list (i), and list (ii). Delete every comment. No course words. Text at least 10 point and sharp.

Honesty

Only the program code may be done with a partner. The video and the reference sheet are yours. Credit any code from a teacher, a tutorial, or an AI tool.

04

Common Ways to Lose a Point

These are the most common mistakes, and how to avoid them.

MistakeHow to avoid it
The list has one item, or the loop does not read itPut several items in the list and read every one inside the procedure
The parameter does nothingUse it in the if or in a calculation so a different argument changes the result
A comment left in the reference sheetSearch the screenshots for # before you submit
The video shows code, not the program runningRecord the program running with a visible input and output
A written answer describes the program in generalName a specific line, variable, and value from your code
The video and the code do not matchRecord the final version last, after the last code change

Check yourself

Answer each one. You see why right away, so read the explanation even when you are right.

Which is required in the program code you submit?
Those are the program requirements. Length and style are not required.
Which would lose a point on the reference sheet?
The reference sheet must not contain comments.
For the video, which is allowed?
No voice, and nothing that identifies you. Text captions are encouraged.
AP

On the AP Exam

These are the ideas the exam asks about. Be ready to explain each one in your own words.

  • Plan the work in order: idea, list/input/procedure, selection and iteration, testing, video and reference sheet, written responses, final checks.
  • Each of the six points needs every part of its row.
  • The program code may be done with a partner. The video, reference sheet, and responses are yours.
  • Credit any code you did not write. Plagiarism can earn a 0 on the whole task.

If you can show it, it is ready.

Good luck. The rules and scoring pages from Unit 6 are your reference.
