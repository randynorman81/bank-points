What Is an Algorithm?

An algorithm is a finite set of instructions that accomplishes a task. Every algorithm is built from just three building blocks.

1

Sequencing

Steps run in order, one after another.

2

Selection

A condition decides which steps run (if, else).

3

Iteration

Steps repeat (for, while).

Algorithm for finding the largest number: (1) call the first number the largest so far. (2) for each other number, if it is bigger, make it the largest so far. (3) when you run out of numbers, the largest so far is the answer.
01

Developing an Algorithm

Good programmers do not start typing. They follow a process.

StepWhat you doExample: average of a list
1. Understandsay what goes in and what must come outin: a list of numbers. out: one number
2. Planwrite the steps in words or pseudocodeadd them all up, divide by how many
3. Writeturn the plan into codea loop with a total, then a division
4. Testtry normal, edge, and unusual inputsa list of one number? an empty list? negatives?

You can also build on algorithms that already exist. You can combine two (find the largest, then use it to scale every value) or modify one (change "largest" to "smallest" by flipping a comparison). Knowing standard algorithms like searching and finding a maximum saves time.

02

Equivalent Algorithms

Equivalent algorithms solve the same problem and give the same results for every input, even though their steps are different. One may be faster, shorter, or easier to read.

03

Testing With the Right Inputs

Running a program once and seeing the right answer proves very little. Good test cases include:

  • a normal input
  • the smallest input (an empty list, one item, zero)
  • the largest input
  • ties and duplicates
  • negative or unexpected values
  • values right at a boundary, like exactly 18 for an age check

Tracing the code by hand (writing down every variable after every line) finds mistakes the same way and is a skill the exam tests every year.

On the AP Exam

These are the ideas the exam asks about. Be ready to explain each one in your own words.

  • Every algorithm is built from sequencing, selection, and iteration.
  • Equivalent algorithms give the same result for every input but may differ in how many steps they take.
  • Algorithms that look similar can give different results. Test edge cases.
  • New algorithms can be made by combining or modifying existing ones.
  • Know the exam pseudocode: ←, DISPLAY, IF, REPEAT, FOR EACH, PROCEDURE, and that lists start at 1.
