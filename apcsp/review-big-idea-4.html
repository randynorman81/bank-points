The Summary

Big Idea 4: Computer Systems and Networks is about how the Internet works and how computers share work.

TermMeaning
Interneta network of networks using open protocols (not the same as the Web)
Bandwidthmost data per second, in bits per second; download time = bits ÷ bandwidth
IP addressunique number for a device; IPv4 = 32 bits, IPv6 = 128 bits
DNSturns domain names into IP addresses
Router, hop, pathforwards packets; one handoff; the chain of devices
Packeta small piece of data with a header (addresses, sequence number) and a payload
TCP / UDPreliable, resends lost packets / fast, no resending
Redundancy / fault toleranceextra paths, so the network keeps working if a part fails
Sequential / parallel / distributedone at a time / at the same time / on many computers
Speedupsequential time ÷ parallel time
Scalabilitykeeps working as the size grows

Practice Set (10 questions)

Calculate carefully, and check the units.

Check yourself

Answer each one. You see why right away, so read the explanation even when you are right.

A 450 MB file is downloaded at 90 megabits per second. About how many seconds does it take?
450 MB × 8 = 3,600 megabits. 3,600 ÷ 90 = 40 seconds.
Devices are connected by these links: A-B, A-C, B-C, B-D, C-D. How many different paths (that do not visit a device twice) go from A to D?
A-B-D, A-C-D, A-B-C-D, and A-C-B-D. That is 4 paths.
Why was the Internet designed with many possible paths between devices?
Redundancy makes the Internet fault tolerant.
Packets from one message arrive at the destination out of order. How does the receiver put the message back together?
Each header carries a sequence number.
A user types www.example.org into a browser. Which system translates that name into an IP address?
DNS is the phone book of the Internet.
Which is the main reason IPv6 was created?
32 bits give about 4.3 billion addresses. IPv6 uses 128 bits.
Which protocol is the better choice for a live video call where a lost packet is not worth waiting for?
For live data, speed matters more than perfection.
A job takes 90 seconds sequentially and 45 seconds when run in parallel. What is the speedup?
Speedup = 90 ÷ 45 = 2.
Three independent tasks take 20, 20, and 30 seconds. What is the shortest possible time to finish all of them with two processors?
Put the 30-second task on one processor and the two 20-second tasks (40 seconds) on the other. The job finishes in 40 seconds.
Which two statements about the Internet and the World Wide Web are true? select TWO
The Web runs on top of the Internet, and the Internet's open protocols let any device join.
