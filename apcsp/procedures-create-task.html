Procedures and the Create Task

Procedures make programs shorter, easier to read, and easier to change. The AP Create Performance Task asks you to write one with a parameter and a real algorithm inside.

00

Definition

Procedural abstraction means giving a group of instructions a name so you can use it without thinking about how it works inside. A parameter makes the procedure general: one definition works for many different inputs. Procedures also let you break a big problem into smaller, simpler pieces, called modularity.

IdeaWhat it meansWhy it helps
Procedural abstractionuse a procedure by its name, without the detailsreduces how much you have to think about at once
Reusecall the same procedure again and againless repeated code, fewer mistakes
Generalizationa parameter lets one procedure do many jobsone change fixes every use
Modularitysplit a big job into small procedureseach piece is easier to write, test, and fix
def star_line(count): line = "" for i in range(count): # iteration line = line + "*" if count > 5: # selection line = line + " wow!" return line print(star_line(3)) # *** print(star_line(7)) # ******* wow!

That procedure has a parameter (count) that changes what it does, and its algorithm uses sequencing (steps in order), selection (the if), and iteration (the for loop). It is also called twice with different arguments.

01

Examples

Everything from the unit works together. Each of these is a procedure with a parameter that affects what it does.

reuse

Same code, many calls

def banner(text): print("=" * 10) print(text) print("=" * 10) banner("Level 1") banner("Game over")

Without the procedure you would type the three lines every time. With it you change the look in one place.

modularity

A procedure calls another

def double(n): return n * 2 def double_then_add(n, extra): return double(n) + extra print(double_then_add(5, 1)) # 11

Small procedures build bigger ones. double_then_add uses double without repeating its code.

selection

Parameter decides the branch

def grade(score): if score >= 90: return "A" elif score >= 70: return "C or better" else: return "Keep working" print(grade(95)) # A

The argument changes which branch runs, which is what 'the parameter affects the functionality' means.

iteration

Parameter sets the repeats

def countdown(start): while start > 0: print(start) start = start - 1 print("Go!") countdown(3)

A bigger argument means more passes through the loop.

random

Library inside a procedure

import random def fortune(name): answers = ["yes", "no", "maybe"] return name + ": " + random.choice(answers) print(fortune("Ana"))

Procedures can use library procedures, like random.choice, to do their job.

02

Common Problems / Errors

The Create Task procedure rules: it must have at least one parameter that affects what the procedure does, and the algorithm inside must include sequencing, selection, and iteration. You must also call the procedure.

A parameter that does nothing

def hello(name): print("Hello") # name is never used! hello("Ana")

The parameter must change the behavior. This one is ignored, so it would not count.

A parameter that matters

def hello(name, times): for i in range(times): print("Hello,", name) hello("Ana", 2)

name and times both change what the procedure prints.

Define it AND call it

A procedure that is never called does nothing. Make sure a line later in the program calls it with arguments.

Write what it does in words

The written response asks you to explain what the procedure does and how it works. Start by saying what the parameter means and what comes back.

Typical exam questions: which statement describes a benefit of using a procedure (reuse, readability, easier to change), what a call returns for a given argument, and how a change to the procedure affects every call.

A good procedure has a parameter that matters, uses sequencing, selection and iteration, and gets called.
