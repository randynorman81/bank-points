Lists and Indexing

Until now, one variable held one value. A list holds many values, in order, under one name. Lists are the main data structure on the AP exam, and the Create Task needs one.

00

A Row of Numbered Boxes

Picture a row of boxes. The whole row has one name, and every box holds one item. That row is a list.

favorites = ["pizza", "tacos", "soup", "pasta"] print(favorites) # shows the whole list print(len(favorites)) # shows 4, how many items are in it
  • A list is written with square brackets [ ], and the items are separated by commas.
  • Items can be strings, numbers, or a mix. [10, 20, 30] and ["Ana", 15, True] are both lists.
  • len(list) tells you how many items the list holds. The exam calls it LENGTH(list).
  • A list can be empty: scores = []. Items can be added later.
01

Index: the Position of an Item

To use one item, you say which position it is in. That position number is called the index.

favorites = ["pizza", "tacos", "soup", "pasta"] print(favorites[0]) # pizza, the FIRST item print(favorites[2]) # soup print(favorites[len(favorites) - 1]) # pasta, the LAST item

Click through: which item is at each index?

favorites[0] is pizza. In Python the first item is at index 0.

favorites[2] is soup. It is the third item, because counting starts at 0.

The last item is at index len(favorites) - 1. With 4 items, that is index 3, not 4.

Python starts counting at 0. The first item is index 0 and the last is len(list) - 1. A list with 4 items has indexes 0, 1, 2, 3.
02

The Big Exam Trap: 0 Versus 1

Python counts from 0. The AP exam's reference language counts from 1. You must know which language you are reading.

What you wantPythonAP exam pseudocode
make a listfavorites = ["pizza", "tacos"]favorites ← ["pizza", "tacos"]
the first itemfavorites[0]favorites[1]
the third itemfavorites[2]favorites[3]
how many itemslen(favorites)LENGTH(favorites)
the last itemfavorites[len(favorites) - 1]favorites[LENGTH(favorites)]
Exam habit: when you see aList[2] in an exam question, count from 1: it is the second item. When you write Python, count from 0. A good trick is to write the numbers 1, 2, 3... over the items before you answer.
03

Changing an Item

A list can be changed. Assign a new value to one position, and only that item is replaced.

favorites = ["pizza", "tacos", "soup", "pasta"] favorites[1] = "burgers" # replaces tacos print(favorites) # ["pizza", "burgers", "soup", "pasta"]
PythonAP exam pseudocode
favorites[1] = "burgers"favorites[2] ← "burgers"
favorites[0] = favorites[3]favorites[1] ← favorites[4]
Notice the index changes between the two languages. The same item that is favorites[1] in Python is favorites[2] on the exam.
04

When the Index Does Not Exist

Asking for an item that is not there is an error. This is the most common list mistake.

favorites = ["pizza", "tacos", "soup", "pasta"] print(favorites[4]) # ERROR: there is no item at index 4
  • The valid Python indexes are 0 up to len(list) - 1.
  • The valid exam indexes are 1 up to LENGTH(list).
  • If a question asks what happens with an index outside that range, the answer is: the program gives an error.
05

Practice Reading Exam Pseudocode

Here is the kind of question you will see. Work it out first, then click through the answer.

names ← ["Ana", "Ben", "Cy", "Dee"] names[2] ← "Eli" DISPLAY(names[2]) DISPLAY(names[LENGTH(names)])

Trace it one line at a time

Line 1 makes a list of 4 items. The exam counts positions from 1.

names[2] ← "Eli" replaces the second item. Ben becomes Eli.

DISPLAY(names[2]) shows Eli.

LENGTH(names) is 4, so names[LENGTH(names)] is the last item. It shows Dee.

One name, many items, and the index tells you which one.
