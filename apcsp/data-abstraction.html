Data Abstraction and the Create Task

A list is an example of data abstraction: you give a collection of values one name, and you use it without worrying about each individual value. This idea is the heart of the Create Task's written response 2(c).

00

Managing Complexity

Complexity is how hard a program is to write, read, and change. Abstraction reduces it by hiding details behind a name. A list hides many separate values behind one name.

Click: the same program, five scores and then six

With five scores, both versions work. But the left side already needs ten lines, one variable and one print per score.

Now add a sixth score. The left side needs a new variable and a new line. The right side only needs one more number in the list, and the loop does not change.

  • Data abstraction: a collection of values with one name (a list), used without caring about each value.
  • Procedural abstraction: a group of steps with one name (a function), used without caring how it works inside.
  • Both manage complexity: they make a program shorter, easier to read, and easier to change.
01

What the Exam Asks

The AP exam has a standard way to ask about this, both in multiple choice and in the Create Task.

The questionA strong answer says
How does the list manage complexity in your program?The list holds all the (items) under one name, so one loop can handle any number of them.
How would the code change without the list?I would need a separate variable for every item and a copy of the code for each one, so adding an item means writing more code.
Why is a list better than separate variables?It is shorter, handles a changing number of items, and a change in one place fixes everything.
What happens if new items are added?The list code does not need to change if the loop uses the list's length (len), because it adjusts by itself.
Be specific. Saying only 'a list makes it easier' earns no point. Name your actual list, say what your program does with it, and say what would be needed without it.
02

Build a Strong Written Response

Use this recipe for the 2(c) answer. Here it is filled in for a quiz program with a questions list.

StepFill it inExample
1. Name the listthe list and what it storesThe questions list stores every question in my quiz.
2. Say what it lets the program dothe job it doesIt lets one loop ask any number of questions.
3. Say what you would need without itthe extra codeWithout it I would need a separate variable and separate input and if code for every question.
4. Say why that is worsethe costAdding a question would mean writing new code instead of adding one item.
Put together: a full answer

The questions list stores every question in my quiz. It lets one loop ask any number of questions. Without it I would need a separate variable and separate input and if code for every question, so adding a question would mean writing new code instead of adding one item to the list.

This works the same for any project. Replace questions with your list, and say what your loop does with it.
03

Are You Create Task Ready?

Check your own project against the list requirements. A strong list passes every row.

  • It holds several related items (more than one).
  • The program reads items from it, usually in a loop.
  • The loop uses the list's length (len), so adding items needs no code change.
  • You can explain what would be harder without it.
  • The list is in your Personalized Project Reference: where it is created (List i) and where it is used (List ii).
You have already built three complete practice tasks in Unit 6. Each one uses a list this way. Use them as models for your own.
