Encoding Text with Binary

A computer cannot store the letter A. It can only store numbers. So people agreed on a table that gives every character its own number, and then the number is stored in binary.

00

Characters Become Numbers

An encoding is a table that matches each character to a number. The most famous one is ASCII.

CharactersASCII numbersNotice
A` to `Z65 to 90in alphabet order
a` to `z97 to 122also in order
0` to `948 to 57the character 5 is 53, not the number 5
space32even a space has a number
A capital letter and the same lowercase letter are 32 apart. A is 65 and a is 97.
01

Try It: Text to Bits

Type anything and see every character turn into a number and then into 8 bits.

Try it: turn text into bits

Type a short word. Every character becomes a number, then 8 bits.

Message size = (number of characters) x 8 bits. A 5-character word takes 40 bits, which is 5 bytes. The space between two words counts as a character too.

02

Python: ord() and chr()

Python has two helper functions that go back and forth between a character and its number.

print(ord("A")) # 65 (character to number) print(chr(66)) # B (number to character) print(format(ord("A"), "08b")) # 01000001 (the number as 8 bits)
word = "Hi" for letter in word: print(letter, ord(letter), format(ord(letter), "08b")) # H 72 01001000 # i 105 01101001
ord takes one character and gives a number. chr takes a number and gives one character. They undo each other: chr(ord("A")) is A.
03

Reading Bits Back as Text

To decode, cut the bits into groups of 8, turn each group into a number, then look up the character.

01001000 01101001 # 01001000 = 64 + 8 = 72 -> H # 01101001 = 64+32+8+1 = 105 -> i # the message is Hi
The sender and receiver must agreeDecoding only works if both sides use the same encoding. Bits read with the wrong table give the wrong characters.
04

ASCII vs Unicode

ASCII only has 128 characters: English letters, digits, and punctuation. That is not enough for the world.

ASCIIUnicode
Characters128 (English letters, digits, symbols)over a hundred thousand
CoversEnglish onlyevery language, symbols, and emoji
Bits per character7 (stored in 8)more than 8 for many characters
The first 128 Unicode characters are the same as ASCII, so older English text still works.
05

On the AP Exam

You will not memorize the ASCII table. You should be able to reason about it.

  • Text is stored by giving each character a number, then storing the number in binary.
  • More different characters need more bits per character.
  • A message with n characters in an 8-bit encoding is 8 x n bits.
  • Two computers must use the same encoding to understand each other.
