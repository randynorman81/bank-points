The Create Task: Rules and Scoring

The Create Performance Task is worth about 30 percent of your AP score. It is also the part you control the most. This page is the rule book, taken from the College Board's own student handouts and scoring guidelines.

00

What You Submit

You design and write your own program. You get at least 9 hours of class time. Then you turn in three components and, on exam day, answer four written prompts about your own project.

The three components

ComponentWhat it isKey rules
Program codeone PDF with your entire programComments are allowed. Cite any code or help you did not write yourself.
Videoa screen recording of your program running1 minute or less, 30 MB or less, no voice narration, nothing that identifies you. File types: .mp4, .webm, .wmv, .avi, .mov.
Personalized Project Reference (PPR)four code segments pasted from your programNo comments, no course content, readable screenshots with text at least 10 point. You may use it on exam day.
Work alone on two parts. You may work with a partner on the program code only. The video and the PPR must be made by you alone.
Dates for this school year: AP Central lists the task deadline as April 30, 2027 at 11:59 PM ET, and the end-of-course exam as Friday, May 14, 2027. Always double check AP Central, and ask your teacher for the class calendar. Only components submitted as final are scored, and you cannot change them afterward. If you do not submit your PPR by the deadline, you will not have it on exam day.
01

The Program Requirements Checklist

Your program must have every item below, written by you. Calls to existing code or libraries are fine, but they do not count as student-developed.

RequirementWhat it means in plain wordsIn the program above
Inputthe user (or a device, data stream, or file) gives the program datainput(...)` for the color the user types
Listan ordered collection that stores related data and makes the program easier to write or changecolors
Student-developed procedurea named group of instructions you wrote, with its name and one or more parameterscount_matches(items, target)
Algorithm in the proceduresequencing, selection, and iteration all inside that procedure's bodycount = 0` (sequence), the `if` (selection), the `for` (iteration)
A calla line that runs your procedurecount_matches(colors, choice)
Outputsomething the program shows or plays, based on the input and the program's workthe print lines

The mistakes that lose the point

  • A one-item list. The list needs several items, and it must really help (a program that would be harder to write or change without it).
  • A list that is never used for anything. The list must connect to what the program does, such as looping through it.
  • A call that does not match the procedure. If the procedure has two parameters, the call needs two arguments.
  • Trivial selection or iteration. An if or a loop that never changes the outcome does not count.
  • A parameter that does nothing. At least one parameter must affect what the procedure does.
  • Using an event handler or a built-in as your procedure. Built-in procedures and handlers are not student-developed.
02

How the Six Points Are Scored

Each row below is worth one point. You earn it only by meeting every part of that row. These descriptions follow the College Board's 2026 scoring guidelines.

RowTo earn the pointYou lose it if
VideoThe video shows the program running with input, at least one piece of functionality, and output.It shows only code, screenshots, or a storyboard instead of the program running.
Program requirementsThe code has a student-developed procedure, a call to it, a list, a use of the list, selection, and iteration.The list has one element or is not really used, the call does not match, or selection or iteration is trivial.
Written Response 1Describes documentation that suits the program and explains how another programmer could use it to understand a code segment.The documentation is made up, wrong, or only explains things to the program's user.
Written Response 2(a)Identifies the variables and values that make your iteration stop, and explains why they stop it.The loop has no value that stops it, or your explanation does not match the code.
Written Response 2(b)Gives a call with specific argument values that makes the procedure behave incorrectly, describes the behavior, and explains why.The arguments are only described in general, or the parameter has no effect.
Written Response 2(c)Explains how the list manages complexity, and what the list code would need to change without the list.The list is not in the PPR or not used in the second list segment, or the explanation does not fit the program.
The written prompts change from year to year. In 2025, for example, 2(a) asked about the Boolean expression in the first selection statement, and in 2026 it asked what stops the first loop. So do not memorize one answer. Build a program that gives you something good to say about every part of it.
03

Honesty, AI Help, and Citing Code

Plagiarism earns a 0 on the entire Create task, including your written responses on exam day.

If your program uses...Add a comment like this
code your teacher gave you# This code was provided as starter code by my teacher.
open-source code or an API# This code was made freely available by [source of code].
code written with an AI tool# This code was generated using [AI tool name].
  • AI tools may be used as a helper to understand ideas, write code, and debug. But you must understand every line, because you will have to explain your own code on exam day.
  • Any code you build on must be extended in a new way by you.
  • Do not submit a practice task, a sample, or work someone else changed.
  • Your PPR must not contain comments or course content. Remove them before you take your screenshots.

Meet every requirement, and you give yourself an answer for every prompt.
