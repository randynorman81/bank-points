Unit 1 — Introduction to Programming

Students build programming fundamentals with Karel the Dog: sequencing commands, writing and calling functions, top-down design and decomposition, commenting code, and the control structures (loops and conditionals) that show up in every language, including Python. The unit wraps up with debugging strategies, algorithms, and a set of open-ended Karel challenges.
