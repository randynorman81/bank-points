Unit 1 Performance Task — Design a Karel Solution

3–4 class periods. Mirrors the structure of the real AP CSP Create Performance Task, built only from Unit 1 skills: sequencing, functions, top-down design, comments, abstraction, loops, and conditionals.

📄 Open the Performance Task (PDF)

What you'll turn in

  1. Program code — your .py / CodeHS Karel file, meeting all six requirements in the PDF
  2. Video — a screen recording of the program running start to finish (≤ 1 minute)
  3. Personalized Project Reference (PPR) — one page with two labeled screenshots: your student-developed procedure, and the line that calls it with an argument
  4. Written Responses — four short-response prompts (WR1–WR4), about 100–150 words each

Pick one scenario

  • Variable-Height Skyline — Karel builds a row of ball "towers," where each tower's height depends on a number your code controls
  • Checkerboard Field — Karel fills a rectangular region with balls in a checkerboard pattern
  • Room Sweeper — Karel visits every corner of a walled room, picking up any ball it lands on
  • Hurdle Runner — Karel races east along Street 1, jumping every wall "hurdle" until it reaches the end

Or propose your own scenario for teacher approval.

Scoring

6 points total, one per row: Program & Purpose, World State, Procedure, Procedure Explanation, Algorithm, Testing. Full rubric is in the PDF.
