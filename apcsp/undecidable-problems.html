Some Problems Can't Be Solved

Computers are powerful, but there are limits. A problem is decidable if some algorithm can always give a correct yes or no answer for every possible input. A problem is undecidable if no algorithm can possibly do that, not now, not with faster computers, not ever.

DecidableUndecidable
An algorithm exists…that always gives the right yes/nonone, and this has been proven
Example"Is this number even?" "Is this value in the list?"the halting problem
01

The Halting Problem

The famous undecidable problem: given any program and any input, will the program eventually stop, or run forever?

Click through: why no program can solve the halting problem

Suppose a perfect HALTS checker exists. It looks at any program and any input and always answers correctly.
Now write a sneaky program, TROUBLE. It asks HALTS about a program run on itself, then does the opposite.
Run TROUBLE on itself. Suppose HALTS answers YES, it stops. Then TROUBLE does the opposite and loops forever. HALTS was wrong.
Suppose HALTS answers NO, it runs forever. Then TROUBLE stops immediately. HALTS was wrong again.
No matter what HALTS answers, it is wrong about TROUBLE. So a perfect HALTS cannot exist. This is a proof by contradiction.
Why does this matter? It shows that there is no perfect bug-checker that can analyze every program and always correctly say whether it will freeze. Some questions about programs simply cannot be answered by a program.
02

Hard Is Not the Same as Impossible

These two ideas are easy to confuse.

Unreasonable timeUndecidable
Can an algorithm solve it?yes, an algorithm exists and is correctno, no algorithm can
What is the trouble?it takes far too long for large inputsit is impossible for every input
Examplechecking every route through 30 citiesdeciding if any program ever halts
What do we do?use a heuristic for a good-enough answersolve special cases, or give up on solving every case

Notice that undecidable does not mean you can never tell about one program. You can see that print("hi") stops. The problem is that no single algorithm can answer correctly for every program.

03

You Cannot Just Run It and See

A natural idea is: run the program and watch. That works if it stops, but if it is still running, you do not know whether it will stop in a minute or run forever.

Try it: will this program ever stop?

Pick a starting number. The rule: if the number is even, halve it. If it is odd, multiply by 3 and add 1. Repeat until you reach 1. The program stops only when it reaches 1.

AP

On the AP Exam

These are the ideas the exam asks about. Be ready to explain each one in your own words.

  • A problem is decidable if an algorithm can always give a correct yes/no answer. Undecidable means no algorithm can.
  • The halting problem is the standard undecidable problem: no program can tell for every program whether it will stop.
  • Unreasonable time (solvable but too slow) is different from undecidable (not solvable at all).
  • Algorithms can still solve some specific cases of an undecidable problem. They cannot solve all of them.
