Intro to Digital Information

Photos, songs, text messages, and games look nothing alike, but inside the computer they are all the same thing: bits, which are just 0s and 1s. This page shows how and why.

00

Analog vs Digital

The real world is analog: it changes smoothly with no gaps. A computer can only keep digital data: separate numbers it can count.

AnalogDigital
What it isSmooth and continuous, any value in betweenSeparate steps, a limited set of values
ExamplesA sound wave, a mercury thermometer, a sweeping clock handA digital clock, a song file, a photo file
Can a computer store it directly?NoYes
Sampling rate: measuring more often gives a copy closer to the original, but it needs more data. Between two samples, the computer knows nothing, so a little of the original is always lost.
01

Bits and Bytes

A bit is one binary digit: a 0 or a 1. It is the smallest piece of data a computer has, because a tiny switch can only be off (0) or on (1).

Everything is bits. What the bits mean depends on how the program reads them: the same pattern can be a number, a letter, or part of a color.

03

Two Errors to Know

Because a computer uses a fixed number of bits, two kinds of mistakes can sneak in.

Overflow error

A number is too big for the bits that were set aside. An 8-bit place can only hold up to 255. Adding 1 to 255 has no room, so the result wraps around or breaks.

Round-off error

Some numbers (like 0.1 or one third) cannot be stored exactly in a fixed number of bits, so the computer keeps a very close number instead.

print(0.1 + 0.2) # 0.30000000000000004 (round-off error)
Do not mix them up. Overflow = the number is too large for the bits. Round-off = the number cannot be written exactly, so it is slightly off.
04

On the AP Exam

Digital information shows up in the multiple-choice questions every year. These are the ideas to be ready for.

  • A bit is a 0 or 1, and a byte is 8 bits.
  • n bits can make 2 to the n different patterns.
  • Computers store analog data by sampling it, so a little is always lost.
  • A higher sampling rate means a closer copy but more data.
  • Overflow = too big for the bits. Round-off = cannot be stored exactly.
  • The same bits can mean different things, depending on how they are interpreted.

Everything is bits.
