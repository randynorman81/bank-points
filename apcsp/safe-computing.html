Authentication: Proving It Is You

Authentication is how a system checks that you are who you say you are. There are three kinds of evidence, and the strongest security uses more than one.

FactorSomething you…Example
Knowledgeknowa password or PIN
Possessionhaveyour phone (a code is sent), a security key
Inherencearea fingerprint or face scan

Try it: how long to guess a password?

Type a made-up password (do not use a real one). A program that guesses 10 billion times a second tries every combination. Nothing you type here leaves this page.

Use a different password for every account, so one leak does not open everything. A password manager remembers them for you.

Phishing

Phishing is a fake message that tricks you into giving away private information (a password, a card number) or clicking something harmful. Spear phishing is aimed at one person and uses details about them.

02

Malware

Malware (malicious software) is any program designed to harm you or steal from you. It usually gets in when you install or open something you should not have.

TypeWhat it does
Virusattaches to a program and spreads when it runs
Wormspreads on its own across a network
Ransomwarelocks your files and demands money to unlock them
Spywaresecretly watches what you do
Keyloggerrecords every key you type, to steal passwords and card numbers

How it gets in

Phishing attachments, fake downloads, infected websites, USB drives, or out-of-date software.

How to defend

Update your software, use antivirus, download only from trusted places, and back up your files (so ransomware has nothing to hold hostage).

03

Attacks on Networks

Some attacks are on the network, not on you.

AttackWhat happensDefense
Rogue access pointa fake Wi-Fi network ("Free Airport WiFi") set up by an attacker. Everything you send goes through them.avoid unknown Wi-Fi, use HTTPS and a VPN, never log in to important accounts on public Wi-Fi
DDoS (distributed denial of service)thousands of infected devices (a botnet) all send requests at once so a website is overwhelmed and crashestraffic filtering, extra servers; keep your own devices updated so they do not join a botnet
Man-in-the-middlean attacker sits between you and a site, reading or changing the messagesencryption (HTTPS) so what they see is nonsense
Encryption from Unit 8 is the main defense on the road. HTTPS and its lock icon mean the traffic is encrypted and the certificate says whose website it is.

AP

On the AP Exam

These are the ideas the exam asks about. Be ready to explain each one in your own words.

  • Authentication proves who you are. Multifactor authentication uses two or more kinds of proof (know, have, are).
  • Phishing tricks people into giving up private information. Know its red flags.
  • Malware includes viruses, worms, ransomware, spyware, and keyloggers.
  • A rogue access point is a fake Wi-Fi network. A DDoS attack uses many devices to overwhelm a site.
  • Encryption (HTTPS), software updates, strong unique passwords, and backups are the main defenses.

Most attacks start with a person, not a program.
