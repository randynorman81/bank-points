Square

There's no Square() function in this library at all — a square is just a Rectangle where you happen to pass the same number twice.

00

Definition

CodeHS's graphics library has Circle and Rectangle — that's it. A square isn't its own shape; it's simply a Rectangle(width, height) call where width and height happen to be the same number.

square = Rectangle(60, 60) # same number twice = a square square.set_position(100, 100) # still the TOP-LEFT corner, same as any Rectangle square.set_color(Color.green) add(square)

Everything you already know from the Rectangle page applies here without any changes — set_position() still means the corner, and it still has no built-in setter to resize it later.

01

Examples

Use one variable for the side length, and pass it in twice — that guarantees the shape stays a square even if you change the size later.

side = 60 square = Rectangle(side, side) square.set_position(100, 100) add(square)
What you wantCode
The side lengthsquare.get_width() (or get_height() — they're equal)
The corner's x positionsquare.get_x()
The corner's y positionsquare.get_y()
Move itsquare.move(dx, dy)

Centering a square

Same correction as centering any Rectangle — but since width and height are the same value, you only need to calculate the offset once.

side = 60 square = Rectangle(side, side) x = get_width() / 2 - side / 2 y = get_height() / 2 - side / 2 square.set_position(x, y)
02

Common Problems / Errors

square = Square(60) NameError: name 'Square' is not defined

There is no Square function in this library — only Circle and Rectangle. Use Rectangle(side, side) instead.

Accidentally a rectangle

Rectangle(60, 90) is not a square — the two numbers have to match exactly. A typo in either one quietly produces a rectangle instead.

Safer pattern

Store the side length in one variable and pass it twice: Rectangle(side, side). Now there's only one number to get right, and only one place to change it.

03

Python Code vs. Pseudocode

Same answer as the rest of the Graphics section: this is all specific to CodeHS's Python graphics library, not the official AP CSP pseudocode.

Worth noting here specifically: even the idea of "a square is a rectangle with equal sides" isn't something pseudocode defines — it's a modeling decision this particular library made. A different graphics library could just as easily have its own Square class. Always check what your actual tools provide rather than assuming.

Spotify Examples (5)

Squares show up constantly in music apps — almost every piece of cover art is one.

01

The "Now Playing" cover art

side = 100 cover = Rectangle(side, side) cover.set_position(20, 20)

The large square art shown for the currently playing song.

02

A row of playlist thumbnails

thumb1 = Rectangle(50, 50) thumb1.set_position(20, 140) thumb2 = Rectangle(50, 50) thumb2.set_position(80, 140)

Same side length, different x positions — a simple thumbnail row.

03

Centering the app icon

side = 64 icon = Rectangle(side, side) x = get_width()/2 - side/2 icon.set_position(x, 10)

True centering, using the same one-variable side length.

04

Checking it's really square

is_square = (cover.get_width() == cover.get_height())

Compares the rectangle's own width and height to confirm it's actually a square.

05

A grid of album squares

side = 40 gap = 10 for i in range(4): album = Rectangle(side, side) album.set_position(20 + i * (side + gap), 200) add(album)

Four evenly-spaced album squares in a row, using a loop and one side-length variable.
