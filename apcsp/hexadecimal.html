Hexadecimal

Long strings of 0s and 1s are hard to read. Hexadecimal (hex) is base 16, and it packs 4 bits into one digit, so a long binary number turns into a short, easy one. You will meet it again in color codes.

00

Sixteen Digits

Base 10 has ten digits (0 to 9). Base 16 needs sixteen, so it borrows the first six letters.

Hex digit0123456789ABCDEF
Decimal value0123456789101112131415
A = 10, B = 11, C = 12, D = 13, E = 14, F = 15. The biggest single hex digit is F, which is 15.

The place values are 1, 16, 256, 4096 ... Each place is worth 16 times the one to its right.

01

Hex and Binary: the Perfect Match

One hex digit = exactly 4 bits. That is why programmers love hex: it is binary written in a much shorter way.

02

Hex to Decimal and Back

Multiply each digit by its place value and add, just like binary.

# 2F in hex # place values: 16 1 # digits: 2 F (15) # 2 x 16 + 15 = 47
HexWorkingDecimal
1A1 x 16 + 1026

1001 x 256256
Two hex digits = one byte00 is 0 and FF is 255. That is the whole range of one byte, which is why a color value fits in two hex digits.

Decimal to hex: divide by 16. The quotient is the left digit and the remainder is the right digit. 200 / 16 = 12 remainder 8, so C8.

03

Python Does Hex

Python can write a number in hex and read hex back.

print(hex(255)) # 0xff (0x means hex) print(int("ff", 16)) # 255 print(format(200, "02X")) # C8 (2 digits, capital letters)
A hex value like 1A is not the decimal number 1A. Always say which base you are in. 10 in hex is 16 in decimal.
04

Why It Matters

Hex is not a required skill on the AP exam, but it explains how colors are written in the next lesson.

  • Hex is base 16, using the digits 0-9 and A-F.
  • 1 hex digit = 4 bits, so 2 hex digits = 1 byte.
  • Hex is a shorter way to write binary, the computer still stores bits.
  • Web colors like #FF8800 are three hex bytes: red, green, blue.

Hex is binary in a short suit.
