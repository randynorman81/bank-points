Simulations

A simulation is a program that imitates something in the real world so you can study it without doing it for real. The AP exam asks you why simulations are useful, what they leave out, and how random numbers make them work.

00

What a Simulation Is

A simulation uses a model: a simplified version of something real. The model keeps the parts that matter and leaves out the rest. This is abstraction.

Real thingSimulation of itWhy simulate
a hurricane's patha weather modelyou cannot test a real hurricane
a new bridgea stress test on a computercheaper and safer than building it
a pandemic spreadinga population modelyou can test ideas without harming anyone
rolling dice 1,000 timesa loop with random numbersmuch faster than doing it by hand
01

Random Numbers Drive It

Real events are uncertain, so a simulation uses random values. Each time you run it, you can get different results.

import random flips = [] for i in range(5): flips.append(random.choice(["heads", "tails"])) print(flips) # a different list every run
Python (random library)What it doesAP exam pseudocode
random.randint(1, 6)a random whole number from 1 to 6, both includedRANDOM(1, 6)
random.choice(items)a random item from a list(use items[RANDOM(1, LENGTH(items))])

One run of the coin-flip loop

Start with an empty list. The loop will run 5 times.

Pass 1: random.choice happened to pick heads, and append adds it.

Passes 2 and 3: tails, tails. The results are random, so another run would give a different list.

After 5 passes: the list holds the whole simulation's results. 3 tails, 2 heads this time. Run it again and the counts change.

02

Counting the Results

A simulation is only useful when you summarize what happened. Use a counter (or a list of counters) in the loop.

import random made = 0 for shot in range(100): if random.randint(1, 10) <= 7: # 7 of 10 numbers means a 70% chance made = made + 1 print("Made", made, "of 100") # usually near 70, but not always exactly 70
  • The if decides the outcome of each trial. Here, a number from 1 to 7 counts as a made shot.
  • The counter made is the accumulation pattern from the last page.
  • Run it many times to get a better picture. 100 trials give a closer answer than 10 trials.
More trials means a more reliable answer. A simulation of 10 free throws can easily look very different from the true 70%. A simulation of 10,000 will be close.
03

Advantages and Limits

The exam asks both: why use a simulation, and why it cannot be fully trusted.

AdvantageLimit or risk
Safer: test dangerous things without dangerThe model leaves out details, so results may not match reality
Cheaper and faster: no real materials or real timeThe results depend on the assumptions the programmer chose, which can be biased
Repeatable: run it thousands of timesA simulation gives evidence, not proof
Can test 'what if': change one value and rerunRandom results differ each run
Exam wording: a simulation abstracts the real thing by removing details. It can be used to investigate a hypothesis, but it may not be exactly like the real world. A choice that includes 'guarantees the exact real result' is wrong.
04

Practice Reading Exam Pseudocode

A typical question gives a simulation and asks what could happen.

heads ← 0 REPEAT 4 TIMES { IF (RANDOM(1, 2) = 1) { heads ← heads + 1 } } DISPLAY(heads)
  • RANDOM(1, 2) is 1 or 2, so each pass has a 50% chance of adding to heads.
  • The loop runs 4 times, so heads can be 0, 1, 2, 3, or 4.
  • A question will ask which values are possible. The answer is all five, even though 2 is the most likely.
  • It could not display 5, because the loop only runs 4 times.

A simulation is a simplified model plus random numbers.
