Variables

A named box that holds a piece of data. Naming one, filling it, and changing what's inside it is the single most-used skill in every Python program you'll ever write.

00

Definition

A variable is a named box that holds a piece of data in your program's memory while it runs. Instead of typing the number 15 over and over, you store it once under a name — like age — and use that name anywhere in your code.

age = 15 print(age)

Naming a variable

Python has strict rules about what a name is allowed to look like, and separate, looser conventions about what a good name looks like.

Allowed

  • Letters, numbers, and underscores (_)
  • Must start with a letter or underscore — never a number
  • Any length you want

Not allowed

  • Spaces, or punctuation like - @ ! #
  • Starting a name with a digit
  • Python's own reserved words — if, for, while, True, class, etc.

The equals sign: =

This is the single most important thing to unlearn from math class. In Python, = is the assignment operator, and it only flows one direction: take whatever is on the right, and store it in the name on the left. That's different from math, where x = 5 is a statement that stays true both directions.

x = 5 x = x + 1 print(x) # prints 6 -- compute the right side first, then save it to the left

A variable can change

A variable isn't locked to one value, or even one type, forever. Assigning a new value with = always overwrites whatever used to be there — even if the new value is a completely different type.

data = "hello" # data is currently a string print(data) # hello data = 42 # now data is an integer instead print(data) # 42

This is called dynamic typing — Python figures out a variable's type from whatever value is currently stored in it, and that can change every single time you reassign it with =.

Common Problems / Errors

Most variable mistakes are naming mistakes — Python refuses to run the line at all rather than guess what you meant.

ValidInvalidWhy the invalid one fails
score2ndScoreCan't start with a number
student_namestudent nameNo spaces allowed
total_pointstotal-pointsA hyphen reads as subtraction
_tempclassclass is a reserved keyword
Case-sensitivity bites people constantly: age, Age, and AGE are three completely different variables to Python — not the same one typed differently. Good style uses lowercase with underscores between words (snake_case), like total_score, so this never comes up by accident.
Also common: reading = as "equals" the way math class taught you, and expecting 5 = x to work the same as x = 5. In Python, only a variable name can sit on the left of =.

Python Code vs. Pseudocode

AP CSP's official pseudocode (the language used on the multiple-choice exam) and real Python both do the same basic things — they just look different every time. Get used to seeing both side by side now.

AP CSP Pseudocode

age ← 15 DISPLAY(age) age ← age + 1 DISPLAY(age)

Python

age = 15 print(age) age = age + 1 print(age)
What you're doingAP CSP PseudocodePython
Store a valueage ← 15age = 15
Show a valueDISPLAY(age)print(age)
Change a variable's own valueage ← age + 1age = age + 1
Pseudocode doesn't ask you to think about a value's type the way these notes do — a variable just holds "a value." Python is stricter: every value is specifically a string, an integer, a float, or a list, and that exact type decides which operations are allowed.
