Variables

A named box that holds a piece of data. Naming one, filling it, and changing what's inside it is the single most-used skill in every Python program you'll ever write.

00

What Is a Variable?

A variable is a named box that holds a piece of data in your program's memory while it runs. Instead of typing the number 15 over and over, you store it once under a name — like age — and use that name anywhere in your code.

age = 15 print(age)

Here, age is the variable. It now holds the value 15, and it will keep holding it until you tell Python to store something else there.

01

Naming a Variable

Python has strict rules about what a name is allowed to look like, and separate, looser conventions about what a good name looks like.

Allowed

  • Letters, numbers, and underscores (_)
  • Must start with a letter or underscore — never a number
  • Any length you want

Not allowed

  • Spaces, or punctuation like - @ ! #
  • Starting a name with a digit
  • Python's own reserved words — if, for, while, True, class, etc.

02

The Equals Sign

This is the single most important thing to unlearn from math class. In Python, = is the assignment operator, and it only flows one direction: take whatever is on the right, and store it in the name on the left.

In math

x = 5 means x and 5 are the same value, always — symmetric. Writing 5 = x means the exact same thing.

In Python

x = 5 means "store 5 in x." Writing 5 = x is a syntax error — you can't assign into the number 5.

Because it only flows one direction, this line makes perfect sense in Python even though it's impossible in math:

x = 5 x = x + 1 print(x) # prints 6

Read the right side first: Python looks up the current value of x (5), adds 1 to get 6, then stores that new value back into x. No equation is "solved" — it's a two-step instruction: compute the right side, then save it to the left side. This exact pattern powers counters, running totals, and every loop you'll write.

04

Variables Can Change

A variable isn't locked to one value, or even one type, forever. Assigning a new value with = always overwrites whatever used to be there — even if the new value is a completely different type.

data = "hello" # data is currently a string print(data) # hello data = 42 # now data is an integer instead print(data) # 42
This is called dynamic typing.Python figures out a variable's type from whatever value is currently stored in it — and that can change every single time you reassign it with =.

The name never changes. What's stored inside it can, at any time.

That's the whole idea of a variable: one label, pointed at whatever value you need right now. Pick a type below to go deeper.
