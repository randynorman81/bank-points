Float

Numbers with a decimal point — short for "floating-point number."

← All Variables String Integer Float List

What makes a float different

A float is any number that has a decimal point — 3.14, 0.5, -2.0, even 7.0. It's used for anything that isn't a whole number: money, averages, measurements, percentages. Like integers, floats are written with no quotes.

price = 4.99 # a float count = 4 # an integer

Notice 7.0 is still a float, not an integer — it's the decimal point that decides the type, not whether the value happens to be a whole number.

Math operators

Floats use the exact same operators as integers — + - * / // % ** — and behave the way you'd expect from decimal math:

print(2.5 + 1.5) # 4.0 print(5.0 / 2) # 2.5

Mixing integers and floats

You can freely do math between an integer and a float in the same expression — Python doesn't require you to convert first. But the moment a float is involved anywhere in the expression, the result becomes a float, even if it could have been a whole number:

total = 10 + 2.0 print(total) # 12.0, not 12

This is called type coercion — Python automatically converts the integer to match the "wider" type (float) so the math can happen, rather than raising an error the way it does when you mix a string with a number.

Converting to a float: float()

Just like int(), you can convert other types into a float on purpose:

grade_text = "89.5" # a string grade = float(grade_text) # now a float: 89.5

Converting an integer to a float just adds a .0: float(6) is 6.0. Converting a float down to an integer with int() works too, but remember from the Integer page that it truncates instead of rounding.

Rounding: round()

If you actually want to round to the nearest value instead of truncating, use round() instead of int():

print(round(9.6)) # 10 print(round(3.14159, 2)) # 3.14 -- round to 2 decimal places
Good to know, not something you'll be tested on directly: floats can sometimes show tiny rounding errors, because computers store decimal numbers in binary and some decimals (like 0.1) can't be represented exactly. Try print(0.1 + 0.2) sometime — it's 0.30000000000000004, not a clean 0.3. This is a property of floating-point math in every programming language, not a bug in your code.
