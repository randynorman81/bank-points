PYTHON NOTES  /  TYPE: FLOAT

Float

Numbers with a decimal point — short for "floating-point number."

00

No Quotes Needed, Either

A float is any number with a decimal point — 3.14, 0.5, -2.0, even 7.0. It's used for anything that isn't a whole number: money, averages, measurements. Like integers, floats are written with no quotes.

price = 4.99 # a float count = 4 # an integer

Notice 7.0 is still a float, not an integer — the decimal point decides the type, not whether the value happens to be a whole number.

01

Mixing Integers and Floats

Floats use the exact same operators as integers — + - * / // % **. You can freely mix an integer and a float in the same expression without converting first.

total = 10 + 2.0 print(total) # 12.0, not 12
Type coercion: the moment a float is involved anywhere in an expression, the result becomes a float — even if it could have been a whole number. Python widens the integer to match, instead of raising an error the way it does when you mix a string with a number.
02

Converting & Rounding

Convert into a float on purpose with float(), the same way int() converts into an integer.

grade_text = "89.5" # a string grade = float(grade_text) # now a float: 89.5

If you actually want to round to the nearest value instead of truncating, use round():

print(round(9.6)) # 10 print(round(3.14159, 2)) # 3.14 -- 2 decimal places
Good to know, not tested directly: floats can show tiny rounding errors, because computers store decimals in binary and some (like 0.1) can't be represented exactly. Try print(0.1 + 0.2) sometime — it's 0.30000000000000004. That's a property of floating-point math in every language, not a bug in your code.

One float anywhere in the math, and the whole answer becomes a float.

That's type coercion — Python widening to the more precise type instead of throwing an error.
