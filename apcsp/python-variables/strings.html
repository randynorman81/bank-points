PYTHON NOTES  /  TYPE: STRING

String

Text data — letters, words, sentences, and any characters at all, wrapped in quotes.

00

Quotes & the String Literal

A string is a sequence of characters treated as text rather than code. Python only knows something is a string because it's wrapped in quotes — double "like this" or single 'like this'. Both work identically; just be consistent.

name = "Alex" greeting = 'Hello there'

The quoted text typed directly into your code — "Alex" — is called a string literal. It's "literally" that exact text, written right there, as opposed to a variable that happens to be holding a string. In name = "Alex", "Alex" is the literal, and name is the variable it's stored in.

Need an apostrophe inside your string, like it's? Wrap the whole thing in double quotes instead: "it's a nice day". With single quotes, Python would think the string ended right after it.
01

Numbers Are Just Characters

This is the single most important idea about strings for AP CSP: anything inside quotes is text, even if it looks like a number. Python does not do math with it — every digit is a character, exactly like a letter.

A number

5 is an integer. Python can add it, subtract it, multiply it — it behaves like math.

A string that looks like a number

"5" is a string. To Python it's just the character 5 — no different from the character a.

print(5 + 3) # 8 (real addition, both are integers) print("5" + "3") # 53 (joining two pieces of text)

"5" + "3" does not add up to 8. Because both sides are strings, + switches jobs entirely — instead of math, it joins the text together end to end. This is called string concatenation, a different operation from addition even though it uses the same + symbol.

02

Concatenation

Concatenation works on any strings, not just number-looking ones — it's how you build one longer piece of text out of smaller pieces.

first = "Social" second = "Circle" school = first + " " + second print(school) # Social Circle
Watch the middle piece: " " is a string literal that's just a single space. Concatenation doesn't add spaces for you — if you want one, you include it yourself.
03

Mixing Strings With Numbers

You cannot concatenate a string directly with an integer or float — Python raises an error, because it can't tell whether + should mean addition or joining.

age = 15 # print("I am " + age) ← ERROR: can't concatenate str and int print("I am " + str(age)) # works: converts 15 to "15" first

str() converts whatever is inside the parentheses into a string, so it can safely be joined with other text. This fix comes up constantly — any time you print a message that includes a number.

04

Length & Indexing

A string is really a sequence of individual characters in order, and Python lets you work with it that way.

len()

len("hello") returns 5 — the number of characters in the string.

Indexing

"hello"[0] returns "h" — the first character.

Zero-indexing: Python counts positions starting at 0, not 1. The first character of a string is at position 0, the second is at 1, and so on — in a 5-character string, the last one is at position 4, not 5.

Quotes are the whole signal. No quotes, no text — just a number.

Whatever's between the quotes is characters, full stop. That single idea is behind everything above.
