Quotes and the string literal

A string is a sequence of characters — letters, numbers, symbols, spaces, anything — treated as text rather than code. Python only knows something is a string because it's wrapped in quotes: either double quotes "like this" or single quotes 'like this'. Both work identically; just be consistent.

name = "Alex" greeting = 'Hello there'

The quoted text typed directly into your code — "Alex", 'Hello there' — is called a string literal. It's "literally" that exact text, written right there in the code, as opposed to a variable that happens to be holding a string. In name = "Alex", "Alex" is the string literal, and name is the variable it gets stored in.

Need an apostrophe inside your string, like it's? Wrap the whole thing in double quotes instead: "it's a nice day". If you used single quotes, Python would think the string ended right after the it.

Numbers inside quotes are just characters

This is the single most important idea about strings for AP CSP: anything inside quotes is text, even if it looks like a number. Python does not do math with it — it treats each digit as a character, the exact same way it treats a letter.

1

A number

5 is an integer. Python can add it, subtract it, multiply it — it behaves like math.

2

A string that looks like a number

"5" is a string. To Python, it's just the character 5 — no different from the character a.

Watch what happens when you use + on two number-looking strings:

print(5 + 3) # 8 (real addition, both are integers) print("5" + "3") # 53 (joining two pieces of text)

"5" + "3" does not add up to 8. Because both sides are strings, + switches jobs entirely — instead of doing math, it joins the text together end to end. This is called string concatenation, and it's a different operation from addition even though it uses the same + symbol.

Concatenation

Concatenation works on any strings, not just number-looking ones — it's how you build one longer piece of text out of smaller pieces:

first = "Social" second = "Circle" school = first + " " + second print(school) # Social Circle

Notice the " " in the middle — a string literal that's just a single space. Concatenation doesn't add spaces for you; if you want one, you have to include it yourself.

Mixing strings with numbers

You cannot concatenate a string directly with an integer or float — Python will raise an error, because + can't decide whether you mean addition or joining:

age = 15 # print("I am " + age) ← ERROR: can't concatenate str and int print("I am " + str(age)) # works: converts 15 to "15" first

The fix is str() — it converts whatever is inside the parentheses into a string, so it can safely be joined with other text. This conversion comes up constantly in AP CSP any time you print a message that includes a number.

Length and indexing

A string is really a sequence of individual characters in order, and Python lets you work with it that way. Two tools you'll see often:

len()

len("hello") returns 5 — the number of characters in the string.

Indexing

"hello"[0] returns "h" — the first character. Python counts positions starting at 0, not 1.

Zero-indexing trips a lot of people up: the first character of a string is at position 0, the second is at position 1, and so on. In a string with 5 characters, the last one is at position 4 — not 5.
