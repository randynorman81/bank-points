What is a list?

Every type on the last three pages — string, integer, float — holds exactly one value. A list is different: it's a single variable that holds many values at once, in order. You write a list with square brackets [ ], separating each value with a comma.

scores = [85, 92, 78, 100] print(scores)

Here, one variable — scores — is holding four separate integers at the same time.

A list can hold any type — even mixed together

A list isn't limited to one type of data. It can hold strings, integers, and floats all in the very same list:

student = ["Alex", 15, 3.8] # ^str ^int ^float print(student)

In student above, position 0 is a string (a name), position 1 is an integer (an age), and position 2 is a float (a GPA) — three different types, sitting together in one list.

Getting one value out: indexing

Lists use the exact same indexing idea as strings — square brackets with a position number, counting from 0:

student = ["Alex", 15, 3.8] print(student[0]) # Alex print(student[1]) # 15 print(student[2]) # 3.8
That's the basics for now: square brackets to create one, commas to separate values, and [index] to pull one value back out. We'll come back with a full lesson on lists — adding and removing items, looping through them, and more.
