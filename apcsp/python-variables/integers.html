PYTHON NOTES  /  TYPE: INTEGER

Integer

Whole numbers — no decimal point, ever, and no quotes around them.

00

No Quotes Needed

An integer (int) is a whole number — positive, negative, or zero — written with no quotes at all. The moment you put quotes around a number, it stops being an integer and becomes a string instead.

points = 10 # an integer label = "10" # a string that looks like ten, but isn't

Python tells these apart automatically just by whether quotes are present. points can be used in math; label cannot — see the String page for what happens when you try.

01

Math Operators

Integers support all the operators you'd expect, plus two that don't exist in ordinary math class.

OperatorNameExampleResult
+Addition7 + 29
-Subtraction7 - 25
*Multiplication7 * 214
/Division7 / 23.5
//Floor division7 // 23
%Modulus (remainder)7 % 21
**Exponent7 ** 249
Big gotcha: / always gives you back a float in Python, even when both numbers are integers and it divides evenly. 10 / 2 is 5.0, not 5. Need a whole-number result? Use // instead.
02

Floor Division & Modulus

These two show up constantly on the AP CSP exam, usually together.

// — how many whole times

17 // 5 is 3. 5 goes into 17 three whole times, with the leftover thrown away.

% — what's left over

17 % 5 is 2 — the remainder after dividing 17 by 5 as many whole times as possible.

% is especially useful for questions like "is this number even or odd?" — n % 2 == 0 is true only when n divides evenly by 2.

03

Converting: int()

Sometimes a value isn't an integer yet but needs to be one — most often, text a user typed in, since input() always returns a string.

age_text = "15" # a string age = int(age_text) # now an integer: 15 print(age + 1) # 16 -- real math now works
Converting a float to an integer with int() doesn't round — it truncates, chopping off everything after the decimal point. int(9.9) is 9, not 10.

No decimal, no quotes — and remember, / still gives you a float.

Reach for // and % whenever you need a strictly whole-number answer.
