Routers and Hops

A packet leaves your laptop and has to reach a server on the other side of the planet. Nobody hands it a map. A router is a device that forwards packets toward their destination. It reads the destination address and passes the packet to the next router that is closer. Each handoff is called a hop.

The path a packet takes is the list of devices it travels through. No single router knows the whole path. Every router just makes a good choice for the next hop, like asking for directions at every intersection.

Example: Laptop → A → B → Server is a path with 3 hops (three links).
01

A Network Is a Graph

Computer scientists draw a network as a graph: nodes (the devices) and links (the cables or wireless connections). Two nodes joined by a link are neighbors.

Graph wordNetwork meaning
Nodea device: laptop, router, server
Link (edge)a cable or wireless connection
Neighborstwo nodes joined directly by a link
Patha chain of links from one node to another

In Python a graph is often stored as a dictionary: each device name points to the list of devices it connects to. You build this in the routing walkthrough.

02

Finding a Path

How does a computer find a route? One classic idea is breadth-first search: start at the source and explore all its neighbors, then their neighbors, ring by ring, like ripples in a pond. The first time you reach the destination, you have a route with the fewest hops.

The trick is a queue of paths (add at the end, take from the front) and a list of places you have already seen, so you never go in circles.

Try it: break a router and watch the traffic reroute

Click a router to switch it off (a storm, a cut cable, a power outage). The packet finds a new path if one exists.

03

Redundancy and Fault Tolerance

The Internet has many paths between any two points. That is called redundancy. If a router or cable fails, packets are rerouted along a different path. A system that keeps working after a part fails is fault tolerant. It has no single point of failure.

Why it matters

Storms, cut fiber, and power outages happen all the time. Because of redundancy, most people never notice.

The cost

More redundancy means more cables and routers to buy. A network with one path is cheap but fragile.

04

Hops, Delay, and traceroute

Every hop adds a little delay (latency) because a router has to read the packet and decide. Usually fewer hops means a faster trip, though a busy router or a slow link can matter too.

The traceroute tool lists every router between you and a website, in order. Each line is one hop:

HopRouterTime
1home router (192.168.1.1)2 ms
2ISP edge router9 ms
3regional backbone router17 ms
4cloud provider router24 ms
5the web server26 ms

Check yourself

Answer each one. You see why right away, so read the explanation even when you are right.

What is one step of a packet from one router to the next called?
Each handoff from one device to the next is a hop.
Devices A, B, C, and D are linked A-B, A-C, B-D, and C-D. How many different paths (without going back) lead from A to D?
A-B-D and A-C-D. Two paths means that if one link fails, the other still works.
What do you call a network that keeps working when one part fails?
Fault tolerant systems have redundancy: more than one path.
A network has exactly one router that connects the school to the rest of the Internet. What is true about that router?
If it fails, there is no other path. Adding a second connection removes the single point of failure.

On the AP Exam

These are the ideas the exam asks about. Be ready to explain each one in your own words.

  • A router forwards packets toward their destination, one hop at a time. No router knows the whole path.
  • A path is a sequence of connected devices. There can be many paths between two points.
  • Redundancy (extra paths) makes the Internet fault tolerant.
  • Be ready to count paths and hops in a diagram, and to say what happens when one device fails.
