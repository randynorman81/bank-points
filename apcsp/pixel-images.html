PYTHON NOTES  /  SUBJECT: A PICTURE IS A GRID OF NUMBERS

Pixel Images

Zoom in far enough on any digital picture and you find a grid of tiny squares called pixels. Each pixel is just a number (or a few numbers), so a whole picture is just data.

00

Pixels

A pixel (picture element) is one tiny square of one color. An image is a grid of them, read row by row.

Try it: draw a 1-bit picture

Click squares to make them white (1). Watch the bits that describe your picture.

01

Resolution and Bits per Pixel

Two numbers decide how much data a picture holds.

IdeaMeaningMore means
Resolutionwidth x height, the number of pixelssharper picture, more data
Bits per pixelhow many bits describe each pixel's colormore possible colors, more data
File size (before compression)width x height x bits per pixel = total bits. Divide by 8 to get bytes.
PictureWorkingSize
8 x 8, black and white (1 bit)8 x 8 x 1 = 64 bits8 bytes
100 x 100, 256 shades of gray (8 bits)100 x 100 x 8 = 80,000 bits10,000 bytes
100 x 100, full color (24 bits)100 x 100 x 24 = 240,000 bits30,000 bytes
Bigger picture, more pixels, more bits. That is why a high-resolution photo takes more storage than a thumbnail.
02

Python: a Picture in a List

We can store a black-and-white picture as a list of strings, one string per row, and draw it with a loop.

image = ["0110", "1001", "1001", "0110"] for row in image: print(row.replace("0", ".").replace("1", "#")) # .##. # #..# # #..# # .##.

replace swaps every 0 for a . and every 1 for a #, so the bits turn into a picture you can see. The loop runs once per row.

rows = len(image) # 4 rows cols = len(image[0]) # 4 columns print(rows * cols, "bits") # 16 bits
03

Metadata: Data About Data

A photo file holds more than pixels. It also holds metadata: facts that describe the picture.

The dataThe metadata
the pixels of a photodate taken, camera model, GPS location, image size
the audio of a songtitle, artist, length
the text of a messagewho sent it, when, how long
Metadata is not the picture itself. It can still reveal private things, like where a photo was taken. Metadata can be changed or removed without changing the pixels.
04

On the AP Exam

Picture questions are about how data is represented and what happens when it changes.

  • An image is a grid of pixels, and each pixel is stored as bits.
  • More pixels or more bits per pixel means more data and a bigger file.
  • Metadata describes data (date, location, size) and helps you find and organize it.
  • Changing the data can change what you see, but changing metadata does not.
