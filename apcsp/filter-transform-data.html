A program goes through a list of test scores and builds a new list containing only the scores above 70. This is…
Keeping only the items that meet a condition is filtering.
A program turns a list of prices in dollars into a list of prices in euros by multiplying each by 0.9. This is…
Each item is changed to a new value.
Which code pattern finds the total of a list called prices?
Summarizing uses an accumulator, a variable that grows as the loop adds each value.
A school has one list of student IDs with names and another list of student IDs with grades. How can the two be joined?
Combining data uses a shared key.
AP

On the AP Exam

These are the ideas the exam asks about. Be ready to explain each one in your own words.

  • Data is processed with filtering, transforming, sorting, summarizing, and combining.
  • Programs do these with loops, conditionals, and a variable that collects the result.
  • Know how to name the operation a described program is performing.
  • Combining data sets uses a shared key and can reveal new information.
