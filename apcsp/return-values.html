Return Values

print only shows something on the screen. return hands a value back to the line that called the function, so the rest of the program can use it.

00

Definition

A function can finish by returning a value. A call to that function is then replaced by the value it returns, so you can store it in a variable, use it in math, or print it. The exam writes this as RETURN(expression).

def double(number): return number * 2 # hand the answer back result = double(4) # the call becomes 8, which is stored in result print(result) # 8 print(double(5) + 1) # double(5) becomes 10, then + 1 is 11

print versus return

print(...)return ...
What it doesshows text on the screensends a value back to the call
Can the program use the value?no, it is only displayedyes, store it or use it in math
Ends the function?noyes, right away

print inside, nothing to use

def double(n): print(n * 2) answer = double(4) # prints 8 print(answer) # None: nothing came back

double showed 8 but gave nothing back, so answer holds None.

return, then use it

def double(n): return n * 2 answer = double(4) # nothing printed yet print(answer) # 8

The value came back, so you decide what to do with it.

The exam rule: a RETURN can appear anywhere in a procedure, and as soon as it runs, the procedure ends and control goes back to the calling program. Any instructions after it do not run.
01

Examples

Wherever a call appears, picture it being replaced by the value it returns.

store it

Save the answer

def square(n): return n * n result = square(6) print(result) # 36

square(6) becomes 36, and 36 goes into result.

use it in math

Call inside an expression

def double(n): return n * 2 total = double(3) + double(10) # 6 + 20 print(total) # 26

Each call is replaced by its value before the addition happens.

nested calls

A call inside a call

print(double(double(3))) # inside first: double(3) is 6 # then double(6) is 12 # prints 12

Work from the inside out. The inner call finishes first and its value becomes the argument of the outer call.

return ends it

Nothing runs after return

def test(): return 1 print("never runs") print(test()) # 1

return leaves the function immediately, so the print after it is skipped.

strings too

Return text

def make_username(first, last): return first[0] + last name = make_username("Ana", "Lopez") print(name) # ALopez

A function can return any kind of value: numbers, text, True or False.

02

Common Problems / Errors

Printing is not returning. If a function only prints, the call has no value to store or calculate with.

Forgetting to use the returned value

double(4) # returns 8, but 8 is thrown away x = double(4) print(x) # now it is used

A returned value that you do not store or print just disappears.

Code after return

def f(n): return n + 1 n = n * 100 # never runs

Everything after a return that has run is skipped.

No return means None

A function that never returns anything gives back None. Printing the call shows None, which usually means you wanted return instead of print.

Return what you mean

return n * 2 sends back the value of the expression. return does not need brackets, but the exam writes RETURN(n * 2) with them.
